# 합의 보존과 답변 결속

- 최신 명시 요청이 바꾼 항목만 교체하고 나머지 합의·미커밋 변경을 보존한다.
- 대화·권위 문서에 있는 답을 재사용한다. 새로 빠진 중요한 판단이나 충돌만 최소한으로 묻는다.
- 받은 답은 해당 요구의 수용 기준과 검증 근거에 결속한다. 질문 없이 처리 가능한 요청은 결과물을 바로 만든다.
- Nenova/Mindmap 코드 변경의 새 중요 미결정·모순에 대한 답/수용조건 결속은 insight-requirement-review가 맡는다. 명확한 문장·단순 수정·이미 답 있는 요구에는 이 담당을 호출하지 않는다.
