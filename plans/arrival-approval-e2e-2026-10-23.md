# 실제 송장 최신 원가 검증 및 정수 표시

- 요청: 승인 원가가 모든 조회 영역에 연결되는지 격리 환경에서 검증. 후속: 소수점 표시 제거.
- 계산/저장 원가 정밀도, 과거 매입/손익/재고 불변. UI 문자열만 정수 반올림.
- 비용 경로: 실제 CO 송장2914 캐시→native SQL 입고→승인→재승인→다운로드→hotel/catalog/pivot/incoming reader.
- DB writer 변경 없음. test-only SQL은 loopback14339/호출별 전용 DB 검증 후 실행. 운영 연결정보 로드 금지.
- 기존웹피벗은 수량 소수점 설정과 도착원가 정수 표시를 분리. 환율 입력 정밀도 보존.
- 카탈로그/전산피벗은 이미 원 단위 표시라 유지.
- 검증: 실제 SQL 통합, 실제 Next 페이지 조회, React 렌더, 회귀/ERP guard/build. 비원가 UI 헤더·수량은 fixture라 운영 전체 데이터 검증과 구분.
- 배포한다면 코드만. DB migration/repair/recalculation 불허.
- 기준선 적용: 읽기참고/기존원장보존/오류표시/차수연도 분리. 해당없음: 신규메뉴/새입력/쓰기/키보드변경. 예외: 브라우저1920x1080은 IAB 제한으로 미검증.
