# 네덜란드 주광 분류: 인보이스 고정

2026-11-17 사용자 결정: CL2/YCL2 원문 코드로만 주광을 분류한다. CL21/CL23/CL38/MCL73은 기타다. 현재 DB 주문량은 분류 근거가 아니다.

## 기준과 부작용

| 동작 | 입력/정책 | ERP 주문·출고·입고·재고·견적·매출·손익 |
|---|---|---|
| 분석→입고 초안 | NL `line.cl`을 `sourceEvidence.invoiceCustomerCode`로 보존. 공백 제거·대문자화 | 기존 명시 저장 절차 외 변경 없음 |
| 원가 다운로드 분류 | 같은 문서의 품목별 코드와 송이수만 합산. 정확히 CL2/YCL2만 주광. DB 주문 조회/우선배분 없음 | 전부 보존 |
| 기존 입고에 코드 없음 | 원가 다운로드는 유지하되 주광 분류는 원본 코드 확인 필요. 기타/0으로 위장하지 않음 | 전부 보존 |

수량·단가·환율·운임·관세·검역 계산식 변경 없음. 공동 품목은 주광/기타 수량을 별도 비교 열에 보존한다. 기존 승인 파일·과거 차수 시트 소급 변경 없음.

## 검증

- 양성: CL2/YCL2 및 공백·대소문자 변형, 공동 품목 24+24, 0송이.
- 반례: 46-2 Strong Gold CL21 50 + CL38 50 + MCL73 50 = 기타150/주광0; YCL22/BCL2/KCL2.
- 코드 누락: 명시적 SOURCE_REQUIRED, DB fallback 없음, 원가 자체는 출력 가능.
- 연도: 동일46-02의 2025/2026 digest 분리, numeric year 거부.
- 메뉴 기준선: 원장 보존/실패 명시 적용. 새 메뉴·버튼·업무 순서 변경 없음(영상 갱신 해당 없음). 이전 전체 E2E/영상 요청은 별도 미완료이며 이 단위 검증으로 대체하지 않는다.
