# 국가별 발주서 ETA·누락 방지

## 기준·부작용
- 선택 국가/명시 연도/전체 세부차수와 현재 생성 결과를 다운로드까지 고정한다.
- ETA는 달력 또는 YYYY-MM-DD 직접 입력. 영문 요일은 UTC 달력일에서 계산한다.
- 국가별 이 PC/브라우저 기본값만 저장한다(localStorage). ERP/주문/입고/재고/견적/손익/확정 원가는 모든 동작에서 보존한다. 새 API·SQL·DB 쓰기 없음.
- 최초 기본값은 확인된 PeriodDay 차수 시작일+7일. 저장한 ETA는 차수 시작일 차이만큼 이동한다. 같은 주 세부차수는 동일, 연도 경계도 실제 달력 날짜 차이로 계산한다. 달력 근거 없는 업로드 차수는 임의 ISO 주차를 만들지 않고 직접 날짜 선택한다.
- 잘못된 날짜/손상된 저장값/저장 실패는 안내하고, 이전 결과나 국가로 다운로드하지 않는다.
- 확인 필요 품목 제외 생성 금지. ViewOrder 미노출 활성 주문이 있으면 전체 다운로드 차단. 기존 수량 수정 기능은 유지하고 파일에만 반영한다.
- ETA 반영은 각 시트 A1 제목을 복사 수정하고 제목 행만 최소60pt로 늘려 줄바꿈 잘림을 방지한다. 원본 workbook, 수량, 수식, 나머지 스타일·행·합계는 불변이다.

## 검증
국가별 출력 왕복에서 A1 외 셀 동일, 기본값/수정/같은 주/다음 주/연도 경계/날짜 오류/손상 저장값/분류 분할 검증. 실제 로컬 UI에서 달력·직접 입력·취소·초점·키보드·다운로드·엑셀 재열기 확인. 가이드 갱신 후 ERP 필수 gate·CI·배포.

## 한계
자동 실행은 브라우저 보안 설정을 우회하지 않는다. 이 변경은 파일 다운로드이며 데스크톱 앱 자동 열기 기능은 별도 명시 설정·보안 검증 전 미지원이다.
