# 주차별 매출 수익률 검증 표시 — 2026-10-29

## 사용자 범위

DB를 변경하지 않고 주차별 매출탭에 누락·불일치 검증을 연결한다. 2026년 38·39차 입고·운임 근거를 읽기 대조하고, 확인하지 못한 수익률을 정상으로 표시하지 않는다. 테스트·PR·배포·실브라우저 검증까지 수행한다.

## 기준 원장

| 기준 | 근거와 소비자 |
|---|---|
| 연도·차수 | 명시적 OrderYear + major/subweek. API·원문 SQL·UI 응답 적용이 같은 범위여야 한다. |
| 빠른 기본 조회 | 기존 저장 계산본 조회 유지. 기본 GET에 전차수 재계산·자동 저장을 추가하지 않는다. |
| 검증 전 | 저장 숫자는 참고값. 저장/확정 이력은 원천 정확성 인증과 다르다. |
| 산술 검산 | 기존 수식 감사는 계산 자체만 검증한다. 동일 payload로 계산한 일치만으로 SQL 원천 완전성을 인증하지 않는다. |
| 원천 대사 | 현재 SQL 입고 행·운임 행·매출·재고 감사와 표시 저장본을 별도 대조한다. SQL 입력원장과 첨부 인보이스 원본의 열람 여부를 구분한다. |
| 누락·오류 | NULL/미조회/실패를 0원으로 대체하지 않는다. 근거 부족·불일치·검증 실패는 정상 수익률 상태가 될 수 없다. |
| 추정 | 승인된 계산상 추정도 실제 원문 확인과 별도 상태로 표시한다. |
| 범위 변경 | 다른 연도·차수의 늦은 응답을 현재 화면에 적용하지 않는다. |
| 미검증 항목 | Q 및 운임행 합계 일치는 환율·통관비·운임 배분·기초기말 평가액 전체 인증이 아니다. |

## 부작용 행렬

| 동작 | 주문·출고·ShipmentDate/Farm | Estimate | 재고·StockHistory | WebProfitReport/저장본/확정본 |
|---|---|---|---|---|
| 기본 조회 및 상태 표시 | 보존 | 보존 | 보존 | 읽기·보존 |
| 명시적 원천 검증 | SELECT만 | SELECT만 | SELECT만 | SELECT만, 갱신 금지 |
| 오류/취소/다른 차수 이동 | 보존 | 보존 | 보존 | 보존 |

이번 작업에서는 재계산 저장, 보고서 확정/해제, SQL 보정, 마이그레이션을 수행하지 않는다. 기존 업무 저장 API의 정책은 변경하지 않는다.

## 배포 차단 조건

- 누락·실패·검증 전·다른 차수 응답이 정상 인증되는 회귀
- API/진단 경로의 DB 쓰기 또는 runtime DDL
- 필수 ERP 계약·dnSpy 근거 검사·빌드 실패
- 기존 저장본/수기값/확정본 변조
- 실브라우저 핵심 흐름 미검증은 완료로 보고하지 않음

## 검증 예정

정상 합성 fixture 및 누락/0/중복/교차연도/통화/늦은응답 반례, SELECT-only SQL probe, 전체 ERP 계약, manifest/write guard, webpack build, 배포 후 ping 및 38·39차 상태 확인. 최종 결과와 미검증 범위는 세션 기록에 남긴다.
