# 업무 매뉴얼 한 편의 기준 (수입부 인수인계부터 적용)

2026-11-12. 사장님 지적("신규 누르기 → 닫기 누르기 수준이라 왜·언제·무엇을 보고·무엇을 넣는지가 없다")에 따라 세운 기준이다.
`data/import-handover.json`의 매뉴얼은 이 기준을 지켜야 하고, `__tests__/importHandover.test.cjs`가 자동으로 검사한다.

## 매뉴얼 한 편에 반드시 들어가는 여섯 가지

| 번호 | 항목 | 무엇을 쓰나 | 이것이 없으면 |
|---|---|---|---|
| ① | 왜 · 언제 | 이 일을 안 하면 무엇이 막히는지, 무엇이 오면 시작하는지, 요일·시간·빈도 | 새 사람이 "지금 해야 하는 일인지" 알 수 없다 |
| ② | 준비 자료 | 시작 전에 손에 있어야 하는 파일·메시지·화면과 받는 곳 | 화면을 열고 나서 멈춘다 |
| ③ | 단계 1, 2, 3… | 단계마다 **무엇을 보고 / 무엇을 넣고 / 왜** 세 줄 | 버튼 순서만 남는다 |
| ④ | 끝났는지 확인 | 화면·목록·상대방 답으로 확인하는 방법 | 저장이 안 됐는데 끝난 줄 안다 |
| ⑤ | 자주 틀리는 곳 | 실제 기록에 나온 실수와 그때 처리 | 같은 실수를 되풀이한다 |
| ⑥ | 다음 일 | 누구에게 넘기는지, 다음 절차가 무엇인지 | 일이 그 자리에서 끊긴다 |

## 번호 규칙

- 단계 번호는 의미 있는 업무 단계마다 1, 2, 3… 을 붙인다. 클릭마다 번호를 늘리지 않는다.
- **영상 목차 · 영상 자막 · 글 매뉴얼의 단계 번호와 제목이 같아야 한다.** 녹화 스크립트는 글 매뉴얼(`data/import-handover.json`)의 단계 제목을 읽어 목차와 자막에 쓴다. 다르면 자동 검사가 실패한다.
- 영상은 `C:/Users/USER/.codex/WORKFLOW_VIDEO_GUIDELINES.md`와 `docs/WORKFLOW_VIDEO_GUIDES.md`를 따른다(전체 화면에서 위치 안내 → 번호·강조 → 확대 → 실제 입력·결과 → 축소, 1920×1080, 브라우저 100%, 연습용 자료, 실제 화면).
- 실제 업무에서 넣지 않는 값은 영상에서도 넣지 않는다(예: 신규 품목 등록의 박스 무게·관세율은 실제 등록의 1%만 채워져 있어 "비워 둘 칸 확인" 단계로 만들었다).

## 근거 표시

- **확정**: 서로 다른 두 가지 이상의 근거가 맞는다(예: 전산 기록의 작성자·시각 + 화면 기록).
- **추정**: 한 가지 근거뿐이다(예: 화면 해독 문장만).
- 업무표의 줄과 매뉴얼마다 근거 종류와 건수를 적는다. 근거 없는 "확정"은 자동 검사가 막는다.

## 쓰는 말

- 주어는 업무 절차다. 사람 이름은 "이 절차를 실제로 하던 사람"으로만 쓴다.
- 사람의 능력·태도를 평가하는 문장, 개인 상태를 짐작하는 문장은 쓰지 않는다.
- 이 화면은 업무 지원·인수인계 자료다. 그 목적에 맞지 않는 낱말은 `lib/importHandover.js`의 `BANNED_WORDS`로 막는다.
