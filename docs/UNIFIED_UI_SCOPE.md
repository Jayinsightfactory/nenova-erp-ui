# 전체 탭 UI 통일

사용자 범위: 거래처관리 시범에 한정하지 않고 모든 메뉴에 일관된 화면 언어 적용.

## 공통 적용 계약
- _app에서 globals 다음 unified-ui.css를 한 번 로드. 일반/팝업/자체 shell/모바일 페이지 모두 동일 진입점.
- 색상 토큰, 네비게이션, 버튼, 입력창, 탭, 카드, 표 테두리/헤더, 모달, 상태 배너, 스크롤바 통일.
- 사용자 업무상 의미를 갖는 인라인 색(부족·확정·추가·취소)은 보존. 모든 셀을 흰색으로 덮지 않는다.
- 표 width/height, virtual row height, sticky top, overflow, 입력값과 이벤트를 변경하지 않는다.
- print에는 신규 스타일을 적용하지 않는다. 견적서·A4 출력의 기존 규칙 보존.
- 개별 커스텀 컴포넌트의 추가 통일 필요 항목은 정적 inventory로 분류하며, 공통 스타일 적용만으로 모든 업무 동작 검증을 완료했다고 주장하지 않는다.

## 부작용
모든 변경은 화면 CSS 및 공통 CSS import. API/SQL/DB/저장 payload/연도·차수/권한/계산/이력은 변경하지 않는다. 운영 쓰기 시험을 하지 않는다.

## 검증
전체 pages route 정적 목록, 일반·standalone 공통 import, print 범위, 숫자 입력·체크박스, 의미 색과 virtual row geometry 보존을 검사. 1920×1080과 작은 화면 fixture 캡처 및 공통 shell 회귀를 실행. 복잡한 페이지의 실제 업무 데이터 상태는 별도 운영 읽기 검증으로 구분.

별도 하위 모델 도구가 없어 메인이 설계·구현·검사 담당.
