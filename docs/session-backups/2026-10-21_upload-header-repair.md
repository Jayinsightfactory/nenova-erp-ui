## 확정한 원칙
- 업무키는 연도 + 세부차수 + 업체이며 품목 변경은 품목키까지 포함한다.
- 주문 수량·기존 출고·재고·견적·매출을 변경하지 않는다. 헤더 복구를 위한 주문 재업로드 금지.
- EXE 헤더 조회는 삭제 필터가 없으므로 삭제된 헤더까지 검사한다. 중복·모호한 상태에서는 자동 추가하지 않는다.
- 운영 보정은 예방 코드 배포 이후, 사전 조회 → 롤백 리허설 → 트랜잭션 보정 → 별도 연결 재조회로 검증한다.
