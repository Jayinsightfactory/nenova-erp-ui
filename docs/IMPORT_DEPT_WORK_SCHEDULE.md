# 수입부 하루 · 주 · 월 업무표와 근거

갱신 2026-11-12. 수입부 업무를 새 직원이 이어받도록 만든 업무 지원·인수인계 자료다. 화면에서는 「부서별 업무 매뉴얼」 첫 화면의 「수입부 인수인계 업무표」로 본다.
이 문서와 `data/import-handover.json` 은 `scripts/build-import-handover.cjs` 한 곳에서 만든다. 매뉴얼 기준은 `docs/IMPORT_HANDOVER_MANUAL_STANDARD.md`.

- **확정** = 서로 다른 두 가지 이상의 근거가 맞음(예: 전산 기록의 작성자·시각 + 화면 기록). **추정** = 한 가지 근거뿐.
- 주어는 업무 절차다. 사람 이름은 그 절차를 실제로 하던 사람을 가리킬 때만 쓴다.

## 7. 아직 매뉴얼을 못 만든 절차

- **네덜란드 · 태국 · 에콰도르 발주** — 요일은 담당자 일정표로 확인. 화면 근거는 나라마다 2~3번이라 단계별 입력 기준을 쓰지 못함
- **월 결제표 · 송금 증빙 메일 / 중국 대사표 대조** — 지출결의서 매뉴얼의 다음 단계. 결제일 규칙이 확인된 뒤 만든다
- **콜롬비아 카네이션 고정 주문 조정** — 승인 절차와 반영 시점이 미확인
- **신규 공급처 열기(견적 문의 → 거래 신청서 → 송금 대상 등록)** — 1번 관측
- **입고 등록 · 패킹리스트와 나머지 글 매뉴얼 6편의 영상** — 글 매뉴얼만 있음. 전산 프로그램 · 엑셀 · 메신저 화면은 연습용 자료로 녹화할 방법을 먼저 정해야 함
- **신규 품목 등록 — 전산 프로그램(nenova) 화면판 영상** — 지금 영상은 네노바웹 품목관리 화면. 칸 구성은 같음
