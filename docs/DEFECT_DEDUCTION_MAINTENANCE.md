## 사용자 최종 결정 — 임의 변경 금지
- 수량이 다르면 별도 자료로 인정한다. 같은 업체·품목이라는 이유로 일괄 차단하지 않는다.
- 누락 고정키는 OrderYear + 원래 OrderWeek + CustKey + ProdKey + Quantity + 정규 SourceUnit이다. 조회중인 적용차수로 원차수를 바꾸지 않는다.
- 새 차수, 다른 수량, 다른 연도·업체·품목·단위는 자동 제외하지 않는다. 송이/스팀(대) 등 기존 단위 동의어는 정규화한다.
- 파일명과 카톡표식은 누락 예외키가 아니다. 다른 파일 재업로드도 동일 업무키면 제외한다.
- 주광·태림 수기14건과 후속 수기4건은 보존. 브르트15단, 태림화이트50대, 디디스커스14단 등 협의·수기값을 원문추정값으로 덮지 않는다.
- 원문 부재·표식 공유만으로 오류 확정/견적 삭제하지 않는다. 브라우저 저장감사·원문·실제견적을 함께 대조한다.
- 이전 11견적삭제/16정리/4초안 계획은 실행 전 철회됐다. 철회 JSON의 executable:false를 풀거나 옛 계획을 실행하지 않는다.

## 구현 경계와 부작용
- 누락/취소는 WebSalesDefectDeductionHistory INSERT만 수행한다. 원장값·견적·주문·출고·재고·손익은 보존한다.
- PERMANENT_OMIT_CANCEL은 원 누락 HistoryKey 한 건에만 효력이 있다. 재누락 새 HistoryKey는 옛취소로 해제되지 않는다. 중복취소는 멱등이다.
- 취소는 고정제외 해제다. 등록완료 강제변경이나 견적 자동생성이 아니다. 출고·단가·중복·잔량·다른 검토차단은 다시 검사한다.
- 영업지원 권한, 선택연도, 원 누락이력 잠금, 선택버전 및 기등록견적 보존 검사를 유지한다.
- lib/defectPermanentOmission.js omissionSql을 목록/업로드미리보기/새원장저장/최종등록 판정에 공유한다. UI만 예외를 바꾸지 않는다.
- 목록·사전검사·미리보기 일치는 업무상 중복이 전혀 없다는 증거가 아니다. 같은 품목의 수량차이는 다른 신고일 수 있으므로 원문과 등록 연결을 별도로 확인한다.

## 2026-11-03 영업지원 문제 해결 창
전체 불량 확인·등록은 미등록 원장을 새 창으로 전달한다. 정상 항목 기본접힘, 문제 항목에 단가 입력/업체·품목·수량 수정/원문·견적 대조를 직접 제공한다. 입력은 기존 버전·권한·원문 가드를 통과한 뒤 재조회하며 클라이언트가 등록허용을 임의 부여하지 않는다. 관리자 원문 재검토는 실제 불량방 파일 해시/메시지 해시/순번과 대조 사유를 기록한다. 일반 영업지원에게는 관리자 대조 또는 이번 보류를 안내한다. 정상 자동수집도 수동단가 입력 허용, 과거 해제/원문/단위/연결견적 검토차단은 유지한다.
동일 수량의 선택묶음은 전원 보류 상태에서 명시적으로 한 행만 선택한다. 다른 수량·다른연도·단위는 묶지 않는다. 미해결/보류는 register ids에 포함하지 않는다. 재조회 중·조회실패·편집저장 중에는 등록금지. 실제 등록 후 요청한 모든 성공키의 재조회가 있어야 검증완료다. 영구 누락과 이번 등록 보류를 혼용하지 않는다.
검증: defectResolution.test.js, scripts/defect-resolution-smoke.cjs(API전부모의), 기존 source/ledger/manual-cost 회귀.

## 2026-11-04 단가 후보·보류 분리
품목명 유사성으로 다른 ProdKey 단가를 자동 대입하지 않는다. 현재 품목번호의 최근5차수 실제 양수분배 단가가 없으면 다른 규격 후보와 업체/차수/단위를 보여주고, 명시 매칭정정→재조회 후 기존 자동단가를 적용한다. 자동선택/후보는 defectRecentCostSql 공유, 조회실패는 COST_LOOKUP_FAILED로 구분한다. 이전 차감 견적 실체가 없는 행은 출고없음이 아니라 보류 사유이며 재생성하지 않는다. 영업지원 등록대상/보류 목록을 분리, 보류원장과 수기는 보존한다.

보류 목록의 첫 정보는 원불량 orderYear+orderWeek이다. 현재 조회/적용 차수 또는 단가 출처 차수로 대신 표시하지 않는다. 하위차수·전년도를 보존하고 값이 없으면 미확인으로 안내한다.
