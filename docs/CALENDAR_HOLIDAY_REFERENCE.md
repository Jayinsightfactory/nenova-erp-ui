# 홈 달력 공휴일과 일정 상세

데스크톱 홈의 달력 설정은 한국과 요청된 11개국을 선택하며 이 PC의 계정별 표시 국가·색상을 보관한다. 공휴일은 각 나라의 **현지 달력 날짜**이며 시간대 변환으로 전날·다음날에 옮기지 않는다. 전국 기준 자료이고 미국·호주 등의 지역별 휴일, 업체별 휴무는 포함하지 않는다.

공휴일 기준 자료는 MIT 라이선스 [python-holidays 0.109](https://github.com/vacanza/holidays)로 2000~2100년을 미리 생성한다. 요청 때 외부 서비스 호출·달력 계산·SQL을 수행하지 않는다. `lib/calendarHolidays.cjs`가 한 번 읽은 자료에서 조회한 날짜만 제공한다. 미래 연도는 현행 규칙을 적용한 참고 자료이며 임시휴일·법 변경·종교 관측에 따라 바뀔 수 있다. 예정인 종교 휴일은 ‘예정’으로 표시한다.

중국의 실제 연휴·대체근무는 [2026년 국무원 공지](https://www.beijing.gov.cn/fuwu/bmfw/sy/jrts/202511/t20251104_4258838.html), [2027년 국무원 공지](https://chinajob.mohrss.gov.cn/h5/c/2026-11-09/635850.shtml)의 기간을 사용한다. 대체근무는 휴일과 별도 종류이며 설정에서 표시를 선택한다. 다른 연도는 기본 공휴일 규칙이다. 네덜란드 5월 5일은 유급휴무 여부와 구분해 [정부의 공식 공휴일 목록](https://www.government.nl/themes/work/working-hours/question-and-answer/work/public-holidays-in-the-netherlands)에 따라 표시한다.

갱신은 `python -m pip install -r scripts/requirements-calendar.txt` 후 `python scripts/generate-calendar-holidays.py`를 실행한다. 공지 변경을 확인하고 코드의 보정과 확인일을 먼저 갱신한다. 자동 생성된 파일의 날짜만 바꿔 최신 검증을 한 것처럼 기록하지 않는다. 국가별 휴일 추가/이동, 연말·새해, 중국 연휴·대체근무, 네덜란드 해방기념일을 검증한다.

저장된 일정은 제목을 눌러 한글 상세창에서 편집한다. 주차별 일정은 원본 한 시리즈와 기존 `deadline`, `inclusive`, `resetDate`를 유지하며 전체 수정임을 표시한다. 기존 시리즈의 고급 설정은 접어 두되 값을 보존한다. 개인 업무는 기존 반복 규칙과 owner 저장본을 사용한다. 개인 상세 조회는 소식 DB 조회를 건너뛰어 편집창이 피드 조회에 묶이지 않게 한다.

참석자는 참고용 문자열이며 초대나 메시지를 발송하지 않는다. 홈 알림은 조회 중인 일정에 한해 홈이 보이고 앱이 실행 중일 때 배너로 제공한다. OS 백그라운드 푸시가 아니다. `private` 달력 일정은 작성자에게만 반환하며 다른 관리자에게도 반환하지 않는다. 이전 앱이 새 필드를 생략해 수정해도 저장된 비공개 범위와 상세 정보는 보존한다. 공통으로 공개하면 새 일정 표식을 갱신한다. ERP 원장 쓰기는 없다.
