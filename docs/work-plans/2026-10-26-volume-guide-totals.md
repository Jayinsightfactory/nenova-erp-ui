# 물량표 안내·즉시 합계 기준

- 범위: 네덜란드 단계 가이드, 네덜란드/중국 화면 및 XLSX의 현재 초안 주문·입고·잔량. ERP writer 변경 없음.
- 기준: 사용자 수량 변경을 주문 표시합계에 반영. 입고는 원본 입고 보존. 잔량=입고-현재 업체 수량합계(+네덜란드 명시 재고 셀). ERP 저장 재고 스냅샷과 다르다.
- 기존 중국 XLSX는 원주문을 주문, 수정 셀합계를 입고로 잘못 표시. 네덜란드 화면은 수식 셀을 건너뛰어 캐시가 남았다.
- 표시/엑셀 동일 helper, 수식은 보존하고 캐시 갱신. 0/소수/부족 음수/입고전용/추가업체/지역이동/교차연도 테스트.
- 가이드는 기본 켜짐, 명시 false 저장 유지. 차수→조회→편집→저장→검토→명시 적용. 실제 성공 응답/현재 revision만 상태 근거. stale/차단은 완료 아님. 가이드 자체 fetch/ERP action 없음.

## 근거
- 실제 로컬 dnSpy FormQuantityPivot 재실행: ViewOrder/StockList 완전 연도차수키, ViewWarehouse 별도 조회. native 저장/재고 산식 변경 없음.
- SELECT-only probe: 2026/43-02/533/1487 수량200, 확정true, Amount381818/Vat38182, native 날짜join1, Farm0. 해당 차수 확정124행 금액13316274/VAT1331626. 운영 시험 쓰기 없음.
- 기준선 적용: shell 보존, 페이지 스크롤, 키보드, 명시 적용·현재 검증. 해당 없음: 신규 메뉴/스키마/원장 수정.
- 검증: ERP 계약, dnSpy evidence, manifest, writes guard, pivot, build 및 격리 MSSQL 분배 회귀 통과. 실제 빌드 CUA에서 양쪽 5→8 편집 시 주문8/입고20/잔량12 및 총계 확인. 가이드 저장→검토→차단 안내 및 끄기 새로고침 유지 확인. 운영 시험 분배는 수행하지 않음. 배포 결과는 세션 기록 참조.
