# 호텔 손익 도착원가 이전 최신 차수 대체

## 요청과 완료 기준

- 호텔 손익 상세에서 현재 대차수의 도착원가가 없으면 같은 연도·같은 품목의 최근 이전 대차수 값을 표시한다.
- 현재 대차수 값, 이전 최신 값, 값 없음이 화면에서 구분되어야 한다.
- 미래 차수·다른 연도·다른 품목 값은 사용하지 않는다.
- 웹 표시 전용이며 엑셀·인쇄 및 ERP 원장을 변경하지 않는다.

## 기준표

| 항목 | 기준 | 소비자 |
|---|---|---|
| 연도 | 저장된 호텔 결산의 `OrderYear` 정확 일치 | SQL 조회 |
| 품목 | 양수 `ProdKey` 정확 일치 | SQL 조회·순수 선택 helper |
| 현재 차수 | `MajorWeek` 숫자 정확 일치 | 순수 선택 helper |
| 대체 차수 | 현재 값이 없을 때 `MajorWeek < 요청값` 중 최대값 | 순수 선택 helper·웹 표시 |
| 세부차수 | 선택된 대차수의 활성 행 전체 | 웹 표시 |
| 중복 농장행 | 같은 세부차수·환산단위에서 가장 높은 현재 단가 | 기존 정책 유지 |
| 단위 | `Product` 환산 메타데이터가 있을 때만 환산 | 기존 helper |
| 표시 | 대체값에 `이전 최신 차수` 배지와 주황색 차수 | 웹 상세 |

## 부작용 표

| 동작 | WebArrivalCostLine | WebRaumPnl/Item | Order/Shipment | Stock | Estimate/WebProfitReport | 엑셀·인쇄 |
|---|---|---|---|---|---|---|
| 호텔 상세 열기 | SELECT | SELECT | 보존 | 보존 | 보존 | 변경 없음 |

## 실행형 fixture

- 양성: 요청 37차가 없고 36-1·36-2·35-2가 있으면 36-1·36-2만 반환한다.
- 정확값 우선: 37차가 하나라도 있으면 36차 대체값을 사용하지 않는다.
- 근접 실패: 38차 값은 37차 상세에 사용하지 않는다.
- 교차연도: SQL이 `OrderYear=@yr`로 고정되어 이전 연도 동일 차수를 포함하지 않는다.
- 미매칭: `ProdKey`가 없는 손익행에는 다른 품목 단가를 붙이지 않는다.

## EXE·원장 영향

이 기능은 `WebArrivalCostLine`과 `Product`를 읽기만 하는 호텔 웹 상세 보조정보다.
nenova.exe 주문·출고·재고·견적 저장 경로를 호출하지 않으며 `OrderDetail`,
`ShipmentDetail`, `ShipmentDate`, `ShipmentFarm`, `Estimate`, `StockHistory`,
`WebProfitReport`를 모두 보존한다.
