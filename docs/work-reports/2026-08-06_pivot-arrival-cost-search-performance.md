# 피벗 통계·도착원가 검색 및 대량조회 보강

## 요청과 원인

- 피벗 통계의 품목 필터는 화면에 표시되는 `prodName`만 검색해 `수국화이트`처럼 품종과 품명을 붙여 입력한 검색어를 놓쳤다.
- 도착원가 조회는 현재본 행 전체와 Product/Farm 마스터 전체를 한 번에 내려보내고, 입력 중인 필터도 매번 조회해 브라우저 렌더링량과 DB 응답량이 불필요하게 커졌다.
- 업로드 원장에 농장키가 없지만 원본 농장명이 전산 농장명과 정확히 일치하는 경우에도 화면에서 자동 후보를 보여주지 않았다.

## 적용 내용

1. 피벗 통계 품목 필터
   - 표시값은 기존처럼 품종 열과 중복되지 않는 `prodName`을 유지한다.
   - 검색 별칭에는 국가·품종·영문 품명·한글 표시명을 포함한다.
   - `수국화이트`, `수국 화이트`, `Hydrangea White`가 동일한 `White` 옵션을 찾도록 정규화한다.

2. 도착원가
   - 목록 API에 최대 300행, 화면 기본 200행 서버 페이징을 적용하고 전체 건수와 다음 페이지 여부를 반환한다.
   - 전체 Product/Farm 마스터를 목록 응답에서 제거한다.
   - 품목은 공용 `/api/products/search`를 사용해 실제 주문 사용량·최근 사용량 기반으로 상위 후보를 표시한다.
   - 농장은 입력어가 있을 때 일치 후보 최대 30개만 조회한다.
   - `FarmNameRaw`와 전산 `FarmName`이 정규화 기준으로 정확히 같으면 자동 후보를 표시하고, 사용자가 저장하기 전까지 ERP 원장은 변경하지 않는다.
   - 필터 입력 중 자동 조회를 막고 `조회` 실행 시에만 적용한다.

## 보존한 업무 불변식

- 도착원가는 `WebArrivalCost*` 웹 전용 원장만 저장하며 Product, Farm, Warehouse, Shipment, Estimate, Stock 원장에는 자동 반영하지 않는다.
- 품목·농장 후보를 선택하고 저장 버튼을 누른 경우에만 기존 매칭 저장/이력 흐름이 실행된다.
- 차수·연도 범위 및 기존 피벗 집계 계산식은 변경하지 않았다.
