## 원인

엑셀 칸 복사는 클립보드에 TSV 글자 + 표 그림이 같이 들어간다. 페이지 붙여넣기가 그림을 먼저 가져가 Vision OCR을 돌려 장미(화이트몬디알)→화이트로즈, 호접→흰자처럼 읽혔다.

버튼 「텍스트로 품목 추가」는 원래 JSON `{text}`만 보내 OCR을 쓰지 않는다.

## 변경

클립보드에 주문 글자가 있으면 텍스트만 파싱. 표 사진만 있을 때만 OCR. 각 행에 텍스트/이미지 표시.
