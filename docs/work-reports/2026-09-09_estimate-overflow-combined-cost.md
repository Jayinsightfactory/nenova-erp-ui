## 증상과 근거

기존 구현은 가격 수정과 overflow 조합을 지원하지 않았고 이 제약이 통합 저장 버튼에도 적용됐다.
가드를 제거하기만 하면 신규 다음 차수에 이전 단가가 들어가므로 원자 저장으로 보완한다.

명령: `dnSpy.Console.exe --no-color -t ClassShipmentDate "C:\Program Files (x86)\Wooribnc\Nenova\Nenova.exe"`.
이 메서드는 SdetailKey의 모든 날짜 Cost/Amount/Vat를 저장된 EstQuantity로 계산하며 수량을 바꾸지 않는다.
기존 `executeEstimateCostOnly`가 이 범위를 구현한다. 운영 동일 2026/36-01·36-02 품목의 읽기 전용
probe를 다시 수행했고 상세 증거는 로컬 outputs에만 보관한다. 운영 시험 쓰기는 금지한다.

## 기준 원천 및 사용자 동작별 부작용

| 동작 | 주문/출고/재고 | 단가/금액 | 업체단가/차수단가 | Estimate/손익 |
|---|---|---|---|---|
| 미리보기 | 모두 보존 | 원본 스냅샷과 수정 의도 검증만 | 모드·연도·중복 검증만 | 보존 |
| 확인 후 적용 | 기존 overflow의 동일 원자 수량 계약 | 명시 수정된 상세 전체 날짜만 기존 cost core로 갱신 | 명시 fixed/weekFav만 기존 core로 갱신 | 명시한 Estimate 가격만 갱신, 손익 직접보존 |
| 실패/취소 | 전체 보존/롤백 | 전체 보존/롤백 | 전체 보존/롤백 | 전체 보존/롤백 |

- 요청 `combinedCosts={items,mode,week}`는 기존 update-cost 입력과 같다. 연도/업체는 외부 수량 요청과 동일하며 별도 override 금지.
- 생략은 기존 수량 저장. 객체가 있으면 preview/apply에서만 허용하며 잘못된 모드·0/false·빈 배열을 묵살하지 않는다.
- 순서: V2 gate → 원본 수량/가격 잠금·편집 보호 → 읽기 전용 단가 검증 → overflow 계획/확인 → 수량/재고 → 단가 core → 편집 revision 한 번 → 동일 UUID 감사 결과 → commit.
- 모든 단가 기준값은 수량 쓰기 전에 검증한다. 쓰기 후 기준값 변경은 같은 트랜잭션 saved 응답만 사용한다. 임의 최신 GET으로 stale 검사를 우회하지 않는다.
- 신규 다음 출고는 원본 상세의 명시 수정 단가(0 포함), 없으면 기존 단가를 사용한다.
- 기존 다음 출고는 기존 단가를 유지한다. 그 상세 자체도 명시 가격 편집에 포함되면 해당 요청 가격을 적용한다. 서로 다른 가격을 임의 평균하거나 원본 가격으로 덮어쓰지 않는다. 확인창에 실제 다음 가격을 표시한다.
- 같은 다음 품목으로 여러 원본이 합쳐질 때 서로 다른 유효 단가는 차단한다.
- 미리보기/작업 해시에 전체 가격 items·mode·week를 포함한다. 가격만 바꿔 같은 UUID로 재요청하면 거부한다.
- 미분할 기존 경로는 기존 수량→단가 저장을 유지하며 이 결합 저장의 원자 성공으로 표시하지 않는다.
- 수량 저장 뒤 cost core가 자체 raw 보존 검증을 연속 수행하며, 외부 편집 보호가 잠근 동일 연도/부모차수/업체에만 참여한다. 내부 revision 중복 증가 금지.

UUID 재사용/가격 변경 거부, 이전 연도 보존, 1920×1080 통합 저장 확인/취소/별도 가격 POST 없음.

## 화면 회귀 보완

- 일반 수정 저장 버튼의 클릭 이벤트가 `modeOverride`로 전달되면 React 객체를 JSON으로
  변환하다 요청 전 실패한다. 이벤트와 업무 모드를 분리하고 `once/fixed/weekFav`만 허용한다.
- 원자 수량·단가 성공 뒤 별도 차감 저장이 실패해도 성공 결과를 0건으로 덮어쓰지 않는다.
  성공한 초안만 전송 당시 값과 비교해 제거하고, 실패 초안과 저장 중 새로 입력한 값은 보존한다.
- 전체 성공 후에도 초안 객체를 통째로 초기화하지 않는다. 출고 삭제로 대상이 없어진 단가
  초안은 명시적으로 정리한다. 확인창 취소는 수량·단가 적용 요청을 보내지 않는다.
