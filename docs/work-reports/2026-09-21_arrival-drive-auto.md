# 업무드라이브 → 도착원가 자동 반영 설계

## 범위·기준 원장

- 사용자 요청: 최신 차수 원가자료가 업무드라이브에 들어오면 서버가 직접 읽어 도착원가에 등록.
- 수신 저장소: `lib/workDrive.js`의 불변 sha256 파일과 최신 index 메타데이터. 브라우저 다운로드 불필요.
- 웹 원가 저장: 기존 `createArrivalCostImport` 트랜잭션 재사용. 신규 등록은 원가만이며 호텔 매입단가 입력은 계속 수동.
- 스케줄: 운영 서버 60초마다 확인. 활성화 설정은 관리자 명시 저장, 기본 꺼짐. 재시작 시 설정과 이력으로 복구.
- 최신 기준: 같은 연도·국가의 파일명 세부차수 숫자순, 같은 차수는 원본 수정시각. 업로드 시각만으로 구본을 최신으로 바꾸지 않음.
- 선택 범위: 파일명 차수와 실제 파싱 행 차수 일치분만. 과거 시트 및 다른 국가 행은 자동 저장하지 않음.
- 모호한 연도/국가/차수, 분할 파일 충돌, 원가 없는 행, 수동 수정된 현재본은 검토 필요로 보류.
- 최초 활성화는 해당 연도·국가의 최신 파일만 대상. 과거 차수 일괄 백필 아님.
- 자동 반영 성공은 DB commit 결과 기준. 파일 hash+연도+차수 멱등 표식을 같은 트랜잭션에 기록.
- 상태/원본파일/차수/등록건수/미매칭건수/오류를 도착원가 화면에 표시. 관리자만 설정 변경.
