# 주차별 매출이익 보고서 22~28차 Excel 전체 재분석

## 결론

- 2026년 22~28차 원본 Excel 7개, 전체 78개 시트를 다시 읽었다. 특정 요약 셀만 비교하지 않고
  값·수식·수식 참조·재고 품목단가·통관비 구성요소를 함께 추출했다.
- 본표의 정상식은 `C=N+L+O`, `G=Q×R+S×R`, `I=E+G+H-F`, `J=C-I`, `K=J/C`다.
- `재고잔량`은 참고용 시트가 아니라 기초/기말 재고의 **품목별 수량과 평가단가 원천**이다.
  웹은 이 원천을 직접 쓰지 못해 비수식 카테고리에서 재고단가 입력 경고가 반복됐다.
- 이번 변경은 정확한 `ProdKey + EstUnit`이 검증된 47개 품목에 원본 Excel 단가 원천을 연결한다.
  직접 검증단가와 사용자가 확정한 도착원가는 언제나 이 catalog보다 우선한다.
- 품명 유사검색으로 단가를 붙이지 않는다. 원본에 가격이 없거나 전산 품목이 새로 생긴 경우는
  기존대로 `입력 필요`를 유지한다.

보조 비율식 `M/L`의 0 나눗셈이다. 본표 계산은 이 셀을 참조하지 않으므로 본표 금액 오류로
전파되지 않는다.

## 재고잔량 시트 해석

- 기초: `B:G` — 품목, 수량, 표시단가, 총계
- 기말: `J:O` — 품목, 수량, 표시단가, 총계
- 호주: `P:R` — AUD 품목단가, AUD 합계, 원화 환산 합계
- 7개 파일에서 품목단가 행 1,366개, 정규화된 품목 키 108개를 확인했다.
- 105개 키는 22~28차 동안 단가가 동일했다.
- 단가 변경은 수국 S.PK 3,200↔3,300원, 진라벤더 3,200↔3,300원뿐이며 정상 범위다.
- 카네이션은 모든 파일에서 기초 `F30=11,000`, 기말 `N30=110,000`으로 10배 차이가 반복된다.
  이 값은 명백한 이상치로 격리하고 자동 근거로 사용하지 않는다.

### 재고 평가 방법

1. 콜롬비아 수국·카네이션·장미·루스커스·알스트로, 베트남
   - `(상품매입 원화 + 포워딩 원화 + 그외통관비) ÷ 당주 매입수량 × 재고수량`
   - 28차 본표 F 수식에서 직접 확인했다.
   - 품목 catalog가 이 카테고리를 덮어쓰지 않는다.
2. 호주
   - `재고수량 × P열 AUD 품목단가 × O37 AUD 과세환율`
   - 28차 O37은 1,068.23이며 R열 합계가 본표 F13과 일치한다.
3. 그 밖의 비수식 카테고리
   - 원본 표시단가는 부가세 포함값이다.
   - 웹 공급가 평가는 `재고수량 × 표시단가 ÷ 1.1`이다.

## 전산 품목 연결

- 28차 `품목리스트`의 품목번호, 국가, 품명, 견적단위를 `재고잔량`과 대조했다.
- 정확히 확인된 47개 `ProdKey`만 versioned catalog에 등록했다.
- 출고단위가 박스여도 견적단위가 단인 미국 SALAL TIPS·Douglas Fir는 전산 재고 환산 뒤 단 단가를
  적용한다. 호주도 단 단가, 이스라엘·일부 네덜란드·에콰도르는 송이 단가를 적용한다.
- 중국 안개꽃·시네신스처럼 원본 한 행이 여러 전산 품목으로 나뉜 경우도 국가·품종·단위가
  확인된 품목번호만 명시적으로 연결했다.
- 태국 안스리움 샘플, 네덜란드 아마릴리스, 호주 Dingo Fern처럼 원본 가격 또는 전산 품목 연결이
  불충분한 항목은 자동 연결하지 않았다.

## 웹 적용 우선순위

1. 같은 `OrderYear + OrderWeek + ProdKey`의 직접 확정 재고단가
2. 같은 품목·단위의 사용자가 확정한 도착원가
3. 2026년 28차부터 정확한 `ProdKey + EstUnit`의 Excel 재고단가 catalog
4. 위 근거가 없으면 `입력 필요`

다른 연도, 28차 이전, 유사 품명, Product.Cost, 최근 임의 매입단가로는 자동 보정하지 않는다.
단, dnSpy에서 Product.Cost가 현재 출고단가임을 확인했으므로 평균원가 6개 카테고리와 호주를
제외한 품목에는 `Product.Cost/1.1`을 **추천값**으로만 표시한다. 사용자가 확인·저장한 해당 차수의
WebStockPriceEvidence만 이후 계산에 사용한다.
보고서 조회 과정에서 Excel 근거를 DB로 복사하거나 ERP 원장을 수정하지 않는다.

## 남는 입력 항목

- 관세·선율 등 실제로 매주 달라지는 통관 입력값
- 원본 22~28차에 없던 신규 품목의 재고단가
- 원본에 가격이 비어 있거나 전산 품목을 하나로 확정할 수 없는 항목

즉, 기존 Excel에 이미 단가가 있고 전산 품목번호가 정확히 확인된 품목을 사용자에게 다시 찾으라고
요구하는 문제는 제거한다. 반대로 근거가 실제로 없는 신규 품목은 임의 계산하지 않고 구체적인 품목만
입력 대상으로 남긴다.
