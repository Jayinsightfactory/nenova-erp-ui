# 붙여넣기 주문등록 기초재고 상단 연결

## 사용자 동작과 저장 영향

| 사용자 동작 | UserFavorite | Order/Shipment | Stock/Estimate/손익 |
|---|---|---|---|
| 기초재고 입력·변경, 추가/취소 예상잔량 확인 | 보존 | 보존 | 보존 |
| 기준차수 변경 | 저장본 존재 여부 SELECT만 수행, 현재 입력 유지 | 보존 | 보존 |
| 저장본 불러오기 | 선택한 사용자 저장본 SELECT | 보존 | 보존 |
| 현재 값 저장·덮어쓰기·새 기록 저장·삭제 | 현재 사용자 `paste-stock-note` 행만 INSERT/UPDATE/DELETE | 보존 | 보존 |
| 추가·취소 전체 등록·분배 | 기존 원자적 일괄 계약 그대로 | 기존 계약 그대로 | 기존 계약 그대로 |

## 계산 기준

- 예상잔량 = 기초재고 + 취소수량 - 추가수량
- 카톡명과 기초재고명이 달라도 두 이름이 같은 `ProdKey`로 확정 매칭된 경우에만 같은 품목으로 계산한다.
- 서로 다른 `ProdKey` 또는 미매칭 이름은 이름이 비슷하다는 이유로 합치지 않는다.
- 변경 적용 차수와 기초재고 기준 차수를 상단에 동시에 표시하고, 기준차수 변경만으로 저장본을 자동 적용하지 않는다.

## UI 기준

- 기준 화면은 1920×1080, 확대 100%다.
- 붙여넣기 입력 높이를 줄이고 분석 결과 아래에 품목별 기초·취소·추가·예상잔량을 최대 132px 스크롤 표로 배치한다.
- 기초재고 입력·저장 영역의 버튼은 저장본 불러오기/선택, 새 기록 저장, 현재 값 저장 또는 덮어쓰기로 구분한다.
