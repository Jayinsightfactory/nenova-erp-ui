## 동작

1. `견적서 출력` 옆에 `담당자별 견적서 출력`
2. 담당자 선택 → 그 담당자이면서 선택 연도·대차수에 분배가 있는 업체 기본 체크
3. 같은 차수의 나머지 분배 업체는 꺼진 채 목록. 켜면 같이 인쇄
4. 인쇄 옵션 다이얼로그로 넘어가 기존 iframe srcdoc 경로 사용
