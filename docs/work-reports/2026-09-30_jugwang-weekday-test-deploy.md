# 주광 요일별 견적 테스트 버전 배포

## 사용자에게 제공하는 범위

- `/estimate/weekday?popup=1`, 메뉴 `주광 견적서`.
- 거래처 직접 선택, 엑셀 원문 파싱, 품목 수동 연결, 요일별 수량 초안.
- PeriodDay 실제 달력 기반 목~수 주기와 앞/현재/뒤 차수 연결.
- 분배·날짜·확정 상태 읽기 대조, 부분수량 날짜/차수 이동 초안과 화면 내 변경기록.
- 입고원천 변경 입력 없음. 사용자의 정정은 재고수량 변경이며 입고기록은 보존한다.

**아직 제공하지 않는 기능:** 실제 ERP 적용, 영속 작업안/변경이력, 재고수정 전후값 연결, 요일별 EXE 견적 출력. ERP 적용/인쇄 버튼은 비활성이고 새로고침하면 초안은 사라진다. 현재 조회 결과를 재고잔량·사용 입고차수의 증거로 위장하지 않는다.

## 분리·부작용

최신 master `946152206cd9bfb0226de4c63a48cebc40d1923f`에서 별도 Git 작업공간을 만들었다. 다른 세션의 손익·주문·확정 변경은 포함하지 않았다. 기존 견적 관리 페이지/API 수정도 이번 읽기 전용 메뉴 배포에는 포함하지 않았다.

신규 API는 달력/주문/분배/입고 참고/확정 SP 출고이력을 SELECT만 한다. 업로드는 임시파일을 파싱 후 삭제한다. 주문·분배·입고·재고·견적·손익 원장 쓰기와 런타임 DDL은 없다.

## 근거와 검증

- 기존 dnSpy 및 승인 계정 읽기 확인: 주광농원 CustKey 533, 2026/37~39의 01/02 모두 확정. 38-01 실제 날짜 9/17·9/20, 38-02 실제 날짜 9/20. 이 불일치를 자동으로 수정하지 않는다.
- EXE ShipmentFarm에는 특정 WarehouseDetail 연결이 없으므로 입고 후보를 실제 사용 원천으로 단정하지 않는다.
- 전체 `test:erp-contract` 통과. 신규 기능 테스트 4개 통과.
- `test:nenova-dnspy-evidence`, 변경 기준 SHA의 manifest 및 ERP write guard 통과. 신규 API 3개 검사.
- Next production build 통과.
- 1920×1080 CSS pixel, deviceScaleFactor 1, 100% Chrome headless fixture: 업로드/품목연결/전산대조/부분수량 다음차수 이동, 적용·인쇄 비활성, 입고원천 편집 입력 부재, 페이지 가로 잘림 없음, pageerror 없음.
- fixture QA에서 마지막 엑셀행의 구역 분류 누락을 수정하고 회귀 테스트 추가. 달력 중복행이 분배 날짜수량을 곱하지 않도록 단일 OUTER APPLY 집계.
- 독립 REVIEWER(P0_LOCAL, 현재 모델 상속)에서 영문 OutUnit 별칭의 잘못된 주문수량열 선택 P1을 발견했다. 고정 별칭표로 SQL/응답/행렬 단위를 정규화하고 알 수 없는 단위는 NULL/대조불가로 유지했다. 별칭 positive/unknown near-miss 회귀 추가.
- 네이티브 브라우저 도구는 커널 경로 오류로 시작되지 않아 설치된 Chrome의 독립 headless 검증을 사용했다. 개발서버의 기존 instrumentation/crypto 의존 문제와 달리 production build/start는 통과했다. 운영 사용자 브라우저 동작은 배포 후 별도로 확인한다.

## 배포 상태

PR #828은 master d16defb39ccfafbcc1e10eb96a1900873de56384로 병합되었고 Cafe24 Deploy 36690848418은 성공했다. 배포 후 실제 계정의 달력 조회는 성공했으나 weekday-compare가 500을 반환했다. fixture/빌드 성공만으로 실제 대조 성공을 선언하지 않았다.

운영 쿼리의 MIN/MAX(ISNULL(sd.isFix,0))는 bit 피연산자를 지원하지 않는다. 기존 shipment/stock-status와 동일하게 집계 내부를 int로 변환하도록 수정하고 두 집계의 회귀 검사를 추가했다. 연도·차수·거래처·품목 범위 및 SELECT-only 부작용은 그대로다. 후속 배포와 실제 2026/37~39 및 2025 동일차수 대조를 재확인한다.
