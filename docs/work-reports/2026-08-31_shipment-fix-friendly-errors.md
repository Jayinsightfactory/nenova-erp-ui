## 사용자 계약

모든 확정 화면은 기본 문구로 아래 세 가지를 함께 표시한다.

1. 무엇이 문제였는가
2. 이번 요청으로 원장이 변경됐는가
3. 다음에 무엇을 해야 하는가

프로시저명, 내부 상태 코드, `Master/Detail`, `Product.Stock`, `AppLog.Step`은 기본 설명에서 숨기고 접힌 `기술 기록`에서만 보존한다.

## 상태 표시 계약

| 내부 상태 | 사용자 표시 | 의미 |
|---|---|---|
| `FIXED` | 확정 | 출고행 전체 확정, 점검 경고 없음 |
| `FIXED_PENDING_STOCK` | 출고확정·점검필요 | 출고행은 모두 확정됐으나 음수재고 또는 출고 상태 불일치 점검 필요 |
| `PARTIAL` | 일부만 확정 | 확정행과 미확정행이 함께 존재 |
| `UNFIXED` | 미확정 | 출고행이 있으나 확정행 없음 |
| `NO_SHIPMENT` | 출고없음 | 확정 대상 출고행 자체가 없음 |

`FIXED_PENDING_STOCK`을 알 수 없는 상태로 처리해 `출고없음`으로 표시하던 회귀를 금지한다.
