# 주차별 매출이익보고서 — 엑셀 원천 입력 경계 정정

## 결과

- 2026년 22~28차 원본 7개, 전체 78개 시트, 수식 12,865개를 허용된 원본 SHA로 다시 검사했다.
- 계산 가능한 C~U 값과 E/F 최종액은 읽기 전용으로 유지한다.
- 본표에 직접 나타나는 입력칸은 정확한 해당 차수 과세환율 R 원천이 없을 때뿐이다.
- H는 관세·선율·검역·창고료·트럭비 구성요소 화면에서, S는 입고 항공료 전표와 포워딩 원천에서 계산한다.
- 평균원가 공식 밖의 재고 품목은 같은 차수·품목의 검증 매입·취득원가가 없을 때만 매입단가 입력 대상으로 표시한다.
- 기초재고와 기말재고 중 어느 시점만 근거가 없어도 그 시점의 OrderYear+OrderWeek에만 근거를 저장한다.

## 재고 원가 정정

- E/F는 판매·분배단가가 아니라 매입·취득원가 기준이다.
- ShipmentDetail.Cost와 Product.Cost를 재고 매입원가 후보로 쓰던 경로를 제거했다.
- 원본 수식이 확인된 콜롬비아 수국·카네이션·장미·루스커스·알스트로와 베트남은
  `(Q×R + S×R + H) ÷ 당주 매입수량 × ProductStock 재고수량`으로 자동 계산한다.
- 소량 샘플은 동일 재고시점·동일 단위의 검증 매입원가만 수량가중평균한다.
- 그 밖의 품목은 WebStockPriceEvidence, 확정 도착원가, 정확한 역사 workbook 품목 근거 순으로 사용한다.

## 28차 합계 범위 정정

- 22~27차 마지막 본표 행은 `공제`, 28차부터는 `국내`다.
- C/E/F/J 합계에는 마지막 본표 행을 포함한다.
- G/H/I/L/N/O/P/Q/S/T 합계에서는 마지막 본표 행을 제외한다.
- U 합계 표시 분자는 공제/국내와 베트남을 제외하되, U 행별 분모 P에는 베트남 구매액을 포함한다.
