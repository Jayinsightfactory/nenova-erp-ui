# 미분류 6차수 원가 공란 — 읽기 전용 확인

기존 `stem-dataset.json`와 연간 관세 원천 감사 JSON을 재사용했다. 신규 SQL 조회·DB 변경은 없다.

16행의 외화 상품금액 합계는 각 저장 보고서 Q와 정확히 같다. 각 행의 R·통화는 없고 S는0이라 G가 계산되지 않는다. 따라서 부대매출만 있는데 잘못 생성된 Q라고 단정하거나 Q를0으로 지우면 안 된다. 품목 미매칭 실입고 금액이다.

해당 입고 13건의 재고성 동반품목은 모두 단일 국가다. 운송료 등 비용행은 국가 판단에서 제외했다. WarehouseKey는 3853/3857/3858/3907/4159/4167/4365/4447/4448/4472/5060/5071/6575다. 국가·품종은 동반품목을 통한 참고 범위이며, NULL ProdKey의 상품명이 확인된 것은 아니다.

관세 원천 lines의 USD는 기존 통화 추정 로직 결과이므로 독립된 송장 통화 증거가 아니다. 해당 lines의 sourceCountry·storedExchangeRate·freightForeign도 미확인이다. 현재 캐시에 해당 입고의 농장 국가·원문 송장 통화를 독립 확인할 자료는 없었다.

국가 평균 보완을 적용한다면 동일 입고의 단일국가를 참고한 계산임을 남겨야 한다. 원DB 품목 매칭이나 국가별 금액 재분류를 변경하지 않는다. 서로 다른 통화 금액을 하나의 R로 임의 합산하거나, 근거 없이0원 처리하지 않는다. 이 6행 예외는 분류된 국가 행의 검증 완료와 별도로 보고한다.
