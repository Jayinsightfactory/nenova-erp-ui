# 주차별 매출이익 엑셀 담당자 답변 (2026-08-19)

엑셀 시트 단어로 질문한 38항에 대한 1차 답. 미확인은 `확인해볼게`.

## 확정

| 번호 | 결정 |
|---:|---|
| 1 | 매주 넣는 값: **관세**, **한국방역**. **환율**도 매주 넣되 기준값을 띄우고 그걸 바탕으로 입력 |
| 2 | 백상 = **kg당 단가** |
| 3 | 백상 단가가 바뀌어도 **예전 차수는 예전 단가 그대로** |
| 5 | 선율 1/2/3 분할은 엑셀에도 나눠 넣음 |
| 6 | 관세 0은 **나라마다 원래 0인 경우**가 있음 |
| 7 | 한국방역은 **값이 있을 때만** 넣음 |
| 9 | 태국 1차만 입고는 정상. **2차 비용은 비워도 됨** |
| 10 | 콜롬비아 한쪽 차수만 있으면 그 차수만, 없는 차는 0 |
| 12 | 월드운송료는 무게 추천값이 아니라 **실제 청구액** |
| 17 | 그 주 환율이 없어도 빈칸으로 두지 말고 **반드시 입력하게** |
| 29 | 카네이션 기말 110,000은 **오타**. 쓰지 않음 |
| 36 | 본표가 같으면 수식·데이터가 맞은 것. 실무 합격선은 **수익률이 같으면** 됨 |
| 37 | 숫자가 다르면 `재고잔량` / `그외통관비` / `포워딩` / `구매현황` / `콜롬비아 1차·2차` **전부** 같이 봄 |
| 38 | 이후 차수도 시트 이름·칸 의미는 지금과 같게 유지 |

## 아직 확인 중

4(선율 구성), 8(GW=입고), 11(수국 vs 4품목 — 아래 설명 후 재질문), 13(부가세 나누기 — 아래 근거), 14~16(환율), 18~28, 30~35.

## 구현에 바로 쓰는 변경점

- 매주 필수 입력은 선율·백상이 아니라 **관세 + (있을 때만) 한국방역 + 환율(기준값 제시 후 저장)**.
- 백상은 매주 금액이 아니라 kg 단가. 과거 차수 소급 금지.
- 월드운송료 자동 트럭 추천은 참고만. 저장·본표는 **실제 청구액**.
- 환율 원천이 없어도 조용히 0 처리하지 않고 입력칸을 연다.
- 태국 2차 빈칸은 경고가 아님.
- 카네이션 110,000은 계속 격리.
