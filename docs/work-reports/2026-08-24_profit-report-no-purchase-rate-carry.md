# 주차별 매출이익보고서 — 무매입 차수 과세환율 이월

## 사용자 확정 규칙

- 현재 차수에 재고화 대상 매입이 있으면 해당 차수의 정확한 과세환율만 사용한다.
- 현재 차수에 매입이 없으면 바로 이전 대차수부터 가장 최근의 정확한 과세환율을 찾아 이어 사용한다.
- 연속해서 매입이 없는 차수는 계속 거슬러 올라간다.
- 탐색 중 매입은 있으나 정확한 환율이 없는 차수를 만나면 그보다 과거 값을 쓰지 않고 입력 필요로 둔다.
- 01차의 직전은 전년도 52차다. 같은 차수 번호의 다른 연도 자료를 섞지 않는다.
- 호주 AUD뿐 아니라 보고서의 모든 국가·화종·통화에 같은 규칙을 적용한다.
- `CurrencyMaster`, 판매·분배단가, `Product.Cost`는 과세환율 원천으로 쓰지 않는다.

## 적용 범위와 부작용

| 동작 | 조회 | 저장·원장 영향 |
|---|---|---|
| 현재 차수 정확 환율 선택 | WebProfitReport, FreightCost, WebTaxableExchangeRate, 원본 workbook, KCS | 없음 |
| 무매입 차수 이전 환율 탐색 | 이전 대차수의 위 원천과 재고화 대상 매입수량 | 없음 |
| 행별 환율과 호주 재고 평가 | 계산 응답에 원천연도·원천차수·원래 원천·이월거리 표시 | 없음 |
| 사용자가 환율을 직접 저장 | 기존 과세환율 저장 화면 | WebTaxableExchangeRate와 이력만 변경 |

GET 조회 중 이월값을 자동 저장하지 않으며 주문·출고·재고·견적·손익확정 원장을 변경하지 않는다.
