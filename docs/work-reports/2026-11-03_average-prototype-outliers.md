## 권장 보완

- 실제 외화 Q/S가 있는데 R만 없는18차는 G전체를다른품종평균으로대체하기보다 확인가능한과거공식환율 또는승인참고환율로 알려진 Q/S를 환산하는 성분별보완이 더 적합하다. 실제통관일인증과참고시점규칙은분리한다.
- 호주SteelGrass도2025exact매입9행이있다. 상품가격을보존하고부족운임·통관·환율만보완하는경로를우선하면국가전체품종혼합왜곡이줄어든다.
- 과거스냅샷F와다음E는같은평가결과를이어야하지만,현재F가다른검증방식이면평가변경효과가마진에포함된다. 이를판매마진과구분한재고평가영향으로상세표시한다.
- row.calc E/F를바꾼뒤inventoryValuation.value/stock.evidenceValue가옛값이면상세설명과숫자가충돌한다. 원본basis는보존하되유효fallbackbasis를별도표시한다.
- 숫자산출이되었다는이유로실제원가·회사수익률정확성인증을하지않는다. 이번표는이상치를숨기지않고계산근거를개선하기위한중간검산이다.

## 후속 독립 확인 — 구현 중, 배포 승인 아님

- 선택 우선순위를 `exact past → exact reference → same-variety past → same-variety reference → country past → country reference`로 정정했다. 다른 품종의 과거 국가 평균이 같은 품종의 참고 원가를 밀어내지 않게 한다. 최종 재생 수치 확인은 남아 있다.
- 코드 읽기에서 누락 수량의 null→0 차단, 불완전 H0의 비관세 완료0 오인 방지, E/F 유효 평가 메타 동기화 패치를 확인했다. 실행형 반례와 최종 재생 결과 확인 전에는 위 차단 항목을 완료 처리하지 않는다.
- 18차 성분 보존용 공식 관세청 HTTP 조회5건은 성공했다(DB 접근0). 2026-04-27 요청은 USD1476.92/AUD1056.39(적용4/26~5/2), 2026-05-04 요청은 EUR1728.25/USD1476.35/CNY215.97(적용5/3~5/9)이다. 근거는 `.verify/average-18-official-fx-review.json`이다.
- 이 요청일은 기존 국가별 통관주간 계산 규칙을 확장한 참고일이다. 실제 신고일이나 해당 입고의 실제 적용환율을 확인했다는 뜻이 아니다. 알려진 Q/S 보존 및 적용일 근거를 함께 남겨야 한다.
