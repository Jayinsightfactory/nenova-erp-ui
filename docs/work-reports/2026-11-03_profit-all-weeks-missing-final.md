## 결과 요약

**저장본 1~43차의 E/F/G/H/R/I/J/K 숫자 변동은 0행이다.** 03차 이후 숫자 세부차수 관세를 지원하고 원인 표시를 보완했지만, 미확인 원가·관세를 임의 금액으로 채우지는 않았다. 따라서 모든 차수의 수익률이 확정되었다고 볼 수 없다.

- [저장본 최종 진단 전수 CSV — 1,302행](2026-11-03_profit-all-weeks-missing-final.csv): 차수·국가·품목·빈 열·정확한 원인·확인 위치. 31차 에콰도르는 원가 공란 없이 매출 분모0만으로 이익률 공란인 정상행이므로 제외했다.
- [기초·기말 원가 미확인 품목 상세 — 155행](2026-11-03_profit-inventory-missing-items.csv): 재고평가 공란의 실제 품목키·품명·재고차수·단위 혼재.
- [44차 최종 진단 CSV — 59행](2026-11-03_profit-week44-missing-final.csv): 진행차수 단일 최종 재조회, SELECT1,291/쓰기0·v3. 중국33입고행/32고유품목의 관세 연결 및 기존 관세/비관세 분리 근거 등이 미확인이다. C/E/F/G/H/I/J/K 전후 변동0. 산출 완료 뒤 상주 핸들로 자연 exit0은 발생하지 않아 해당 probe PID만 종료했다. 확인 위치는 위 전수CSV의 동일 진단코드별 메뉴/필드를 따른다.
- [변경 전 전체 기준](2026-11-03_profit-all-weeks-missing-baseline.md): **45~50 미래차수는 이전 조회 성공이며 최종 코드 운영 브라우저 재검증은 대기다.** 위 저장본 최종 건수 및44차 진단 건수에 합치지 않았다.
- 1,302/155는 진단·품목 행 수이며 문제 차수 수가 아니다. 같은 차수·국가의 여러 원인이 중복될 수 있다.
- 최종 관세 정책 미연결은 705입고행/217품목(중국179·태국34·호주2·에콰도르2)이다. 숫자03 입고를 상세 검증하면서 변경 전702행/216품목보다 누락 근거가 더 구체적으로 드러났다. 실제 관세를 새로 누락시킨 것이 아니다.
- 배포/운영 스모크는 아직 대기다. DB 쓰기는 하지 않았다.
- 01~50은 삭제 여부를 제한하지 않은 SQL Master의 차수 존재 범위다. 모든 차수가 활성 거래나 완료된 매출을 가진다는 뜻이 아니다. 실제 보고서·관세 원천 조회는 기존 활성행 필터를 따른다.

## 사용자가 확인할 구체 사례

- 미국 02차 SALAL TIPS(ProdKey1718): 재고수량은 있으나 기말 평가 매입원가 근거가 없어 F/I/J/K가 공란이다. 입고 실제 매입단가와 재고 단위를 확인한다.
- 네덜란드09차 Anthurium Graciosa15cm(181), Tulip Single Orange Juice(1959): 원가 미확인과 단위 혼재가 함께 남는다. 재고155를 곧바로 송이 또는 단으로 일괄 환산하지 않는다.
- 콜롬비아 장미08차: 여러 품목 원가와 단위 혼재, 음수재고가 함께 존재한다. 예 Hearts50cm(1204), MondialWhite50cm(1276). DB 재고 보정으로 숫자를 맞추지 않았다.
- 중국 초기 차수: 원래 Product.CounName이 콜롬비아/국내인데 품명이 CHINA인 행이 존재한다. 품명 분류와 국가 다수결 통화가 달라지는 것이며, 인보이스 통화 원문 없이 USD/CNY를 임의 교체하지 않았다.
- 중국 운임 총액이 맞아도 일부 유가 품목의 배분 수량이 없으면 품목별 관세는 보류한다. 총운임 금액만 일치한다고 품목 배분을 인증하지 않는다.

## 안전 검토

숫자03~99를 별도 입고로 계산하되 Customs1/2 양수 실제 합계가 있으면 03 이후 금액이 이미 포함되었을 가능성이 있으므로 범위 확인 전 가산하지 않는다. 명시0는 보존한다. 40/41/43차 대상국의 실제 customsRow가 모두null임을 감사 산출물에서 확인하여 이 가드가 현재 비교 수치에 추가 영향을 주지 않는다. 문자suffix는 숫자로 강제 변환하지 않는다.

저장본 baseline12SELECT와 after12SELECT는 각각 실제 새 조회 실행이다(구현 담당 실행 기록 확인). 이후 양수합계 중복 가드 추가는 현재 대상의 customsRow가 모두null임을 재사용하여 추가 SQL0, fixture 재검증으로 확인했다. live 이전 감사의 유효 재실행은 SELECT5,233/쓰기0이고 최초4,748 결과는 불완전하다. 실제 확정본은 활성키0으로 실자료 대조 대상이 없으며 확정 원본 불변은 계약/fixture로 별도 검증해야 한다. 모든 신고서·원산지 특혜를 전수 인증한 것은 아니다.
