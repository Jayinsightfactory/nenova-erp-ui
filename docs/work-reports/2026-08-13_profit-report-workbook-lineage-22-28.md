- 산출 기준: XLSX OOXML을 읽기 전용으로 파싱했다. 공유수식은 마스터 좌표에서 각 셀 좌표로 확장했고, 값·수식·저장 캐시를 분리했다.

## JSON 구조 및 재현성

- `formulaCatalog` + `workbooks`: SHA로 중복 제거한 정확한 수식 문자열과 모든 시트의 used range, 셀 값/수식/캐시, 수식 패턴, 오류, 외부참조
- `sameCoordinateChanges`: 차수간 동일 좌표 변화 전체
- `carryForwardFToE`: 22→23 … 27→28의 F/E 행별 비교
- `finalReportLineage`: C:K·N:U의 셀별 lineage와 대형 범위 catalog
- `directInputCandidates`: 반복 빈도·변화·downstream 근거 기반 후보 그룹
- `integrity`: 입력 SHA-256 전후 동일 여부와 산출물 자체 통계
