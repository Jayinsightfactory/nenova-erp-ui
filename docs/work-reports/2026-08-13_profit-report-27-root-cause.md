# 2026년 27차 매출이익 보고서 합계·카테고리 수준 차이 분석

## 비교 원천

- 웹: 2026년 27차 운영 화면 읽기 전용 조회(버전 `13e2d1c`), 2026-08-13
- 엑셀: `__tests__/fixtures/profit-report-22-27.json`의 27차 원본 추출값
- 운영 원장 저장·수정은 수행하지 않았다.

검증 수준: Excel 수식과 카테고리 합계 대조는 완료했다. 다만 원본 Excel 상세행에는
`ShipmentKey/SdetailKey/EstimateKey/ProductStock/ProdKey/CustKey` 연결키가 없으므로, 어느 ERP
원장행이 달라졌는지를 키 단위로 확정한 것은 아니다. 아래에서 "확정"이라고 할 수 있는 범위는
J 차이가 C/E/F/G 차이에서 수학적으로 파생된다는 점과 카테고리별 차이 금액까지다.

## 원인 산식

정상 엑셀 공식은 `I = E + G + H - F`, `J = C - I`다. 따라서 현재 차이는 다음처럼 정확히 연결된다.

- `ΔI = ΔE + ΔG + ΔH - ΔF`
- `-6,117,864.03 = -3,658,863.11 - 148,470.13 + 0 - 2,310,530.80`
- `ΔJ = ΔC - ΔI`
- `+17,711,312.03 = +11,593,448 - (-6,117,864.03)`

즉 J 102.4% 차이는 J 공식 오류가 아니라 C/E/F/G 원천 차이가 합쳐져 확대된 결과다.

## 항목별 차이 위치와 추가 원장 검증 범위

### C 매출액 +11,593,448

운영 화면의 카테고리별 합계와 Excel 저장값이 다르며 증가분은 다음 네 분류에 집중된다.

- 베트남: +4,364,000
- 네덜란드: +2,880,100
- 중국: +2,465,600
- 콜롬비아 수국: +1,883,749
- 콜롬비아 카네이션: -1(반올림)

또한 웹의 `기타(미분류)` 1,223,171은 합계 제외 행으로 표시된다. 원본은 `국내 / 왁스 / 판매요청/단` 견적이다. 이 행을 임의 국가에 넣지 않고 마스터 국가·화종 정정 대상으로 유지한다. 현재 자료에는 Excel 판매현황·불량차감·그외매출 상세행을 ERP 상세키와 연결한 표가 없으므로, 운영 매출·견적 원장이 실제로 변경됐다고 단정하지 않는다.

### E 기초재고 -3,658,863.11

차이는 사실상 베트남 한 분류에 집중된다.

- 웹 E는 27차 직접입력 > 26차 활성 확정 보고서 F > 26차 저장 F > 26차 ProductStock 자동평가 순으로 선택한다.
- 과거 27차 엑셀 E에는 당시 수기로 확정한 별도 재고평가액이 들어 있다.
- 원본 파일 안에서도 26차 F, 27차 E, 재고잔량 시트 금액이 서로 달라 단순 전차수 수식 복사값이 아니다.

따라서 계산식 문제보다 선택된 재고평가 원천 차이일 가능성이 크다. 실제 27차 응답의 `source.E`와
`beginStockKey`를 기록하지 않았으므로 ProductStock 직접 이월이라고 단정하지 않는다.

엑셀 F에는 수기 재고단가와 보정값이 포함돼 있고, 27차 원본에는 카네이션 단가 110,000처럼 11,000의 10배로 보이는 이상값도 존재한다. 웹은 마지막 재고 스냅샷 수량에 웹 재고단가표, 수국 단가표, 품목원가, 최근 매입단가 순으로 평가한다. ProductStock의 StockKey·ProdKey별 수량, 웹 적용단가·출처, Excel 재고잔량 품목행을 연결한 교차표가 없으므로 수량 차이인지 평가단가 차이인지 아직 확정하지 않는다.

### G 매입액 -148,470.13

오차율은 0.07%로 목표 범위 안이며 카테고리 합계상 중국에 차이가 집중된다. WarehouseKey/WdetailKey별 원장과 Excel 구매현황·포워딩 상세행을 연결하지 않았으므로 중국 포워딩이 실제 원인이라고 확정하지 않는다.

### H 그외통관비

27차는 웹과 엑셀 합계가 10,813,030으로 정확히 일치하며 저장된 historical fixture 구성요소의 공식 재계산도 일치한다. 이는 수식과 저장된 구성요소 재현이 맞다는 뜻이며, 운영 DB의 개별 관세·선율·창고료·월드운송료 원장행이 Excel 원본행과 모두 동일하다는 뜻까지 포함하지는 않는다.

## 수정 범위

- 2026년 28차 이후는 실제 입고 날짜별 관세청 주간 과세환율을 구매금액으로 가중평균한다.
- AUD도 동일한 관세청 원천을 사용한다.
- 날짜 하나라도 공식 환율 조회에 실패하면 일부 날짜만으로 계산하지 않고 해당 분류를 `입력 필요`로 둔다.
- 수기 R 값은 자동값보다 항상 우선한다.
- 이익률 분석은 현재 차수와 같은 연도의 직전 최대 4개 차수를 비교하며, 실제 거래처·품목 단가와 판매비중 변화를 후보로 보여준다. 원인을 단정하지 않고 `특가·재고소진 여부 확인`으로 표시한다.
- 검증·입력 안내는 본표 아래 접기 영역으로 이동한다.

  상세키 연결자료가 없어 아직 단정하지 않는다.
- 이번 코드 보강은 부분 환율, 날짜 대체, 전차수 환율 혼용, 교차연도 혼입처럼 향후 오차를 만드는
