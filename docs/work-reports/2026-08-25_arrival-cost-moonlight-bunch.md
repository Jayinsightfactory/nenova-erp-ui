## AI 구성

| 담당 | 역할 |
|------|------|
| Cursor 직접 | 실파일 대조, 파서·화면 수정, 계약 테스트, 배포 |

## 원인

- 입고수량이 단인데 파서가 도착원가(송이) 449~476원을 표시 원가로 저장했다. 원래 값은 도착원가(단) 약 8,986원이다.
- 시트명 `14-1A`는 파일명 `33-2`와 한 문자열로 찾으면 매칭이 깨져 전 시트가 33-2로 오염됐다.

## 변경 요약

| 파일 | 내용 |
|------|------|
| `lib/arrivalCostExcel.js` | 단/박스면 도착원가(단) 우선. 시트명 차수를 파일명보다 앞세움 |
| `lib/arrivalCostView.js` | 차수 구간으로 품목 그룹을 묶음 |
| `pages/arrival-cost.js` | 차수 헤더 + 품목 한 줄에 농장 원가. 농장 행은 눌러야 열림 |
| `docs/contracts/arrival-cost.json` | 단원가·시트차수·한눈에 보기 계약 |

주문·출고·견적·재고는 읽지 않는다. 이미 올라간 행은 같은 엑셀을 다시 올려야 한다. 이 파일은 여러 차수 시트가 있어 콜롬비아 해당 차수 현재본이 같이 갱신된다.

## 사용자 확인 포인트

- 33-2 문라이트는 농장별 약 8,986원. 476원이 아니어야 한다.
- 목록은 차수 구간 아래 품목 한 줄에 `농장1 8,986원 / 농장2 …`로 보인다.
- 배포 후 원가 엑셀을 다시 업로드해야 한다.
