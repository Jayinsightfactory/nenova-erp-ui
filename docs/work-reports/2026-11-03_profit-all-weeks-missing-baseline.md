# 전체 차수 미확인 원천 목록 — 변경 전 기준

이 목록은 수정 전 감사 기준이다. 최종 수정 후 잔존 목록과 혼동하지 않는다.

후속 정밀분류에서 31차 에콰도르는 원가 공란 없이 매출 분모0만으로 K가 공란인 정상행임을 확인했다. 이 변경 전 원본 CSV에는 당시 기준상 포함되어 있으나 최종 목록에서는 제외했다. 변경 전1,426행을 모두 오류로 해석하지 않는다.

- 전수 행: [CSV 1,426진단행](2026-11-03_profit-all-weeks-missing-baseline.csv). 같은 국가·차수의 여러 품목/기초·기말 원인이 각각 기록되므로 문제 차수 수와 같지 않다.
- SQL 등록01~50차 중 저장본01~43차, 진행44차, 미래45~50차를 분리했다.
- 저장본 감사 SELECT12/쓰기0. live 재실행 SELECT5,233/쓰기0. 최초4,748회 결과는 읽기 wrapper가 환율 SELECT 분기를 차단했으므로 완료 증거로 사용하지 않는다.
- K 공란 중 C/E/F/G/H가 모두 명시0이면 정상 무활동으로 제외했다. 매출이 있는데 원가가 없는 행은 제외하지 않았다.
- 품목키 누락은 DB 품목이 없다는 뜻이 아니라 웹 관세 정책에 exact 품목 연결이 없다는 뜻이다.
- 통화 충돌은 현재 국가 기반 웹 추정과 보고서 분류의 충돌이다. SQL의 실제 통화가 USD로 확인되었다는 뜻이 아니다.
- 배분 미완전은 운임 총액 차이와 품목 분모 미완전을 모두 포함한다. 원문의 유가 품목을 버리거나 임의 0 배분하지 않는다.
- CSV의 확인위치는 사용자 확인 경로와 테이블/필드를 제시한다. 근거가 없다는 이유로 DB 입력·보정을 수행하지 않았다.

빈열: E 기초재고액, F 기말재고액, G 매입액, H 그외통관비, R 환율, I 매출원가, J 매출이익, K 이익률.

## 산출 근거와 한계

로컬 `.verify/profit-all-weeks-audit.json`, `.verify/profit-live-weeks-audit.json`의 파생 행 및 누락 진단을 읽어 생성했다. 신규 SQL 조회 없이 구현 담당의 안전한 조회 결과를 재사용했다. 원본 SQL이 현재 스냅샷과 역사적으로 동일하다는 인증, 모든 통관 신고서 원문 대사, 조건부 특혜 적용 확정은 이 목록의 범위가 아니다.

현재 범위에서 DB 추가 수정, 원가 재저장, 재고 재계산, 확정본 변경은 모두 금지다. 사용자 승인 운임 차이655/917 CNY는 그 자체만으로 보류 근거가 아니다.
