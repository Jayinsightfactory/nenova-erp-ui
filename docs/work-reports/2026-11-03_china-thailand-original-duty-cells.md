### 적용 승인 후 전체 시트 추가 대조

2026-11-03 사용자 적용 승인 후 전체 시트의 동일행 수식과 기존 연간 SQL 지문을 재대조했다. 원본 1,238행이 정확 품명 214키에 연결되며 고유 품목·세부차수는 1,092조합이다. 이것은 원본 관측 규모이지 실제 금액 복구 수가 아니다. 같은 품목·세부차수의 세율 충돌은 없었다. 17-1의 예외는 K42~K46(3075,3086,3087,3089,3088) 전체이며, 28-2 CLOUD의3210 PreservedBlue도21.4%, 32-2 CLOUD의3120 비짜루500g도21.4%다. 따라서 알려진17/27차 외에도 확인된 모든 직접 원본 차수율을 보존해야 한다.

원본과 SQL에 exact 품명은 있지만 해당 SQL 차수 입고가 없는3163/26-02,2507/30-01,2741·3143/33-01은 실제 입고 직접 연결에서 제외한다. 태국 Oncidium/Vanda/White Necklace의 동일행5%는 해당 원본 세부차수만 연결 가능하며 국가 전체 또는 상품의 광역 기본값으로 확대하지 않는다. 수량·신고행1:1 및 실제 납부 인증은 별도다.3211 Burgundy와3384 Orange의25%는 사용자 승인 동일 보존Asparagus 형태 규칙이며 직접 원본 exact 관측으로 표시하지 않는다. CO3.2 미확인 상태는 유지한다.

- 중국 원본은 꽃21.4%, 유칼립투스8%, 프리저브드25% 구조를 실제로 담고 있다. 다만17-1과27-2 등에서 프리저브드도generic others21.4%로 계산된 예외가 있어 과거전체를25%로소급하면원본과달라진다.
- **CO는 원산지증명서(Certificate of Origin) 조건 문맥이다. 콜롬비아 국가코드와 혼동하지 않는다.** 확인한 중국원본에서3.2% 숫자/수식/원산지조건셀을찾지못했다. 사용자설명과공식조건을별도로연결해야하며CO발급여부를엑셀에서확인했다고표시할수없다.
- 태국은 중국율을복사하지않는다. zip의12차,최신36·38파일의26/31/36/38차에서 운임포함CNF원화×5%가확인된다. 중국과같은절차로품목을연결하는것이지같은세율을적용하는것은아니다.
- 전산공식정책8% 추론이 원본Preserved25%를우선순위로덮는문제는 별도정정후보다. 신고39차8%라는관측이과거모든프리저브드25%원본을자동무효화하지않는다.
