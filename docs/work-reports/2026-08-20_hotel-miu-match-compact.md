## 동작

- 엑셀 텍스트 붙여넣기는 그대로 텍스트 파싱(이미지 OCR 아님).
- 이번 입력 행을 화면 너비로 늘리지 않고, 입력 | 매칭 | 수량 | 단위 를 붙여 둔다.
- 주문·출고 쓰기 없음.

## 사용자 확인 포인트

- 새로고침 후 엑셀 칸 복사 → 입력 이름 바로 옆에 매칭 이름과 수량이 붙어 있는지.
