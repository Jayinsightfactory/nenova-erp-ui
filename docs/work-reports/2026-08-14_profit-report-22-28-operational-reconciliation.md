# 주차별 매출이익보고서 22~28차 운영 원장 대조

## 결론

- 차수 없는 `매출원가 양식.xlsx`의 7행 설명을 계산 규칙의 최상위 원본으로 고정했다.
- 22~28차 원본 7개는 전체 시트·셀·수식 fingerprint 재생성에서 금액 1원, 비율 0.01%p 허용범위 안으로 모두 일치했다.
- 현재 운영 DB와 과거 Excel의 차이는 계산식 하나로 설명되지 않는다. 과거 보고서 작성 뒤 출고·입고 원장이 수정된 `현재 원장 변동`과, 기존 웹이 재고단가 근거가 없을 때 최근원가/Product.Cost를 사용한 `잘못된 대체 단가`가 함께 있었다.
- 26차 F→27차 E만 원본 workbook 내부에서 3,658,862.88875원 불연속이며 전액 베트남이다. 사용자 확정 규칙에 따라 웹은 26차 마지막 확정 재고를 27차 기초재고로 이월하고, 이 예외 Excel 값으로 덮어쓰지 않는다.

## 적용한 재고 평가 규칙

1. 수량은 해당 대차수의 마지막 `isFix=1` ProductStock 세부차수만 사용한다.
2. 27차 기초재고는 같은 연도 26차 마지막 확정 재고이며, 01차만 전년도 52차로 넘어간다.
3. 단가는 같은 연도·세부차수·품목의 직접 확정 단가를 우선한다.
4. 직접 단가가 없을 때만 같은 연도·세부차수·품목·매입단위의 사용자 확정 도착원가를 수량가중 평균한다.
5. 단순 업로드/자동매칭, 단위 불일치, 다른 차수, 다른 연도, 최근매입단가, Product.Cost, 카테고리 평균은 사용하지 않는다.
6. 근거가 없으면 잘못된 금액을 만들지 않고 입력 필요로 표시하며, 최종 E/F 금액 직접입력은 허용하지 않는다.

## 아직 직접 확인이 필요한 값

미래 차수의 계산식이나 DB 자동값이 아니라 외부 청구서로 확정되는 값만 남긴다: 백상 창고료, 관세, 선율, 한국 방역, 콜롬비아 소독, 콜롬비아 방역 공제. 재고단가는 E/F 최종금액을 넣는 방식이 아니라 품목별 확정 단가 근거를 저장한다. 과거 22~28차 원본에는 값은 있으나 확정자·확정시각 sidecar가 없어서 역사 원본 셀 근거와 미래 운영 저장 근거를 구분한다.
