# 원가 자동반영 24시간 대기

## 기준 및 부작용 (구현 전 고정)
- 사용자의 최신 지시: 매분 검사 대신 원가파일이 생긴 뒤 1일 후 반영.
- 권위 시각: 업무드라이브 ingestFile의 서버 uploadedAt. 원본 PC mtime은 최신 버전 선택에만 사용하며 대기시간을 줄이는 데 쓰지 않는다.
- 새 hash 버전은 자신의 uploadedAt+24시간. 동일 hash 재수신은 uploadedAt 보존. 최신 후보부터 고른 뒤 대기하므로 구버전을 대신 반영하지 않는다.
- 표시와 실행은 같은 순수 일정 정책. 24시간 직전 저장 금지, 경계부터 가능. 등록시각 없으면 보류.
- 파일 색인·설정 변경 감지 + 다음 예정시각의 단발 타이머. 서버 재시작은 저장 시각에서 예약 복원. 일시 실패만 5분 재시도.
