# 네노바 PC 프로그램 사용 안내

## 설치

`Nenova-Desktop-Setup-1.0.0-x64.exe`를 실행하고 설치 위치를 선택합니다. 설치 후 바탕 화면 또는 시작 메뉴의 **네노바 업무**를 실행합니다. Windows 64비트용이며 기존 Nenovaweb 계정으로 로그인합니다. 기존 `nenova.exe`와 별도 프로그램으로 설치됩니다.

이 배포본은 코드 서명 인증서가 적용되지 않아 Windows에서 게시자 확인 경고가 나올 수 있습니다. 배포 폴더의 `SHA256.txt`로 파일 무결성을 확인할 수 있습니다.

## 업무 탭과 창

- 상단 **메뉴** 또는 **＋**에서 업무 화면을 검색하고 엽니다. 같은 메뉴도 여러 탭으로 열 수 있습니다.
- 탭을 누르면 해당 화면으로 돌아갑니다. 탭을 드래그하면 순서가 바뀌며, 이름을 더블클릭하면 이름을 바꿀 수 있습니다.
- **창 분리** 또는 탭을 창 밖으로 드래그하면 별도 창이 됩니다. Windows 창처럼 이동·최대화·다른 모니터 배치가 가능합니다.
- **창 이동**에서 대상 창을 선택하거나 다른 창의 탭 영역에 드래그하면 다시 합쳐집니다. 이동 중 화면을 다시 불러오지 않아 현재 입력이 유지됩니다.
- **☆**로 즐겨찾기에 추가·해제합니다. 즐겨찾기는 메뉴 화면에서 열 수 있습니다.
- **− / ＋**로 해당 업무 탭의 배율을 조절합니다. 숫자를 누르면 100%로 돌아옵니다. 80%로 조절해 더 넓게 볼 수도 있습니다.
- 인쇄·엑셀·업로드는 기존 웹 화면의 기능을 사용합니다. 상단 인쇄 버튼은 현재 탭을 인쇄하며, 다운로드는 저장 대화상자에서 위치를 선택합니다.

사용자 제한 메뉴는 **네노바 홈**에서 기존 웹 권한에 따라 접근합니다. 메뉴 목록 자체가 업무 권한을 부여하지 않습니다.

## 키보드

| 키 | 동작 |
|---|---|
| Ctrl+T / Ctrl+K / Ctrl+L | 업무 메뉴와 검색 |
| Ctrl+Tab / Ctrl+Shift+Tab | 다음 / 이전 탭 |
| Ctrl+N | 새 업무 창 |
| Ctrl+W | 현재 탭 닫기 확인 |
| Ctrl+D | 즐겨찾기 추가·해제 |
| Ctrl+R / F5 | 새로고침 확인 |
| Ctrl+P | 현재 탭 인쇄 |
| 탭에 초점을 둔 뒤 F2 | 탭 이름 변경, Enter 저장 / Esc 취소 |
| 탭에서 Ctrl+Shift+← / → | 탭 순서 이동 |
| Alt+← / Alt+→ | 이전 / 다음 화면 이동 확인 |
| Tab / Shift+Tab, Enter / Space | 버튼 이동·실행 |

## 저장과 복원

같은 계정으로 다시 실행하면 업무 탭 주소·순서·배율, 창 위치와 즐겨찾기를 복원합니다. 구성은 Windows 사용자별 암호화 파일로 보관합니다. 로그인 유효기간이 지나면 다시 로그인합니다.

**탭 전환·창 이동 중 입력 유지와 업무 데이터 저장은 다릅니다.** 종료·새로고침 전에 각 업무 화면의 저장·등록을 완료해야 합니다. 모든 화면의 미저장 입력을 재실행 후 복구하는 기능은 아닙니다. 붙여넣기 주문등록 등 웹 자체의 초안 복원은 해당 기능의 범위를 따릅니다.

탭 하나를 닫을 때는 화면 자체의 미저장 경고도 따릅니다. 창 전체 또는 프로그램 종료 시에는 해당 탭들의 미저장 입력을 버린다는 확인을 받습니다. 기본 선택은 계속 작업입니다.

모든 창은 로그인 계정 하나를 공유합니다. 로그아웃·계정 변경 시 기존 계정 화면이 잠기고, 다른 계정 로그인 시 이전 화면과 초안 저장소를 정리합니다. 여러 계정의 동시 로그인은 제공하지 않습니다.

## 연결과 업데이트

인터넷과 기존 Nenovaweb 서버 연결이 필요합니다. 연결 실패 뒤 등록·확정 작업을 자동 재전송하지 않습니다. 처리 결과가 불확실하면 업무 화면에서 저장 여부를 확인합니다.

웹 화면 변경은 서버의 최신 화면으로 반영됩니다. PC의 탭·창 관리 기능과 메뉴 목록 업데이트는 새 설치파일로 진행합니다. 자동 설치 업데이트는 포함하지 않습니다.

제거는 Windows 설정의 설치된 앱에서 **Nenova Desktop**을 선택합니다. 기존 ERP 원장과 `nenova.exe`는 제거 대상이 아닙니다.
