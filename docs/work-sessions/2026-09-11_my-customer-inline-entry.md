## 고정된 결정

- 로그인 계정 담당 업체(`IsMine=1`)는 기존처럼 업체 버튼의 맨 앞에 둔다. 나머지 활성 업체는 최근 주문순으로 계속 검색·선택할 수 있다.
- 업체 선택은 더 이상 별도 집중 화면으로 이동하지 않는다. 차수·업체 버튼을 남긴 채 아래 품목표를 즉시 다시 읽는다.
- 품목표에서는 사용횟수를 숨기고, 현재 주문·입력 수량·입력 단위(박스/단/송이)·입력 후 수량만 보인다.
- `콜롬비아카네이션`처럼 품종 헤더가 있는 경우 표시명 선두의 `CARNATION`만 화면에서 감춘다. 원본 품목명, 검색, API payload, 저장 값은 바꾸지 않는다.
- 1920×1080, 100%를 기준으로 품목표는 자체 스크롤하고 입력 품목 요약은 바로 오른쪽에 둔다.

### 1. 사용자 요청 — 한 화면에서 업체·품목·입력 수량 확인

**Q.** 내 업체 주문등록에서 업체를 다시 선택하기 위해 화면을 되돌아가지 말고, 업체 선택 뒤 같은 화면 아래 품목을 나열해 수량을 입력하고 입력 품목도 바로 옆에서 보게 해 달라고 요청했다.

**A.** `focusMode` 전환과 ‘차수·업체 다시 선택’ 동선을 제거했다. 차수 및 업체 버튼은 계속 보이며 업체 변경 시 해당 업체·선택 차수의 조회 결과만 갱신한다. 입력 품목 요약을 품목표 오른쪽 패널의 첫 영역으로 이동했다.

**결과.** `pages/orders/my-customers.js`

### 2. 사용자 요청 — 카네이션 표기 중복·사용횟수 제거·더 많은 품목 표시

**Q.** 콜롬비아카네이션 품종 묶음 안의 `CARNATION` 중복 표기와 사용횟수를 없애고, 한 화면에 최대 품목을 보게 해 달라고 요청했다.

**A.** `compactCustomerProductLabel`을 추가해 카네이션 그룹의 화면용 영문 접두만 제거했다. 사용횟수 열을 삭제하고 행/헤더 높이를 줄였으며 품목표를 화면 높이 기준 내부 스크롤로 만들었다. 현재 주문과 입력 후 값을 단위와 함께 유지한다.

**결과.** `lib/myCustomerOrderEntry.js`, `pages/orders/my-customers.js`, `__tests__/myCustomerOrderEntry.test.js`, `docs/contracts/my-customer-order-entry.json`
