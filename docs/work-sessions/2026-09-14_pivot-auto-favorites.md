## 고정 결정

- 페이지 진입과 유효한 연도·세부차수 변경은 자동 조회한다.
- 행·열·값·필터 드래그와 좌클릭 메뉴는 동일 배치 경로를 사용한다. 이동 시 원본을 재조회하지 않고 재집계한다.
- 즐겨찾기는 서버의 현재 사용자 목록이다. 이름으로 새 저장/선택 덮어쓰기/불러오기/삭제한다.
- 조합을 불러와도 선택 차수는 바꾸지 않는다. 수량·매입단가 같은 원본 자료는 저장하지 않는다.
- 마지막 화면은 이 브라우저의 인증 사용자별 키로 저장한다. 이름 있는 즐겨찾기는 같은 계정의 다른 PC에서도 조회 가능하다.
- 기존 사용자 구분 없는 localStorage 키는 자동 승계하지 않는다.

### 1. 요청

**Q.** 새로고침 없이 자료가 보이고 사용자별 즐겨찾기 조합이 저장되며, 필드를 행·열로 옮길 때 실제 피벗이 바뀌어야 한다.

**A.** EXE의 FormQuantityPivot_Load → SetCombo/GetData를 확인했다. 자동 조회, 개인 즐겨찾기, 모든 영역 이동과 접힌 그룹 해제를 구현했다. 개인 설정 복원 전 편집 차단, 로그인 8초 제한, SHA-256 열 너비 식별자도 추가했다. 로컬 계약·UI·빌드 및 원격 ERP Contract Guard 통과. 운영 배포 후 조회 전용 확인을 진행한다.
