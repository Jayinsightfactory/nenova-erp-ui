# 업무 드라이브 차수 우선 탐색 / 세부 분류

## 요청 → 결정
- 차수는 왼쪽 첫 영역, PC별 업로드는 오른쪽 끝에 배치. PC 현황 접기 제공.
- 기존 8개 대분류 아래 파일명 기반 세부 분류 버튼과 건수 제공.
- 원가자료/운임·물류/통관·관세, 지출결의/송금·결제/손익·매출보고 등 업무별 세분화.
- 미분류는 확장자로 엑셀/PDF/문서/이미지/기타 구분. 불명확한 파일은 각 대분류의 기타로 보존.
- 목록, 검색, 최근, 칸반에 동일 필터. 대분류 전환 시 세부 선택 초기화.

## 안전 범위
- 서버가 허용한 파일 목록만 대상으로 하는 읽기 전용 UI 분류.
- 기존 대분류, 민감 여부, 권한, 실제 파일, 원가 자동 업로드 규칙 변경 없음.
- MSSQL/ERP 주문·분배·재고·견적·손익 원장 변경 없음. dnSpy 신규 업무 계약 대상 아님.
- 로컬 orchestration 문서 경로는 존재하지 않음; 위임 없이 메인 작업에서 수행.
