# 피벗 필터 값 나열 순서

## 요청과 기준
필터 실제 값의 순서를 위/아래 이동 또는 오름/내림차순으로 지정하며, 같은 순서를 피벗 행/열과 엑셀에 반영한다. 필드 버튼의 배치 이동과 구별한다.

| 동작 | 기본/규칙 | ERP 원장 | 개인 설정 |
|---|---|---|---|
| 순서 초안 | 필터 안에서만 편집, 취소/닫기 시 폐기 | 전부 보존 | 변경 없음 |
| 순서 적용 | valueOrders[field] 원본 primitive 배열; 수동 순서 우선, 새 값은 뒤에 표시 | Order/Shipment/Stock/Estimate/WebProfitReport 보존 | 사용자별 마지막 화면 |
| 오름/내림/기본 | 수동 순서 해제, 기존 sort 사용; 기본은 기존 표 순서 | 보존 | 같은 설정 |
| 즐겨찾기 | 기존 schemaVersion=1에 optional valueOrders, 과거값은 빈 객체 | 보존 | 기존 인증 UserFavorite만 명시 저장 |

NULL/빈문자/선행0 구별, 중복/잘못된 필드 정규화, 정렬로 집계 수량 변화 금지. 검색 중 순서 이동은 비활성화해 숨은 값 이동 혼란을 방지한다. 필터 선택과 순서는 독립이며 필터 초기화는 선택만 해제한다.

## 검증 기준
교차연도 같은 차수 분리, 원본/합계 보존, row/column/export 동일 순서, 빈 값/0/새 값/오래된 즐겨찾기, 취소와 적용 분리, 1920×1080 및 작은 화면.

## 구현·검증
- 사용자 지정값 다음의 새 값은 자연 오름차순이며 필터/행/열이 같은 comparator를 사용한다. rank map은 필드별 한 번 생성한다.
- 메인: 설계/계약/UI/검토/배포. IMPLEMENTER: 준비된 모델·직렬화·테스트 파일만 P0_LOCAL, 도구 정책에 따라 상속 모델. 코드 외부 쓰기 없음.
- ERP 전체 계약, pivot, manifest, dnSpy evidence, write guard 통과. 순서 변경 전후 전체 cellMap 동일(2025/2026 같은 차수 포함), XLSX 및 즐겨찾기 roundtrip 통과.
- 로컬 API 완전 격리 fixture 실브라우저: CL22 → null → 0012 수동 순서, 취소 원복, 적용 후 행 순서, 새로고침 유지, 내림차순, 검색 시 이동 차단 확인. 총수량34 보존, 콘솔 오류0.
- 1920×1080/100% 캡처 확인, 1280×800 필터창 화면 내부 위치 확인. 운영 원장·개인 즐겨찾기를 시험 저장하지 않음.
- 독립 검토 후 기본값 목록을 원본 등장 순서로 일치시켰다. 기존 필터가 하나의 표시값으로 묶는 타입 변형(숫자0/문자0)은 순서 이동 시 모든 원본 멤버를 함께 보존하여 마지막 값만 남는 손실을 방지한다. 기존 필터 선택 의미는 변경하지 않는다.
