## 고정된 결정
- 신라를 라움·초이문과 같은 결산 화면의 별도 업체 탭으로 추가. 공유단가 전파 대상은 기존 라움+초이문만.
- 엑셀 차수로 보존하며 전산 차수 메모는 표시만 한다.
- 원본 1~26차 60:40, 27차부터 80:20. 전차수에 80% 일괄 적용 금지.
- 15차 염색 호접48개는 사용자가 확인한 무상입고0원. 35차 빈 품명은 호접 화이트.

### 1. 사용자 확인과 구현
Q. 신라 결산과 매입단가도 같이 표시하고, 차수별 6:4/8:2를 유지해달라.
A. 신라 전용 파서, 연도/차수 선택 미리보기, 독립 단가 관리, 원본 메모를 구현했다. 일반 전체저장은 동시 변경 유실을 방지하려고 신라에서 막고, 단가는 기존값 대조 후 저장하는 별도 경로를 사용한다.

### 2. 검증
Q. 실제 엑셀을 제대로 읽는가?

### 3. 운영 상태와 남은 작업
A. 운영27b5bd3f에서 신라 버튼, 명시 연도, 업로드 버튼과 독립 안내가 나타난다. 로그인된 사용자 화면의 신라 결산 목록은 현재0건이다.
- Chrome 파일선택 API가 Not allowed로 로컬 원본 첨부를 차단. 지원 문서에 따라 ChatGPT 확장 프로그램의 파일 URL 접근 허용 또는 사용자의 직접 원본 선택을 요청했다. 보안 설정을 임의 변경하거나 다른 방식으로 우회하지 않았다.
- 1920×1080 CSS viewport에서 가로폭1920/가로 잘림없음, 콘솔 오류/경고0건 확인. 기존 Chrome80% 확대율은 자동 단축키로 변경되지 않아100% 검증 완료로 주장하지 않는다. 실제 이미지 캡처는 파일선택창 상태에서 시간초과로 미완료.
- 실제 저장/재조회/운영 단가수정/운영 다운로드 검증은 원본 선택 후 이어서 필요.
- 임시 로그 .agent-shilla-verify.log는 커밋 대상 아님. 이 문서는 후속 운영 확인 전 로컬 작업기록이다.
