# 패킹 매칭 동기화·원가 헤더 코드 전용 배포

## 요청과 기준

운영 DB 변경 없이 검증된 웹 코드만 배포하고 매칭 상태·원가 다운로드를 확인한다.
기존 작업공간의 미커밋 DB 실험·SQL 패치·다른 작업은 포함하지 않는다.
최신 master의 별도 작업공간에 명시 파일만 옮겼다.

| 작업 | 운영 ERP/웹 SQL | 웹 코드/파일 |
|---|---|---|
| 코드 배포 | 마이그레이션·보정·재계산 금지 | 검증된 매칭 UI·XLSX 출력 반영 |
| 매칭 화면 점검 | 조회만; 초안/매칭/입고 저장 금지 | 브라우저 내 선택·해제 표시 검증 |
| 승인 원가 다운로드 | 기존 승인값 GET만; 승인/등록 금지 | 파일 수신·헤더 검사 |

기존 배포가 스키마 적용13개를 무조건 실행하여 코드 전용 요청과 충돌했다.
push/default workflow_dispatch는 마이그레이션을 건너뛰고, 별도 승인 후 명시
`apply_db_migrations=true`인 수동 배포만 실행하게 보호한다. 실 shell 조건에
node marker를 주입한 테스트로 누락/빈값/false/0/TRUE 모두 SQL 단계0회임을 검사한다.
EXE/SP/SQL writer, 재고 차수 계산 패치는 이번 배포에 포함하지 않는다.

## 기존 검증

원본41-2 중국 XLSX 28행, 159박스/2380단/30900송이로 격리 실제 웹 입고와
도착원가 다운로드를 완료했다. 상단 미매칭2→1→0→해제1→재선택0 확인.
중국 항공 상단 병합 B5:B6/C5:C6 해제, C5:D5 병합 외 기존 서식/금액 보존.
직전 전체ERP 계약·dnSpy·쓰기 가드·격리 빌드 PASS. 실제41-2 원가 승인값을
입력한 시험은 아니므로 시험 파일을 운영 승인 자료로 취급하지 않는다.

## 배포 결과

새 master 기반 체크아웃에서 빌드, 전체 ERP 계약, 계약 manifest 108개,
ERP 쓰기 가드(변경 API 0개), dnSpy 근거 검사를 통과했다.
실 shell 코드 전용 조건 7개 테스트도 통과했다. 빌드는 운영 DB 환경값 없이
외부 소켓 차단 preload로 실행했다. 실제 PR/배포/운영 읽기 결과는 후속 기록한다.
