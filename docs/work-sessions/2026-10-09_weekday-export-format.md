**Q.** 출력물 연도를 빼고 날짜는 10/07처럼, 품목은 한글화하며 0은 빈칸으로 출력한다.

**A.** 날짜는 MM/DD, 차수는 대/세부차수만 표시한다. 내부 열 식별키는 연도를 유지해 교차연도 수량 혼합을 방지한다. 명시 Product.DisplayName을 비교 응답과 matrix 표시 메타데이터로 전달하고 엑셀에 우선 사용한다. 없으면 기존 suggestDisplayName 사전을 사용하고 미등록 토큰은 임의 번역하지 않는다. 항목과 소계의 숫자0은 서식이 있는 빈 셀로 출력하되 내부 합산에는0을 유지한다. 음수·양수는 수치로 남기며 품목 행 자체는 제거하지 않는다.

**기준선.** 범위·기존 양식·전체 웹 품목·윌슨 분리·읽기 안전·계약 검증 적용. 화면틀·입력·확정·이동·진행률 신규 변경 해당 없음. XLSX 인쇄양식 크기는 화면1920×1080 기준의 예외이며 원본 양식을 유지한다.

**검증.** 생성 파일 재읽기에서 등록/자동/혼합 한글명, MM/DD, 연도별 키,0/미확인 빈칸·소계0, 음수잔량, 동적 품목 그룹과 원본 스타일 보존 테스트 통과. ERP 계약·dnSpy evidence·manifest·쓰기 가드·최종 production build 통과. 독립 검토에서 발견된 혼합명 변환 누락을 수정했다. Excel 직접 렌더링은 미실시다.
