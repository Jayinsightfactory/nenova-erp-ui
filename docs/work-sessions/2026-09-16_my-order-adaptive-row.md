# 품목 행: 기본 한 줄, 긴 이름만 줄바꿈

Q. 모든 품목을 두 줄로 표시하지 말고 짧은 품목은 한 줄, 긴 품목만 줄바꿈해 달라.

A. 이름·기존수량·입력·단위·최종수량을 하나의 grid 행으로 배치한다. 이름만 가변 폭/자동 높이이며 생략은 금지한다. 인접한 짧은 카드가 긴 카드 높이로 늘어나지 않도록 align-items:start를 사용한다. 입력/X 분리 유지.

부작용: CSS만 변경. 모든 Order/Shipment/Stock/Estimate/WebProfitReport 원장, API, 업무키, 수량 환산 및 저장 핸들러 보존. 1920×1080 및 좁은 화면에서 짧은 이름 한 줄/긴 이름 줄바꿈/입력 접근성을 모의 데이터로 검증한다.
