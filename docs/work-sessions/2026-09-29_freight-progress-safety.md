## 고정 결정 / 기준
- 선택 행 여러 개 동시 적용, 기존 최종값 저장·잠금·작업번호·원자성 유지.
- 자동 환산 불명 시 모든 적용 행의 박스수를 직접 입력하고 명시 확인한 경우만 수기 사용.
- 수기 확인은 범위·수량·품목 선택 변경 시 해제. 연도/차수/출고일/재고 가드는 우회하지 않음.
- 기존 조회 자료로 운임 초안 자체를 구성할 수 없는 경우 임의 차수/출고일을 만들지 않음.
- 누적 진행은 실제 클라이언트 단계이며 서버 내부 진행률을 추정하지 않음.
- 실패 감사는 성공 영수증과 다른 ActionType. 응답 유실/commit 불명/busy는 UNKNOWN.
- 실패 payload는 허용 업무 필드만 저장; 편집 토큰/비밀값 제외.
