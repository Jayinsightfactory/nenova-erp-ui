| 항목 | 내용 |
|---|---|
| 화면 / 날짜 | orders/paste / 2026-09-15 |
| 부작용 | 초안 표시·분석 입력만 변경, ERP 원장 보존 |

## 결정

- 분석 버튼은 입력 패널 상단 sticky toolbar에 둔다.
- 데스크톱 입력 패널과 textarea 세로 높이를 확장한다.
- 드래그한 정확한 글자 범위만 제외하며 같은 범위 재선택으로 해제한다.
- 제외된 글자는 공백으로 마스킹해 줄바꿈과 인접 수량·품목을 보존한다.
- 주문 AI와 기초재고 파서 모두 동일한 필터를 사용한다.
- 원문 수정 시 제외 범위 초기화, 선택 문자열이 달라진 stale 범위는 무시한다.
- 제외 변경 뒤 이전 분석 결과를 비워 재분석 없이 기존 결과로 저장하지 않는다.

### 요청과 결과

**Q.** 분석 버튼이 아래에 숨어 있다. 영역을 키우고 줄이 아닌 단어 단위로 제외하게 해달라.

**A.** 상단 분석 버튼, 입력 영역 확장과 단어 선택/해제를 구현했다. ERP 저장 정책은 보존했다.

**검증 기준.** 글자 범위·역방향 선택·부분 해제·Unicode·기존 줄 제외 호환,
원문 변경 안전성, 1920×1080 버튼 노출과 가로 잘림, 분석 요청 텍스트 검증.
운영 ERP 쓰기와 유료 AI 호출은 검증에서 하지 않는다.

pages/api/orders/parse-paste.js의 기존 사용자 변경은 포함하지 않는다.
