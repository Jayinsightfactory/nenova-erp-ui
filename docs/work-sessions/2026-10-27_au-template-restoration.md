## 고정 결정
- 운영 DB 보정 금지. 이전 SELECT-only 44-01 인보이스/품목 snapshot을 격리 fixture로 사용.
- 원본 38-1 통관비 고정요율 460/33000/10000/90000은 수정 가능한 과거 기본값이며 현재 확정 비용이 아님.
- 원본 양식 계산을 기본 활성 시트로 추가. 기존 승인/미승인 계산본과 원본수식 비교 시트 그대로 보존.
- 매주 확인 판매가 O열 입력 시 N/Q/R/S/T 및 R11/S11/T11 계산. 미입력 판매가를 0원 매출/손실로 만들지 않음.
- 과거 참고판매가를 38-1로 명시하고 현재 판매가에 자동 적용하지 않음. 원본 /0.77 수식과 15% 제목의 불일치 안내.

### 1. 빈 셀 원인과 복원 요청
**Q.** 기존 호주 원가자료와 비교해 빠진 고정값과 수식 복원, 미확인 비용만 입력, 44-01 다운로드 검증 후 배포.
**A.** 기존 exporter는 양식 스타일만 보존하고 고정내용을 비운 뒤 일부 결과만 채웠다. 해시로 묶인 원본 콘텐츠를 추출, 전체 동적 행 범위와 통관·판매 수식을 복원했다. GW 누락은 입력 필요로 표시하고 합계 직접 입력도 지원한다.

### 2. 판매·이익 열/상단 합계
**Q.** 판매·매주확인·이익·이익률·총판매가·총이익 및 상단 합계도 빠진 것 같다.
**A.** 해당 제목과 수식 전부 복원. 실제 판매가 미입력 칸 O열만 선택 입력으로 남긴다. 숫자 0은 명시 판매가로 인정, 미입력은 공란 계산, 분모 0 이익률 오류 방지.
