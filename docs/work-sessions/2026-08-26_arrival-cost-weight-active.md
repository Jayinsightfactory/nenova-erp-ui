## 이어받을 때 고정된 결정

- 특별기준 안내는 CW/GW 용어 대신 `콜롬비아장미 면 활성화`처럼 품종으로 말한다.
- 품종 버튼에도 같은 문구를 붙인다. 필터 규칙은 그대로다.

## 질문 → 답변

### 1. 2026-08-26 09:21 — GW/CW 분류

**Q.** gw/cw 는 어떻게 분류되게 설정된거지?

**A.** 엑셀 시트 머리 GW/CW를 행에 저장하고, 콜롬비아만 화면에서 가린다. CW>GW=장미만, CW≤GW=장미 숨김(카네이션·알스트로). 마스터 설정값은 없다.

### 2. 2026-08-26 09:37 — 활성화 안내

**Q.** 안내를 콜롬비아장미 면 활성화 이런식으로 표시해줘야 해.

**A.** 힌트와 품종 버튼을 `33-1 콜롬비아장미 면 활성화` / `콜롬비아카네이션·알스트로 면 활성화`로 바꿨다. 숨기는 규칙은 그대로다.
