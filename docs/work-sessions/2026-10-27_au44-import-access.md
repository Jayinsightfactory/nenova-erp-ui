# 44-01 호주 Woolly bush 수입부 권한 오류

| 항목 | 내용 |
|---|---|
| 기간 | 2026-10-27 |
| 화면 | 수입부 업무도구 / Woolly bush 품목·입고량 분류 |
| 운영 부작용 | SELECT 조회만. 계정/입고/재고/원가 수정 없음 |
| 배포 | 검증 후 PR/배포 결과 후속 기록 |

## 고정 결정
- Authority4/7은 기존 수입부 역할이다. DeptName 공란이어도 입고 업무 허용. 관리자 승격이나 DB 계정 변경 아님.
- 비활성/삭제/무식별 및 다른 부서는 계속 거부. 요청 body 역할 신뢰 금지.
- Woolly bush는 파일별 품목·수량 분류. 공용 자동별칭 금지 및 원문4합계 보존.
- 최신 코드의 Woolly 행→입고 준비 연결은 이미 있으므로 중복 변경하지 않음.

### 1. 분류 버튼에서 관리자 오류
**Q.** 마지막 두 품목은 관리자 오류로 직원이 작업 불가. `Woolly bush 품목·입고량 분류` 클릭 때 발생.
**A.** canManageInvoiceReceipt가 부서명/관리자만 보고 숫자4를 놓침. 읽기 전용 계정 집계에서 수입부4계정의 부서명 공란 확인. 인증된 역할4/7 허용을 추가하고 API GET/POST·operation wrapper 테스트. 운영 AppLog 조회에 해당 실패 기록은 없어 로그에서 403을 직접 확인했다고 주장하지 않음.

### 2. 매번 수동 매칭 / 마지막 두 행
**A.** 저장된 11행과 공용 매칭 비교: 일반9행은 현재 저장 매칭으로 MANUAL 재사용. Woolly2행은 AI description에 색상이 누락돼 ALLOCATION 유지. 원본에는 Green/Red Tip이 있지만 순서만으로 자동 확정하지 않음. 격리11행 fixture에서 분류 후 Green6박스180단900송이, Red4박스120단600송이, 전체65박스/AUD20443.75 보존 통과.
별칭 seed만 있는 이름이나 다른 표기는 아직 확인 대상이며 모든 새 인보이스 자동매칭 완료라는 뜻은 아니다. 추가 유료 AI 분석 없음.

## 검증
- 관련 권한·공용매칭·분류22테스트 통과. 실제PDF 시각 대조 후 제품표만 fixture화, 은행/개인정보 제외.
- 실제 dnSpy ExcelLoadingPackingList 실행, 수량 필드/입고→재고계산 순서 확인. writer/SP 변경 없음.
- 전체 ERP 계약/manifest/write guard/dnSpy/build 및 배포 결과 후속 기록.
- 운영 직원 계정으로 실제 분류 저장은 미검증(운영 쓰기 금지 유지).
