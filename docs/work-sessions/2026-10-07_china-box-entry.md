## 대화 결정

**Q.** 중국 물량표에서 박스번호를 셀에 직접 입력하는 것 외에 `품목·업체·수량·박스 입력` 형태로 여러 건을 빠르게 입력하고 한 번에 적용할 수 있게 해 달라.

**A.** 기존 셀 편집은 유지하고, 별도의 일괄 입력 모달을 추가한다. 여섯 행부터 입력할 수 있고 Enter로 다음 칸으로 이동하며 마지막 칸에서는 다음 행을 만든다. 입력 전체를 검증한 뒤 한 번에 현재 작업본에 반영한다. 이후 기존 `작업 저장`을 눌러 서버 작업본에 저장한다.

박스번호는 수량과 독립 필드이며, 기존 패킹리스트의 박스별 배정량에 영향을 주지 않는다. 직접·일괄 수정은 같은 셀 이력 형식으로 기록한다. 표의 품목합계·업체합계는 수량 기준으로 즉시 재계산된다. 후속 요청에 따라 박스번호는 웹 작업 화면의 참고값으로만 유지하고, 다운로드 엑셀 수량 셀에는 숫자 수량만 내보낸다. 이 화면은 웹 작업본 저장 및 엑셀 다운로드 기능이며 ERP 원장에 직접 수량 업로드하는 API는 호출하지 않는다.

기능 구현 및 자동 검증은 완료했으나 운영 배포 전이다. 운영 DB 확인은 조회 이외에 실행하지 않았다.
