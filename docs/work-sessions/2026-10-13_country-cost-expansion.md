# 국가별 인보이스 도착원가 확장

## 요청과 보존 범위

인보이스 인식값과 사용자가 확인한 무게·운임·환율·통관비를 국가별 기존 원가식에 적용하고 원본 서식으로 출력한다. 기존 입고 재채택 기능은 제외한다. 운영 테스트 입고·재고 쓰기, EXE/SP/스키마 변경, 유료 AI 재분석은 수행하지 않는다.

## 구현

- 기존 중국 해상·항공 및 네덜란드 외 미국·베트남·호주·뉴질랜드·에콰도르 공식과 콜롬비아·태국 그룹 배분식을 source hash/sheet/cell로 고정한다.
- CNF 포함 운임은 추가 운임 0을 직접 확인해야 하며 자동으로 입력하지 않는다. 과거 환율·관세·고정비를 현재 기본값으로 사용하지 않는다.
- 박스·단·송이 변환은 명시 계수와 실제 입고 수량으로 검증한다. 그룹 분모·행 수량 합·CO GW/CW 합이 다르면 승인하지 않는다.
- TH 검역 손실·소독비 반영 확인을 별도로 받는다. 원본 P15의 잘못된 단 원가는 복제하지 않는다.
- 입력 변경 시 공식 적용 확인을 해제한다. 승인 입력 재조회는 수량 환산·그룹 문자열과 값을 복원하되 적용/손실 확인은 다시 받는다.
- 출력은 승인 snapshot과 현재 실제 입고 MATCH만 사용한다. 원본 색상·너비·높이·병합·인쇄 설정을 보존한 현재 승인값 보고서이며 역사값·수식 캐시·판매가를 유출하지 않는다.

## 검증 기록 (진행 중)

- 실제 decompiled ExcelLoadingPackingList.MakeTempTable에서 BoxQuantity/BunchQuantity/SteamQuantity 및 UPrice/TPrice 분리를 다시 읽었다. native writer 변경 없음.
- 초기 코어 165개 및 추가 TH 승인/복원 테스트 통과. mock SQL 테스트는 실제 운영 저장 증거가 아니다.
- 실제 Chrome source component fixture: 10공식 × 1920×1080/1280×800, 100% 배율, 20시나리오 계산·키보드 입력 후 확인 해제·가로 overflow 없음, API 전송 0, JS 오류 0. live 운영 저장 검증이 아니다.
- 10개 출력 fixture를 artifact-tool로 읽기 전용 렌더했다. NL 수량 통화서식, AU/NZ/EC 긴 헤더, VN/NZ 긴 금액 소수점을 수정하고 재렌더했다. 원본 폭·색상은 유지한다.
- 독립 검토에서 TH/CO 그룹 박스수와 실제 입고 박스수 대조 누락을 발견해 보완했다. 99/1 가짜 배분, 누락·취소·BOX 불일치 회귀를 포함한 그룹 67개 및 코어 24개 테스트 통과. 승인 검증을 완화하지 않고 export fixture도 실제 박스수를 제공하도록 수정했다.
- 보완 후 20개 브라우저 시나리오 및 exporter 22개 재통과. 최종 통합 회귀·배포는 아래 후속 기록 전까지 미완료다.
- ERP 전체 회귀, dnSpy 근거, manifest, write guard 초기 통과. 최종 변경 후 재검증·빌드·배포 결과는 후속 기록한다.

## 최종 로컬 통합 검증

- master d9b4c946를 통합했다. 이전 squash 병합과 충돌한 파일은 기존 c593135d와 master 내용이 동일함을 확인하고 이번 확장본을 유지했다. INDEX는 양쪽 기록을 모두 보존했다.
- 국가별 계산·승인·출력 236개 통과, 최종 전체 ERP 계약/교차연도 회귀 통과, dnSpy evidence 통과, manifest 102개 통과, write guard 통과(변경 API 0개), production build 통과.
- PR: https://github.com/Jayinsightfactory/nenova-erp-ui/pull/1035 . 이 기록 시점에는 원격 CI/배포 대기이며 운영 완료를 의미하지 않는다.

## 근거와 한계

국가별 셀 근거와 원본 결함은 `docs/plans/invoice-additional-country-evidence.md` 참조. 실제 최신 인보이스에 입력할 환율/비용/손실은 사용자가 확인해야 한다. 시험값을 운영 승인 원가로 보고하지 않는다. 실제 업무 파일·스크린샷·임시 스크립트는 outputs에만 두고 커밋하지 않는다.

메뉴 기본값: 기존 화면틀 유지·페이지 주 세로 스크롤·1920×1080/100%·native 입력/선택 키보드 조작 적용. 넓은 표 가로 스크롤은 예외. 인쇄 크기는 원본 설정 유지.

하위 작업은 기존 세션 작업자를 재사용했다. 메인은 설계·계약·ERP 영향·통합·최종 검토를 담당하고 구현자는 서로 다른 모듈/UI/export 파일만 수정했다. 지정 구형 비용 모델 일부가 제공되지 않아 기존 사용 가능한 모델 설정을 유지했다. 하위 작업 권한은 P0_LOCAL이다.
