## 고정된 결정
- 업체명 3행, CL 4행의 별도 실제 셀. 기존 3행 헤더도 입력 허용.
- 지역은 작업 물량표 내 설정이며 Customer 원장은 변경하지 않는다. 업체 열 전체를 이동한다.
- 업체 추가와 품목 추가는 원본 화면 위 검색 팝업으로 분리한다.
- 입고만 있는 품목도 표시하며, 빈 분배 셀을 자동 주문으로 만들지 않는다.
- 저장은 초안 저장이다. 실제 ERP 적용은 재검증·명시적 적용과 기존 CATEGORY_REPLACE 계약을 따른다.
