## 고정된 결정

- 반복 상태 문구는 셀 배경색으로 대체한다.
- 수량·초안·변경·선출고와 실제 오류는 보존한다.
- 기준 확정 버튼과 출고 없는 품목을 포함하는 필터는 보존한다.

## 질문 → 답변

**Q.** 미분배 표시와 기준 미확정 문구가 필요 없다. 색상으로만 표현해 달라.

**A.** 요일 셀의 미분배 문구와 최초분배·세부차수 잔량·차수 잔량의 반복 기준 미확정 문구를 제거하고 셀 배경색으로 표시한다. 수량과 기준 확정 버튼, 품목 범위 필터, 상세 정보는 유지한다. 변경·초안·선출고 강조색을 우선한다.

## 범위·근거

화면 표시만 변경한다. 사용자 동작에 따른 OrderDetail, ShipmentDetail, ShipmentDate, ShipmentFarm, Estimate, WebProfitReport 및 재고·매출 원장은 모두 보존한다. 읽기 API와 SQL·자격 판정·저장 요청은 변경하지 않는다. 직전 상태 안내 작업의 실제 FormEstimateView dnSpy와 교차연도 SELECT 근거를 유지한다.

## 검증·이어받기
