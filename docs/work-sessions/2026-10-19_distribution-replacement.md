## 고정 결정
- 양재동 6품목은 현재 출고 대상이 아니다. 과거 주문 복원 금지.
- 연도+세부차수+업체+품목으로 전체교체 범위를 판단한다.
- 주문 없이 남은 분배도 누락 취소 대상에 포함한다.
- 미매칭 또는 검증 후 상태 변경은 부분 저장하지 않고 재검증한다.
- 운영 기존 잔여 데이터 보정은 이번 요청 범위 밖이다.

### 1. 요청과 결과
**Q.** 배포 코드를 확인해 전체교체에서 누락 업체/품목이 남지 않도록 보완·검증·배포. 운영 DB 수정 금지.

**A.** 서버 발행 검증 서명, 강제 전체교체, 원본 분배 누락 검사(트랜잭션 잠금 포함), 늦은 확정 변경 중단을 추가했다. 사용자에게 누락 취소 건수와 범위를 표시한다.

**검증.** 전체 ERP 회귀검사·빌드·계약검사·쓰기 범위 검사 통과. 주문 없는 6품목의 실제 미리보기 생성 테스트와 서명/누락 차단 테스트 통과. 운영 실제 저장은 금지되어 미검증.

**남은 확인.** PR CI 및 배포 완료, 운영 읽기 전용 화면 확인. 기존 6건의 삭제/보정은 실행하지 않는다.
