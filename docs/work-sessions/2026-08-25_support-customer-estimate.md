## 이어받을 때 고정된 결정

- 처리상태의 `{거래처명} 견적서 열기`는 화면 선택 연도·부모차수 + 해당 행 CustKey로 견적서관리 팝업을 연다.
- 예: 청화원예 → `/estimate?popup=1&year=YYYY&week=WW&custKey=&highlightDeductions=1`.
- 같은 33차라도 2025/2026을 섞지 않는다. 화면 선택 연도가 정답이다.
- 팝업은 기존 GetData/GetDetail만 재사용하고 Estimate를 쓰지 않는다.
- 미확정 포함은 이번 딥링크에만 적용하고 localStorage 토글을 바꾸지 않는다.
