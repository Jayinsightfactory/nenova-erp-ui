# PR1641 AWB 오인식 수정

## 요청과 결정
- 전년도 동일 차수, 차수 없는 AWB, 호주 AWB, PC 자동수집 shared-awb 시험 XLSX가 콜롬비아 게이트를 풀던 반례를 수정한다.
- 연도·세부차수·번호와 실제 원본을 확인할 때만 반영 가능. 부족한 증거는 보류하며 무료/유료 AI를 호출하지 않는다.
- 운영 DB 수정·마이그레이션·입고/원가 저장 테스트 금지. 코드만 배포한다.

## 구현
- `collectArrivalDriveAwbEvidence`: 실제 XLSX 헤더의 유일한 AWB 번호, PDF magic/SHA256/Air Waybill 본문/콜롬비아/사업연도/번호·체크디짓 대조. 파일명 명시 연도·차수와 cycle 충돌 검증. 다른 국가·삭제·시험·다운로드·egress 차단.
- 파일명 또는 임의 index/request proof만으로 통과 금지. 검증 Map은 서버만 만든다.
- `verifiedCandidates`: GET 표시·자동 예약·수동 실행·저장 직전 공통 검증. 원본과 AWB evidence hash 변경 시 기존 importer 호출 전 차단.
- 검증 전용 `getFileForVerification`은 기존 접근/삭제/path 검사를 공유하지만 index에 다운로드를 쓰지 않는다. 읽기→watch→다시 읽기 무한 예약을 방지하며 실제 다운로드 감사는 유지한다. 임시 폴더 index 원문 지문 보존·접근거절·삭제 반례 검증.
- 기존 SQL/테이블/산식/중량/환율/입고·재고·매출·견적·손익 변경 없음. 명시 범위가 없는 원본·스캔 PDF는 검토 필요로 남는다. 외부 발행자의 전자서명 진위까지 보장하는 기능은 아니다.
- PDF 검증은 파일당 20MB/10쪽, 후보 최대10개, 총15초 제한. 가장 최신 CO 원가 후보만 읽는다.

## 근거와 검증
- 실제 EXE `FormWarehouseView`를 dnSpy CLI로 재추출: WarehouseMaster/WarehouseDetail 조회·삭제 동작 확인. 이번 변경은 그 writer/SQL을 호출하거나 변경하지 않는다. 운영 DB 신규 probe·쓰기 실행0.
- 실제 메모리 XLSX/PDF로 정상1건과 교차연도·다른 차수/국가/번호·명시0/false·해시 불일치·위장 PDF·시험 산출물·proof 주입·삭제/교체 반례 통과.
- production worker 실행 fixture에서 저장 직전 AWB 변경 시 저장0 및 review 확인. 다른 국가 기존 예약/즉시처리/원가 import 중복·롤백·수동 보호 회귀 통과.
- 전체 ERP contract, dnSpy evidence, manifest206, 쓰기 scope(변경API1) 통과. webpack 및 GitHub CI/배포/운영 조회는 후속 결과 기록.
- 메뉴 기준: 기존 reason 표시 재사용, 새 UI/탭/업무순서 없음. 메뉴틀·키보드·사용가이드 영상 변경 해당 없음.
