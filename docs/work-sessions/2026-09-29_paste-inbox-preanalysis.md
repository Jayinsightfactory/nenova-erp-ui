## Q → A

**Q.** 우측에 실제 매칭 업체/품목을 미리 표시하고 Claude 분석이 선행돼야 작업이 빠르다.

**A.** 기존 우측은 전산 이력 대조 결과이므로 미해결 항목에 원문이 남았다. 화면에 보이는 변경 메시지와 가까운 행을 순차 분석하고 실제 업체/품목/수량을 별도 사전 매칭 영역에 표시한다. 적용 완료 판정은 기존 정확한 원문/행ID/업무키 감사만 사용하며 분석 결과와 섞지 않는다.

## 기준·부작용

- 원문 그대로 + 전체 연도/세부차수 캐시 키. 2025/2026 동일 차수는 분리.
- 페이지 인스턴스 전용 메모리 캐시 15분/100건. 브라우저 새로고침 이후 영구 보관하지 않는다.
- 한 번에 분석 요청 한 개, 자동 호출 최대 20건. 이후 명시 분석 가능. 숨김/오프라인/저장/언마운트 대기 작업은 시작하지 않는다. 분석 중 사용자 입력을 바꾸지 않는다.
- 결과 열기는 정확한 키와 유효기간을 검사하고 최신 매칭 정보 및 현재 주문/분배를 재조회한다. 수동 재분석은 캐시 갱신.
- 자동 분석: Customer/Product/OrderDetail SELECT, 기존 모델 호출 기록. OrderMaster/Detail, ShipmentMaster/Detail/Date/Farm, Stock, Estimate, WebProfitReport는 전부 보존.
- 매칭 파란색, 확인 필요 주황색. 기존 적용 이력은 별도 펼침; AI 결과에 적용 완료 의미 부여 금지.
- 기존 두 성분 혼합수량 보존. 원문 업체와 전산 업체명이 다르면 원문 업체도 표시.
- dnSpy CLI FormShipmentDistribution GetCustomerList/ShipmentDate/SteamOf1Box 재실행 확인. 읽기 probe 2026/39-02/478/889 OutQuantity40, Amount2836364,Vat283636,isFix=true,Date1,Farm0,ViewOrder1,FixedView1. 운영 시험 쓰기 없음.
- orchestration MD는 체크아웃에 없음. 하위 에이전트 없이 메인 수행.

기존 적용 이력 계약 및 전체 ERP 검사·빌드·배포 스모크를 필수로 수행한다.
