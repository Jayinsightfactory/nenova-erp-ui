# 네덜란드 물량표 단가 겹침 표시

## 질문

네덜란드 물량표 엑셀 다운로드에 기존 물량표 디자인이 적용되지 않고, 업체별 단가가 별도 열로 추가되어 열이 너무 많아지는 문제 수정 요청.

## 답변·결정

- 업로드 경로도 `xlsx-js-style`로 통일해 기존 색상·테두리·셀 서식을 보존한다.
- 업체마다 단가 열을 추가하던 구조를 제거한다.
- 단가는 기존 수량 셀의 두 번째 줄 사용자 지정 숫자 표시형식으로 보여준다.
- 수량 셀의 실제 값은 계속 숫자이므로 주문 합계와 기존 수식은 단가를 섞지 않고 정상 계산한다.
- 원본 열 수, 병합, 열너비, 색상, 테두리, 헤더, 합계행과 수식을 그대로 보존한다.
- ERP 원장은 읽기만 하며 단가를 ERP에 저장하지 않는다.

## 검증

- 네덜란드 단가 순수함수·UI 계약 테스트
- 샘플 XLSX 값·수식·스타일 검사 및 렌더링
- 전체 Pivot·ERP 계약·manifest·쓰기 가드·Next 빌드
