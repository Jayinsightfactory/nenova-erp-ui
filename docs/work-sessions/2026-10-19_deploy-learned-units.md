## 고정 결정
- 진단은 GitHub 기존 SSH 연결을 사용하며 파일명/통계만 출력한다. 비밀/업무 파일 내용은 출력하지 않는다.
- data/order-import-units.json은 lib/orderImportUnits.js가 저장하는 운영 학습 설정이다. 생성 산출물로 취급하거나 초기화하지 않는다.
- 새 master가 이 파일을 변경하지 않을 때만 기존 내용 그대로 fast-forward를 허용한다.
- 서버에 비공개 백업을 남기며, 백업 이후의 기존 앱 저장도 덮어쓰지 않는다.
- 새 master의 같은 파일 변경, 잘못된 JSON, staged 수정, 다른 미확인 파일은 차단한다.
- DB migration 기본 false, 기존 계약 검사/빌드/스모크를 유지한다.
- 메뉴 기준선: 해당 없음(메뉴/UI 변경 없음). dnSpy·DB probe: 이번 변경에는 해당 없음(ERP writer/reader 변경 없음).

## Q&A
### 1. 기존 수정파일은 무엇이며 왜 배포가 안 되는가?
**Q.** 원인을 모르니 배포까지 해결해 달라.
**A.** 읽기 전용 진단 run39218404660에서 서버의 학습 단위 파일 변경을 확인했다. 생성 이력 두 파일과 package-lock은 기존 허용 대상이나 학습 파일은 미분류여서 배포가 중단됐다. 파일 내용 공개 없이 저장 코드를 확인하고 원본 유지·백업·upstream 충돌 차단을 추가했다.
**결과.** 필수 검사와 PR/배포 진행 중. 운영 반영은 성공한 deploy run으로만 판정한다.
