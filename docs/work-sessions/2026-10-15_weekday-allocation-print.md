# 주광 Excel 최신값 대조와 분배 기준 견적 출력

## 질문 → 답변/결정

- Excel에 웹 최신 수량, 윌슨 구분, 합계·잔량이 들어가는가? 실제 웹 다운로드를 화면 DOM과 대조했다. 활성 57품목 × 54수량열 = 3,078셀 불일치 0. 전체 파일 113품목의 합계 관계 1,356건 불일치 0. 반복 이름 565셀 일치. 웹 0값 840개는 양식의 빈칸으로 표시되고, 미확인/비적용 1,963칸도 빈칸 유지한다.
- 출고일 선택 출력이 안 되는 이유? 기존 버튼과 서버가 확정을 요구했다. 최신 사용자 지시에 따라 주광 인쇄를 별도 저장 분배 기준 API에 연결한다. 기존 ERP 확정 견적 대조 경로는 보존한다.
- 윌슨은 인쇄 때 또 더하는가? 아니다. 저장 ShipmentDate 총량에 이미 포함되므로 한 번만 견적 단위로 출력한다. Excel만 일반/윌슨을 별도 셀로 보여 준다.
- 확정되지 않은 분배도 출력 가능한가? 새 경로는 확정을 출력 조건으로 사용하지 않는다. 미리보기에는 실제 확정 상태 건수를 표시한다. 초안은 먼저 분배 적용해야 한다.

## 기준선

적용: 기존 shell, 페이지 세로·표 가로 스크롤, 키보드 출력·닫기, 1920×1080/100%, ERP 계약·교차연도·native 근거.
해당 없음: 신규 메뉴, DB 쓰기, 재고 SP, 원장 보정.
예외: 사용자 명시 지시로 새 분배 출력에서 native DetailFix=1 제한을 적용하지 않는다. 기존 확정 견적의 의미는 바꾸지 않는다.
