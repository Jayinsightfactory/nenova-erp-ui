# 중국·네덜란드 물량표 최신 입고 차수 및 표시 수정

## 요청과 결정

**요청:** 네덜란드와 중국 물량표 첫 진입 차수는 입고가 있는 최신 차수로 설정한다. 2026년 41-01처럼 입고가 있지만 물량표 결과가 비어 보이는 문제를 해결하고, 중국 수량은 셀 중앙에 정렬한다. 앞선 박스번호 기능 관련해서는 박스번호가 엑셀 수량 업로드에 섞이지 않도록 한다.

**동작:** 차수 목록은 선택 연도 `OrderMaster` 입력차수와 국가별 `dbo.ViewWarehouse.OutQuantity > 0` 차수의 합집합으로 만든다. 첫 진입 기본차수는 해당 국가의 최신 양수 입고 차수이며, 입고가 하나도 없을 때만 최신 주문 차수로 대체한다. 입고 조회는 `OrderYear`로 한정하고 네덜란드는 CounName 네덜란드/Netherlands/Holland/Dutch 변형, 중국은 중국/China 표기만 포함한다. 이전/다음 이동은 합집합 차수 목록을 따른다.

네덜란드/중국 데이터는 선택된 정확 차수로 다시 불러온다. 입고 주차 선택과 수량 표시 변경은 조회 전용이며 주문·출고·재고·견적 원장에는 쓰지 않는다. 중국 수량 표시 CSS는 셀 전체 폭에 맞춰 중앙정렬하고, 중국 엑셀 최종 수량 셀에는 숫자 수량만 출력하며 박스번호 메타데이터는 제외한다.

## 확인 범위와 한계

EXE 기준은 `docs/exe-golden/FormQuantityPivot.md`의 `ViewWarehouse.OutQuantity`이다. 이 변경은 코드에서 41-01 입고주차를 차수목록/기본차수 대상으로 포함한다. 다만 배포 전 운영 DB에서 2026-41-01의 실제 국가별 행을 직접 조회했다는 뜻은 아니며, 실데이터는 배포된 인증 화면에서 선택주차와 피벗 결과를 확인해야 한다.

중국 물량표는 웹 작업본 저장과 엑셀 다운로드 기능이다. 현재 페이지는 ERP 주문수량을 직접 업로드하는 엔드포인트를 호출하지 않는다. 엑셀 다운로드는 ERP 원장 변경과 다르다.
