# 2026-09-15 전산 피벗 필드 값 필터

## 질문 → 답변

- 질문: 피벗의 가로·세로·행·열·값 이동뿐 아니라 필터 버튼을 눌렀을 때 나오는 실제 값 선택도 전산처럼 동작해야 한다.
- 답변: 필드를 필터 영역으로 옮기는 조작과 필드의 실제 표시값을 고르는 조작을 분리했다. 필터 영역의 필드명 버튼은 값 목록을 바로 열고, 다른 영역은 별도 `⌄/●` 버튼으로 같은 목록을 연다.
- 질문: 필터를 적용했는지 바로 알 수 있어야 한다.
- 답변: 필터 영역 버튼에 `전체`, 단일 선택값, `첫 값 외 N`, `선택 없음`, `필터 꺼짐`을 표시하고 적용 중인 버튼을 강조한다.
- 질문: 필터에서 무엇이 바뀌는지 명확해야 한다.
- 답변: 현재 조회 결과의 실제 distinct 값만 체크박스로 제공하며, 선택값은 같은 브라우저 피벗 모델을 통해 화면 집계와 엑셀에 동일하게 반영한다. 전체 선택은 필터 초기화, 전체 해제는 의도적인 0행 결과다.
