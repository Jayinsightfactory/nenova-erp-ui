# 2026-10-07 네덜란드 물량표 매칭 새 창·키보드 조작

## 질문과 결정

- 요청: 업체별 수량 열 폭을 줄여 한 화면에 더 많은 업체를 보이고, 글자와 수량은 더 읽기 쉽게 한다.
- 요청: 미매칭 선택 시 물량표 페이지를 이동하지 않고 별도 창에서 매칭한다.
- 요청: 매칭표에서 원본 품목 옆에 ERP 품목, 원본 업체 옆에 ERP 업체가 나란히 보인다.
- 요청: 모든 Nenovaweb 페이지의 핵심 업무를 키보드로 편하게 조작할 수 있도록 고정 지침화한다.
- 결정: 고객별 폭 52px, 표 기본 글자 14px, 수량 15px 굵게. 표 안 방향키는 조작 가능한 셀 사이를 이동하고 텍스트·숫자 입력의 브라우저 기본 방향키 동작을 보존한다.
- 결정: 팝업은 동일 출처 메시지와 요청 토큰·창 식별자로만 결과를 수신한다. 매칭 취소는 초안을 바꾸지 않고, 선택은 ERP 키가 유효한지 확인 후 로컬 초안에 반영한다.
- 결정: 키보드 기준을 `AGENTS.md`와 `docs/UI_LAYOUT_AND_MENU_CONTRACT.md`에 추가한다. 신규/수정 페이지는 Tab 순서, Enter/Space, Escape, 방향키, 시각적 초점 및 팝업 초점 복귀를 준수한다.

## 구현·검증

- 원본 업체/품목의 미매칭 동작을 동일 출처 새 매칭 창으로 바꾸고, 원본↔ERP 매칭 열을 인접 배치했다.
- 업체 키를 매칭해도 원본 업체명·단가 그룹 식별은 유지하도록 확인했다.
- 관련 UI/팝업 테스트, UI layout, ERP 계약 테스트, dnSpy evidence guard, production build를 검증했다.
- 브라우저 기준 1920×1080 CSS px에서 팝업을 확인했다. 로컬 브라우저는 로그인되지 않아 품목 API 후보 목록은 검증하지 않았으며, 인증된 후보 선택은 테스트로 보완한다.
- 이 변경은 물량표 화면/로컬 매칭 초안만 바꾸며 ERP 저장 API 또는 원장을 추가 변경하지 않는다.
