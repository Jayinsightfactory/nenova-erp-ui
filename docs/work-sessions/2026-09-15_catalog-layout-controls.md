# 거래처 카탈로그 배치·글씨 기본값

| 항목 | 내용 |
|---|---|
| 화면 | /catalog, /catalog/preview, /catalog/print, PPT 다운로드 |
| 작업 | codex/catalog-layout-controls |
| 기준 화면 | 1920×1080 CSSpx, 100% |

## 기획·고정 결정

- 전체 카탈로그 공통 설정: 위/아래/좌우 여백, 칸 간격, 이미지 크기 및 가로/세로 위치.
- 정사각형 유지가 기존 기본값. 영역 채우기는 직사각형 프레임으로 남는 공간을 사용하며 사진 비율은 왜곡하지 않고 크롭한다.
- 제목/로고 숨기기와 최소 여백으로 이미지 최대화 가능. 개별 사진 크롭/확대는 기존 편집기를 유지한다.
- 영문/한글/단가/기타1~3 글씨 크기를 각각 설정한다. 설정은 저장본에 포함되며 '기본값 저장'은 이 브라우저의 이후 카탈로그에 적용한다. 기존 저장본은 그 저장본의 설정을 우선한다.
- 원본 이미지 파일, 품목명·단가 데이터, ERP 원장을 변경하지 않는다.

## Q&A

Q. 이미지 여백을 줄여 슬라이드를 크게 채우고 위치를 조절하며 한글명·단가·기타의 글씨 기본값도 설정하고 싶다.

A. 정사각형 고정 레이아웃과 하드코딩 글씨 크기를 공통 설정으로 전환한다. 편집·미리보기·인쇄·PPT가 같은 계산을 사용하며 저장/재열기도 검증한다.

## 검증 기준

## 검증 결과

- ERP 계약·dnSpy 근거·manifest·변경 write guard 및 production build 통과. 변경 API 0개.
- 순수 레이아웃/폰트 테스트: 기존 기본값, 0 여백, 직사각 채우기, 좌표 경계, 폰트 높이, 2025/2026 동일 차수의 초안 round-trip 보존 통과.
- 이미지 테스트 13개: 정사각/가로/세로 사진과 프레임 조합의 비율·회전·수동 crop 보존 통과.
- Playwright 1920×1080: 이미지 70%, 가로/세로 100%, 한글24pt·단가20pt·기타18pt, 저장/재열기/새 초안 기본값, 미리보기 및 PPT XML 폰트 대조 통과. 기존 8칸 경계 및 1280×720 설정 패널 조작 확인.
- 별도 검토에서 숫자 입력 중 조기 clamp 문제를 발견해 입력 문자열을 보존하고 blur/Enter 때 정규화하도록 보완. 키보드로 24를 한 글자씩 입력하는 검증 추가.
- 브라우저 검증은 API를 fixture로 차단해 운영 쓰기와 외부 AI 호출 없이 수행. 이미지 파일·ERP 원장 변경 없음.
- 임시 스크립트/캡처/PPT는 C:/Users/USER/AppData/Local/Temp/catalog-layout-*이며 저장소에 커밋하지 않는다.

기존 설정 없음, 0 여백, 제목 숨김, 잘못된 저장값, 교차연도 보존, 이미지 비율·위치·텍스트 크기의 출력 일치, 작은 화면 조작 가능성을 검사한다. 운영 데이터 변경 없이 fixture와 브라우저 다운로드로 검증한다.
