# 2026-10-08 웹·PC 메뉴별 즐겨찾기

Q. 기존 메뉴 옆에 즐겨찾기 추가/해제 구분 버튼을 웹과 PC에 모두 적용해 달라. 앱 업데이트 후 변경이 보이지 않는다.
A. 최초 업데이트 버튼 위치로 잘못 해석한 변경은 철회했다. 전체 메뉴 이름과 별을 별도 버튼으로 제공하고, ☆/★로 상태를 구분한다. 미등록 메뉴도 화면을 열지 않고 추가할 수 있다. 선택 뒤 원래 메뉴는 남기고 즐겨찾기 목록과 색상을 갱신한다.

확인: 사용자 PC 설치 버전은 1.3.0. 당시 공개 최신도 1.3.0이라 새 변경이 없었다. 본 수정은 1.3.1로 배포해 기존 앱의 업데이트 버튼으로 받게 한다.

보존: 기존 계정별 웹 즐겨찾기 및 PC별 암호화 즐겨찾기 저장 방식 유지. ERP 원장 쓰기 없음. 웹↔PC 자동 동기화는 이번 범위 아님.
