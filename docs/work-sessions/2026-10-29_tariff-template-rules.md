# 도착원가 원본 양식의 관세 규칙 — 읽기 전용 조사

작성일: 2026-10-29. DB·앱 코드·원본 Excel 변경 없음. 법정 세율 안내가 아니라 **사용자가 보관한 원가 양식에서 실제로 사용한 수식**의 조사다. 파일명/시트의 차수만으로 해당 자료의 연도가 2026년이라고 확정하지 않는다. 원본 환율도 현재 SQL 차수에 복사하지 않는다.

## 결론

품목별 관세 **후보 데이터**는 생성할 수 있다. 그러나 국가별 세율 하나를 모든 차수에 적용하는 것은 원본과 맞지 않는다. 중국은 같은 품목명도 차수별 세율이 달라지고 오참조 수식도 있어, 전표·차수·품목 단위의 근거/보류 상태가 필요하다.

| 국가 | 원본에서 확인한 계산 | 범위와 제한 |
|---|---|---|
| 콜롬비아 | `33-1` K14 `관세 (없음)`, K15:K78 공란, M15=`J15+K15+L15` | 이 시트에서는 공란 관세가 0으로 합산됨. 모든 국가 품목의 법정 면세를 증명하지 않음 |
| 태국 | CNF 원화 × 5% | Den/MOK/Oncidium/ARAN 등의 실제 수식. 일부 초기 양식 및 22 시트는 숫자/문자 직접 입력이므로 수식 확정 근거와 구분 |
| 호주 | Copper Glow 6.9%; 관측한 기타 일부 품목 0% | Red Tip/Pink/건조 Banksia 등 미관측 품목으로 복제 금지 |
| 중국 | 기본 조회표 21.4%, Eucalyptus 8%; 행별 25%/8% 직접 수식 예외 | 같은 이름의 차수별 충돌 9개, 잘못된 다른 행 참조 1개가 있어 전체 차수 공통 확정 규칙으로 삼을 수 없음 |

## 1. 에콰도르: 실제 원본은 25%

`41-1 Ecuador 원가자료.xlsx`, `41-1`:

| 셀 | 원본 수식/값 | 의미 |
|---|---|---|
| C7 | 1520 직접 입력 | 이 양식의 환율; 현재 SQL 환율을 대체할 근거 아님 |
| C11 | `(G11*E8)+E11` = 541.95 | 항공 운임+문서비 |
| E8/G11/E11 | 135 / 3.37 / 87 | CW / 단가 / 문서비 |
| C10 | `SUM(E14:E22)` = 1200 | 전체 수량 |
| G14 | `E14/$C$10` = 1/12 | 해당 행 수량 비중 |
| H14 | `F14+($C$11*G14/E14)` = 1.101625 | FOB + 배분된 항공비, 송이당 CNF |
| J14 | `H14*$C$7` = 1674.47 | 송이당 CNF 원화 |
| K14 | `J14*0.25` = 418.6175 | 송이당 관세; K14:K22 공유수식 전체 25% |
| L14 | `($P$10*G14)/E14` = 182.5 | 그 외 통관비 배분 |
| M14 | `J14+K14+L14` = 2275.5875 | 송이당 도착원가 |

장미 외 실제 기간 시트에도 별도 근거가 있다:

- `37-1` B19 `Gypsophilia Overtime 750g`, K19=`J19*0.25`, J19=784.20851063829787, K19=196.05212765957447.
- `40-2` B27 `Gypsophilia Xcelence 750g`, K27=`J27*0.25`, J27=808.38333333333333, K27=202.09583333333333.

예제 안개 시트가 아니라 실제 차수 이름의 관측이다. 다만 원본 연도와 SQL 품목 키의 연결은 별도 검증해야 한다. `docs/FREIGHT_PIPELINE.md`의 에콰도르 25% 설명과 이 원본의 관측값은 일치하지만, 그 문서만으로 모든 품목·모든 연도의 25%를 확정하면 안 된다.

## 2. 중국: 조회표보다 행별 직접 수식이 우선

`CHINA 중국 원가자료 (3).xlsx`, `35-2 CLOUD`의 J7:N14:

1. CARNATION (J8/N8): 21.4%
2. ROSE (J7/N7): 21.4%
3. LISIANTHUS (J9/N9): 21.4%
4. EUCALYPTUS (J10/N10): 8%
5. Sinensis (J11/N11): 21.4%
6. Gypsophila (J12/N12): 21.4%
7. others (J14/N14): 21.4%

위 순서는 K25의 중첩 `IF(ISNUMBER(SEARCH(...)))` 순서이다. SEARCH는 대소문자를 구별하지 않는 부분 문자열 검색이다. 이 시트 J13/N13의 `40cm / 21.4%`는 운임 G열 조회에는 사용되지만 관세 K25의 분기에는 없다. 이전 시트의 others는 J13/N13에 있어 셀 좌표를 모든 차수에 고정하면 안 된다.

수식 흐름: H25=`F25+G25`(FOB+운송비), J25=`H25*$C$7`, K25=조회된 세율×J25, M25=`J25+K25+L25`. 이 시트는 단 기준이다(G24 `운송비 (단)`, H24 `CNF (단)`). 송이 수량에 단당 관세를 바로 곱하면 단위 오류가 된다.

직접 행 수식 사례:

- `35-2 CLOUD` K69=`J69*0.25`: ASPARAGUS Preserved Dark red.
- 같은 시트 K57:K59, K65는 `J행*0.08`: 유칼립투스/비짜루.
- `25-2 CLOUD` K24=`J24*0.25`: ASPARAGUS Preserved White.

**25%가 전기간 공통 품목 규칙인지는 확정할 수 없다.** 동일 이름의 Amaranthus White는 `26-2 CLOUD!K24` 조회식 21.4%, `29-2 CLOUD!K25` 직접 25%, `34-2A CLOUD!K36` 다시 조회식 21.4%이다. Preserved Blue도 27-2 21.4%, 29-2 25%이다. 수기 수정/양식 누락/시점별 정책 중 무엇인지는 파일만으로 단정할 수 없다. 해당 9개 품목은 후보의 `unconfirmed=true`, `conflictingRates`로 분리했다.

**오참조:** `21-2 MEL ` (시트명 끝 공백) K30=`J31*0.08`. 품목은 비짜루인데 자기 행 J30이 아닌 다음 품목 J31을 참조한다. K30/J30의 약 13.9416%를 새 세율로 추출하면 안 된다. 해당 관측은 `cross-row-reference`로 보류했다.

또한 `35-2 CLOUD!K24` 헤더는 `관세 (없음)`이라고 쓰였지만 실제 아래 수식은 양수 관세다. 제목보다 실제 셀 수식/입력값을 따라야 한다.

## 3. 호주: Copper Glow와 기타 관측 품목을 구분

ZIP `PREMIUM GREENS원가자료.xlsx`:

- Copper Glow 6.9% 실제 수식: `12-1!H14=G14*0.069`, `13-1!H14=G14*0.069`, `15-1!I14=H14*0.069`, `17-1!I22=H22*0.069`, `18-1!I22=H22*0.069`, `20-1!I21=H21*0.069`.
- 0% 실제 수식이 관측된 이름: Banker Bush, Stenocarpus, Emu Feather, Emu Grass, Steel Grass, Fern Umbrella, Fern Sea Star, Koala Fern, Wolly Bush Green Tip, Goanna Claw, Fern Rainbow, Thryptomene Calycina Natural White.
- `24-1!I13=H13*0` (Banker Bush), H13=`F13*$D$6`, F13=14.5, D6=1090, H13=15805. F열 원본 단가 자체가 CNF이므로 같은 항공비를 또 추가하지 않는다.

## 4. 태국: 5% 수식과 직접 입력값 구분

ZIP `태국 덴파레 원가 자료 - EXCEL 2026 (1) (1) (2).xlsx`, 시트 `23`:

- C5는 `.22-1`로 시트명과 차수 표기가 다르다. `23`을 23차라고 자동 연결하지 않는다.
- C7=1550, E8 CW188.5, E9 운임단가1.65, G11=`E8*E9`=311.025.
- E11=`221.27+95.19`=316.46, C11=`E11+G11`=627.485.
- H15=`($J$8/$J$10)*(F15/$K$8)`: 그룹의 박스 비중 × 그룹 내 송이 비중.
- I15=`G15+($C$11*H15/F15)`=0.604405316091954: 송이당 CNF.
- K15=`I15*$C$7`=936.828239942529, L15=`K15*0.05`=46.8414119971264.
- N15=`K15+L15+M15`=1087.86757357841, P15=`N15*O15`=10878.6757357841 (O15=10송이/단).

Den/MOK/Oncidium/ARAN 등 관측 이름만 후보에 넣었다. Anthurium·Vanda·White Necklace 등 미관측 품종으로 5%를 자동 복제하지 않는다.

시트 `22`의 L17:L34는 `₩48.86` 같은 **문자 직접 입력값** 18개다. 수식과 동일하게 취급하지 않는다. 초기 시트 `1`의 J30=37.9175도 직접 숫자 입력이며, 헤더는 `관세 (송이) 5%`; `11!J30=I30*5%`는 실제 수식이다. 초기 양식에는 FOB가 빈 대기 행에도 운임만으로 계산되는 값이 있으므로, 수식이 존재한다는 이유만으로 실제 입고품목/과세 실적이라 단정하면 안 된다.

## 5. 과세표준·반올림·도착원가 반영

- 확인한 원본 수식의 과세표준은 FOB만이 아니라 **배분 항공비를 포함한 CNF 원화 단가**다. 에콰도르/태국은 송이, 중국은 단, 호주 양식은 CNF 단가/해당 행 단위여서 단위 보존이 우선이다.
- 확인한 관세 수식에 ROUND/FLOOR/CEILING/TRUNC는 없다. 소수 저장값이 유지된다. 셀의 표시 자릿수는 반올림 계산식이 아니다. 웹의 10원 절사 추정식과 같다고 주장할 수 없다.
- 관세는 도착원가에 포함된다. 따라서 관세 증가 D를 보고서 H에 더하는 직접 효과뿐 아니라, 기초/기말 재고 평가에 포함되는 관세의 변경도 구분해야 한다. 매입 G·매출 C 고정 시 `Δ이익 = -Δ기초재고액 -ΔH +Δ기말재고액`, `Δ수익률 = Δ이익/C`이다. 단순 `-D/C`는 재고 평가를 고정한 민감도일 뿐이다.
- 이미 도착원가에 관세가 포함된 항목에 보고서에서 다시 관세를 더하면 중복될 수 있다. 양식 수식과 SQL 관세 저장/품목 기본율을 각각 출처로 표시해야 한다.

## 안전한 후보 데이터 생성 기준

1. 실제 연도+차수+전표/AWB+품목 키에 원본 품목을 명시적으로 연결한다. 이름 부분 일치만으로 확정하지 않는다.
2. 해당 행의 직접 수식/입력값을 우선하고, 그 다음 해당 시트 조회표를 적용한다. 다른 차수의 예외를 소급 복제하지 않는다.
3. 금액 직접 입력, 0 명시, 공란, 원가 미확정, 수식 오참조를 서로 다른 상태로 둔다.
4. 현재 SQL 환율/실제 운임은 현재 근거를 사용한다. 원본 환율이나 과거 예시 금액을 복사하지 않는다.
5. 중국 충돌 9품목과 오참조 행, 미관측 품종, 연도 미확정은 자동 적용 차단한다.
6. 이 조사는 후보 자료 생성까지만 수행했다. 운영 DB 입력·웹 계산식 수정·배포는 하지 않았다.
