# 중국 인보이스 박스·단·송이 원본 보존

| 항목 | 내용 |
|---|---|
| 기간 | 2026-10-20 |
| 화면 | 수입부 패킹리스트 |
| 원장 부작용 | SELECT 집계만, 운영 쓰기 없음 |
| 배포 | PR/CI/배포 결과는 후속 기록 |
| 다음 힌트 | 중국 AI 비정형 genChina의 1박스·1송이 기본값 제거 |

## 고정 결정
- 사용자 양식 Order=박스, Bunch=단, PCS=송이. 헤더 의미로 분리하며 모든 국가에 강제하지 않는다.
- 내부 JSON pcs는 기존 박스 필드다. 외부 PCS라는 단위명과 혼동하지 않는다.
- 품목 매칭은 원본 수량을 변경하지 않는다. 없는 수량을 1로 채우지 않는다.
- 원문 상충값은 검토 대상으로 보존. 품목 매칭과 수량 검증은 별도다.
- 기존 운영 입고 수량은 이번 코드 수정으로 자동 보정하지 않는다.

### 1. 수량이 인보이스 그대로 업로드되어야 한다
**Q.** 매칭했는데 문제가 남고 박스/단/송이가 섞인다. 수정해 달라.
**A.** CN AI 프롬프트의 total_bunch=quantity ordered 모호성과 genChina의
pcs=1/bunch_st=1/total_stems 누락을 확인, 원본 수량 순수 함수와 회귀시험으로 수정.
실제 dnSpy ExcelLoadingPackingList에서 F/I/J가 박스/단/송이 별도 저장임을 확인.
**결과.** 실제41-1 원본 테스트20/20, 전체 ERP contract 및 build 통과.
SELECT 집계는 원본과 기존 입고 수량 불일치를 보여주나 자동 복구하지 않았다.

## 미완/주의
- 실사용 PDF 재분석 및 운영 입고 쓰기 검증은 하지 않았다. 유료 AI 호출 없음.
- 원본 불일치 경고를 품목 선택만으로 무시하지 않는다.
- 로컬 probe 스크립트와 generated history, previous-dependencies-link는 커밋 제외.
