## 고정 결정

- 보고서 상단 버튼은 조회한 연도/차수를 별도 창에 전달한다. 초안 입력과 조회 범위가 다르면 열기 차단.
- 공용 메뉴에도 별도 진입점 추가. 일반 URL은 shell 하나, popup=1은 간소화 shell.
- 기존 경고·원천 점검·실제 재고조정 이력을 연결한 화면이다. 독립 검증 에이전트 전체 구현이라고 표시하지 않는다.
- 확정본/계산 저장본/현재 원장 조회를 구분하고 stale 및 실패를 정상 판정으로 숨기지 않는다.
- 운영 SQL은 행 존재를 읽는 SELECT probe만 실행. 실제 EXE FormStockView CLI 확인. SQL/SP/계산식 변경 없음.

## Q&A

### 1. 별도 새창에서 확인

**Q.** 매출자료 메뉴페이지에서 별도 새창으로 확인할 수 있게 해 달라.

**A.** `/sales/profit-validation`에 연도·차수 선택과 보고서 금액/경고, 통관·환율·입고 점검, 현재 StockHistory 이력을 묶었다. 보고서의 `수익률 검증 새창` 버튼과 공용 메뉴에서 열 수 있다. 조회 실패·취소·범위 변경을 처리하고 원래 보고서의 초안은 저장하거나 이동하지 않는다.

**결과.** 코드·계약·합성 회귀 및 로컬 브라우저 검사 스크립트 작성. 실제 검사/배포 결과는 아래에 이어 기록한다.

## 미완 범위

독립 수량 대사, 원가 증거 독립 검산, 최초 원인 역추적은 이전 설계안의 후속 구현 대상이며 이번 새창 연결에 포함하지 않는다. 공개 저장소에는 운영 원문·금액·비밀번호·SQL 출력 파일을 커밋하지 않는다.
