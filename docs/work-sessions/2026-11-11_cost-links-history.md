## 고정된 결정
- 기존 국가별 원가파일을 근거로 입력 수량·단가·환율에서 원가·판매·이익·합계까지 연결한다.
- 승인 스냅샷은 증거이므로 변경하지 않는다. 별도 원본 양식 계산 시트가 재계산 대상이다.
- 기존 XLSX의 과거 시트 XML/참조를 변경하지 않고 현재 계산 시트를 별도 이름으로 추가한다.
- 원본 권한·등록 해시 확인, 계정/연도/국가/운송/통화/양식별 private 파일 이력, 잠금·원자적 포인터. DB 및 Drive 다운로드 이력 쓰기 없음.
- 서버에 원본이 없는 과거 차수는 임의 생성하지 않는다. 이후 다운로드부터 누적되며, 기존 모든 과거 파일을 찾아 복원했다는 의미가 아니다.

### 1. 수식이 끊긴 부분 수정
**Q.** 숫자를 바꾸면 원가·이익·합계도 계산되고 과거 차수 시트도 남아 있어야 한다.

**A.** 비교 계산표의 수량·상품금액을 원본 계산 시트의 입력에 연결했다. 상품 합계는 SUMPRODUCT로 변경하고, 그룹 수량·운임·중량 참조도 연결했다. 추정 통관비는 원본 수식과 기존 입력의 조정 차이를 분리하여 최초 금액을 유지하면서 중량 변경이 반영되게 했다. 실제 청구 합계는 고정 근거로 유지한다.

### 2. 실제 Excel 검증
**A.** Excel 전용 COM 인스턴스·매크로 차단·외부 링크 갱신0·폐기용 합성 파일을 사용했다. NL/US/NZ/VN/EC/CN 항공·해상/CO 구형·42-1/TH/AU 총11양식에서 단가·수량·환율 변경 후 원가/총판매가/총이익 연결을 확인했다. 수식 오류0. 실제 운영 비용 정확도나 운영 입고 전체 E2E를 검증했다는 뜻은 아니다.

**결과.** scripts/verify-cost-links-excel*. 실제 네덜란드 원본61개 탭을 보존하고 현재3개를 추가한64개 시트 파일을 Excel로 열어 현재 계산 단가 변경 전파를 확인했다. 원본 파일은 덮어쓰지 않았다.

### 3. 보존·동시성 검증
**A.** 이전 시트 XML 동일성, 새 시트 참조/스타일/인쇄범위 재매핑, 같은 내용 재다운로드 중복 방지, ZIP timestamp 독립 fingerprint, 교차연도/계정 분리, 파일 잠금 및 원본 권한 철회를 검사했다. 실제 원본의 달러 서식 `$&`가 문자열 치환에 잘못 해석되는 문제도 실제 Excel에서 발견·수정했다.
