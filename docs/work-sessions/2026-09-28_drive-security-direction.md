## 고정 결정
- 카톡에서 받아 PC에 저장한 기록은 유출이 아니다.
- 기본 ‘외부 전송·반출 확인’과 ‘수신·내부 기록’, ‘전체 활동’을 분리한다.
- 수신은 중립/녹색 참고 표시. 외부 복사도 불법 유출로 단정하지 않고 업무 목적 확인으로 표시.
- 받은 파일을 이후 USB/외부 목적지로 복사하면 그 별도 이벤트는 반출 확인 대상에 남는다.
- 기존 원본 감사 기록은 삭제하거나 재작성하지 않는다. 접근 권한과 수집 정책도 유지.

### 1. Q → A
**Q.** 카톡에서 받아 저장한 것은 유출이 아니므로 보안이력 페이지를 수정·배포.

**A.** 기존 목록에는 수신이 섞이고 미리보기/파일 흐름에는 copy가 일괄 ‘복사 유출’로 표시되었다. 공통 표시 정책을 도입해 목록/미리보기/상세에 동일한 방향 판정을 적용한다. 파일 흐름 읽기 결과에 destKind/dest를 보존해 과거 수신도 올바르게 표시한다.

**검증.** 신규/과거 수신 경로, 받은 파일의 USB 재복사, 권한 유지, 수신 기록 보존, 합계 일치, 기본 필터, 오류/로딩/늦은 응답 보호 회귀 통과. UI-layout / ERP contract / dnSpy evidence / manifest / writes / build 통과.

**배포.** PR #771, merge `5ee665c17405d5ae09ce4088fd33aea93f4f117d`, Cafe24 run `36368669526`.

**실브라우저.** 인증된 운영 화면의 30건 = 반출 확인 15 + 수신 15. 기본 표에 수신/복사 유출 문구 없음. 수신 탭 15건, 녹색 행/유출 아님 확인. 수신 파일 시트 미리보기 헤더도 동일 판정. 1920×1080/100% 및 800×900 가로 overflow 없음, 모달 닫기 정상, browser error 로그 없음. viewport 복원. 증거 `.tmp/drive-security-inbound-1920.png`는 운영 파일명을 포함하므로 커밋하지 않음.
