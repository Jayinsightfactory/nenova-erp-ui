# 알스트로 입고 빈칸 점검·업체명 병합

## 요청과 확인
- Q: 44-01 물량표 주문 옆 입고와 농장 입고가 비어 있다. 업체명 옆 박스를 병합해 이름만 표시해 달라.
- A: 2026/44-01 알스트로 ViewWarehouse 및 WarehouseMaster/Detail+Product 원본 모두 0행. 2025/44-01은 19행/1872, 2025/44-02는 10행/496. 2026/43-01은 15행/1648. 삭제 포함 원본 조회에서도 2026/44 입고 없음. 미등록 차수에 이전 차수 입고를 가져오지 않는다.
- 2026/41-01=1520, 41-02=1360, 42-01=1312, 42-02=1168도 같은 SELECT-only probe에서 확인. 원문 업체정보·연결정보 저장 없음.
- 실제 dnSpy CLI FormQuantityPivot.GetData/btnExcel_Click 재실행: ViewWarehouse.OutQuantity 및 ExportToXlsx 사용 확인. 관련 golden은 docs/exe-golden/FormQuantityPivot.md. 기존 SQL/수량 원천 보존.

## 검증
- 2025/2026 실제 export→XLSX→실제 import 파서, 20품목/2업체에서 병합 보조열의 숫자15행 이상 품목 오인 방지.
- 입고64 및 농장64/합계1280 보존, 무입고의 빈칸/합계0 보존. 전년도·다른 차수 대체 없음.
- 별도 Excel 프로세스 합성 파일에서 병합업체명/두열복사삽입/새업체명/수량편집/삭제/입고·잔량 연동/두열통삭제 확인. 저장 후 실제 파서: 삽입6행/36, 삭제4행/28.
- 메뉴 기본값: 적용—핵심 이름 가독성·Excel 키보드 입력·원수량/승인 보존. 해당 없음—새 메뉴/웹 shell/ERP 쓰기. 운영 분배 저장은 수행하지 않음.
- 전체 필수 검사와 배포는 진행 중, 미검증.
