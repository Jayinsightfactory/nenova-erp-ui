# 에콰도르 과거 재고·원가 누락 대사

## 질문과 확인
- 사용자: 31차 기초·기말재고 원가 누락과 이전차수 수량 이월을 SQL 기준으로 확인하고 수정·배포.
- 조사: 최초 관측 재고 차이와 후속 차수의 품목별 순조정이 정확히 반대였다. 수량 일치만으로 같은 목적이라고 단정하지 않고 확인했다.
- 사용자 답변: 후속 조정은 과거 부풀려진 재고 제거 목적이 맞다.
- 결정: 기존 이력 보존, 후속 이중차감 방지 이력과 native CALC를 하나의 트랜잭션으로 처리한다. 판매단가나 미래 매입단가로 빈 원가를 채우지 않는다.

## 구현과 검증 경계
- [기준·부작용·dnSpy 근거](../plans/ecuador-stock-cost-2026-10-21.md)
- 명시 연도/품목/시작·상쇄 차수, 사용자 목적 확인, 원천 지문, 롤백 리허설이 모두 필요하다.
- 기존 StockHistory, 현재 Product.Stock, 주문·출고·견적·매입·매출 확정자료를 보존한다. 대상 ProductStock의 native 후속연도 계산은 계획에 공개한다.
- 신규 계약과 교차연도/불일치/NULL/음수/실패 fixture, 독립 검산의 이중차감 위험 안내를 추가했다.
- 운영 원본·숫자·개인정보는 Git에 넣지 않는다. 재현 증거는 ignored `.verify/historical-stock-repair`에 보관한다.
