| 항목 | 내용 |
|---|---|
| 날짜 | 2026-10-27 |
| 화면 | /sales/shilla-miu-board |
| 부작용 | CSS/표시속성만 변경, 저장·등록 이벤트와 ERP 원장 보존 |
| 상태 | 로컬 빌드·브라우저 확인, CI/배포 진행중 |

**Q.** 버튼 디자인을 통일하고 다른 버튼과 색감만 차별화.
**A.** 공통 ERP font/radius 기반32px 형태, 저장청록/조회보라/매칭파랑/주문초록/삭제연빨강. 탭·파일선택·모달 포함. 신규 업무 기능 없음.
**검증.** CSS 모듈로 호텔 페이지에 한정. Chrome 주요 버튼 실제높이32px, Tab초점/비활성/파일선택/표 안 버튼 확인. build/dnSpy/manifest/writeguard/UIlayout 통과, 전체회귀와 운영배포 후속기록.
**기준선.** 적용: 단일shell, 페이지스크롤, 키보드, 명시등록/초안저장 보존. 해당없음: SQL/업무키/수량변경. 정확1920x1080 및 모바일 전체화면은 미검증.
