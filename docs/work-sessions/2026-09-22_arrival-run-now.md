## 고정 결정
- 기존 24시간 자동 예약은 변경하지 않는다.
- nenovaSS3의 명시 확인 후 선택된 최신 파일 버전 한 개만 즉시 처리한다.
- 원본 파일/등록시각을 변경하지 않으며, 일반 업로드로 과거 시트까지 재등록하지 않는다.
- 수동 현재본·수동 매칭·다른 파일군 충돌은 강제 덮어쓰지 않는다.

**Q.** 대기 국가 작업, 즉시 처리 기능 보완.

**A.** API action=run-now 및 파일별 확인 버튼을 추가하고 공통 worker와 기존 저장 잠금/멱등/보호 정책을 재사용했다. 진행과 파일별 완료/보류를 표시한다. 응답 오류를 저장 실패로 단정하지 않는다.

## 검증 / 후속
- 단위 및 전체 ERP 계약검사, dnSpy, manifest, 쓰기 가드 통과.
- 로컬 빌드 성공. PR #744 병합 bba79e4d63457d64ddd5b405e015dcf409baad66.
- 원격 계약검사 35680087791 성공, Cafe24 배포 35680179456 및 hydration smoke 성공(4m38s).
- 운영 1920×1080에서 4개 파일별 `지금 검증·처리` 버튼 표시 확인.
- 태국38-1 버튼 클릭 시 내장 브라우저 확인창에서 CDP 응답이 멈췄고 getJsDialog는 undefined였다. 원가 중복 요청을 하지 않고 사용자에게 확인창 승인을 요청했다. 해당 시점 SELECT에서 기존 현재본 행수가 그대로였다. 4개 국가 실제 저장은 아직 완료로 보고하지 않는다.
- 다음 작업: 사용자 확인창 해제 후 해당 파일 결과 조회부터 시작. 성공 파일은 재실행하지 말고 나머지 국가만 확인/처리. 기존 수동 원가 보호 오류는 우회하지 않는다.
