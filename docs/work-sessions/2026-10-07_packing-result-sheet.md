# 패킹리스트 결과 시트와 특이사항 복사

## 사용자 요청 / 범위
- 결과 전체를 엑셀형 표로 표시하고 오른쪽에 특이사항을 나란히 표시한다.
- 특이사항 품목·수량·사유를 별도 창에서 카카오톡에 붙여넣을 수 있게 한다.
- 기준 viewport: 1920 × 1080 CSS px, 100%. 좁은 화면은 세로 배치.
- 이번 변경은 파일 변환 결과의 표시·복사만 담당한다. ERP 주문/분배/입고/재고 SQL, 확정, 잠금, EXE는 변경하지 않는다.
- 주문 대비 부족/초과 수량은 실제 주문 조회가 연결되지 않았으므로 추정 표시하지 않는다.

## 예시 확인
- 사용자 제공 `41-1 중국 해상 ci1.pdf`: 7페이지 렌더/텍스트 확인.
- Total of Flower Material = 단수, Stems = 송이 수, Order = 박스 수. Unit Price는 CNY/단.
- 장미 길이와 혼합 길이를 임의 단일 길이로 바꾸지 않는다.
- 동일 인보이스의 기존 XLSX를 실제 파서 회귀로 확인: 101행, 429박스, 5,390단, 68,775송이. 품목금액126,325 CNY / 부대비45,825.50 / 전체172,150.50.
- PDF 무료 파서는 현재 네덜란드 지원 양식에만 적용된다. 중국 PDF의 AI 분석은 기존 명시 선택 경계를 유지한다. 이번 작업에서 유료 AI를 자동 실행하지 않았다.

## 보존 계약
| 동작 | 파일/화면 | ERP 원장 |
|---|---|---|
| 결과 조회·행 선택 | 브라우저 표시 | 보존 |
| 특이사항 복사 | 사용자 클릭 시 클립보드 / 수동 선택 대안 | 보존 |
| 엑셀 다운로드 | 기존 버퍼와 차단 조건 그대로 | 보존 |

기존 미매칭, 후보 확정, 금액 불일치 수동 확인, 잘린 응답 차단을 우회하지 않는다. 숫자 0과 미확인을 구분한다. 공급사 원문은 HTML로 실행하지 않는다.
