# SQL 원장 기준 전체 차수 재검증

## 범위와 확인 결과

- 실제 업무 원천이 존재하는 76개 연도·차수: 2025년 29개, 2026년 46개, 2027년 1개.
- SQL 매출/차감/기타매출/외화매입 독립 합산 5,044개 값: 웹 live 조회와 차이 없음.
- 마지막 ProductStock 재고수량 1,261개 분류 비교: 웹 수량과 차이 없음.
- 76개 live 보고서 28,001개 산술 항목 일치. 자동 저장 입력 118개 revision의
  43,205개 산술 항목 일치. 이는 원가/실사 정확성 인증이 아님.
- 금융 원행 집계·수량/단가 근거의 전후 hash는 2025/2026/2027 모두 안정 관측.
  DB snapshot isolation이 아니며, 비교 후 사용자 변경까지 보증하지 않음.
- 수동 확정 revision은 실제 조회 결과 없음. 자동 계산 payload와 혼동하지 않음.
- 잘못된 연도키의 2026년 01/02차 원행은 기존 안전조건에 의해 제외됨. 원장 자동보정 없음.
- 2026년 당차수 재고 수량식 차이 관측: 01,03,08,12,13,14,17,25,30,43,45,50차.
  01/35차에는 보고서 기초와 전산 직전 차수 선택 정책 차이도 있어 정답을 단정하지 않음.
- 2026년 32차 알스트로는 저장된 재고조정을 포함하면 독립 수량식과 일치함.
- 일부 에콰도르 과거 잔량 품목은 같은 연도 해당 시점 이전 매입금액행이 없음.
  미래 매입단가를 과거에 역적용하지 않음. 이전연도 취득/재고조정/품목 연결은 별도 확인 대상.

## 구현

- 기존 검증 새창의 독립 검산에 SQL 원행 N/L/O/Q 대사, 연도키 충돌 제외,
  과거 매입 존재 여부와 웹 원가 연결 누락을 구별한 설명 추가.
- 국내 수국 분류의 JS/SQL 조건 불일치 수정. 운영 대상 원장의 분류 변경은 없음.
- FLOAT SUM 순서의 미세차이를 실제 원천 변경으로 오판하는 것을 방지.
- 원장/확정본/수기값/계산 정책/재고수량은 변경하지 않음. 실제 금융 원행은
  gitignored `.verify/source/`에만 보관하고 공개 문서/테스트에는 합성 자료 사용.

## 잔여 검증과 배포

신규 회귀/기존 독립 검산 테스트 통과. 전체 ERP gate/build, PR CI, Cafe24 배포 진행 중.
인증된 운영 브라우저 검산은 로그인 만료로 미검증이며 사용자 로그인 필요.
H/R/S 전체 증빙과 모든 FIFO 원가의 독립 재현까지 완료했다고 주장하지 않는다.
이 작업은 보고서 조회 오류와 원장 자체 문제를 분리하며, 실제 수량/원가 원장 보정은 포함하지 않는다.
