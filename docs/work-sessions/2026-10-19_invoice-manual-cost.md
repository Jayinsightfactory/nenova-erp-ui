## 결정
- 미매칭 품목은 기존 검색으로 직접 지정한다. 관세율·환율·통관비는 직접 입력 가능하다.
- 관세율 화면은 퍼센트25, 서버 기존계약은0.25. 빈칸과 명시0을 구분한다.
- 최종 승인 입력은 서버 snapshot에 저장하고 재조회·복원한다. 저장 전 편집값은 서버 저장본이 아니다.
- 기존 입고 연결은 새 입고 생성 없이 웹 작업만 기록한다. native writer는 링크 문서에서 차단된다.

## Q&A
### 1. 직접 입력·배포·저장 검증
Q. 인보이스 미매칭을 직접 입력으로 수정하고 배포, 입력값 저장과 기존 입고 중복 없는 원가 저장·엑셀을 검증해 달라.
A. 직접 입력 필요 행 필터와 퍼센트 관세 입력을 추가했다. 필터는 입력 도중 행을 숨기지 않는다. 기존 서버 원가 저장·복원·엑셀 경로를 보존한다.

### 2. 실제 자료
입고일2026-10-11 입력을 웹 revision3으로 저장·재조회했다. 운영 LINK_EXISTING_COST COMMITTED, Warehouse7662 단일건, 전체85상세 전후 동일 확인. 원문146행·상품82행·16251송이 대조 통과. 실제 도착원가는 아직 PENDING이다. 레우코취2품목의 관세율 직접입력값이 필요해 사용자에게 요청했다. 임의0 저장하지 않았다.

- 직접 입력/원가/연결/엑셀80테스트 중71성공,9개 선택적 비공개 원본검사 건너뜀.
- 분리 MSSQL fixture: 연결 재시도·교차연도·원가 저장/조회·추정 엑셀·ERP 보존 통과.
- 전체 ERP/빌드/배포와 운영 다운로드 결과는 후속 기록 필요. 운영 원가 승인·다운로드 미검증.
- `.tmp-*` 운영 probe자료는 커밋하지 않는다.
