## 고정 결정
- 매칭 완료와 원본 숫자 검토를 구분하고 구체적인 해결 동작을 표시한다.
- 확인 완료를 임의 생성하거나 실제 누락 수량·단가를 추정하지 않는다.
- 적용된 원문 확인은 기존 assertPackingSourceReviewed로 현재 파일/송장연도/행을 검증한 경우만 미리보기 경고를 해제한다.
- 다음 단계의 기존 서버 검증·중복입고 보호는 유지한다.

### 사용자 요청과 결과
Q. Cloudland 13행이 수동 확인 완료인데 원문 검증 필요라며 다음 단계로 못 간다. 수정해 달라.
A. 자동 검산 근거 부재를 단순 오류처럼 표시하던 문구를 수량·단가 대조 안내로 바꿨다. 원문 확인 버튼은 행 수정 위치에 초점을 둔다. 남은 건수/적용 버튼/입고 이동 순서를 안내하고, silent return 조건도 이유를 표시한다. 적용된 원문 확인을 무시하던 미리보기는 기존 검증 통과 여부를 반영한다.

## 검증
- 실제 dnSpy ExcelLoadingPackingList의 연도/차수와 SP 순서 재확인. 기존 운영 SELECT 근거는 plans 문서 참고.
- 대상 64개: 63 통과, 화면 크기 자동검사 1 skip. 전체 ERP 계약, dnSpy, manifest119, API write guard 통과. 빌드 최초 통과, 최종 문구 수정 빌드 진행.

- outputs/packing-review-guide.png는 격리 fixture이며 운영 자료가 아님.
- 임시 .tmp-* 및 생성 history JSON은 커밋하지 않는다.
