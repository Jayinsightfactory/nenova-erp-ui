## 고정 결정
- 국가·품종·품목검색은 기존 필터 공유. 현재 표의 직사각형 선택만 일괄 입력 대상.
- 빈 일괄 입력칸은 변경 없음, 명시0은0. 관세25는25%. 무게/CBM 소수3자리, 관세% 소수2자리.
- 셀 더블클릭/Enter 개별입력, Shift+방향키 범위선택. 변경 확인 후 명시 저장.
- 필터 뒤 숨겨진 초안도 저장 확인 목록에 모두 표시; 탭 이동은 초안 보존. 이탈 경고.
- PK 잠금+기존6필드 대조, stale/삭제/사후검증/감사 실패는 전체롤백. 자동 HTTP 재시도 없음.
- EXE는 박스송이 독립 저장. 기존 웹의 곱셈 정책을 단위항목 변경에만 적용하고 미리보기 표시. 비용항목만 변경 시 기존 박스송이 보존.
