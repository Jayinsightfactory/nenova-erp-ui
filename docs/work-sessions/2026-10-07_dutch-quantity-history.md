## 대화 결정

### 1. 합계 자동 갱신

**Q.** 수량을 수정했을 때 총수량이나 합계가 자동으로 바뀌지 않는 부분도 고쳐 달라.

**A.** 주문 행의 주문 요약과 업체별/주문 총합계를 초안 수량으로 재계산해 화면과 엑셀 내보내기에 적용했다. 입고·재고 같은 다른 요약은 변경하지 않으며 수식 셀도 덮어쓰지 않는다.

### 2. 셀별 수정 이력

**Q.** 한 번 수정한 셀 안에 작은 수정 이력을 표시하고, 클릭하면 상세를 볼 수 있게 해 달라.

**A.** 셀에 `이력 N` 표시를 두고 누르면 변경 전→후 수량과 시각을 보여준다. 이력은 100건으로 제한하며 로컬 초안과 서버 저장 작업본을 복원해도 유지한다.

### 3. 배포·안전성

**Q.** 기능 수정은 프로젝트 배포 절차까지 마무리.

**A.** PR #943으로 master 병합, 필수 ERP 계약/교차연도 검증과 배포 전후 자동 스모크 완료. 수량 편집 기능은 기존처럼 ERP에 직접 기록하지 않고 별도 업로드 적용 단계에서만 전산 반영한다.
