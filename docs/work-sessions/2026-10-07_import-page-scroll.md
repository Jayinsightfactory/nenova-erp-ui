| 항목 | 내용 |
|---|---|

| 화면 | `/import/tools`, `/sales/farm-quality` |
| 부작용 | 화면 높이/스크롤/초점만 변경. API·권한·원장·수량·저장 이력 보존 |
| 브랜치 | `codex/import-page-scroll` |
| PR/배포 | 검증 후 기록 |

## 고정된 결정
- 앞으로 새 페이지는 주 페이지 세로 스크롤이 기본. 작은 목록/상세/이력 내부 스크롤을 중첩하지 않는다.
- 넓은 표의 가로 스크롤, textarea, 명시적 모달은 필요한 예외다. 다른 대용량 가상화 표는 이번에 일괄 변경하지 않는다.
- 기존 인증된 피드백 iframe은 유지하되 실제 내용 높이로 확장/축소한다. 숨긴 탭 복귀와 상세 열기/닫기를 검증한다.
- 목록 클릭과 상세 이동은 표시 동작이며 저장 요청을 발생시키지 않는다.
- 주문·분배·재고·견적·손익 및 피드백 저장 SQL은 전부 보존한다. 새 DB/EXE 동작은 없다.

## Q&A
**Q.** 앞으로 피드백 등은 그냥 페이지를 내려서 보게 해 달라. 작업 시작.

**A.** 수입부 목록/파일 미리보기/이력과 기존 농장피드백의 고정 높이를 제거하고 자연스러운 페이지 스크롤로 전환한다. 향후 기준을 AGENTS와 UI 계약에 기록한다.

## 검증·모델
- 메인: 설계·ERP 부작용·통합·배포. 하위 구현: gpt-6.1-sol/high/P0_LOCAL, 지정 gpt-5.6-terra 미제공 대체. 파일 경계·실행환경 사전 준비 완료. 외부 쓰기 금지.
- 기준: 1920×1080 CSS px/100%, 좁은900/480. 페이지 끝 접근, 내부 세로 스크롤 부재, 표 가로 이동, 상세·닫기·초점, 오류/초안 보존.
- 로컬 production Chrome: 항공60행/피드백80건 fixture, 1920×1080/100%,900/480 통과. 중첩 세로 스크롤0, iframe 높이 증가·감소/탭 복귀, iframe 위 휠로 주 페이지 이동, 독립 피드백 URL, 오류0/운영쓰기0.
- 독립 검토 gpt-5.6-sol/high/P0_LOCAL: observer 실패 fallback 및 삭제 후 초점 복귀 P2 두 건 발견하여 보완. observer 미지원/등록실패/다른 페이지 이동은 일반 iframe 스크롤로 복구하며 단위4검사 통과.
- 화면 원장 side-effect: 조회/목록선택/스크롤/상세닫기 → 모든 ERP·피드백 원장 보존. 기존 저장/삭제 API payload와 권한은 변경하지 않음.
- 최종 전체 ERP 계약·빌드 통과, production Chrome 재검증 통과. API 변경0, manifest 및 쓰기 가드 통과. 배포 결과는 후속 갱신.
