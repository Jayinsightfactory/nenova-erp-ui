## 수입부 확인 묶음 보기 보완

- 요청: `수입부 확인`은 기본적으로 같은 거래처끼리 나열하고, 버튼형 `품종`을 누르면 같은 품종끼리 나열한다. 두 기준 중 하나만 활성화한다.
- 구현: 기본 `거래처`/선택 `품종` 버튼과 활성 상태를 추가하고, 선택 기준이 바뀌는 지점에 구분선을 표시한다.
- 안전 기준: 조회된 원본 행 배열은 재배열하지 않는다. 화면 정렬 후에도 원본 행 인덱스와 `DeductionKey`를 유지하여 농장 입력·확정·확정취소 대상이 바뀌지 않는다.
- ERP 영향: 표시 전용 정렬이며 불량차감·견적·주문·출고분배·재고 원장은 변경하지 않는다.
- 검증: 순수 정렬 fixture와 1920×1080 브라우저 smoke에서 기본 거래처 묶음, 품종 전환, 활성 버튼, 원본 행 인덱스 보존, 가로 잘림 없음을 확인했다.
- 후속 보완: 품종 보기의 묶음 키를 품종 단독에서 전산 `Product.CounName → Product.FlowerName → 거래처`로 변경했다. 중국·콜롬비아의 동일 품종은 별도 국가 제목 아래 나뉘며, 국가 미확인 행은 확인 가능한 국가 뒤에 표시한다.
- 진입 위치 보완: `농장 불량 피드백` 바로가기는 조회·저장 작업 도구줄이 아니라 영업수입불량차감의 `미처리·다음 차수 재시도` 바로 다음 업무 탭에 배치하고, 같은 창에서 피드백 페이지로 이동한다.
- 기존 분석 노출 보완: 운영 2026년 원장에서 농장·품목 분석 그룹 145개가 조회되지만 수동 생성 피드백 건은 0개라 기본 피드백 화면이 빈 화면으로 보였다. 진입 기본 화면을 불량 그래프로 바꾸고, 기존 불량 중 분석에 반영된 농장·품목 그룹 수를 상단에 표시한다. 수입부 미확정·농장/품목 미지정 행은 기존 계약대로 제외 건수로 안내한다.

## 농장별 불량률·차수별 이슈 후보 보완

- 요청: 특정 농장을 선택해 차수별 불량률 변화를 보고, 특정 차수에 불량이 많았던 품목을 찾아 피드백 이슈로 처리한다.
- 분모: 같은 연도 `ViewWarehouse.OutQuantity`를 원대차수·농장·단위로 합산한다. 농장 추이는 해당 농장의 모든 입고 품목을 분모로, 품목 후보는 동일 `ProdKey` 입고만 분모로 쓴다.
- 단위: `Product.OutUnit`과 불량 원단위가 정확히 같은 경우만 비율을 계산한다. 박스·단·송이 변환은 하지 않는다.
- 누락 표시: 운영 API 대조에서 기존 피벗 기준 농장·품목 직접 연결은 101개 그룹 중 69개였고 32개는 연결되지 않았다. 분모가 없거나 0이면 0%로 오인시키지 않고 `입고 분모 없음`으로 표시한다.
- 이슈 생성: 차수별 후보는 불량률 우선, 동률은 불량수량 순으로 보인다. 사용자가 `이슈로 처리`를 눌러야만 기존 WebFarmQualityCase/Event 경로로 초안을 열며, 자동 저장하지 않는다. 같은 원본 불량로 이미 만든 건은 `기존 이슈 열기`로 연결한다.
- ERP 영향: Warehouse/Product는 읽기 전용이며 주문·분배·재고·견적·결산 원장을 변경하지 않는다.
