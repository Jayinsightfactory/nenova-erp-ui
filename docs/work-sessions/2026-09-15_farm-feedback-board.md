# 농장 피드백 상태별 4열 보드

## 고정 결정
- 사용자 정정: 단일 목록의 폭 축소가 아니라 요청 전 / 답변 대기 / 답변 도착 / 재발 확인을 네 세로 열에 동시에 표시.
- 각 열은 독립 스크롤, 상태명·건수는 상단 유지. 카드에 농장/품종/발생 차수·수량/주요 품목/최신 코멘트 유지.
- 개선 관찰·완료·제외는 기존 필터에서 조회. 그 외 상태 개수 안내로 누락 오인 방지.
- 복수 이력이 다른 상태이면 동일 항목을 해당 열마다 표시. 개별 이력과 저장 대상 선택은 보존. 열 개수 합계는 고유 농장 합계가 아님.

## 부작용
| 동작 | 피드백 저장 원장 | ERP 주문/출고/재고/견적/손익 |
|---|---|---|
| 보드 표시·필터·카드 선택 | 보존, 기존 읽기만 | 보존 |
| 명시적 이력 저장 | 기존 보호 로직 유지 | 보존 |
