# 중국 CL 헤더·알스트로 수량 표시

## 요청과 기준
- 중국 물량표 다운로드: 업체명과 CL을 서로 다른 위아래 셀로 표시.
- 확인 답변: 알스트로는 업로드 후 화면과 다시 내려받는 엑셀 모두 원수량(원수량/16) 표시.
- 기존 파일은 알스트로 숫자 셀값을 16으로 나누어 내보내고 업로드 정규화에서 16배 한다. 새 파일은 A2 단위 표식과 실제 수량 숫자를 저장하고, 표식이 있는 파일만 환산을 생략한다. 괄호 값은 다운로드 시점 참고값이며 재업로드는 숫자 원본을 읽는다.
- 중국 전용 헤더 행은 `클라이언트 번호` 식별자로 명시하고 파서가 건너뛴다. 기존 3행 헤더 파일과 네덜란드 형식은 유지.
