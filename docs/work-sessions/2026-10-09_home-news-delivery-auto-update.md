# 홈 소식·전달 상태·자동 업데이트 안내

## 요청과 결과
- 기존 지침과 수입부 피드백이 홈에 없다는 요청: 7일 필터를 제거하고 CURRENT 지침과 권한 있는 현재 연도 피드백 최신 20건을 표시한다. 7일은 새 소식 배지에만 적용한다. 현재 연도에 사례가 전혀 없으면 직전 연도만 조회하며 실제 연도를 보존한다. 일부 조회 실패 시 유효한 결과를 유지한다.
- 전달이 모두 미확인이라는 요청: 동일 원문·정식 source identity의 새 정확한 시각 정보를 병합한다. 잘린 원문은 완료 근거로 인정하지 않는다. 확인 대기/확인 중/미확인/조회 실패를 구분하고 같은 계정·연도·차수·원문 근거에 한해서 조회 중 기존 결과를 유지한다.
- 새 버전 자동 안내 요청: PC 1.3.6은 인증 후, 온라인 복귀, 6시간 주기로 확인한다. 실패하면 15분 후 재시도하며 중복 확인은 제한한다. 탭바에 업데이트 필요 안내를 표시한다. 다운로드와 재시작은 사용자가 실행하며 입력·열린 탭을 보존한다. 기존 1.3.5 사용자는 이번 업데이트를 먼저 적용해야 한다.

## 검증
- 홈 fixture: 오래된 내용, 읽음 revision, 2025/2026 경계, 빈 현재 연도 fallback, 일부 실패, 소유자·권한 분리 통과.
- 전달 단위 테스트 3종과 실브라우저 격리 fixture: 1920×1080/100%, 1366×768, 완료/미확인 구분, 실패 시 초록 상태 제거, 가로 넘침 없음, ERP 쓰기 없음 통과.
- Electron 단위 25개, native smoke 1920/1024/800, 계정별 탭·즐겨찾기 복원, 닫기/취소, 실제 updater 다운로드 및 SHA512/손상 거부 통과. 모든 fixture는 별도 프로필을 사용하며 설치하지 않는다.
- ERP 계약, dnSpy evidence, 변경 manifest/write guard, UI layout, Next production build 통과.
- 수정 전 운영 화면에서는 최초 조회 중 모두 미확인처럼 보였으나 이후 122건 전달완료와 56건 조회 중으로 확인됐다. 모든 미확인이 영구 오류라고 판단하거나 실제 미전달을 완료로 바꾸지 않는다.
- 설치 파일 1.3.6 SHA256: `3ADE97EEFBF7F7D62756CA9541ABCE8CF973C8A1759D20989E52B1F4E6B91FC0`.

## 기준선
- 적용: 기존 색상, 한 줄 탭, 접근 가능한 안내 버튼, 반응형/키보드 native smoke, 실패 상태 분리, 계정별 읽음/입력 보존.
- 해당 없음: 새 메뉴, ERP 주문·출고·재고·견적 쓰기, 운영 데이터 보정. 기존 읽기 전용 delivery proxy만 수정한다.
- 예외: 기존 모든 메뉴에 대한 UI 전체 실사 완료를 의미하지 않는다. 현재 설치 앱에 강제 설치/재시작하지 않았다.
