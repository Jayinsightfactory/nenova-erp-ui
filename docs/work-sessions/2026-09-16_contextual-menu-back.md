# 2026-09-16 메뉴 내부 단계 우선 뒤로가기

## 질문

메뉴별 뒤로가기가 새 창을 닫거나 다른 메뉴로 이동하지 말고, 내 업체 주문등록에서는 차수·업체 선택 초기 화면으로, 손익계산서에서는 결산 목록 초기 화면으로 돌아가야 한다.

## 답변·결정

- 공통 뒤로가기 버튼은 취소 가능한 페이지 내부 복귀 이벤트를 먼저 보낸다.
- 내 업체 주문등록은 선택된 차수·업체와 입력 초안을 유지한 채 차수·업체 선택 영역을 다시 펼치고, 템플릿·실행 로그를 닫는다.
- 손익계산서는 상세 또는 업로드 미리보기에서 결산 목록으로 돌아간다. 저장하지 않은 내용이 있으면 확인하고, 저장·업로드·신라 매칭 진행 중에는 복귀를 막는다.
- 페이지가 이미 초기 상태일 때만 기존 메뉴 이동 기록, 브라우저 이력, 대시보드 순으로 이동한다.
- 이 변경은 API 호출이나 ERP·손익 원장 쓰기를 만들지 않는다.

## 검증

- 공통 이벤트 단위·정적 회귀 검사
- 내 업체 주문등록, 라움·초이문·신라 손익계산서 계약 검사
- 전체 ERP 계약·dnSpy 근거·쓰기 범위·프로덕션 빌드 검사
