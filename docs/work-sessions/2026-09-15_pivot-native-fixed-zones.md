# 전산 피벗 EXE형 고정 드롭 위치

## 사용자 요청

- 마우스로 필드 버튼을 드래그하되 `nenova.exe`처럼 행·열 버튼을 놓는 위치가 공간적으로 정해져 있어야 한다.

## 적용 결정

- 필터: 배치판 맨 위 전체 폭
- 세로 행: 피벗 표의 왼쪽에 해당하는 왼쪽 영역
- 가로 열: 데이터 표의 위쪽에 해당하는 오른쪽 상단 영역
- 값: 데이터 숫자 셀에 해당하는 오른쪽 하단 영역
- 각 영역에 `표 전체`, `표 왼쪽`, `표 위쪽`, `표 숫자` 안내를 상시 표시한다.
- 기존 필드 버튼 직접 드래그, 같은 영역 순서 변경, 파란 삽입선, 오른쪽 값 필터는 유지한다.

## ERP 영향

- 브라우저의 사용자별 피벗 표시 설정만 변경한다.
- 조회 API와 SQL, 집계 원본, 엑셀 숫자값을 변경하지 않는다.
- Order/Shipment/Warehouse/ProductStock/Estimate/WebProfitReport 원장은 모두 보존한다.

## 검증

- `npm run test:pivot-exe`
- `npm run verify:erp-change`
- 1920×1080 실브라우저에서 고정 위치와 직접 드래그를 확인한다.
