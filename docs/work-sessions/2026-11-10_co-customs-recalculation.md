## 고정된 결정
- 콜롬비아 42-1 원본 통관비는 GW×460+33,000+품종수×10,000+99,000+40,000. 실제 청구 확정액이 아닌 원본 기본값 계산본이다.
- 자동 환율은 기존 조회 시세+15원 endpoint를 사용한다. 수동값과 명시 비용0은 보존한다.
- 공동 AWB 전체 중량·운임을 한 번만 배분한다. 농장 GW를 전체 GW/CW로 대신하지 않는다.
- 없는 중량·운임의 TEST_ONLY 다운로드 검증을 실제 재무 원가 검증으로 보고하지 않는다.
- 생성 엑셀의 계산 시트만 입력에 반응한다. 기존 확정 스냅샷 시트와 운영 DB는 보존한다.

### 1. 원본 통관비 자동화
**Q.** 인보이스에 없는 비용만 입력하면 다운로드되게 하고, 원래 통관비 수식을 적용하라.

**A.** 원본 수식과 기본값을 순수 helper로 연결했다. 기존 명시 총액은 그대로, FORMULA 선택 시 GW와 품종수로 재계산한다. 평균 FOB 4자리 반올림이 정확히 입증되는 기존 입고는 계산 복제본만 총금액÷송이로 정밀화한다. 진짜 금액 불일치는 차단한다.

### 2. GW 수정 후 재계산
**Q.** 남은 재계산 문제를 고치고 46-1로 검증·배포하라. 운영 DB는 수정하지 말라.

**A.** 판매 적용 행수 COUNT가 중량배분표 AB12를 덮어써 원가→추천가→판매 COUNT→원가의 순환을 만들었다. 판매 진단만 AK14:AL15로 이동했다. 원본 산식·배분계수·다른 국가 배치는 변경하지 않았다. 독립 A1 의존성 검사에 정상/옛 순환 반례를 추가했다.

**결과.** 46-1 읽기 스냅샷 31입고265상품으로 실제 웹 컴포넌트에서 다운로드했다. Microsoft Excel readOnly 테스트에서 GW100→101: 통관258,000→258,460, 원가합계+460원, 265개 상품원가·판매·이익 갱신 및 원복 통과. Artifact 재계산·수식오류0·렌더 확인도 통과했다. GW100/CW120/운임100USD는 시험값이다.
