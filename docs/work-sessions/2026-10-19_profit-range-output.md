# 주차별 매출이익 범위 출력

## 요청과 답변

- 요청: 엑셀에 1차부터 선택 차수까지 넣고 인쇄 차수를 선택하게 한다. 특정 차수 및 이전 차수의 비정상 이익률 원인을 확인한다.
- 구현: 선택 연도를 고정한 차수별 GET → 브라우저 조립. 각 차수 표시열/원본 두 시트. 현재 표시열을 사용하는 선택 인쇄. 진행률·취소·오류 차수 표시, 실패한 부분 파일은 생성하지 않는다.
- 진단: SQL SELECT와 실제 보고서 계산을 대조했다. 재고조정으로 기말이 줄어든 경우와 평가금액 누락/근사 평가/저장 결과 노후화를 별도로 판단한다. 비율이 크거나 음수라는 이유만으로 실제 손실 또는 계산 오류로 단정하지 않는다.
- 합계 이익률은 기존 원본 계약을 유지한다. 국가별 이익률의 단순 산술평균으로 변경하지 않는다.
