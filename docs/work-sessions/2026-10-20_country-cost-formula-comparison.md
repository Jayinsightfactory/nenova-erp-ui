# 국가별 도착원가 원본 수식·저장값 비교

| 항목 | 내용 |
|---|---|
| 날짜 | 2026-10-20 |
| 화면 | 인보이스 도착원가 양식 다운로드 |
| 원장 부작용 | 없음. 승인 자료 SELECT, 파일 생성만 변경 |
| 작업트리 | nw-cost-export-formulas |
| 상태 | 로컬 검사 통과, 병합·배포·실브라우저 검증 전 |

## 고정 결정

- 기존 입고, 주문, 재고 및 승인 원가를 수정하지 않는다.
- 원본 계산값과 저장값·차이를 함께 표시하도록 사용자가 승인했다.
- 저장 당시 값은 첫 시트에 유지하고 별도 `원본수식 비교` 시트에서 계산한다.
- 원본의 과거 비용 상수, 판매가, 깨진 참조는 복사하지 않는다.
- 중국 해상은 실제 CBM 배분이다. CBM/박스당 단수가 없으면 입력 필요로 표시하며
  일부 행만 배분해 정상 합계처럼 보이지 않게 한다.

## Q&A

### 1. 다른 국가 양식도 누락·원본 수식 확인
**Q.** 입고내역으로 채우는 셀과 기존 수식을 확인해서 적용하고 원장은 보존해 달라.
**A.** 10개 양식의 해시 일치 원본을 읽어 배분식과 헤더를 대조했다.
format-only 자산에는 값·수식이 없으며 기존 출력기가 모든 설명 셀을 채우지 않았다.
차수, 중량, 통관 항목명을 복구하고 개별 청구내역이 없는 셀은 내역 미보유로 표시했다.
원본 배분식·환율·관세 계산을 비교 시트에 추가했다.

### 2. 원본 계산과 승인 원가 차이
**Q.** 원본 계산값과 저장값·차이 함께 표시.
**A.** 행별 단가와 합계 각각 원본 계산·저장·차이로 나눈다.
중국 해상 승인 수량 배분과 원본 CBM 배분의 차이를 숨기지 않는다.
환율 B4와 중국 해상 W/X 입력을 바꾸면 파일 안에서만 재계산된다.
개별 부대비는 자료가 없어 총액을 임의로 역산하지 않고 승인 통관 총액을 사용한다.
따라서 이 비교는 원본 배분 산식 비교이며 원본 청구서 재현을 의미하지 않는다.

## 검증

- 원본 10개 포함 export 검사 38/38.
- 10개 생성 파일을 별도 스프레드시트 계산기로 재계산, 캐시 일치·환율 변경 확인.
- 해상 CBM 일부 누락 시 전체 합계 입력 필요 확인.
- 실제 2026 42-01 중국 승인 자료 SELECT-only 출력:
  저장 합계 29,048,581.029768원, 환율 215원. 이전 다운로드 숫자 셀 672개 동일.
  CBM/박스당단수 미보유로 원본 계산 합계 입력 필요.
- ERP 계약, dnSpy 근거, manifest, 쓰기 가드, 빌드 통과.
- EXE MakeTempTable의 BoxQuantity/BunchQuantity/SteamQuantity/UPrice/TPrice 분리 확인.
- 실제 브라우저 새 다운로드, 최종 배포는 아직 미검증.

## 비공개 검증 파일

`.tmp-*` 파일과 실제 원본 엑셀, 운영 스냅샷은 커밋하지 않는다.
원본 수식 근거는 `docs/plans/country-cost-export-formulas.md` 참고.
