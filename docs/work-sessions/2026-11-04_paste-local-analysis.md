# 2026-11-04 붙여넣기 분석 Claude 호출 절감

| 항목 | 내용 |
|---|---|
| 화면 | 붙여넣기 주문등록 / 영업부 붙여넣기 / 카톡 재고 |
| 범위 | 분석 및 후보 검증, 기존 읽기 SQL와 ERP저장 보존 |
| 상태 | 로컬 기능검사 완료, 전체검사/CI/배포 진행중 |

## 고정 결정
- 목적은 Claude 사용량 및 분석시간 절감. 별도 Python 서비스는 추가하지 않는다.
- 전체 줄/업체/품명/명시수량/단위/동작이 기존 규칙 결과와 일치할 때만 최초 모델 파싱 생략.
- 정확 전산명/수동 서버별칭과 공통 ranker가 동의하는 활성 품목만 로컬 확정; 규격/국가/화종 충돌은 기존 검증.
- 동일 검증 task는 한 번 호출하고 원래 행에 분배. API 응답에 시도횟수/토큰/경과시간 기록.
- 카톡 재고의 기존 분석은 Claude를 사용하지 않는다.

### 1. 목적 정리
Q. 쌓인 매칭 데이터로 Python처럼 처리해 Claude 사용량과 분석 시간을 줄여 달라.
A. 기존 JS 규칙/정확 매칭으로 먼저 처리하고 불확실한 항목 검증만 모델 사용. 불완전 원문은 기존 전체모델분석 유지. 같은 원문 성공 cache도 기존 그대로 활용.
결과. pasteLocalAnalysis.js / pasteAiMatchReview.js / parse-paste.js. 격리된 실제 handler 100회 모델0회, 운영 평균 속도/절감율은 아직 미측정.

## 이어갈 요청
기초/현재/변경사항 좁은 열, 최신비고/전체펼침, 카톡입력 모달, 현재재고 직접수정(수정·냉해·폐기·분실·누락)은 이번 비용개선과 별개로 남아 있다. UI는 아직 구현했다고 보고하지 않는다.
