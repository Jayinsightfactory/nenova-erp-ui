## 고정 결정

- 붙여넣기 취소·추가는 SystemActionLog.LogKey 하나가 작업 1건이다. 시간으로 합치지 않는다.
- 본인 작업 기본, 연도/차수/거래처/품목 검색 시 같은 실행의 전체 항목을 보여준다.
- 과거 잘린 감사 상세는 불완전 표시. 새 실행은 비밀정보 없는 전체 요약을 보존한다.
- 작업권 인계는 관리자 확인과 관찰 stamp 일치가 필요하다. 이전 토큰 무효화, SQL 잠금/재고 검증 우회 금지.
- 불러오기는 초안을 보존하고 원본/최신/희망값 비교. 상충은 사용자 선택; 사라진 행은 저장 금지.

### 1. 작업별 주문 변경이력

**Q.** 어느 업체 취소→어느 업체 추가를 내가 처리한 한 건으로 보여달라.

**A.** 별도 작업별 탭과 API를 추가했다. 주문 행별 이력은 유지한다. 사전검증은 실제 적용 이력과 구분하며 커서 단위 검색으로 오래된 기록도 조회한다.

### 2. 닫은 창 때문에 사용 중인 경우

**Q.** 무시하고 적용하는 버튼도 가능한지 확인하고 처리해 달라.

**A.** 단순 검증 무시는 덮어쓰기 위험이 있다. 명시적 작업권 인계로 이전 창의 저장 토큰을 무효화한 후 최신 값과 초안을 대조하도록 했다. 인계 자체는 ERP 저장을 하지 않는다. 닫기 시 최신 토큰 해제와 만료 복구도 보완했다.

### 3. 불러오기 후 수정 저장 불가

**Q.** 최신 내용 불러오기를 눌러도 수정 저장이 안 된다.

**A.** 데이터만 갱신하거나 폴링 응답 경합 때문에 오래된 편집 상태가 남는 경로를 보완했다. 입력 원본 스냅샷을 저장하고 초안 보존/충돌 선택을 추가했다. 삭제 제한 안내는 일반 초안 안내로 분리했다.

## 검증 근거

- 로컬 dnSpy ClassEstimate Insert/Update/Delete 재확인. EstimateKey 기반 원장 경로 변경 없음.
- 운영 읽기 전용 SystemActionLog 최근 5건 및 2026/36/Cust13 lease 조회. 운영 업무 쓰기 없음.
- fixture 브라우저 1920×1080: 충돌, 내 값 유지, 이미 반영, 초안 없음, 행 누락, 작업권 실패 통과. ERP POST 차단하여 검증.
- ERP 계약 전체, dnSpy 근거 검사 통과. 최종 build/changed-scope 검사/배포 결과는 PR에 기록.
