- 사용자 원본 복구 확인 후 원본4212KB 복구. 무료 분석은 미지원. 승인된 유료 분할 분석을 명시 실행했으나 약2분 이내 `PDF 누락·중복 페이지가 있습니다`로 종료. 입고/원가/재고 저장0. 자동 재시도0.

- 원본 페이지/상품/금액/ERP writer는 보존. 페이지 coverage 검증을 완화하거나 결과를 성공으로 바꾸지 않는다.
- 프롬프트에 정확 JSON 예시/필드/허용 분류/로컬번호/구간 길이/빈페이지 supporting 포함을 명시.
- 잘못된 응답형식·응답개수·중복번호·원본/로컬번호 혼동을 별도로 안내. 원본 누락이라고 오진하지 않는다. 숫자 개수 외 원문·개인정보를 오류에 포함하지 않는다.
