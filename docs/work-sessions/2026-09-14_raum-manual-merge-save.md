## 고정 결정

- 강남 기본·행사 시트 합산 결과는 수동 확인 후 저장할 수 있다.
- 이 조합은 자동 저장하지 않는다. 확인은 새 파일·상세·업체·연도 변경마다 해제한다.
- 금액 불일치·누락 요약·다른 지점 중복은 확인으로 우회하지 않는다.
- 화면과 API/core가 같은 검증 정책을 사용하고 차단 사유를 저장 버튼 옆에 표시한다.
- 운영 사용자의 실제 업로드 저장은 대신 실행하지 않는다.

### Q. 합산은 정상인데 저장 버튼을 눌러도 문구나 변화가 없다.

**A.** 강남10+행사3=13 합산을 허용하면서 duplicate branch 검증은 실패시키고 전체저장 버튼을 disabled로 만드는 모순을 코드와 fixture로 재현했다. 최신 요청에 따라 자동 저장 차단과 수동 확인 후 저장을 분리한다.
