## 고정 결정

- 엑셀 범위는 기존 요청대로 1~조회 차수 전체, 차수당 시트 하나.
- 인쇄 미리보기는 체크한 차수만. 기본은 현재 차수 하나이며 대상 개수를 표시한다.
- 출력 항목은 화면 컬럼과 별도 브라우저 저장. 처음에는 화면 설정을 가져오고, 이후 명시 버튼으로 복사한다.
- 기존 화면 v3 키를 유지하고 복원 전에 기본값을 저장하지 않는다. 빈 선택도 보존한다.
- 데이터/원가/확정본/SQL/SP 변경 없음. 이전 실제 EXE·SQL 근거를 재사용한 출력 전용 변경이며 신규 운영 데이터 대사는 아니다.

### 1. 차수 범위와 항목 선택
**Q.** 41차까지 모두 미리보기하는지, 엑셀·인쇄 항목을 선택하고 기존 컬럼과 함께 다음 방문에도 유지해 달라.
**A.** 엑셀은 전체 범위, 인쇄는 선택 차수만이었다. 범위/개수 표시와 독립 출력 선택, 화면 설정 복원 안전장치, 빈 선택 출력 차단, 선택 변경 시 미리보기 무효화를 추가했다.

### 2. 18차 HTTP502
**Q.** 18차 조회 실패 HTTP502로 부분 파일이 생성되지 않는다.
**A.** 실패 차수만 2초/4초 대기 후 최대2회 재시도. 완료된 차수는 재조회하지 않는다. 400/401/403/500/범위 오류는 자동 재시도하지 않으며 실패 시 부분파일 금지를 유지한다. 확인 당시 운영 ping200 및 별도 배포 진행은 확인했으나 502의 서버 원인은 확정하지 않았다.
