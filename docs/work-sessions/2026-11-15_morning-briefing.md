## 2026-11-16 추가 — 데스크톱 자동 업데이트 "조용히 받아 두고 앱을 끌 때 설치"

**Q3. "버전 업그레이드할 때, 직원이 네노바 데스크톱앱 실행하면 자동업데이트 되게 못하나?" → (세 방법 중) "a"**
- A안: 새 버전이 확인되면 조용히 내려받아 두고, 직원이 앱을 끌 때 설치 → 다음에 켜면 새 버전. 업무 중 앱이 스스로 꺼지거나 재시작하지 않는다.
- 예전에 자동 설치를 꺼 둔 이유(저장 안 한 입력 보호·명시적 확인)는 유지: "지금 재시작하여 업데이트"는 여전히 확인 창을 거치고, 끌 때 설치는 직원이 종료 확인을 통과한 뒤(will-quit)에만 켠다.
- 유지한 안전장치: 버전·파일명·크기·sha512 검사, 낮은 버전 금지, 여유 공간 1GB(받기 전 + 끌 때), 받기 실패 시 업무 계속. 추가: Windows 로그오프·종료 중(session-end)에는 설치를 시작하지 않음, 직원이 받기를 직접 취소하면 그 실행에서는 다시 자동으로 받지 않음.
- 구현: `desktop/updater.cjs`(background 기본 켬, `armQuitInstall`·`blockQuitInstall`), `desktop/main.cjs`(will-quit·session-end 연결), `desktop/shell/shell.js`(문구: "끌 때 업데이트"·"지금 재시작하여 업데이트").
- 검증: `desktop/tests/updater.test.cjs` 15건(신규 5), 실제 electron-updater 로 받기→종료 처리기 배선 확인(`npm run test:updater`: 정상 종료+공간 충분일 때만 조용히 설치 1회, 재실행 없음, 설치 파일은 실행하지 않음), `npm run test:smoke`·`test:exit`·`test:restore`.
- 미검증: 실제 설치본에서 "옛 버전 → 조용히 받음 → 끌 때 설치 → 다시 켜면 새 버전". 이 PC의 실제 설치본을 시험용으로 덮어쓰지 않으려고 하지 않았다. 또 1.3.26 이 이 기능이 들어간 첫 버전이라, 직원 PC에서 자동 흐름이 실제로 보이는 것은 그다음 버전(1.3.27)부터다.
