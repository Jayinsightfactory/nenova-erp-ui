# 붙여넣기 주문등록 영업방 이력 밀도 개선

## 요청과 정정

- 요청: 영업방 최신 이력 카드가 설명 문구와 여백을 많이 차지해 한 번에 볼 수 있는 카톡 목록이 적음.
- 정정: “이력만”은 품목/업체 정보를 감추라는 뜻이 아님. 업체명·품목명·수량·전산 이력을 짧고 쉽게 보이고, 그 외 장황한 부가 설명을 줄이는 것.

## 변경 내용

- 카톡 원문 요청과 연결된 전산 이력을 좌우 한 줄 카드에 업체, 품목·수량·단위, 간결한 상태/전후 수량으로 표현.
- 상세 원문·매칭 근거는 기존 접기 영역에 유지하고, API 조회/ID 연결 규칙·저장 상태 판정은 변경하지 않음.
- 카드 사이 여백, 내부 여백, 반복되는 보조 문구를 줄임. 좁은 화면의 세로 배치는 유지.
- 이 변경은 UI 전용이며 ERP API, DB, 원장 및 쓰기 경로를 수정하지 않음.

## 검증 및 배포

- 단위 UI 테스트, ERP 계약, dnSpy 근거, 변경 manifest, ERP 쓰기 가드, 빌드 및 실브라우저 smoke 결과를 작업 종료 때 기록.
- 브라우저 smoke는 1920×1080, 1366×768, 1100×768에서 수행하고 API 요청은 로컬 fixture로 가로챔. 금지된 운영/외부 쓰기는 0건.
- PR/병합/Cafe24 배포/운영 브라우저 smoke의 결과는 완료 후 여기에 추가.
