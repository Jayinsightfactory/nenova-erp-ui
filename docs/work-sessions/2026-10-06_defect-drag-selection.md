# 불량 목록 체크 영역 확대·드래그 대량 선택

사용자: 체크 공간이 너무 작아 클릭하기 어렵고, 목록 수정·정리뿐 아니라 등록 가능한 항목 선택에도 드래그 대량 선택이 필요하다.

범위: 영업 입력 행 선택, 영업지원/이월 등록 선택, 수입부/영업지원 관리 선택의 클릭 영역과 포인터 드래그. 농장·크레딧·보완 필요 체크는 행 선택과 별개이며 이 드래그에 포함하지 않는다. 공유 ERP/API/권한/등록 가능 기준은 변경하지 않는다.

기준: 체크 주변 최소44×44 CSS px, 체크22px, 번호·수정 버튼 분리. 첫 행을 누를 때 선택/해제 방향을 결정하고 시작 행~현재 행 범위를 기준으로 선택을 갱신한다. 등록 불가 행은 건너뛰며 관리/등록/영업 선택은 서로 혼용하지 않는다. 마우스/펜으로 선택 영역에서만 시작하며 입력·검색·수정 버튼의 드래그를 가로채지 않는다. 클릭·Space 키 및 터치 스크롤은 보존한다. 표 상하단 자동 스크롤, 포인터 종료/취소·창 blur·탭/연도/차수/조회 변경 시 정리한다.

검증 완료: 범위/역방향/선택 해제/기존 선택 보존/등록 가능 혼합 순수 fixture, 1920×1080·100% 일반/팝업 실마우스 드래그·큰 클릭 영역·Space·대량 자동 스크롤·상태 초기화·오류0, ERP 필수 검사와 빌드. 일반/팝업 실마우스 fixture 통과(API 쓰기 시도0·화면 오류0), 순수 범위/기존 불량 테스트 및 ERP 계약·dnSpy·manifest·write guard·layout 검사 통과. 최종 빌드 및 운영 배포·읽기 전용 스모크 완료.
