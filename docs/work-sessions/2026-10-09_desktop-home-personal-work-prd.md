# PC 홈 개인 업무·순환 소식 기획 — 2026-10-09

| 항목 | 내용 |
|---|---|
| 화면 | 네노바 PC 앱 홈 |
| 산출물 | docs/plans/desktop-home-personal-work-prd.md 및 대화 내 조작 시안 |
| 원장 부작용 | 기획·코드 읽기·예시 시안만, DB 접근/운영 쓰기 없음 |
| 배포 | 새 홈 기능은 미구현·미배포. 별도 로그인 ID 수정은 PR1001 배포 완료 |

고정 결정: 표시한 위치는 개인 체크리스트, 기존 즐겨찾기는 아래 유지. 제목 아래 지침/피드백 두 뉴스 줄. 업데이트/검색 폭 축소. 개인 업무는 수입부 공용 기록과 독립 저장. 뉴스는 멈춤/원문 보기, 실제 갱신 시각 표시. PC 한 줄 탭/즐겨찾기와 기존 입력 보존.

Q. 개인 업무 입력·수정, 새 지침과 수입부 피드백 전광판, 작은 업데이트/검색을 PRD와 아름다운 참고 시각화로 기획해 달라.

A. 기존 일일업무/지침/피드백 API를 읽기 전용으로 조사하고 Microsoft To Do, Linear Inbox, Atlassian Home 공식 참고를 비교해 PRD를 작성했다. 1차 갱신 목표는 30초 폴링이며 즉시 push 구현으로 오인하지 않도록 구분했다. 개인 업무 서버 저장·반복 실행·권한·버전 충돌·실패 복구와 네이티브 IPC 연결을 명시했다.

미완: 운영 기능 구현, 실제 PC 홈 통합·릴리스, 전체 메뉴 UI 예약 점검은 별도 후속 작업이다. 예시 시안은 실제 업무 저장/실시간 연결을 하지 않는다. orchestration 문서는 현재 누락되어 사용자 역할 지침을 따랐다.
