# 전체 메뉴 공통 UI

## 요청 및 구현
거래처 시범 화면만이 아니라 모든 탭의 디자인을 통일하라는 요청. `_app.js`에서 screen 전용 공통 테마를 로드하여 버튼, 입력, 필터, 표, 모달, 메뉴의 색상·테두리·폰트를 통일했다.

## 보호 범위
API/SQL/주문/분배/재고 데이터 변경 없음. 표 행 높이와 가상 스크롤 구조, 인쇄 스타일, 화면별 의미 있는 셀 색상은 유지했다. 각 페이지의 개별 인라인 스타일을 전면 재작성한 것은 아니다. 외부 iframe 내부 디자인도 범위 밖이다.

## 검증
- npm build 통과.
- ERP contract 전체 및 UI layout 111개 페이지 검사 통과.
- 74개 메뉴 대상 1920x1080 fixture 스크린샷: 72개 화면 HTTP200, 공통 테마 적용 및 문서 가로 넘침 없음.
- 내 작업/Orbit 보고서 2개는 서버 인증 게이트로 HTTP404. 화면 내부 검증 완료로 세지 않는다.
- 붙여넣기/입고단가/분류관리에서는 강제503 fixture에 의한 데이터 미연결 예외가 기록됨. 실제 운영 장애로 단정하지 않음.
- 거래처 fixture 1920x1080 및 800x800: 모달 범위, 신규/수정 payload, 실패 시 입력 보존, 브라우저 예외 없음.
- 스크린샷과 상세 결과: 로컬 outputs/unified-ui/report.json. 운영 데이터가 있는 전체 기능 smoke가 아님.
