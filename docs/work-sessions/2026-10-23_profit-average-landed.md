# 국가별 평균 도착원가 표시

## 요청과 범위

사용자: 엑셀 기준 평균 도착원가로 웹도 표시하고 국가별 차이를 확인한다.
DB 원장 불변. 새 작업트리 `nw-profit-average-landed`, 브랜치
`codex/profit-average-landed`, 기준 `fe57180f`.

현재 확인된 수식 범위만 설명·표시를 보완한다. 모든 국가를 동일한 평균식으로
전환하는 정책은 원본 엑셀에서 입증되지 않았으므로 이번 변경에서 임의 확대하지 않는다.

## 사전 근거

- 실제 설치 `C:/Program Files (x86)/Wooribnc/Nenova/Nenova.exe`의 FormStockView를
  `dnSpy.Console.exe --no-color -t FormStockView`로 확인했다. GetData는
  StockMaster/ProductStock을 읽고 연도차수 키로 현재/이전 재고를 연결한다.
  EXE 표시 OutUnit과 보고서의 EstUnit 환산수량은 다른 개념이다.
- 2026년 1~41차 WarehouseDetail 19,708행을 SELECT만으로 조회했다.
  기존 매입수량 fallback과 EstUnit 명시 환산 비교의 차이102행 중87행은 미연결 품목,
  9행은 미국 SALAL의 송이/단 차이,3행은 0수량,3행은 에콰도르 샘플 박스다.
  콜롬비아 5품종/베트남 평균 적용범위에서는 이 차이가 발견되지 않았다.
  다른 국가의 기존 집계수량을 새 평균단가 분모로 무조건 사용하지 않는다.
- 26~31차 및41차 현재 API를 SELECT-only runner로 조회:4,845쿼리,
  관측 시작/종료 독립 원장 지문 동일(STABLE_OBSERVED). INSERT/UPDATE/DELETE/
  MERGE/DDL/EXEC/batch/transaction을 runner에서 차단했다.
- 콜롬비아 장미26/27차는 단위 혼합으로 품목별 FIFO, 베트남27/30차는 당주 매입 없음으로
  품목별 FIFO를 사용한다. 다른 확인된6개 평균 카테고리는 유효 입력일 때 평균 우선이다.
  41차 평균 결과는 승인 통관기간 환율 추정표식을 유지한다.

## 계산 표시 계약

### 국가별 원본 재검증

26~31차 사용자 원본6개 파일을 기존 SHA 검증 추출본으로 전체 대조했다.
`주차별 매출이익 보고서`의28~31차 F7:F11(콜롬비아5품종),28/29/31차 F21(베트남)은
`(G+H)/SUMIF(구매현황!N:N,국가품종,구매현황!D:D)×재고잔량M`이다.
기초까지 합산한 이동평균이 아니라 당차수 매입수량 기준 평균이다.

| 국가 | 원본에서 입증된 범위 | 이번 표시 |
|---|---|---|
| 콜롬비아5품종·베트남 | 위 평균식. 일부 앞차수는 직접입력 | 실제 평균 선택 시 단가/분모/수량 표시 |
| 호주 | 품목별 AUD단가×수량×환율, 일부 차수 부대비용 추가 | 현재 채택 품목별 근거 표시, 국가평균이라고 오표기하지 않음 |
| 네덜란드·태국·중국·에콰도르 | F가 직접입력/0/빈칸 | 평균식 미입증, 품목별 근거 보존 |
| 미국 | F가0/빈칸 | 품목별 근거 보존 |
| 이스라엘·뉴질랜드·일본 | E/F빈칸, 별도 noEnding 손익식 | 기존 noEnding 및 원가 보존 |

원본 오류를 복제하지 않는다.28차 구매현황82행,29차68/69행,30차67/68행의
SERVICE FEE 수량1이 원본 평균분모에 포함되지만 SQL 상품 매입수량에는 비용행을
제외한다. 호주27차 재고잔량 R54=SUM(R39:R52)는53행60단 누락이다.
호주27~29차 F13은 R54와 같고30~31차는 R54+Q54와 근사하며,
Q54는 과거 고정608410/2030×잔량이다. 전 국가·차수에 통일된 평균식이라는 근거가 아니다.
모든 E는 상수/빈칸으로27차베트남,29차카네이션·장미·알스트로는 이전F와도 다르다.

평균 적용 행에서만 `(외화매입+포워딩)×환율+그외통관비`를 매입수량으로 나눈
실제 채택 단가를 표시한다. 그 단가와 환산재고수량의 곱이 기말재고액이다.
기초는 이전 기준기간의 평가 결과이며 현재 차수 단가로 역산하지 않는다.
품목별 원가/FIFO/단위 혼합/무매입/근거 누락/확정본 근거 미보관은 구별한다.
판매단가·분배단가로 대체하거나 여러 단위의 수량을 합쳐 가짜 평균을 만들지 않는다.
