# 전산 피벗 네이티브 필드 드래그

## 사용자 요청

- 피벗 필드를 작은 이동 버튼으로 옮기는 방식이 아니라 `nenova.exe`처럼 필드 버튼 자체를 마우스로 드래그하고 싶다.
- 행·열·값·필터 영역 배치도 EXE와 유사하게 보여야 쉽게 사용할 수 있다.

## 적용 기준

- 필드 버튼 전체가 드래그 대상이다.
- 드래그 중 현재 대상 영역을 파란색으로 강조하고, 놓일 정확한 순서를 파란 삽입선으로 표시한다.
- 영역 사이 이동뿐 아니라 같은 영역 안의 순서 변경도 지원한다.
- 필드 오른쪽 `▼`는 위치 이동이 아니라 실제 값 필터를 연다.
- 필터 영역을 위쪽 전체 폭, 세로 행·가로 열·값 영역을 아래쪽에 배치해 네이티브 PivotGrid의 필드 영역 구조를 따른다.

## ERP 부작용

- 브라우저 표시 모델과 사용자별 화면 설정만 변경한다.
- API·SQL·조회 범위는 변경하지 않는다.
- `Order*`, `Shipment*`, `Warehouse*`, `ProductStock`, `Estimate`, `WebProfitReport`를 모두 보존한다.

## 검증

- 영역 사이 정확한 삽입, 같은 영역 재정렬, 값 집계 방식 보존을 순수 함수 테스트로 고정했다.
- 피벗 전용 회귀와 Next 프로덕션 빌드를 통과했다.
