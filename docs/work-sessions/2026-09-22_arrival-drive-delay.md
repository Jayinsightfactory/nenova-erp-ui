## 고정 결정
- 매분 전체 확인 대신 파일/설정 변경 감지와 단발 예약.
- 기준은 업무드라이브 서버 등록시각 uploadedAt+24시간. 새 내용 버전은 새 등록시각부터 대기.
- 최신 파일 먼저 선택하고 대기하므로 이전 파일을 대신 등록하지 않는다.
- 완료 파일은 재업로드하지 않으며, 서버 재시작 뒤에도 원래 예정시각을 복원한다.
- 국가 설정은 기존 2026 네덜란드 유지.

### 1. 요청과 구현
**Q.** 1분마다 확인하지 말고 원가자료 파일이 생기고 1일 지나면 자동 업로드.
**A.** 공통 arrivalDriveTiming에 24시간 기준을 추가하고 표시·실행·예약에서 함께 사용. 기존 저장 SQL 및 수동 원가 보호는 변경하지 않음.
**검증.** 가상 시계로 24시간 직전/정각, 신규 버전, 비활성화, 중복 이벤트, 서버 복구 예정시각 검사.

## 완료 검증
