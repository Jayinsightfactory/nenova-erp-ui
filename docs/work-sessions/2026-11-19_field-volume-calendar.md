# 현장물량표 요일 세로 배치와 업체별 품종 요약 (2026-11-19)

Q. 가로로 이어지는 요일을 세로로 보고 빠렛 옆 박스수와 요일·지역 오른쪽 업체별 품종을 보고 싶다.

A. 품종명은 한 번만 표시하고 같은 셀에서 요일마다 새 줄로 나눈다. 하단 요일·지역 제목의 C셀에 업체총량(품종수량,...)을 추가한다. 빠렛 괄호에는 기존 스냅샷의 실제 박스수를 사용한다. 원본 환산을 보존하므로 카네이션45박스는 기존40박스/빠렛 기준1.1(45)다.

단일시트·A3가로·입출재잔 수식·1차합산 선택을 유지했다. 기존 메뉴·데스크톱 연결·UI 조작순서는 변하지 않는다. 운영 원장 쓰기0. 구현·검증 근거는 [기준표](../plans/field-volume-calendar-2026-11-19.md), 마지막 배포 상태는 WORK_MEMORY.md 참조.
