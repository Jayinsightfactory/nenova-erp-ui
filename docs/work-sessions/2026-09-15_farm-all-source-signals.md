# 농장 불량 자동감지 전체 원본 적용

## 사용자 요청

“자동감지이슈는 그대로인데? 원본범위는 늘어났어도” → 수정안 승인 “시작”.
원본 목록 확대뿐 아니라 미확인·농장 미지정 원본의 반복을 실제 자동감지에 포함한다.

## 결정

- 기존 확정 불량률, 원본 데이터, 피드백 저장 적격성 유지.
- 농장 지정 원본의 4개 패턴에 미확인 자료도 포함하되 확인 필요 표시.
- 농장 미지정은 동일 품목·주차의 여러 업체 / 동일 업체·품목의 차수 반복만 감지.
- 내부 업체키를 응답 키에 포함하지 않음. 업체명은 펼친 근거에 유지.
- 자동감지 전체 단위 기본값, 확정 분석 필터와 분리.
- 확인 필요 후보는 원본 확인만 가능하며 미완전 원본으로 이슈 자동 생성 금지.
- 하나의 원본이 여러 이슈에 포함될 수 있으므로 감지 원본 고유 건수 별도 표시.

## 변경/검증 기록

전체 ERP 회귀·신규 감지 및 저장 차단·dnSpy·쓰기 가드·빌드 통과.
Chrome 1920×1080 및 760×900에서 신규 농장 미지정 후보, 별도 전체 단위,
업체명 근거, 확인 필요 후보 생성 차단, 기존 적격 피드백 입력 진입 확인.
운영 원장/피드백 저장 없음. 최종 PR·배포·실제 감지 수치는 후속 기록으로 남긴다.
로컬 outputs/의 fixture·검증 로그는 커밋하지 않는다.
