# 2026-10-15 품종별 총 조정수량 (수국 제외)

## 요청과 기준
사용자: “품종별 총수량도 +-로 표시해줘 수국 빼고.”
조정표의 현재 연도/차수/검색을 기준으로 품종별 총 조정수량을 추가한다. 수국은 요약에서만 제외하고 기존 품목행은 보존한다.

## 데이터 계약
기존 StockHistory AfterValue-BeforeValue와 Product.FlowerName/OutUnit의 조회 결과만 사용한다. SQL/원장 쓰기/재계산 없음.
운영 SELECT로 장미(단/송이), 카네이션(단/박스) 혼합을 확인하여 품종+단위별 합산한다. 단위 미확인은 품목별 분리한다.
수국/Hydrangea 품종 제외. 품종미확인일때만 원품명/표시명으로 수국fallback제외. 명확한 비수국은 품명만으로 제외하지 않는다.
무이력 빈칸, 유효0은0, 누락값/오류는 확인필요. 작은 비0을 임의0으로 반올림하지 않는다.
