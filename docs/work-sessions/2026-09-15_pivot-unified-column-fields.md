# 2026-09-15 전산 피벗 가로 열 일괄 너비·필드 영역 이동

## Q&A

**Q. 피벗통계에서 가로 열 하나를 조절하면 전체 열이 함께 조절되고, 필드값을 가로·세로 행열·값 영역 사이에서 버튼 형태로 옮기고 싶다.**

**A.** 기본 화면인 전산 피벗에 `세로 행 / 가로 열 / 값 / 필터` 영역을 명확히 표시하고, 각 필드 칩에 `⇄` 이동 버튼을 추가했다. 필드명 또는 `⇄`를 누르면 네 영역 이동 버튼이 열리며 기존 드래그 이동도 유지한다.

**A.** 가로 데이터 열은 개별 열 ID가 아니라 사용자별 공통 `__data` 너비를 사용한다. 표의 가로 데이터 열 하나를 드래그하거나 `가로 열 전체 너비`를 입력하거나 자동맞춤을 실행하면 현재 피벗의 모든 가로 데이터 열이 같은 폭으로 바뀐다. 과거 개별 `col-*` 너비 설정은 첫 값을 공통 너비로 승격한 뒤 제거한다. 세로 행 머리글 너비는 필드별 설정을 유지한다.

## 원장·호환성

- `nenova.exe FormQuantityPivot` dnSpy 근거의 15개 필드와 Row/Column/Data/Filter 배치를 보존했다.
- 변경은 브라우저 표시·사용자별 레이아웃 설정뿐이다.
- 조회 API, 피벗 원본 숫자, XLSX 숫자값, `OrderDetail`, `ShipmentDetail`, 재고·견적 원장은 변경하지 않았다.
- 교차연도 분리는 기존 `OrderYear + OrderWeek` 계약과 fixture로 유지된다.
