## 질문 → 답변

**Q.** 개발 이야기에서 말로만 설명하지 말고, 실제 화면 자료가 남아 있으면 함께 보여 달라.

**A.** MindMap/Orbit의 저장소 기록에 남은 게스트 테스트 화면 한 장을 첫 시각 근거로 연결한다. 이 화면은 흩어진 작업을 지도에서 살펴보려 한 배치와 조작을 보여 주지만, 개인 작업 이름이나 실제 연결 결과는 보이지 않는다. 따라서 `시도한 화면`으로 표시하고 결과 화면이 확인되지 않았다는 문구를 함께 둔다.

## 근거와 표시 원칙

- 원천: `mindmap-viewer` 커밋 `aa78dbdf13aa71d433b2f9c5e9e6bd5b288fd737`, `test-screenshots/03-personal.png`.
- 원본 Git blob과 가져온 PNG의 `git hash-object`가 모두 `159ce7a8c1a9e2f26d5a393959b05f673db8694f`로 일치한다. 이미지를 재생성하거나 편집하지 않았다.
- 공개 파일은 개인 작업 데이터가 없는 게스트·빈 궤도 화면을 시각 검토한 뒤 로컬 정적 PNG로 둔다.
- 2026년 3월 25일은 저장소 자료가 남은 기록의 날짜다. 실제 캡처 시각은 확인되지 않았으므로 촬영 날짜로 표현하지 않는다.
- 이미지가 열리지 않아도 실패 안내를 화면에 남기고, 전체 크기 원본 링크를 제공한다.
- 이 캡처만으로 실제 작업 연결 결과, 현재 운영 상태, 배포 완료를 주장하지 않는다.

## 회귀 계약

- 이야기 ID, 로컬 허용 경로, 실제 PNG 시그니처, 원천 저장소·전체 커밋 해시·경로를 검사한다.
- `attempt` 단계, 제약 설명, 결과 자료 미확인 문구를 검사한다.
- UI의 정적 설정 import, 이미지 오류 표시, 전체 크기 링크를 검사한다.
- 전체 개발 이력 테스트 명령에 새 시각 근거 검사를 포함한다.

- 원본 링크 보완 후 최종 `npm run test:full-development-history` 57/57, `npm run build` exit 0 확인. dnSpy·ERP 쓰기 가드 재검사 통과.
- 화면 기본값: 정적 사진 비율 유지·전체 페이지 스크롤 적용, 키보드 원본 링크 제공. 매칭·실제 ERP 반영·초안 입력은 해당 없음. 기준 viewport 실브라우저 검증은 배포 후 수행 예정.

- 전체 개발 이력 회귀 검사 57/57 통과.
- 전체 ERP 계약 검사, dnSpy 근거 검사, 변경 manifest 검사, ERP 쓰기 범위 검사가 모두 종료 코드 0으로 통과.
- 최초 통합본 빌드 1회 통과. 이미지 실패 뒤에도 원본 링크를 남기는 보완 후 재빌드는 메인 작업에서 진행 중이다.
- 커밋·PR·병합·배포와 운영 화면 확인은 아직 완료되지 않았다.
