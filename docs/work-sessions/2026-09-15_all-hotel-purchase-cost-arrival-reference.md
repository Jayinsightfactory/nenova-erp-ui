# 2026-09-15 모든 호텔 매입단가·도착원가 참조

## 질문 → 답변 요약

### 사용자 요청

- 차수별 매입단가 관리가 신라뿐 아니라 다른 등록 호텔에도 동일하게 적용되어야 한다.
- 호텔별 저장 상세 견적의 `1개당 매입단가` 바로 옆에서 해당 차수 도착원가를 확인하고 싶다.
- 도착원가는 웹 확인용이며 엑셀 다운로드에는 넣지 않는다.

### 반영 결정

- 라움·초이문 공통 단가 계약은 유지한다.
- 신라와 활성 등록 호텔은 버튼으로 선택하고 각 `PartnerCode` 안에서 독립 단가를 조회·저장한다. 호텔 사이에 단가를 복사하거나 학습 원장을 갱신하지 않는다.
- 상세 웹 조회 때만 `WebArrivalCostLine`의 현재값을 명시 연도·대차수·품목키로 읽는다. 같은 대차수의 세부차수 값은 모두 나열하며 전년도·전차수 값으로 폴백하지 않는다.
- 상세 품목 단위로 안전하게 환산할 수 있을 때만 값을 표시한다. 전산 품목 미연결은 `품목 연결 필요`, 해당 차수 값 없음은 `해당 차수 없음`으로 표시한다.
- 엑셀 API는 기존 `loadRaumPnlDetail`만 사용하므로 웹 전용 도착원가 참조가 포함되지 않는다. 인쇄 모델도 변경하지 않는다.

## 보존·검증

- 매입단가 저장 허용 범위: `WebRaumPnlItem.CostPrice/CostSource`, 해당 부모의 감사 필드.
- 주문·출고·입고·재고·견적·매출·도착원가 원장은 보존한다.
- 신규 교차연도/단위/품목 격리 테스트 및 기존 라움·초이문·신라 회귀 테스트, ERP 계약, dnSpy 근거, 쓰기 가드, Next 빌드를 통과시킨다.
