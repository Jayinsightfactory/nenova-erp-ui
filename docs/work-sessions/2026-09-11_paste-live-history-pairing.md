# 2026-09-11 카톡 원문과 실제 변경 이력 인접 연결

## 사용자 요청과 정정

- 최신 영업방 대화와 적용 히스토리를 함께 보고, 수동 적용 확인도 가능해야 한다.
- 직전 화면은 원문 왼쪽, 전체 주문 변경 이력 오른쪽으로 떨어져 있었다.
- 저장된 비교 보고서만 연결하는 것으로는 부족하며, 실제 변경 이력이 카톡과 매칭되어
  원문 옆에 표시되어야 한다는 최신 요청을 반영한다.

## 구현 범위

- 로그인된 같은 출처에서 명시 연도·세부차수·기간의 주문/분배 이력을 읽기 전용 조회.
- 카톡별 정확 업체·품목·수량·단위·시각 근거를 대조하고 원문 옆에 요청별 표시.
- 주문 이력과 분배 이력 분리. 0→0, 다른 차수, 모호한 별칭, 복합 요청은 완료 증거로
  취급하지 않는다. 이력 부재도 미적용으로 단정하지 않는다.
- 기존 수동 적용 표시와 명시 AI 비교는 유지하며 자동 LLM 호출이나 ERP 쓰기는 없다.
- 왼쪽 두 열 폭에 원문/해당 이력을 나란히 두고 전체 주문 이력은 접힌 참고 목록으로 둔다.

  조회 실패 시 마지막 정상 이력 보존, 가로 넘침 없음 확인. ERP/LLM POST 0건.
