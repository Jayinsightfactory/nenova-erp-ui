## 고정 결정

- 이번 통관 ZIP 가이드만 갱신한다. 기존 모든 영상에 새 지침을 적용한 것으로 표시하지 않는다.
- 영상·한국어 자막·목차의 업무 단계 번호를1~4로 일치시킨다.
- 전체 위치 안내→대상 외곽 강조→부드러운 영상 줌인→실제 조작·결과 확인→줌아웃을 따른다.
- 원본1920×1080/브라우저100%는 유지하고 영상 후처리로만 확대한다. 단계 배지·자막은 고정한다.
- 실제 화면을 연습 fixture로 조작하며 운영/API/DB/계산식은 변경하지 않는다.

### 1. 새 지침으로 가이드 재제작

**Q.** 바뀐 지침으로 가이드 영상을 다시 만들어 달라.

**A.** 기존 통관ZIP 시나리오를4단계로 번호화하고 옵트인 영상 카메라 연출을 추가했다. 초기 최종 프레임에서 확대된 단계배지 중복을 발견해 원본 상단70px·하단180px를 고정하고 본문830px만 확대하도록 교정했다. 추가 독립 검토에서 등록 후 사라진 버튼의 테두리가 이전 위치에 남는 문제를 발견해 결과 확인 흐름도 보완한다.

**결과.** 최종105.55초/1920×1080/브라우저100%/20fps,14,070,246바이트. 실제 원본 촬영은 최초1회와 시각 결함 교정 후 최종1회였다. 카메라 중복은 동일 원본 후처리로 먼저 교정했고, 사라진 버튼의 낡은 강조는 결과 발생 즉시 해제·줌아웃 후 전체 결과 읽기로 다시 촬영했다. 부모가1·3·4단계 결과 원본 프레임을 직접 확인했다. 신규 번호/카메라/결과 순서 검사를 test:workflow-guides에 연결했다.11워크플로·12영상 검사, 실제 플레이어1920/390·자막·4목차·키보드·다운로드·접기 모두 통과. 빌드·PR/배포는 후속 기록한다.
