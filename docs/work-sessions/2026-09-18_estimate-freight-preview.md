# 견적서 운임비 계산 미리보기

| 항목 | 내용 |
|---|---|
| 사용자 요청 | 30~37차 정재훈 담당 지방업체 견적의 상차운임·운송료를 분석하고, 업체별 박스 집계/단가/반올림을 확인하는 버튼 기획 |
| 실측 | 견적 행에서 `... 운송료`는 박스 단위·박스당 1,500원, `현지상차운임`은 업체 총 박스·박스당 2,000원으로 별도 저장됨. 30~32차 실제 화면에서 확인. |
| 안전범위 | 주문·분배·재고·견적 원장에 쓰지 않는 읽기 전용 미리보기부터 구현. 기존 운임 행을 표시해 중복 입력을 차단. |
| 정책 | 박스 환산 후 올림(4.5→5), 버림(4.5→4), 실수량 유지 선택. 세부차수 합산/분리 선택. |
| 구현 | `lib/estimateFreightPolicy.js`, `components/estimate/FreightChargePreviewModal.js`, 견적서 관리의 `🚚 운임비 추가` 버튼 |
| 검증 | 순수 정책 테스트, ERP 계약 매니페스트, dnSpy 근거 검사, ERP 쓰기 범위 검사, Next 빌드 통과 |
| 보류 | 실제 원장 적용은 기존 운임행의 중복·확정상태·세부차수 업체별 합산 정책을 추가 확정한 뒤 별도 저장 계약으로 진행 |
