## 고정 결정
- 사용자는 파일 수동 첨부가 아니라 업무드라이브 최신 차수 원가자료의 서버 자동 반영을 요청했다.
- 관리자 설정으로 대상 연도·국가 지정. 기본 꺼짐, 서버에서 1분마다 실행.
- 국가별 최신 차수, 원본 수정시각 기준. 과거 시트 제외, 중복 hash는 재등록하지 않는다.
- 수동 현재본·수동 수정·다른 파일군 충돌은 보류. 저장 실패는 전체 롤백.
- 기존 사용자 변경이 있는 db09 작업트리를 보존하기 위해 `arrival-drive-auto` 작업트리를 사용했다.

### 1. 자동 업로드 요청
**Q.** 드라이브에 최신 차수 원가자료가 올라오면 직접 자동 업로드.
**A.** 서버 스케줄러·관리자 설정·상태 패널, 공통 후보/범위 정책, 기존 저장 트랜잭션 내 hash 멱등 감사와 수동 현재본 보호 구현.
**검증.** ERP 전체 계약·dnSpy·manifest·쓰기 가드·Next 빌드 통과. 실제 저장 코어 격리 fixture 중복/신규 revision/2025 보존/실패 롤백/수동 현재본 보류 통과.
