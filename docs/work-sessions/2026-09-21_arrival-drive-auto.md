## 고정 결정
- 사용자는 파일 수동 첨부가 아니라 업무드라이브 최신 차수 원가자료의 서버 자동 반영을 요청했다.
- 관리자 설정으로 대상 연도·국가 지정. 기본 꺼짐, 서버에서 1분마다 실행.
- 국가별 최신 차수, 원본 수정시각 기준. 과거 시트 제외, 중복 hash는 재등록하지 않는다.
- 수동 현재본·수동 수정·다른 파일군 충돌은 보류. 저장 실패는 전체 롤백.
- 기존 사용자 변경이 있는 db09 작업트리를 보존하기 위해 `arrival-drive-auto` 작업트리를 사용했다.

## 운영 확인 결과
- 1920×1080 화면/배포 스모크 통과. 2026 네덜란드 자동반영 켜짐.
- 실제 최신 원본은 `38-2 NL 원가자료.xlsx` (37-2 아님). 최초 자동 실행은 XLSX default export 런타임 오류로 저장 전 실패. instrumentation 번들이 선택하는 ESM은 named export만 제공하므로 namespace import로 수정하고 회귀 검사 추가. 원가 저장 완료 전까지 완료로 보고하지 않음.
- #724 배포 35583394197 성공 (ERP 계약 및 hydration smoke 포함). 보완 뒤 자동 재시도 성공.
- `38-2 NL 원가자료.xlsx` 34행, ImportKey=22, 2026/38-2/네덜란드만 현재본으로 저장. 기존 총 Import 19 → 20, DRIVE_IMPORT 감사 1건. 같은 원본 중복 없음.
