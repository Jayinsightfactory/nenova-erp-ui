## 고정 결정

- 사용자는 기존 국가별 변환 로직을 유지하고 각 단계를 개별 작업처럼 검증하는 자동 흐름을 요청했다.
- 자동 준비는 문서 1건의 초안 저장과 서버 검증까지. 실제 입고 등록과 원가 승인 저장은 범위·사유를 담당자가 확인한다.
- 원가 실패는 입고 실패가 아니다. 완료 입고를 재생성하지 않고 실패 단계만 재시도한다.
- 8개 국가 변환 지원과 원가 공식 지원은 별개다. 검증된 공식은 중국 해상 실제량, 네덜란드 항공 금액배분이다. 다른 국가에 임의 공식을 적용하지 않는다.
- documentId/sourceHash/revision/연도/세부차수와 원장 키가 일치해야 다음 단계로 진행한다.
- 실제량 원가를 기본으로 하고 95% 예상은 비교용이다. 누락 환율·금액을 0으로 대체하지 않는다.
- 이 자동 흐름은 사용자 시작·현재 브라우저 문서 범위다. 브라우저 종료 후 무인 서버 배치나 예약 실행은 아니다.

### 1. 국가별 변환에서 원가까지 자동으로, 검증은 개별로

**Q.** 기존 수입부 변환 로직을 각 국가에 적용하고, 원가자료까지 만들되 각 작업을 분리하여 검증 누락을 막아 달라.

**A.** 국가 변환/초안/서버 검증/입고/입고 재조회/원가 계산/승인 저장/원가 재조회 상태를 분리했다. 명시 저장 이후에도 별도 재조회가 성공하기 전에는 완료로 표시하지 않는다. 초안 저장 응답이 불명확하면 재저장 대신 같은 문서를 조회한다.

**발견.** 기존 어댑터의 네덜란드 행 금액 누락과 호주·미국 표시 단위 차이, 생성 인보이스와 원문 인덱스 연결 검증 부족을 추가 보완 대상으로 확인했다. 국가별 generator 자체의 계산식은 변경하지 않는다.

**검증 중간 결과.** 격리 브라우저에서 자동 검증 이슈 중단, 명시 입고 확인 대기, 등록 문서 읽기 전용 재개, 초안 보존, 이슈 복사, 1920×1080/100% 및 1280×800 레이아웃 통과. 실제 운영 API 쓰기는 차단된 fixture 검증이다.

### 2. 최종 안전 검토 보완

- 확정4xx 거절은 수정 가능하게 유지하고 응답 불명 UNKNOWN만 초안 재조회 잠금으로 구분했다.
- 서버 문서가 COMMITTED여도 현재 revision operation이 없고 이전 revision만 있으면 저장된 수정 초안이다. 이때 기존 입고 재조회 루프가 아니라 현재 revision preview 및 명시 수정 승인을 진행한다.
- unknown 원가 요청의 재시도가 로그인 만료 등으로 거절되어도 최초 요청의 미저장이 증명되지 않는다. 정확한 원래 pending을 보존한다. 브라우저401 fixture에서 요청 유지·폼 잠금 확인.
- PR #977: 독립 단계 검증. 최종 배포 완료 여부는 후속 배포 기록으로 확인한다.
