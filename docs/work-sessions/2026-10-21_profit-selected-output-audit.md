## Q&A

### 1. 실제 18차 다운로드·502
Q. 실제 18차도 다운로드 끝까지 확인하고 계속 502면 수정·배포해 달라.
A. 운영 SQL을 현재 보고서 로더로 읽어 18차 16개 카테고리/476 SELECT를 두 번 정상 완료(약6~9초). 실제 SQL payload로 XLSX 생성·재오픈, 1시트 및128개 표시값 일치. 인증된 운영 HTTP 다운로드와 최초502의 nginx/pm2 원인은 아직 미검증이다. 브라우저 및 Windows 컴퓨터 사용 도구 모두 초기화 단계에서 kernel assets 경로 오류가 발생했다. 로컬 계산/파일 성공을 운영 HTTP 성공으로 보고하지 않는다.

### 2. 전체/단일 선택
Q. 전체 선택이면 전체, 한 개 선택이면 한 개 다운로드여야 한다.
A. 이전 component가 인쇄에만 selected 배열을 전달하고 엑셀에는 undefined를 넘긴 것이 원인. 두 경로에 같은 배열을 전달하고 빈 선택 차단, 실제 차수 기반 파일명/시트 수/진행 문구를 적용한다. 단일·전체·비연속 선택 파일을 실제 Chromium 다운로드 후 재오픈하는 회귀를 추가한다. 합성 테스트 파일은 사용자 Downloads가 아닌 ignored .verify 전용 폴더에 저장한다.

### 3. 27~31차 원본과 웹 손익률
Q. 국가·품종별 오차가 어디서 생겼는지 다시 검증해 달라.
A. Downloads의 원본 ZIP에서 5개 파일을 읽었다. 개별 27/29/30/31차 파일과 SHA256 일치. 80개 행의 동일 입력 공통 계산은 원본과 일치하고, 이익 차이는 매출·재고평가·상품/포워딩·통관 입력 차이로 분해된다. 원본 30/31차 베트남 상쇄 이익조정도 동일하다. 독립 SQL 원행 합산 N/L/O/Q 328개 항목 일치. 생성된 5시트 XLSX640개 값도 공통 계산과 일치했다.
원천 수량 및 원가 근거는 별도 위험이다. 30차 발생 에콰도르 수량 불일치가31차로 이월되고31차 E/F 원가 근거 누락이 남는다. 판매단가 대체 평가가 남은 행도 실제 매입원가 검증 완료로 판정하지 않는다. 상세 실제 숫자·파일·원행은 공개 Git에 넣지 않고 ignored `.verify/27-31-comparison.md` 및 `.verify/comparison.json`에만 보관한다.
