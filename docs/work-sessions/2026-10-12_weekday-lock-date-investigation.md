# 주광 견적서 작업 메뉴 안내와 차수·출고일 조사

## 사용자 요청과 확인

- 주광 견적서는 `/estimate/weekday`의 별도 메뉴다. 사용 중 안내에는 이름뿐 아니라 실제 점유 메뉴를 표시해야 한다.
- 2026년 41-01과 41-02의 최근 수량·출고일 변경이 41-02 날짜로 적용되었는지 읽기 전용으로 조사했다. 사용자가 Brut을 지정했고 실제 Product는 CARNATION Brut / ProdKey 359다. 의도한 두 출고일은 아직 확인되지 않았다.
- Brut 현재 원장은 41-01에 10월 11일 4박스와 10월 13일 2박스, 총 6박스이며 41-02 상세는 없다. 최근 감사의 41-02 수량 3 삭제는 10월 12일 행이었다. 원장 전체를 41-02로 덮어썼다는 근거는 확인되지 않았다.
- CustKey 533의 운영 조회에서 41-01에는 2026-10-08/11/13 출고일, 41-02에는 2026-10-11/12 출고일이 존재한다. 날짜와 원장 차수는 일대일 관계가 아니다.
- 조회 시점의 웹 변경 감사에는 2026-10-12T05:40:23.949Z, ProdKey 359, 41-02의 수량 3 삭제 한 건이 확인됐다. 이 기록만으로 사용자가 설명한 두 차수의 날짜 이동을 입증할 수 없다.
- 실제 표는 날짜에 배치하고 기존 날짜의 편집은 effectiveOrderWeek를 보존한다. 동일 품목·날짜에 복수 차수가 있으면 편집을 차단한다. 별도 날짜·차수 이동은 도착 날짜의 달력 차수로 재배정한다. 운영 데이터 오류로 단정하거나 보정하지 않았다.

## 수정 범위와 기준

`ERP_EDIT_LOCKED`의 서버 제공 lease.ownerName/pageCode를 사용해 주광 저장 실패 안내에 `임재용 · 견적서 관리에서 작업 중`을 표시한다. estimate는 견적서 관리, estimate-weekday-apply는 주광 견적서이며 미등록 코드는 다른 작업 화면이다. 토큰·불투명 stamp는 출력하지 않는다.

| 동작 | ERP 원장/재고/견적/손익 | 편집 보호 | 초안 |
|---|---|---|---|
| 오류 안내 표시 | 보존 | 보존 | 보존 |
| 운영 이력 대조 | SELECT만 | SELECT만 | 변경 없음 |

기존 저장 상태 불명 시 조회, UUID 중복 방지, 트랜잭션/잠금 정책을 변경하지 않는다. 강제 해제·운영 보정 없음.

## 엑셀 잔량과 차수 선택

사용자는 음수 잔량의 계산 기준과 41·42차를 선택하여 두 차수만 다운로드하는 기능을 요청했다.

- 잔량은 ERP 재고가 아니다. 최초분배 확정 기준(없으면 현재 미확정 후보)에서 날짜 구간의 출고 합계(유효 초안 포함)를 뺀다. -1은 목~일, -2는 월~수, 대차수는 전체 7일이다. 날짜 구간은 원장 세부차수와 달라질 수 있으므로 음수가 곧 ERP 음수재고를 뜻하지 않는다. 기준/단위를 확인할 수 없으면 null/빈칸이다. 계산식은 수정하지 않았다.
- 상단에 조회된 차수의 연도 포함 체크박스를 추가했다. 기본 전체, 조회 범위 변경 시 초기화, 0개 선택 시 다운로드 차단. 두 다운로드 버튼은 같은 선택을 사용한다.
- 내보내기 업무키는 year+majorWeek이며 선택한 차수 열만 생성한다. 전체 상품 행/양식 서식은 보존한다. 다운로드 중 선택을 잠그고 비동기 대기 후 선택이 바뀌면 저장을 차단한다.
- 파일명은 선택한 연도·차수를 표시한다. 기존 워크시트 연도 숨김 원칙은 같은 연도에서 유지하며 교차연도일 때는 구분한다.
- 운영 DB/원장/확정/재고/초안 저장은 변경하지 않는다.

## 메뉴 기준선

- 적용: 기존 오류 영역의 줄바꿈 및 role=alert 유지, 의미 있는 메뉴명, 사용자 입력 보존, 기존 버튼/키보드 순서 보존.
- 해당 없음: 신규 메뉴·shell·표 레이아웃·입력 기능 추가. 문자열 표시만 변경하므로 별도 열/행 크기 변경 없음.
- 예외 없음. 저장 SQL 변경 없음. 기존 dnSpy 계약과 원장 쓰기 순서를 변경하지 않음.
- docs/CODEX_SUBTASK_ORCHESTRATION.md는 현재 checkout에 없어 사용자 제공 운영 지시를 적용했다.
