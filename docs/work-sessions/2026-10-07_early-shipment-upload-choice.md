## 고정 결정

- 선출고는 이전 차수에 실제 반영된 수량의 표시다. 표시만으로 이번 차수 분배에 자동 추가하지 않는다.
- ‘주광’ 정상 업체열과 ‘주광선출고’ 미매칭 원문 업체열을 구분한다. 미매칭 열별로 업체 연결 후 포함 또는 이번 파일에서 분배 안 함을 선택한다.
- 이름에 선출고가 있어도 자동 제외하지 않는다. 제외는 원문 업체열 수량만 대상으로 하며 정상 업체열과 기존 category missing-to-zero 정책은 유지한다.
- 선택 변경·취소 후 다시 검증한다. 검증 성공한 선택과 아직 재검증하지 않은 선택을 구분한다. 제외 선택은 영구 업체 별칭으로 저장하지 않는다.
- 좁은 셀의 경고는 별도 작은 normal-flow 공간을 사용하고 다른 입력·변경·잔량 버튼을 덮지 않도록 한다. 상세는 기존 팝업으로 확인한다.

### 1. 요청과 실제 변경

**Q.** 선출고와 음수 변동 경고가 다른 버튼을 가리는 전체 구조를 확인하고, 엑셀 미매칭 업체마다 분배 포함 여부를 선택한다.

**A.** 주광 경고의 일반 오류 박스 padding/border 및 absolute overlay를 제거하고 compact warning 공간으로 분리했다. 선출고 상태는 짧게 표시하고 원천 연도·차수·수량 상세와 비고창을 보존한다. 재확인은 현재 날짜 수량 대신 정확한 원천 연도·차수의 실제 저장 수량과 단위를 대조한다. 현재 0/이전 차수 3은 원천 근거가 충분하면 경고하지 않고, 근거 누락·중복·부족·단위 불명은 재확인한다. 업로드의 기존 ‘제외(농장 등)’ 버튼을 명확한 ‘분배 안 함’과 업체 연결 선택으로 바꾸고, 검증된 선택·재검증 필요 선택과 제외 수량행 수를 표시한다. 모달 Escape, Tab 순환, 초점 복귀를 추가했다.

**근거.** 설치 Nenova.exe의 FormShipmentDistribution을 dnSpy CLI 재실행해 조회·날짜 저장 경로를 확인했다. 읽기 전용 2026/Cust533 SELECT: 40-01 상세83/수량4909, 40-02 상세36/수량2754, 41-01 상세38/수량1919. 원장 쓰기 없음. 실제 buildImportPreview fixture에서 정상 주광5+미매칭 선출고3은 제외 시5, 연결 시8, 취소 시미매칭으로 복귀하며 이전 차수/전년도 범위를 보존한다.
