## 고정된 결정

- 사용자가 제공한 Packing List HTML, Checklist HTML, PedidosHome Python/Excel 변환 기능을 네노바웹에서 사용한다.
- 사용자 답변: **팀 공동 저장·수정, 수정자 이력 표시**.
- 공동 상태는 웹 전용 `data/runtime/import-team/`에 저장한다. ERP SQL 원장으로 자동 등록하지 않는다.
- 충돌한 저장은 409로 거부한다. 브라우저는 저장 성공을 확인한 뒤 완료 표시하며 실패 시 초안을 보존한다.
- 체크리스트는 실제 일자, 결제는 연월, 휴가는 연도로 구분한다. 같은 요일/다음 해 상태를 재사용하지 않는다.
- API 키는 서버 환경변수만 사용한다. 첨부 파일의 BAT, 바로가기, Python 자체는 실행하지 않았다.
- 패킹리스트 AI PDF와 브라우저 내부 AWB PDF 텍스트 추출은 별도 처리다.
- 화면 기준 1920×1080 CSS pixel / 100%, 기존 `_app.js` 화면틀을 하나만 사용한다.

## Q&A

### 1. 기존 수입부 도구를 네노바웹에 추가

**Q.** 수입부 직원들이 쓰던 AI 도구들을 네노바웹 기능으로 추가하고 싶다.

**A.** 파일을 읽어 패킹리스트(8개국 및 AWB), 국가별 발주서(7개국), 체크리스트/미결/항공/휴가/재배계획으로 분리했다. 첨부 매칭표 1457개를 초기 기준으로 준비했다. 원본 국가별 Excel 계산·서식·수식은 이관 테스트로 대조한다. 중국 발주서의 원본 CL 인덱스 결함은 분석 문서에 별도로 기록한다.

### 2. 공동 저장과 수정자

**Q.** 팀 공동 저장·수정, 수정자 이력 표시.

**A.** 인증 사용자 ID/이름을 서버에서 기록한다. 클라이언트가 보내는 수정자 값은 사용하지 않는다. version/revision 충돌을 차단하고 이전 요청 응답이 최신 화면 상태를 덮지 않도록 키별 요청 세대를 구분한다. 오래된 수정 이력은 삭제하지 않고 별도 보관한다.

## 검증 근거와 한계

- 실제 첨부 발주 Excel: 콜롬비아 카네이션 80품목, 합계 1010.
- 브라우저 업로드 → 변환 → Excel 다운로드 후 B84=1010, D4=B4+C4 확인.
- 초기 매칭표 1457개, 공동 저장/수정자/409 충돌/401 미인증/400 잘못된 PDF 검증.
- 1920×1080 일반 화면과 popup 단일 shell, 900px 화면 가로 잘림 확인.
- 다른 국가의 발주 계산은 합성 fixture와 원본 코드 대조다. 실제 국가별 파일 검증을 완료했다고 해석하지 않는다.
- 실제 인보이스/AWB PDF가 첨부되지 않았다. AI 추출 정확도/실제 AWB 인식률은 미검증이며 모의 응답과 검증 경로만 확인한다.
- 품목 카탈로그 원본은 별도 업로드가 필요하다. 첨부 matches 파일은 카탈로그 자체가 아니다.

## 작업 분담

프로젝트 하위 작업 규칙에 따라 메인이 설계·계약·통합·외부 작업을 맡았다. 구현 기본 모델이 환경에서 제공되지 않아 `gpt-6.1-sol/high`로 대체했고, 원본 분석은 `gpt-6-luna/high`, 독립 저장 계층 검토는 `gpt-5.6-sol/high`를 사용했다. 하위 작업은 로컬 파일/테스트만 수행했다.

## 후속 사용자 요청: 업로드 증설 및 보완

**Q.** 업로드 한도를 늘리고 나머지를 보완하되, 0으로 변환해 다운로드 가능한 것이 왜 문제인가?

**A.** 정상 0수량은 문제가 없다. 앞서 발견한 문제는 원본 양수 수량을 읽지 못해 0으로 바꾼 것이었다. 정상0은 허용하고 파싱 실패만 구분한다. `plans/import-team-hardening-2026-10-06.md`에 설계와 부작용 경계를 기록했다.

- 로컬1920×1080/100% 실브라우저: 중국59품목/19업체/1850단. AWB총액1379.60/문서일2026-10-01. NL90행/7589송이 코드추출 및 합계 대조. 새 AI호출0, ERP쓰기0, 공동운영자료쓰기0. 카탈로그저장은 브라우저격리테스트만 수행.
- 카탈로그3268원본행 중 같은 국가/품목코드 중복7행은 미리보기에 표시되고 최종3261고유품목으로 저장한다. 병합/교체 모두 사용자 확인 전에는 저장하지 않는다.
- 무료 처리 실패 시 명시적 AI 분석을 선택하도록 변경. 유료 호출의 성공 응답만 계정별 파일캐시로 재사용하며 캐시저장 실패는 추출실패와 구분한다.
