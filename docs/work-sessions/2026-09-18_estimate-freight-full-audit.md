# 견적서 운임·상차운임 전수 확인 (2026-09-18)

## 운임 원장 적용 마무리 (2026-09-18)

- 운임 적용은 `pages/api/estimate/freight-apply.js`에서 세부차수별로만 수행한다. 합산은 미리보기 전용이다.
- 기존 활성 `ShipmentMaster`가 없거나 확정(`isFix=1`)이면 저장하지 않는다. 기존 동일 운임 품목은 건너뛰어 재클릭 중복을 막는다.
- 신규 행은 `ShipmentDetail`과 `ShipmentDate`를 한 트랜잭션에서 생성하고, `ShipmentDetail.OutQuantity`와 `SUM(ShipmentDate.ShipmentQuantity)`를 재조회해 검증한다.
- `OrderDetail`, `Estimate`, `ProductStock`, `StockHistory`, `WebProfitReport`는 변경하지 않는다. 출고일은 기존 정상 출고 상세의 `ShipmentDtm`을 사용해 전산과 동일한 차수 출고일을 유지한다.
- 편집 보호(ERP edit lease), 품목 단위(박스), 운임 품목 매칭이 하나라도 확인되지 않으면 전체 롤백한다.

## 범위와 방법

- 화면: `견적서 관리` 실브라우저(로그인 세션), 읽기 전용 조회
- 기준: 2026년 30~37차, 담당자 `정재훈`, 지방업체로 표시된 업체
- 확인값: 세부 견적의 운임/현지상차운임 품목, 출고일, 수량(박스), 단가, 금액, 비고/차감 표시
- 원장 저장·수량/단가 수정·확정 상태 변경은 수행하지 않음

## 업체별 적용 패턴

- `(주)영남꽃소재`: 품목별 운송료가 주로 `1,500원/박스`, 현지상차운임은 `2,000원/박스`.
- `인터넷공판장 (영남가빈)`: 30~35차 품목 운송료가 `3,000원/박스`인 행이 반복됨. 37차는 일반 품목 운송료 대신 현지상차운임이 `2,000원`과 `1,500원`으로 **1차/2차 별도 행**으로 기록됨.
- `부산 서부꽃집`: 품목 운송료 `3,000원/박스`, 현지상차운임 `2,000원/박스` 패턴.
- `월드천사`: 현지상차운임이 `1,000원/박스`로 반복되며 30차에는 `[단가차감]` 음수 행이 있음. 차감 행을 신규 운임으로 합산하면 안 됨.

- `신라호텔`, `태광플라워 양주지점`, `미정화훼유통`, `원당 태광플라워`, `로뎀농원`: 확인 차수·화면에서 운임 행이 없는 차수가 반복됨. 운임을 일괄 자동 추가할 대상이 아님.

## 세부차수 합산 여부

현재 저장 데이터는 업체별로 다르며, 전 업체를 합산 또는 분리하는 공통 규칙은 확인되지 않았다.

- 대부분 화면은 운임 종류별로 한 행을 보여주지만, 실제 출고일(`ShipmentDate`)이 행에 붙어 있다.
- 37차 인터넷공판장의 `현지상차운임`은 `2차 출고 운임비`와 `1차 출고 운임비`가 별도 행으로 명시되어 분리 저장되어 있다.
- 따라서 신규 운임 기능은 기존 행을 덮어쓰거나 주요차수로 합산하면 안 되며, 기존 `ShipmentDate`/비고를 보존하고 업체별로 `분리`를 기본값으로 미리보기해야 한다.
- 30차처럼 출고 목록에 30-01·30-02가 동시에 표시되는 업체는 세부 행의 실제 출고일과 비고를 기준으로 분배해야 한다. 단순히 업체별 합계만 보고 합산 정책을 추정하면 안 된다.

## 운임 추가 버튼 설계에 반영할 결론

1. 업체 선택 후 현재 세부차수의 일반 품목을 국가/품종별로 박스 환산해 **미리보기만** 한다.
2. 기존 운임/상차운임 행은 `기존 행`으로 표시하고, 신규 예상 행과 분리한다.
3. 단가 기본값은 업체·운임종류별 최근 확인 단가를 제시하되 직접 수정 가능하게 한다.
4. 4박스+5단과 같이 박스 환산 잔량이 생기면 `버림/올림/반올림`을 선택하게 하고, 결과 박스 수와 근거 품목을 함께 표시한다.
5. 세부차수가 2개 이상이면 `세부차수별 분리`를 기본으로 하며, 사용자가 명시적으로 `주요차수 합산`을 선택한 경우에만 합산한다. 합산 시에도 원래 세부차수와 출고일 목록을 이력으로 남긴다.
6. [단가차감]/음수 행은 운임 추가 계산에서 제외하고 별도 경고한다.
7. 저장 적용은 `FREIGHT_APPLY_SEPARATE_SUBWEEK` 계약으로 제한 제공한다. 합산은 미리보기 전용이며, 확정·중복·품목/단위/출고일 검증 실패 시 전체 롤백한다.
