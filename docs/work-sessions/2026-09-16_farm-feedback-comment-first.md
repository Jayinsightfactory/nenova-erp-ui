# 농장 피드백 코멘트 우선 표시

요청: 답변 대기·답변 도착·재발 확인에서 코멘트 미리보기를 우선하고 상세 최상단에 요청 문구 표시.

- 해당 3개 상태는 농장명 다음에 최근 코멘트를 최대 4줄 표시한다. 요청 전은 불량 요약 우선 유지.
- 상세는 선택 이력 전체의 가장 최근 실제 REQUEST를 표시한다. 최근 3건 밖의 요청도 포함한다.
- 로딩·조회 실패·이력 선택 필요·요청 없음 상태를 구분하며 자동 제안을 실제 요청으로 대체하지 않는다.
- API, SQL, 주문, 분배, 재고, 견적, 손익 및 원본 데이터 변경 없음.
- 회귀 테스트: 최근 요청 선택, 최근 3건 밖 요청, 로딩/오류/요청 없음, 상태별 표시.
- 읽기 전용 독립 코드 리뷰에서 구체적인 회귀 위험 없음.
