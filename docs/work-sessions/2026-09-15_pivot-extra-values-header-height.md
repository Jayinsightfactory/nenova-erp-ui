# 전산 피벗 거래처 헤더 높이·가격 값 보강

## 요청

- 상하 셀 높이는 거래처명/농장명 부분만 조절하고 싶다.
- 기존 웹 피벗에서 보던 분배단가·도착원가 같은 값을 전산 피벗에도 추가한다.

## 결정과 구현

- 가로 축의 `거래처명/농장명` 단계에만 세로 드래그 손잡이를 제공하고 18~120px로 제한한다. 값은 사용자별 브라우저 화면 설정과 즐겨찾기에 보존한다.
- `분배단가`는 기존 웹 피벗과 동일하게 `ShipmentDetail.Cost`를 출고수량으로 가중평균한다. 단순 합계로 가격이 커지지 않도록 전산 피벗에 `수량가중평균` 집계를 추가했다.
- `도착원가`는 기존 운송원가 스냅샷/live 계산을 재사용하고 동일 품목의 여러 농장/AWB 중 최고 표시원가를 사용한다. 사용자 합의대로 부가세 별도 값만 제공한다.
- 두 값은 기존 FormQuantityPivot 원본 SQL을 수정하지 않고 읽기 전용 후처리로 결합한다. 보강 값 조회만 실패하면 원본 피벗은 계속 표시하고 화면에 경고한다.
- ERP 원장 쓰기와 재고·주문·분배·견적 부작용은 없다.
