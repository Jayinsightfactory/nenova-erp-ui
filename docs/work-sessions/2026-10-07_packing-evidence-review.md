## 이어받을 때 고정된 결정
- 업로드 추출 후 GW/CW/운송비 확인창을 자동 표시하고 직접 입력·수정한다.
- 미인식은 빈칸, 명시0은0. GW와 CW/순중량은 혼용하지 않는다.
- PDF 텍스트의 유일한 원문 일치 좌표만 검증 근거로 강조. AI bbox만 있으면 추정 영역임을 표시한다.
- 중국/콜롬비아 기존 freight의 부대비 합계 의미를 유지하며 꽃값을 운송비에 포함하지 않는다.
- 수정 사유와 확인값은 엑셀의 마지막 인식값 확인 시트에 남는다. 첫 시트 고정 배치 유지.
- 실제 입고 SQL 자동저장과 주문/입고 과부족 비교는 이전 설계의 미완 과제이며 이번 변경에 연결하지 않는다.

### 1. GW/CW/운송비 자동 채움과 원본 검증
**Q.** 인식되면 자동으로 불러오되 확인창을 띄우고 직접 수정할 수 있어야 한다. OCR 인식한 페이지 구간을 강조해 시각적으로 검증해야 한다.

**A.** 추출 결과와 별도로 확인 초안을 관리한다. 좌측 PDF·우측 중량/비용 입력창, 페이지 이동·확대, 수정 사유·확인 체크, 닫기 후 초안 복원을 구현했다. 위치 없는 항목은 임의 강조하지 않는다. AI 호출은 기존 명시 버튼을 유지하며 원본 미리보기는 로컬 처리다.

**근거.** `docs/plans/packing-evidence-review-2026-10-07.md`, `lib/importPackingReview.js`, `components/import-tools/PackingEvidenceReview.js`.

### 2. 기존 EXE/SQL 보호
**A.** 실제 로컬 decompile `ExcelLoadingPackingList.GetExcelLoading`은 `dataSet.Tables[0]`만 선택한다. 확인 시트는 마지막에 추가한다. 이는 시트 선택 근거이며 운영 입고 저장까지 검증했다는 뜻은 아니다. nenova.exe 및 SQL 수정 없음.

## 검증 구분
- 실제 7페이지 중국 인보이스 PDF 렌더링 및 6페이지 `4,005.12` 텍스트 좌표 하이라이트를 브라우저에서 확인.
- UI 검증의 AI 응답은 fixture로 가로채며 유료 API를 호출하지 않았다. 실제 AI 인식 정확도 실험과 구분한다.
- 1920×1080/100%, 900/480px 화면; 추가 테스트/배포 결과는 후속 기록.
- output의 원본 파일, 스크린샷, 브라우저 fixture 스크립트는 Git 제외.

### 검증 보완
- 독립 검토에서 read/write 재직렬화의 서식 손실과 누락 통화 추정 문제를 발견하여 수정했다.
- `packingReviewWriter`가 원본 workbook의 최초 write 직전에 확인 시트를 추가한다. 원본 첫 시트 XML(열 너비/값/수식/스타일 참조)과 fonts/borders/fills XML 보존 테스트 통과.
- 집중 테스트 9/9, import-team 179통과/3선택 스킵, operations-knowledge 17/17. ERP 전체 회귀, dnSpy 증거, manifest, 쓰기 가드 통과.
