## 고정 결정
- 최신 사용자 지시로 판매 입력을 항상 비우던 이전 정책을 대체한다.
- 실제 원본 11개 profile 해시 대조. 판매칸이 빈 원본도 있으므로 전부 실판매값이 있었다고 설명하지 않는다.
- 28개 참고 판매 기준은 정확 품목명/환산수량 일치·가격충돌 없음에 한해 사용한다.
- 나머지 품목은 원본 추천식(/0.77, 중국 해상 /0.85×1.1)으로 자동 입력하며 실제 판매가가 아닌 기준가로 표시한다.
- AE:AF에 출처 유형·차수·셀. 판매가 수정 가능, 명시0 유효. 미확인 원가를 0으로 채우지 않는다.
- 운영 입고/원가 승인/매출/손익/재고 원장과 첫 고정 원가 스냅샷 보존.
