| 항목 | 내용 |

| 화면 | 견적서관리 |
| 원장 부작용 | 선택 Estimate만 삭제, 연결 영업 불량 원본·이력 보존, 선택 등록만 해제 |
| 운영 반영 | 진행 중 |

## 고정 결정

- 정상출고·판매요청·다른 차감종류는 삭제 대상 아님.
- 확정해제/재확정/재고계산 없이 EXE ClassEstimate.Delete 방식으로 삭제.
- 연도·부모차수·업체·출고번호·차감번호와 조회 원본값을 잠금 대조.
- 선택 중 오류 한 건이면 전체 취소. 삭제 전 원본/사용자 감사 기록.
- 미저장 단가/수량은 임의 폐기하지 않음.
- 운영 실제 고객 삭제는 검증용으로 실행하지 않음.

### 1. 체크 후 삭제

**Q.** 견적서관리에서 불량차감·검역차감이 삭제되지 않는다. 체크 후 삭제 가능하게.

**A.** 삭제 버튼이 비활성 상태이고 API 연결이 없었다. dnSpy CLI의 실제 Delete 메서드와
운영 CodeInfo/Estimate/트리거/교차연도 범위를 읽기 전용 확인한 뒤 화면·서버를 분리 구현.
삭제 안전 대조용 원본 스냅샷도 별도 전달하여 표시 반올림이나 현재 품목 단위에 영향받지 않게 했다.

**결과.** 체크/전체선택·확인·선택삭제·재조회 구현. 연결 영업 원본과 부분 이월 이력 보존,
교차연도/다른 업체/조회 후 변경 차단, 실패 전체 rollback 검사. Claude CLI 별도 검토 반영.
`docs/work-reports/2026-08-26_estimate-deduction-delete.md`에 근거 기록. 전체 자동검사·견적 검사·빌드 통과.
운영 반영·체크박스 화면 검증 결과는 연결된 변경사항 검토 및 배포 실행에 기록한다.
