# 주광 박스 + 낱개 입력 (2026-10-23)

## 사용자 요청과 결정
- Q: 수국/카네이션은 방향키에서는 박스 입력을 유지하고 클릭하면 박스+송이/단을 입력, dnSpy 방식과 동일하게.
- A: 클릭/F2에서 작은 입력창, Tab/Enter/ESC 및 초점복귀. 수국은 품목별 SteamOf1Box, 카네이션은 BunchOf1Box 사용. 알스트로는 변경하지 않는다. 일반/윌슨 둘 다 지원.
- 1박스+3단(15단 포장)=1.2박스. 수국1송이(30송이 포장)=0.033333333박스, 전산표시0.03과 실제 저장값을 구분. 수국16/50 포장도 최신DB 환산값 사용.
- 실제 dnSpy에서 N2는 표시, 저장은 decimal 표현을 float 컬럼에 전달. 기존 2자리 반올림을 분수 박스에 적용하면 두 날짜의 낱개 합산이 틀어질 수 있어 주광의 해당 환산 경로만 보완.
