# 국가별 발주서 다운로드

요청은 국가·차수·세부차수 버튼을 순서대로 선택하고 조회된 발주서를 내려받는 것이다.

국가 → 차수 → 세부차수를 직접 선택하면 선택 연도·세부차수 원주문만 조회하고 파일별 다운로드 버튼을 표시한다. 연습 주문으로 키보드 선택과 실제 46-01_Holex.xlsx 저장·150송이 재열기를 확인했다. 운영 실주문 다운로드는 미검증.

## 다운로드 전 수량 수정
국가별 발주서에서 기존 주문이 있는 업체별 송이·단 수를 전산값과 대조해 수정한다. 수정값·행 합계·다운로드는 파일 전용이며 저장수량·환산기준은 보존한다. 150송이→140송이 브라우저 다운로드 및 송이/단/0/음수/빈 값 회귀 검사. 운영 실주문 미검증.
