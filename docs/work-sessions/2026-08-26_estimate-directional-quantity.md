# 견적서 수량 증가·감소 구조 변경

## 질문

“구조 변경작업 시작, 수량이 늘어나는 작업에서만 수량검증하면되는거잖아.”

## 답변과 결정

부족재고 검사는 증가에만 적용한다. 감소에서도 연도·업체·출고일·단위·동시 수정 확인과
변경 품목 재고 반영은 필요하다. 기존 품목의 수량 저장은 확정 상태를 유지하고, 변경되지 않은
품종을 해제하지 않는다. 신규 품목 추가는 별도의 기존 품종 범위 사이클을 유지한다.

## 결과

로컬 구현·격리 실제 SQL·전체 자동검사와 가짜 자료 브라우저 저장 검증 완료.
운영 DB 설치·원격 반영·배포·고객 자료 수정은 하지 않았다.

## 재개 지침

기존 “수정작업만 실행” 제한 유지. 운영 반영은 별도 지시와 EXE/웹 작업 중지 구간 확보 후
메인이 수행한다. 진행 중/대기 중 잠금을 지우거나 34-02 부분 해제를 임의 복구하지 않는다.
