# 주광 최신 분배 갱신·윌슨 수량 편집

- Q: 느낌표가 뜨며 수량이 수정되지 않는다. 최신 분배를 계속 가져오되 입력 초안을 유지하고 검증·배포해 달라.
- A: 검증된 동일 업무키/단위의 ERP 합계 변경은 기존 윌슨을 유지한 일반 예상값을 편집할 수 있게 한다. 수정은 기존 명시적 분배 적용까지 초안이다. 미검증·단위 변경·윌슨 초과량은 임의 보정하지 않는다.
- 30초 및 화면 복귀 자동 조회를 추가한다. 초안, 윌슨 초안, 다른 날짜 입력은 보존한다. 입력칸에 초점이 있거나 저장/변경확인/보조 작업 중이면 자동 조회를 미룬다. 새 범위·새 요청 뒤 도착한 응답은 무시한다.
- 핵심 조회 실패 시 이전 자료 유지와 마지막 성공시각 표시. 견적·이력 독립 오류는 분배 갱신을 막지 않고 해당 오류를 표시한다. 저장 전 강제 최신 조회·snapshot/revision 검증은 유지한다.

## 근거와 부작용

- 메뉴 기준선: 화면틀/키보드/초안/페이지스크롤/ERP 반영 전 확인 적용. 새 메뉴·매칭·원장 변경 해당 없음. 예외 없음.
