## 이어받을 때 고정된 결정

1. 사용자는 **DB를 건드리지 말라**고 명시했다. 보정 SQL·SP·스냅샷 저장·보고서 자동 갱신으로 해결하지 않는다.
2. 공식 관세율 존재, 품목 HS 분류 추정, 실제 거래 특혜 자격, 실제 납부액을 구별한다. 최신91개 연결은 조건부이며 전체 품목 관세 인증이 아니다(초기90개 기록은 아래 경과).
3. 관세 실제 입력·명시 0·수기 H는 우선한다. 원문 빈칸을 0원 확정으로 사용하지 않는다.
4. 27차 중국 J10 빈칸 복원은 SQL 실제 행이 없는 정확한 역사 fallback만 대상이다.
5. 40cm 행별 보정은 관세 전용 운임 배분에만 적용한다. 기존 입고 원가 화면의 Excel 호환 출력은 보존한다.
6. 단순 총액 비례 보정으로 근거 부족을 숨기지 않는다. 부분/역전 중량·누락·중복키는 보류한다.
7. 태국·호주·에콰도르 등 다른 국가 품목의 공식 관세율은 이번 중국 네 HS 검증으로 인증하지 않는다.
8. 사용자는 `aside로 작업해봐`라고 요청했다. Aside 열기 queued는 실브라우저 검증 성공이 아니다.

### 3. 2026-11-03 — 26~31차 검증 결과

**Q.** 국가·반차수별로 1만원 이내 맞는지 검증.

**A.** 4국가×6차수×2반차수48조합 중 입고25개. 완전예측14개 가운데 원본 관세가 숫자인12개는11개가±1만원이고29-01중국은+56,289원으로 초과했다. 2개는 빈칸이라 비교불가, 11개는 근거 미완전으로 부분합을 전체값으로 제시하지 않았다. 따라서 모든 차수가1만원 이내라는 결론은 아니다. 기존 실제 관세는 이 독립예측으로 덮지 않는다.

웹 파생값의 변경은26~31범위에서27중국과28중국 두 행이다. 27추정 관세621,939.946원 추가,27기말/28기초102,092.029원 증가. 회사 수익률27차12.744497%→12.538914%,28차7.056038%→7.017363%. DB 변경은 아니다. 전체 수치와 미확정 품목은 상세 비교표를 따른다.
