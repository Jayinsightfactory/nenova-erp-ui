# 카탈로그 이미지·단가·기타 자동 간격

Q. 단가와 기타1·2를 입력했을 때 이미지와 글씨가 겹친다. 자동으로 서로 닿지 않게 배치해 달라.

A. 텍스트 높이를 먼저 예약한 뒤에도 100% 초과 크기가 셀을 침범하던 경로를 수정한다. 입력 줄바꿈과 모든 표시 항목을 높이에 반영하고 이미지/글씨0.25cm, 다음 행0.35cm 안전 간격을 둔다. 확대 요청값은 저장하되 실크기는 남는 영역으로 제한한다. 제목·로고 공간도 보호한다. 편집·미리보기·인쇄·PPT는 공통 계산을 사용한다.

| 동작 | 카탈로그 설정·출력 | Product/Order/Shipment/Stock/Estimate/매출 |
|---|---|---|
| 글씨 입력·이미지 조절 | 자동 위치/크기 계산 | 전부 보존 |
| 저장·PPT | 기존 초안 JSON/파일 | 전부 보존 |

기준1920×1080, 2행×5열, 긴 영문명+한글+단가+기타1 두 줄+기타2, 이미지100/125/200%, 세로0/50/100% fixture로 이미지-글씨와 글씨-다음행 경계를 검증한다. 텍스트 자체가 칸보다 큰 비현실적 설정은 기존 오류 안내/내보내기 차단을 유지한다.
