## 고정 결정

- 기준 해상도 1920×1080 CSS pixel / 100%. 1366×768도 검증.
- 모든 메뉴는 좌클릭. 필터와 필드 설정 진입점을 분리한다.
- 필터 팝업은 누른 버튼에 붙고 화면 밖으로 나가지 않는다.
- 소수점 숨김은 표시 형식일 뿐 숫자 원본과 집계는 바꾸지 않는다.
- ERP 원장 수정/재계산/전산 프로그램 수정은 범위 밖이다.

## 질문과 처리

**Q.** 셀 모양, 가로·세로 크기, 소수점 버튼, 필터 위치·디자인, 정렬 등 지적사항 모두 수정.

**A.** 전산 피벗 표시 계층을 묶음 머리글/행 병합과 명시적인 좌클릭 필터·정렬로 수정한다.
기존 계산·조회 계약과 실패 시 직전 정상 결과 보존은 유지한다.

## 작업 배정

- 메인: 설계, 계약/부작용 검토, smoke, 통합 및 외부 쓰기.
- Terra/high 2개 하위 작업: 표·엑셀 표시와 팝업·컨트롤 분리 구현. P0_LOCAL만 허용.
- 입력 소스/계약/의존성 사전 준비 완료. 하위 작업은 승인·운영 쓰기 없음.

- 피벗 범위/모델/표 구조/XLSX 테스트 통과. 원본 소수 수량과 모든 표시 합계 XLSX roundtrip 대조.
- 전체 ERP 계약, dnSpy 근거, manifest(59개), 변경 쓰기 가드(API 변경 0개), UI layout 통과.
- Next production build 통과. UI 검증은 1920×1080/1366×768, 100% CSS pixel.
- 실제 버튼 시험: 15필드 × 4영역 이동, 빈 선택/AST 필터, 오름/내림/해제,

- 범위 변경 뒤 503 오류에도 마지막 정상 표 유지. 외부 요청 0, ERP 쓰기 요청 0.
