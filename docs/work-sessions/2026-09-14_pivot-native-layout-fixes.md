## 고정 결정

- 기준 해상도 1920×1080 CSS pixel / 100%. 1366×768도 검증.
- 모든 메뉴는 좌클릭. 필터와 필드 설정 진입점을 분리한다.
- 필터 팝업은 누른 버튼에 붙고 화면 밖으로 나가지 않는다.
