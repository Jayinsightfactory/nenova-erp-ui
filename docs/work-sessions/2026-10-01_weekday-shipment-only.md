# 주광 견적서 출고 없는 품목 숨김·품목 추가

| 항목 | 값 |
|---|---|
| 일자 | 2026-10-01 Asia/Seoul |
| 화면 | /estimate/weekday |
| 원장 부작용 | 없음. 표시 필터와 기존 SELECT-only 대조만 사용 |
| 기준 | 1920×1080 CSS px, 100% |
| 배포 | 이 문서 커밋의 PR 및 Cafe24 workflow 결과 참조 |

## 고정 결정

- 전/현재/후 차수 원문에 양수 출고 또는 양수 초안이 하나라도 있으면 표시한다.
- 0/null/빈값만 있는 행은 표에서 숨기고 원문 데이터는 그대로 보존한다.
- 주문·입고·견적 수량으로 출고가 있다고 추정하지 않는다.
- 복수 단위·복수 세부차수는 합계 대신 개별 출고 원문으로 표시 여부를 판단한다.
- 품목 추가는 ERP 품목 검색·조회 후 현재 화면 목록에만 추가하며 0이어도 유지한다.
- 인쇄/수량 환산/확정/재고 로직과 API SQL은 변경하지 않는다.

## Q&A

### 1. 출고 수량 없는 품목 숨김

Q. 출고 수량이 없는 품목은 리스트에 안 보이게.

A. `hasHorizontalShipmentQuantity` 공통 표시 판정을 추가하고 검색·품종 필터 앞에 적용했다.
가로 표의 빈 행을 줄이며 숨김 건수와 전체 숨김 상태의 안내를 표시한다.

### 2. 품목 추가

Q. 품목 추가 버튼이 있으면 될 것 같아.

A. 숨긴 품목 및 기존 ERP 품목을 검색·선택하는 작은 입력 구역을 표 위에 추가했다.
기존 읽기 전용 대조를 성공한 뒤 해당 행을 표시한다. 실패하면 오류와 후보를 유지한다.
선택 품목은 추가 순간 주문/분배가 생성되지 않으며 이후 입력도 여전히 메모리 초안이다.

## 검증·운영 경계

- 양수 소수, 전후 차수만 출고, 날짜별 출고, 교차연도, 혼합 업무키, 초안 및 빈값 fixture.
- 실제 컴포넌트 SSR/이벤트 회귀와 브라우저 fixture; 최종 결과는 PR/실행 로그 참조.
- 원장 저장·재고 조정·확정 작업과 물리 프린터 출력을 시험하지 않는다.
- `output/`의 스크린샷·실행 로그는 로컬 증거로만 남기고 커밋하지 않는다.
- 하위 작업: 모델 override 없이 상속 모델, MECHANICAL 역할, P0_LOCAL의 테스트 2개 파일만.
