# 인보이스 원본 PDF 검증

## 요청과 결정

사용자는 오인식을 직접 확인할 수 있도록 검증 페이지에 PDF를 표시하고, 확실하지 않은 값은 확인 후 진행하도록 요청했다. AI 자체 confidence 100%도 사실 확인을 대신하지 않으므로 PDF 상품행은 모두 담당자가 개별 대조한다.

## 구현

- 왼쪽 실제 PDF canvas, 오른쪽 국가별 원문 품목·수량·단가·금액과 중량·운임 검토.
- 원문 페이지/정확한 인용 근거가 있을 때 클릭하여 위치 표시. 근거 없는 위치를 만들지 않는다.
- PDF 렌더 성공, 모든 상품행 및 인보이스 확인이 필요하다. 파일 변경·렌더 실패·값 수정 시 확인을 무효화한다.
- 수정 사유와 원본/수정값, 확인 시각, 스냅샷을 보존한다. 다운로드와 입고 초안은 동일 검증을 적용한다.
- 기존 ERP 입고 writer와 국가별 환산식은 수정하지 않는다. 운영 DB/재고 쓰기와 추가 유료 AI 분석은 실행하지 않았다.

## 검증 상태

집중 회귀 검사 59 통과/선택 검사 1 생략. 전체 ERP 계약, 변경 manifest, 쓰기 범위, dnSpy 근거 검사 및 production build 통과. 실제 기존 운영 PDF 표시를 확인했고, 신규 UI 브라우저 회귀 및 배포 후 실제 PDF 검증은 최종 결과로 갱신한다.

## 이어서 확인할 사항

UI 브라우저 회귀, 최종 리뷰, PR/배포와 실제 PDF 검증 결과를 확인한다. 파싱하지 못하는 원본을 검토 완료 또는 입고 완료로 설명하지 않는다. 이 기능은 사람의 대조를 강제하는 것이며 AI 정확도 100%를 보장하지 않는다.
