## 이어받을 때 고정된 결정

- 차수는 오름차순/내림차순으로 본다.
- 표시 순서: 차수 → 국가 → 품종(CountryFlower) → 품목명 → 농장별 원가.
- 같은 차수·같은 품목은 `농장1 8,800원 / 농장2 8,000원 / 농장3 8,600원`처럼 농장 원가를 한 줄에 비교한다.
- 품목명 검색 없이 품종 버튼만 눌러도 조회된다(연도 필수, 차수는 선택).
- 수국 Color Grade 표는 농장명을 그룹 첫 행만 적어도 아래 품목 행으로 이어받는다.
- 입고수량은 엑셀 헤더로 단/박스를 분류하고, 전산 OutUnit으로 덮어쓰지 않는다.
- 이미 올라간 행은 파일을 다시 올려야 새 파서가 반영된다.

## 질문 → 답변

### 1. 2026-08-24 13:12 — 이해했나?

**Q.** 도착원가에서 차수 오름/내림, 같은 차수 같은 품목은 농장별 원가, 순서는 차수>국가>품종>품목명>농장. 품명 검색 없이도 품종 선택 조회.

**A.** 그렇게 이해하고 구현한다. 웹 원장 SELECT/표시만 바꾸고 주문·출고·견적은 건드리지 않는다.

### 2. 2026-08-24 13:30 — 농장·입고단위

**Q.** 도착원가 파일에서 농장 표시 인식이 잘 안 되고, 농장 분류가 안 되는 것도 많고, 입고수량이 단인지 박스인지 분류가 안 되는 것 같다.

**A.** 수국 Color Grade 표는 농장명을 그룹 첫 행만 적는다. 파서가 아래 행으로 이어받지 않아 빈 농장으로 남았다. 농장 매칭은 상품명 정규화(cloud/fresh 제거)를 써서 Cloud 같은 농장이 지워졌다. 수량은 전산 OutUnit 또는 무조건 '단'이라 엑셀 단/박스를 구분하지 못했다. 웹 원장만 고치고, 이미 올라간 행은 파일을 다시 올려야 반영된다.

### 3. 2026-08-24 14:13 — CW/GW 특별기준·농장 셀병합

**Q.** 업로드 엑셀의 CW(Chargeable Weight)·GW(Gross Weight)로 특별기준을 넣자. CW가 GW보다 크면 장미 외 원가는 제외하고, CW가 GW와 같거나 작으면 카네이션·알스트로 원가를 보여 달라. 지금은 농장 셀병합이 안 읽혀 원본 농장이 `-`이고 그룹 헤더에 농장미지정이 반복된다.

**A.** 파서가 엑셀 `!merges`를 펼치고, 수량 없는 농장 제목 행도 아래 품목에 이어받는다. 목록은 행의 CW/GW로 표시만 가린다(원장 삭제는 없음). CW>GW=장미만, CW≤GW=카네이션·알스트로(장미 숨김). 농장+원가 문구는 한 번만 적는다. 이미 올라간 33-1 행은 파일을 다시 올려야 농장·CW/GW가 붙는다. Order/Shipment/Estimate/Stock은 그대로다.

### 4. 2026-08-24 14:49 — 특별기준은 콜롬비아만

**Q.** 장미·카네이션 CW/GW 특별기준은 콜롬비아만이다.

**A.** 표시 필터를 콜롬비아 행에만 건다. 에콰도르 등 다른 국가는 CW>GW여도 장미·카네이션을 그대로 보여 준다.

### 5. 2026-08-24 15:29 — 엑셀 재업로드

**Q.** 원가자료 엑셀을 다시 올리면 농장 이슈가 다시 해결되나.

**A.** 웹 도착원가의 원본 농장·단/박스는 새 파서가 적용된 뒤 같은 연도·차수로 다시 올려야 붙는다. 전산 출고 농장분배(ShipmentFarm)는 안 바뀐다. 셀병합 펼치기는 이 배포 전 운영에는 없었다.

### 6. 2026-08-24 16:12 — 배포

### 7. 2026-08-25 11:13 — 업로드 서버연결오류

**Q.** 업로드 시도하면 서버연결오류 발생.

**A.** `서버 연결 오류(502)`는 nginx가 Node 응답을 못 받은 안내. 콜롬비아 원가 파일은 약 2,000행인데, 행마다 INSERT+전체 JSON 이력을 넣어 60초를 넘겼다. 이전 revision은 집합 SUPERSEDE, 새 행은 40건씩 넣고 행 단위 UPLOAD 이력은 생략한다. 주문/출고/견적/재고는 그대로다.

### 8. 2026-08-25 11:42 — 문라이트 476원·차수별 한눈에

**Q.** 33-2 원가자료에서 문라이트가 476원으로 인식되고, 차수별 품목·농장·금액을 따로 보지 말고 한눈에 보게 해 달라.

**A.** 476원은 도착원가(송이)다. 입고수량이 단이면 도착원가(단) 약 8,986원을 쓴다. 시트명 14-1A는 파일명 33-2로 덮이지 않게 한다. 목록은 차수 구간 아래 품목 한 줄에 농장 원가를 모으고, 농장 행은 눌러야 열린다. 이미 올라간 행은 파일을 다시 올려야 한다.
