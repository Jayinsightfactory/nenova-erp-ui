| 원장 부작용 | 표시 전용. 기존 Product SELECT 포장값 전달, DB·수량·출고일·인쇄 보존 |

## 고정된 결정

- 박스 소수는 정확한 Product 포장정보로 단·송이 복합 표시한다.
- 품목 기준 없는 값/충돌/정수 송이로 분해 불가 값은 임의 반올림하지 않고 환산 확인 표시한다.
- 알스트로 16단/박스 표시 보조와 48(3) 합의를 유지한다. 50단은50(3박스 2단).
- 합계를16px 이상 진한 숫자로 우선 표시하고 잔량·상태·변경 버튼을 분리한다.
- 입력/저장 원본값, 계산 helper, digest, 최초 기준, 인쇄 및 금액은 보존한다.
- 하위 구현 gpt-6.1-sol/high(terra 미제공), 검증gpt-6-luna/high, 검토gpt-6-astra/high. P0_LOCAL만.

### 1. 소수점 및 합계 가독성

**Q.** 소수점을 단·송이로 표시하고 잔량·합계·변경 숫자를 여백 없이 더 크게 보여 달라.

**A.** 기존 weekday-compare SELECT의 Product 포장정보가 화면 응답에서 빠진 원인을 확인했다.
같은 업무범위 metadata를 표시 전용으로 전달하며, 합계 전용 큰 숫자와 촘촘한 배치를 적용한다.

**근거.** FormShipmentDistribution decompile의 BunchOf1Box/SteamOf1Bunch/SteamOf1Box와
운영 읽기 전용 품목 조회(카네이션447/389/363:15단/박스,20송이/단,300송이/박스) 확인.

**결과.** 최종 `npm run build`, `npm run test:erp-contract` 통과. 단위·API·matrix 회귀 통과.
1920×1080 / 100%, 1280×800 브라우저 fixture에서 수량 셀 넘침·겹침, 합계/잔량/상태/버튼 분리,
상하 스크롤 동기화와 원본 입력 보존을 확인했다. 합계·잔량16px, 품목·수량14px, 일반행65px.
독립 최종 리뷰 P1/P2 0건. 운영 배포 및 읽기 전용 smoke는 PR 병합 후 기록한다.
