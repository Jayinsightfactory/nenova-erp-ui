## 고정 결정

- 긴 셀 오류는 짧은 알림 버튼과 별도 고정 팝업으로 표시한다. 입력 때문에 행·열이 커지지 않게 한다.
- 수량칸을 직접 비우면 해당 날짜의 미적용 입력을 삭제하며, 0 입력은 수량0 제안으로 유지한다.
- 입력 내역에서 개별·현재 범위 전체 삭제를 제공한다. 연결된 윌슨 초안도 함께 정리한다.
- 보관 입력도 CAS로 정리해 새로고침 후 되살아나지 않게 한다. 저장 실패와 다른 창의 충돌 시 현재 입력을 보존한다.
- 사용자·조회 범위·연도·차수·업체·품목·날짜·단위 및 최신 입력을 검증하고, 저장 확인 대기/복구 작업은 잠금 유지한다.
- EXE 공용 ShipmentHistory, 웹 영속 감사, 확정 견적·분배·재고는 삭제 대상이 아니다.

### 1. 셀 확대와 삭제 불가

**Q.** 입력 후 미확인 문구 때문에 셀이 커진다. 새창처럼 알림을 표시하고 입력히스토리에 삭제 버튼이 필요하다.

**A.** 이월 오류가 좁은 변경 셀 안에서 한 글자씩 줄바꿈되어 행 높이를 키웠다. 전체 문구를 표 밖 팝업으로 옮기고 짧은 알림만 남긴다. 빈칸 입력은 기존 UNCHANGED 처리로 값이 복원되어 삭제되지 않았으므로, 명시적인 초안 삭제 동작과 보관값 정리를 연결한다.

**검증.** 입력/윌슨 초안 삭제·0 구분·기존 연도와 다른 범위 보존·최신값 충돌·저장 실패·pending 복구·팝업 닫기와 행 높이 fixture 및 필수 ERP 계약/근거/manifest/쓰기 가드/빌드를 실행한다. 임시 fixture/probe/log/output은 커밋하지 않는다.

### 2. 운영 검증과 알림 범위 보완

**결과.** PR907(17030083), Cafe24 배포37415093109 성공. 운영 1920×1080/100%에서 테스트용 미적용 입력2를 브라우저 보관 후 개별 삭제하고 새로고침하여 입력0건 복구를 확인했다. ERP 분배 적용은 실행하지 않았다. 긴 오류에서도 행52/초안70px와 표2642px 폭이 유지됐다. 자동 이월 팝업은 입력이 있는 품목·차수로 좁히고 입력 삭제 뒤 관련 경고가 없어지면 알림도 정리한다.
