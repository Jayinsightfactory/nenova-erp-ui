# 주광 페이지 단일 세로 스크롤

| 항목 | 내용 |
|---|---|
| 날짜 | 2026-10-08 |
| 대상 | 주광 견적서 일반·팝업·자식창 |
| ERP 부작용 | 없음. API·수량·금액·확정·재고·견적 출력 보존 |

**Q.** 별도 조정 스크롤 영역 없이 한 페이지를 내려 전체 품목과 작업 영역을 보게 한다.

**A.** 표의 화면 잔여높이 기반 maxHeight 설정을 제거했다. 주광 팝업 shell만 자연 높이와 문서 스크롤로 바꾸었다. 일반 화면은 기존 page-area 하나가 주 스크롤이며 표 내부 세로 스크롤은 없다. 넓은 표의 가로 이동과 명시적 모달은 유지한다.

**검토.** 독립 코드 검토에서 배포 차단 오류 없음. 가로 overflow 컨테이너 안의 thead sticky는 문서 스크롤에 고정되지 않는 기존 CSS 제약을 기록한다. 직접 브라우저 연결은 앞선 시도에서 도구 커널 경로 및 URL 확인 오류가 있었다. 실제 미실행 UI 검증을 완료로 주장하지 않는다.

**결과.** 사용자 후속 확인: 세로만 통합하고 가로바는 유지한다. ERP 계약·dnSpy evidence·manifest·쓰기 가드·UI layout·production build 모두 통과. PR987 병합 `fa0d0808ee5f45abfd270b7e7dca5bc732ff1d44`, CI37755174353 성공, Cafe24 배포37755426969 성공. 배포 hydration/로그인·차수피벗·일반/팝업 화면틀 자동 검사 통과. Chrome 연결 재시도는 2회 timeout으로 직접 조작 미완료.

**추가 읽기 확인.** 운영 선출고 GET 및 비교 조회는 200. 기존 운영 품목의 별도 선출고 PREVIEW는 `409 EARLY_STOCK_PRECISION`으로 차단되어 성공으로 기록하지 않는다. 이번 수정은 표시/CSS만 변경하며 해당 ERP 검사·재고값을 변경하지 않았다. 업무 APPLY는 수행하지 않았다.
