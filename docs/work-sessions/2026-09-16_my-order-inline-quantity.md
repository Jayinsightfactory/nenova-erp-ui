# 내 업체 주문등록 입력 품목 수량 직접 수정

| 항목 | 내용 |
|---|---|
| 화면 | /orders/my-customers 오른쪽 입력 품목 |
| 기준 | 1920×1080, 100% |
| 원장 부작용 | 없음: 기존 qty 초안 상태만 편집 |

Q. 오른쪽 수량을 클릭해 그 자리에서 바꾸고 X와 여백을 둬 오클릭을 줄여 달라.

A. 행 전체 삭제 버튼을 품목명·수량 입력·개별 X로 분리했다. 수량과 X 사이12px, X28px. 수량은 왼쪽과 동일 qty/단위를 사용한다. Enter/blur 편집 종료, Escape 시작값 복원. 편집 중 빈값은 행을 유지해 다시 입력 가능하다. 고객/연도/차수 전환 시 편집 상태 초기화. 저장 중 편집 금지.

| 동작 | Order/OrderHistory | Shipment/Date/Farm | Stock/Estimate/WebProfitReport |
|---|---|---|---|
| 수량 편집·취소·X | 보존 | 보존 | 보존 |
| 최종 주문등록 | 기존 ADD/REPLACE 검증과 저장 그대로 | 기존 보존 계약 | 기존 정책 그대로 |

API·SQL·환산·업무키·EXE 저장 동작 변경 없음. 기존 FormOrderAdd 근거 유지. 검증은 모의 GET 데이터로 입력/0/소수/빈값/Enter/Escape/X/단위 동기화와 좁은 화면을 확인하고 운영 주문은 저장하지 않는다.
