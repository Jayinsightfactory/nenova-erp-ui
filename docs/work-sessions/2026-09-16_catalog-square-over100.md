# 카탈로그 정사각형 이미지 100% 초과 확대

Q. 정사각형 유지에서 이미지 크기를 100% 이상으로 설정하고 싶다.

A. 정사각형 유지 범위를 20~200%로 확장한다. 채우기는 기존 20~100%를 유지한다. 초과 확대는 셀보다 큰 정사각형을 배치하며 겹침·슬라이드 경계 잘림을 안내한다. 편집·미리보기·인쇄·PPT의 기존 공통 계산을 사용한다.

| 동작 | 카탈로그 초안/기본값 | ERP Product/Order/Shipment/Stock/Estimate/매출 |
|---|---|---|
| 크기 조절·저장·다시 열기 | imageSize 보존 | 변경 없음 |
| 채우기 모드 전환 | 100% 상한 정규화·저장 | 변경 없음 |

기준: 1920×1080. 125/150/200% 정사각 비율과 실제 크기 증가, 저장 round-trip, 채우기 상한, 기존 100% 배치 회귀를 검증한다. 운영 데이터 쓰기 없이 브라우저 fixture를 사용한다. 작업 브랜치 codex/catalog-square-over100.
