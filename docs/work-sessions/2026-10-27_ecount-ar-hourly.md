- source collector는 전월+금월 바로가기가 검색을 실행하는 동작까지 반영해 조건을 다시 열고 정확한 일자를 설정한다. 보고서의 실제 기간/식별값/모든 행/합계 재검사.
- 기존 6개 데이터셋 간격을 유지하며 별도 페이지에서 KST 정시 슬롯을 수집. 재시작 중복 슬롯 방지 파일은 시각만 저장. 로그인PC/세션 필요.
