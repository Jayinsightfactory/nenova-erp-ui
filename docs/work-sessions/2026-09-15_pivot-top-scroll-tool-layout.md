# 전산 피벗 상단 이동바·도구 재배치

## 요청

- 긴 표의 좌우 이동바를 표 상단에서도 바로 사용한다.
- 필드 버튼 옆 빈 공간을 활용하도록 아래쪽 표시 설정·즐겨찾기 도구를 오른쪽으로 옮긴다.

## 적용

- 표 본문과 양방향 동기화되는 상단 가로 이동바를 추가했다. 가상 열 렌더링도 본문 `scrollLeft`를 동일하게 사용한다.
- 기준 화면 1920×1080에서는 필드 배치판 오른쪽에 표시 옵션, 크기 설정, 기본 배치 복원과 즐겨찾기를 배치한다.
- 1450px 이하에서는 도구가 배치판 아래로 내려가는 반응형 한 열 구성을 적용했다.
- UI 표시 전용이며 API/SQL과 ERP 원장 쓰기에는 변화가 없다.
