# 기기별 로그인 유지

- 사용자: 네노바 웹앱에서도 작업 가능한지, 시간 경과에 따른 로그인 해제를 없앨 수 있는지 질문. 전체 계정 일괄 변경 대신 **이 기기에서 로그인 유지 선택 제공**을 명시 선택.
- 기존 원인: 로그인 JWT와 cookie가 모두 고정8시간. 활동 중이어도 자동 해제된다.
- 구현: 웹/모바일 로그인 기본 해제 체크박스. 선택 시 불투명 임의 기기 cookie와 서버 hashed runtime session. 기존 JWT/Bearer8시간·서비스 인증 보존. 로그인 응답 JSON에는 긴 기기 자격증명을 반환하지 않음.
- API/SSR 현재 UserInfo SELECT 후 권한 반영·비밀번호 변경/삭제 차단. 모든 verifyReqUser 호출을 await. UserInfo/ERP 원장 쓰기 및 schema 변경 없음. 네이티브 EXE 로그인 불변.
- 기기별 로그아웃은 서버 폐기 표식으로 동시 갱신에도 유지. 다른 기기는 보존. 실패한 로그아웃은 성공 화면으로 이동하지 않는다.
- 일반 브라우저는 최대400일 미사용 제한·사용 시 하루1회 연장. 기존 PC 웹앱은 cookie-change가 업무 view를 stop/hide하는 구조라 중간 쿠키 갱신 없이 고정400일 유지. 쿠키 삭제나 비밀번호 변경 시 재로그인 필요. 서버 data/runtime/remember-device는 Git 제외·배포 유지·권한 제한, 마이그레이션 시 보존 필요. 브라우저와 웹앱은 각각 자신이 로그인한 저장소만 유지.
- 인증된 운영18차 다운로드용 수동 read-only CI smoke도 추가. 기존 서비스 secret이 있어야 실행되며 쓰기 요청 차단, 민감 XLSX artifact 업로드 없음. 최종 실행 결과는 후속 기록.
- 검증: 시간 이동/재시작/기기별 폐기/폐기 경쟁/계정변경/실패 닫힘/Bearer 회귀 단위검사 통과. 전체 gate·CI·배포 진행 중.
- 검색어: 이기기로그인유지 8시간자동로그아웃 rememberDevice nd1 서버세션폐기 400일 웹앱로그인
