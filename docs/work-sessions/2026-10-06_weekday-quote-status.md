## 고정된 결정

- 입력만 저장은 사용자별 브라우저 보관이며 ERP 변경이 없다.
- 분배 적용의 입력은 날짜별 최종 수량이다. 기존100→120이면20 증가하며 중복 목표는 추가 증가하지 않는다.
- 일반·Wilson 웹 구분은 합산 수량 하나로 ERP/Excel/견적에 반영한다.
- 이번 요청은 불필요한 경고의 표시와 행동 안내 개선이다. 전체업체 대차수 확정 가드나 native DetailFix=1 조건은 완화하지 않는다.
- 실제 연결/금액 오류와 조회 실패는 숨기지 않는다. 구조화된 409 eligibility만 업무 대기 상태로 표시한다.
- 확정 현황 페이지는 query로 연도·차수를 자동 선택하지 않는다. 링크는 일반 진입이며 대상 연도/차수 조회를 명시적으로 안내한다.

### 1. 2026-10-06 — 쓸모없는 경고

**Q.** 빨간 경고가 무엇을 하라는 것인지 알 수 없고 쓸모없어 보인다.

**A.** 기존 웹은 출고가 없어도 HTTP409 인쇄 자격 미충족을 '견적 조회 실패'로 표시했다. 미확정 건수도 전체업체 대차수 범위를 설명하지 않았다. API가 기존 eligibility의 구조화 집계만 추가 전달하고 UI에서 분배 전/확정 대기/실제 오류를 구분한다.

**근거.** 실제 FormEstimateView CLI에서 GetPrintDetail.DetailFix=1을 확인했다. SELECT probe는 2026/40 양수1345/미확정97, 선택533 양수105,2026/41·42 양수 없음.2025 동일40·41·42는 양수396/1054/1192 전부확정. 조회 시점 값이며 화면에 하드코딩하지 않는다. 운영 원장 쓰기 없음.

## 검증·결과

API 실제 핸들러 fixture는 기존409/404 상태와 읽기 전용 표시, 미분배·미확정·연결 오류 집계 반환을 검증한다. UI fixture는 정상 대기 표시, 오류 우선순위, malformed/network 오류 유지, scope 표기와 대응 행동을 검증한다. 최종 PR·배포 결과는 GitHub 첨부 PR 및 해당 배포 run에서 확인한다.

## 이어받기

로컬 브라우저 검증은 1920×1080 CSS pixel / DPR1 / 100%와 1280×800에서 수행했다. 미확정82건 안내·출고 없음 안내·연결 오류 상세·조회 실패 재조회 콜백을 확인했고, 문서 가로 넘침 없이 표 내부 스크롤을 유지한다. `test:erp-contract`, dnSpy evidence, ERP manifest, ERP write scope 검사가 통과했다. 임시 검증 페이지는 삭제하며 운영 반영 전 최종 build와 PR CI를 확인한다.
