# 호주 기존 입고 원가 다운로드

## 사용자 질문 / 답변
- 다운로드 버튼 없음: 기존 AU native 입고를 웹 문서에 연결하는 경로는 NL/CN/TH 한정. 해당 문서의 원가패널이 숨겨져 있었다.
- 출하단가 로직 확인,5100이 맞음: incoming 출하단가 열은 TPrice 총액. EXE도 UPrice/TPrice 별도 저장·조회. 최초120×8.5=1020 보정제안 철회.5100 보존.

## 변경
- 선택문서에서 동일연도/세부차수/송장 입고 조회→명시 농장선택→기존 native 원가 계산·미승인 XLSX 다운로드 진입.
- 호주 native 계산본은 저장총액/실제단수로 계산용단가, 실제박스·단·송이로 포장비율 산출. 원래단가 보존, 화면/엑셀에 기준 표시. 기존 승인원가/새인보이스 가드 유지.
- 운영 DB는 SELECT만. 새 입고·원가승인·연결 저장 없음. 국가별 원가수식/템플릿스타일/EXE/SP 변경 없음.
