## 중요 한계와 실패 해석

- 호주·베트남은 새로운 AI 추출 테스트가 아니다. 브라우저의 parse-pdf 요청을 기존 로컬 AI 응답으로 대체했고 실제 외부 분석 요청은 전송하지 않았다. 원본 PDF 렌더는 실제다.
- 해당 과거 AI 결과에는 상품행 위치 근거가 없어 품목 하이라이트는 검증하지 않았다. 날짜·통화 등의 미확인 값도 여전히 담당자 확인 대상이다. 입고 저장 가능/인식 정확도 100% 판정이 아니다.
- 40-2 첫 행의 동일 품명은 같은 페이지에 중복된다. 처음 검사에서 무조건 하이라이트를 기대하여 timeout이 났고, 이는 애플리케이션 오류가 아니라 안전한 모호성 처리였다. 로컬 PDF 텍스트와 findUniqueQuoteItems로 중복을 확인했다. 테스트를 중복 문구 무표시 + 유일한 7번째 행 하이라이트로 수정한 후 통과했다.
- 화면 테스트에서 React 체크 상태 반영 전 즉시 읽은 단정도 실제 체크 반영을 기다리도록 수정했다. 제품 코드 변경은 없다.

## 이어서 작업할 때

사용자가 신규 AI 인식까지 요청하면 남은 비용 승인을 확인한다. 기존 결과 재생 검사를 신규 AI 정확도 검증으로 보고하지 않는다. 실제 저장·원가 계산/ERP 반영은 이번 검사 범위가 아니다.
