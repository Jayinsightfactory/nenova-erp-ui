## 고정 결정

- 첫 화면은 기존 웹과 비슷한 파일 표이며 자동 상세 진입하지 않는다.
- 차수, 파일명, 갱신일, 보기, 엑셀만 배치한다. 카드/요약/홍보 문구/확장 스위치를 제거했다.
- 모바일은 날짜를 파일명 아래에 표시하여 버튼을 유지한다.
- 작은 예시 표시는 보존한다. 실제 비밀번호/실제 자료 연결은 이번 범위가 아니다.
- 주차별 예시 엑셀만 다운로드 가능하고 호텔 엑셀은 연결 대기다.

### 1. 파일만 표시

**Q.** 웹과 비슷하고 쓸모없는 내용 없이 파일들만 보여야 한다.

**A.** 파일 목록으로 재구성했다. 보기를 눌러야 상세를 열고 뒤로가기로 목록에 복귀한다.

**검증.** 예시 SSR/엑셀 수식 테스트 통과. 브라우저 320×740, 390×844, 1920×1080에서 수평 넘침 없음. 보기/복귀와 다른 연도 빈 목록을 확인했다. ERP/API 변경 없음.

## 남은 범위

- 실제 공용 비밀번호, 실제 보고 파일 게시/마감 연동은 별도 구현 전이다.
- .tmp 브라우저 하네스/스크린샷과 기존 작업 세션의 변경은 커밋에 포함하지 않는다.
