## 고정된 결정

- 본 보고서의 공식이나 채택된 단가를 바꾸는 작업이 아니다. 독립 검산 결과를 별도 표시한다.
- 수량은 SP 정의와 동일한 두 자리 반올림, DetailFix 확정 출고, StockType 조정을 사용한다.
- 기초 이월 차이와 당차수 새 차이를 분리하고, 비표준/누락 구간을 넘어 최초 원인을 단정하지 않는다.
- 직접 단가 평가액 검산과 FIFO/평균/판매단가의 원가 타당성을 구분한다. 후자는 증빙 추가 확인이며 정상으로 위장하지 않는다.
- 산술 검산은 보고서 입력값에 별도 공식을 적용한다. 매출·환율·통관비 입력 원천 전체의 독립 감사나 실사 대체가 아니다.
- 확정본/계산 저장본은 현재 원장과 시점이 다르므로 현재 수량만으로 과거 금액을 오류 판정하지 않는다.
- API는 모든 차수 요약과 선택 차수 상세만 반환한다. 큰 품목 이력은 분류 필터·30건 더보기로 페이지에 표시한다.

### 1. 요청 — 기초/기말 원인까지 설명

**Q.** 독립 검산 엔진을 구현하고 차수별 기초재고/기말재고 원인을 상세히 설명, 배포까지.

**A.** 순수 검산 코어, 인증된 SELECT 전용 원천 수집/API, 전후 SHA256 변경 감지, 차수별 상세 UI를 구현했다. 기존 보고서 계산 함수를 검산 정답으로 호출하지 않는다. UI가 보여주는 기존 계산값과 별도 산술 결과를 비교한다.

**결과.** 기초＋입고－확정출고＋조정과 저장 잔량 비교, 앞 차수 차이 이월, 첫 관측 구간, 조정 사유 누락, 음수 잔량, 단가 근거 부족, 기준시점 차이를 구분한다. 모든 차수의 금액 검산은 순차 GET과 진행 상태/취소/실패 표시를 제공한다.

### 2. 실제 원천 확인과 검증

- 설치된 실제 dnSpy FormStockView.GetData, 운영 SP 정의 및 isolation 상태를 SELECT로 확인했다. 상세 지문은 계획 MD에 기록.
- 2026년 1~41차를 읽기 전용 대사하고 26/31/32/41차를 표본 확인했다. 비표준 차수를 단순 제외하면 기초 차이를 잘못 전파하는 반례를 발견하여 해당 구간의 추적을 끊도록 보완했다.
- 운영 품목명/금액/원천 JSON은 공개 저장소에 저장하지 않았다.
- 합성 회귀: 교차연도, 이월/상쇄, NULL/누락/중복, 합계0 조정, 사유누락, 단위환산, 평가단가 누락, 수익률 분모, 산술 반례, 확정시점 분리, GET/method/scope 거부.
- `npm run verify:erp-change` 통과(ERP 계약·dnSpy·manifest·write guard·build). 후속 설명/상세 UI 변경 후 개별 회귀 재통과 및 최종 빌드/브라우저 점검 진행.
- 로컬 Chrome 합성 검증 통과: 정상/팝업 shell, 수량식·최초 관측 원인, 전체 차수 순차 GET, 2025/2026 분리, 원천 변경 보류, 부분 실패, 390px, 키보드, GET-only.
- 실제 로컬 API + 운영 DB 읽기에서 1~41차 요약/32차 상세 정상 응답 및 전후 지문 일치를 확인했다. 응답은 상세 분리로 약 0.2MB 수준이며 전체 이력 JSON을 보내지 않는다.
- `auditLive=1` GET 옵션으로 확정되지 않은 보고서는 최신 원천을 읽어 계산하되 snapshotRefresh/INSERT를 하지 않는다. 활성 확정본은 여전히 저장된 revision을 그대로 읽는다. 일반 보고서 조회 동작은 그대로다.

## 미검증/한계

실사 초기값, 과거 환산계수 변경, FIFO 레이어 원가 증빙의 완전 독립 감사, 세금/전표 원장의 실제 발생 사실은 추가 확인 대상이다. 전후 source hash 일치는 DB 원자적 snapshot 보장이 아니다. 인보이스/실사 확인 없이 자동 보정하지 않는다.

## 배포 결과

최종 전체 verify:erp-change와 최신 소스 build 통과. 최신 빌드로 Chrome 32개 차수 순차 GET/상세/원천변경 보류/390px/키보드 검증 재통과. PR/CI/운영 배포는 아직 완료 전이며 완료 후 이어서 기록한다.

- PR #1102 생성. 후속 경계 보완: 전년도53차/비표준 차수가 native 직전 재고이지만 보고서 기초는52차/숫자 세부차수인 경우 두 기준의 차이를 별도 표시한다. 교차연도·비표준 fixture와 build 재통과. 기준을 자동 변경하지 않는다.
