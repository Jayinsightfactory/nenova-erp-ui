## 고정된 결정
- 영업 기본(달력 대차수+1) ±5 대차수, 세부차수01~04. 연도 이월을 함께 전달한다. 기존 업체별 탭의 +9 선택은 유지.
- 신규 기본 차수를 미리 선택하되 빈 작업은 자동저장하지 않아 차수를 고를 수 있다.
- 텍스트는 자동저장 중/실패에도 편집 가능. 등록·분석·불러오기 중/frozen은 잠금 유지. 저장 도중 변경된 원문은 다음 revision에 저장한다.
- 이미 저장된 작업의 차수는 보존하고 다른 차수는 새 작업 사용. ERP 등록 API/환산/분류 변경 없음.

### 1. 차수와 카톡 입력
**Q.** 기본차수 앞뒤5 정도는 선택해야 하고, 카톡 내용 붙여넣기가 입력되지 않음.

**A.** 차수 미선택 및 autosave의 saving이 상위 fieldset을 disabled로 만들던 원인을 수정했다. 원문 입력 잠금과 실제 처리 잠금을 분리했다. 기본/빠른선택/세부차수 버튼, 빈 초안 자동저장 방지, 저장 중 최신 원문 후속저장을 확인했다. 미선택 원문도 미저장 경고를 유지한다.

**검증.** 순수 차수 ±5·0·연도경계/기존+9 및 빈초안 회귀 추가. Chrome 실제 컴포넌트 격리 fixture에서 44-01 기본,39-04 선택, 여러 줄 paste, 8초 저장지연 중 추가 요청/발주 paste, 서버 revision2에 모든 원문 보존,503 실패후 추가입력 유지 확인. 시각/초점표시 확인. 실제 ERP 주문등록 없음. 정확1920x1080 고정·이미지OCR 외부호출은 미검증.

**환경.** 기존 공용 node_modules 패키지 누락으로 초기 build/test 실패. 작업전용 npm ci 설치 후 재검증. junction 해제의 광범위 명령이 자동승인 차단돼 link 검사 후 unlink만 수행(원본 보존). 임시 .hotel-fixture*는 커밋 제외하고 종료 시 정리.
