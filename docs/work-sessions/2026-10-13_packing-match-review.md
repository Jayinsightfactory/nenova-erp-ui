## 고정된 결정
- 업로드 후 기본 목록은 DB 미매칭과 미확인 유사 매칭만 표시한다.
- 정확한 유일 DB 품목 연결 또는 기존 검증된 수동 확인 근거만 매칭 완료다. 유사도 점수는 확정 근거가 아니다.
- 완료 행은 숨겨도 전체 품목 수량·합계·다운로드·입고 원본 배열은 보존한다.
- 사용자가 전체 보기로 완료 행도 열 수 있다.
- 수동 매칭은 팀 공용 저장 성공 후 결과 재생성으로만 완료된다. 실패하면 대기에 남는다.
- 품목 매칭 완료와 수량/단위/GW/CW/운임/도착원가 검증 완료는 다른 단계다.
- 입고·재고·주문·분배·견적 writer와 nenova.exe/SQL 구조는 변경하지 않았다.

## Q&A
**Q.** 업로드 시 DB와 안 맞거나 100% 매칭되지 않은 품목만 눈으로 확인하고 선택하는 UI로 작업 시작.

**A.** 기존 입고 어댑터의 유일 ProdKey/정확 이름 및 수동 근거 판정을 화면에 재사용했다. 확인 필요 목록을 기본으로 하고 정확/수동/유사/미매칭 건수와 전체 보기 버튼을 추가했다. 원문 품목 클릭은 기존 검색·선택·공용 저장을 사용한다.

**검증.** 정책/UI 테스트 15개 통과. 독립 검토 관련 테스트 31개 통과, P1/P2 없음. ERP 계약·빌드·실브라우저 결과는 배포 후 아래에 추가한다.

## 기준선
적용: 한글 안내, 기존 shell, 페이지 주 세로 스크롤, 표 가로 스크롤, 키보드/초점, 1920×1080/100% 우선 검증. 해당 없음: 신규 메뉴, ERP writer, 단위 환산 변경. 기존 숫자 및 다운로드 대상은 보존.
