|---|---|

| 화면 | 주광 견적서 / 웹 작업 엑셀 |

## 고정 결정
- 카네이션 → 콜롬비아 장미 → 수국 → 알스트로 → 기타 순서. 에콰도르/중국 장미는 기타의 국가별 별도 그룹이다.
- 국가 정보는 조회 범위의 Product 읽기 자료만 사용한다. 누락·충돌은 콜롬비아로 추정하지 않는다.
- 저장 전 미쓰기 확인이 포함된 STOCK_GATE_BUSY 409만 동일 본문·UUID로 최대 5회, 1/2/3/4/5초 뒤 재시도한다.
- 결과 불명확 시 추가 POST 금지, 같은 UUID의 결과 조회만 수행. 확정 생명주기와 재고 보호 조건을 유지한다.

### 1. 재고 계산 대기로 저장 실패
**Q.** “재고 계산 대기 작업이 있어 수량 변경을 저장하지 않았습니다.”라고 나온다.

**A.** 서버의 V2 gate 진입 거절 문구다. 실제 EXE의 분배 확정/취소 후 native 재고 계산 순서를 dnSpy CLI로 확인했다. 17:09:23 SQL 시각의 읽기 전용 probe는 gate가 idle임을 보였다. 최근 3시간 SystemActionLog 조건 조회에는 관련 행이 없어 과거 요청의 정확한 원인/실행자를 특정하지 않았다. 잠금을 해제하거나 임의 복구하지 않는다. 클라이언트에서 명시적인 저장 전 거절만 짧게 기다려 재시도하고 진행 상태와 초안 보존을 알린다.

### 2. 에콰도르가 장미 사이에 섞임
**Q.** 카네이션, 콜롬비아장미, 수국, 알스트로 순서인데 에콰도르가 중간에 나온다.

**A.** 기존 FlowerName 단독 우선순위를 국가 정보와 함께 판단하도록 변경했다. 웹 그룹·검색·엑셀 그룹은 동일 함수로 정렬한다. 품목 수량, 윌슨, 소계 및 앞서 적용한 엑셀 품목명 중복 제거/색상을 보존한다.

## 검증과 남은 확인
- 주광 전체 회귀, strict gate ack/한도/불변 교차연도 본문/불명확 결과 GET-only 테스트 통과.
- 필수 ERP 계약·dnSpy·manifest·쓰기 가드·build 및 운영 배포/1920×1080 Chrome 확인을 수행한다.
- 실제 운영 수량 저장을 시험하려고 실행하지 않는다. 운영 게이트 경합의 재현은 모의 fetch로 검사한다.
- 로컬 근거는 ignored output/weekday-gate-* 및 output/weekday-country-sort-tests.log. 비밀값·운영 원장 덤프는 커밋하지 않는다.
