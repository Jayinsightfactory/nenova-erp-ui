# 물량표 다운로드 잔량 수식

| 항목 | 내용 |
|---|---|
| 날짜 | 2026-10-14 |
| 화면 | 통계 → 물량표 다운로드 |
| 원장 부작용 | 없음. XLSX 셀 수식·계산 캐시만 변경 |
| 배포 | 검증 후 PR/배포 예정 |

## 고정된 결정
- 사용자 확인: 재고는 직접 입력, 잔량은 입고−출고+재고 수식.
- 기존 파일에서 업체별 수량 합계는 `주문` 헤더다. 기존 헤더/수량 원천을 변경하지 않고 해당 요약 셀을 차감한다.
- 재고 공란은 유지하고 수식은 해당 셀을 참조한다. 재업로드의 실제 쓰기 수량 원천은 여전히 업체별 셀뿐이다.
- 잔량 캐시도 동일 계산으로 만들고 합계 0에서도 SUM 수식을 유지한다.

## 질문 → 처리
### 1. 잔량 칸에 수식
**Q.** 잔량 칸에 입고−출고+재고 수식을 넣고 재고는 직접 입력하게 유지.

**A.** 기존 `SUM(입고)-SUM(주문)`에 `+SUM(재고)`를 추가. 기존 curStock 캐시 대신 셀 계산과 같은 초기값을 사용한다. 다른 열·서식·업로드·SQL은 변경하지 않는다.
