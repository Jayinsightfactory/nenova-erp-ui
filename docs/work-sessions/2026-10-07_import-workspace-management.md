## 이어받을 때 고정된 결정
- 항공·휴가·재배·불량피드백·인수인계를 상위 메뉴로 제공한다. 체크리스트는 단일 인스턴스 유지.
- 기존 불량피드백 iframe은 처음 방문 후 유지한다. 기존 SQL/권한/코멘트 정정/삭제 정책은 변경하지 않는다.
- 직원 연차는 연도별, 재배 품종 목표는 공통 설정. 이름은 기존 이력 식별자라 제자리 이름 수정 대신 새 이름 추가. 삭제해도 기존 내역 보존.
- 잔여 일수 직접 수정은 `사용 일수 + 원하는 잔여 = 연간 총 한도` 방식. 사용 내역 보존, 사유 필수, 서버 이중 잠금·휴가 revision 검증, 계정/전후 값 기록.
- 인수인계는 이슈·처리·주의·체크사항, 상태/중요도. 한 번에 한 항목 수정, 서버 전후/계정 이력. 최근50회 노출, 이전 이력 archive 보존.
- 원본 HTML의 PC localStorage 자료는 자동 이관되지 않았다. 원본 100% 동등/모든 파일 자동매칭 보장 금지. 원본 일괄 주간 초기화 대신 날짜별 초기화이며 월별 결제 항목은 아직 고정 목록.

### 1. 메뉴 관리와 원본 기능 대조
**Q.** 항공·휴가·재배도 추가/수정 가능하게 하고 기존 불량피드백을 넣어 달라. 원본 기능 100%인가?

**A.** 기존 개별 내역 CRUD는 있으나 하위 메뉴에 숨겨져 있었다. 독립 상위 탭과 설정 CRUD를 추가했다. 원본 대조 결과를 `docs/plans/import-workspace-management-2026-10-07.md`에 기록했다. 항공 반입대기 배지, 단축키, 완료 강조를 복원했다.

### 2. 잔여 휴가와 인수인계
**Q.** 잔여 휴가 수정, 수입부 인수인계·특이사항, 이슈 처리/주의/체크사항과 계정 로그가 필요하다.

**A.** 잔여 조정 전후와 사유·계정을 휴가 화면에서 확인하게 하고, 인수인계 등록/수정/완료/삭제 및 서버 로그를 추가했다. 변경 실패 시 초안을 유지한다.

## 검증 기록
- 원본 HTML을 정적으로 대조했으며 PC별 기존 저장값까지 이관했다고 가정하지 않았다.
- 초기 전체 ERP 계약 및 빌드 통과. 독립 검토 후 휴가 서버 스키마/순서 변경/중요도 로그/비활성 표식 계정 차단 추가 보완.
- 로컬 Chrome: 1920×1080 CSS px/100%, 900/480 너비. 항공 CRUD·체크 계정, 잔여3일 조정·15→3 계정 로그, 인수인계 CRUD, 탭 이동 초안, 기존 피드백 iframe, 가로넘침0/pageerror0.
- 브라우저 쓰기는 요청 fixture, 서버 쓰기는 임시 저장소 회귀 테스트. 운영 가짜 자료/ERP 쓰기/AI 호출 없음.
- 최종 `test:erp-contract`, `build`, 변경 범위 manifest(80계약), ERP 쓰기 가드 통과. 수입부 테스트 177개 중174통과/선택3skip/실패0. 독립 최종 검토 P1/P2 없음(대상40검사 통과).
- 최종 로컬 브라우저 재검증: 1920×1080/100%, 900/480 너비, 오류0/운영쓰기0. 배포는 후속 기록을 확인한다.
- 운영 읽기 preflight: 2025/2026/2027 휴가·재배·항공 공동 키 모두 revision0/0행. 기존 불량피드백 GET200, Case5건/통합 목록71개. 실제 내용·개인정보·자격증명은 기록하지 않음. 새로운 엄격 스키마가 기존 저장값을 차단하는 사례는 이 조회 범위에서 없었다.
- 독립 검토 P1(휴가 원장 스키마) 및 P2(인수인계 순서·중요도, 비활성 표식, 재배 숫자 합계) 보완. 휴가 원본6필드와 날짜/연도/양수일수/ID 검사, 손상 저장값 자동 수정 금지. 재배 수량·단가는10억 이하/목록10000건 이하로 합계 유한성 보장.

## 다음 작업 시 주의
- 원본 HTML이 아닌 해당 PC localStorage 내보내기가 있어야 과거 일정·휴가 자료 이관이 가능하다.
- JWT의 명시 `accountActive=false`는 차단한다. 기존 전역 JWT 인증의 발급 후 계정 상태 실시간 동기화는 이번 범위가 아니다.
- `output/import-management-smoke.cjs`와 스크린샷은 로컬 검증 산출물이며 운영 자격증명을 저장하지 않는다.
