### 3. 재발 방지 수정

**확인한 빈틈.** 영업지원에는 기존 차감 확인이 있지만 견적서관리 직접 INSERT와 행 편집에는 같은 확인이 없다. 특정 과거 행이 이 경로로 생성됐다는 뜻은 아니며, 재발 가능한 코드상의 빈틈이다.

**범위.** 직접 음수 견적 등록/편집은 실제 차수·출고·업체·품목·차감 유형·단위·수량·단가·날짜·적요가 같은 기존행을 쓰기 직전 확인한다. 같은 거래처·품목의 영업지원/직접등록을 같은 트랜잭션 잠금으로 직렬화한다. 영업지원의 기존 보수적 중복 판정·자동자료 차단·이월 요청키 멱등은 유지한다. 별도 유형·수량·단가의 정상 행을 자동 합치거나 삭제하지 않는다.
