## 고정 결정
- DB는 더 수정하지 않는다.
- SQL 품목별 실제 매입행을 사용한다. 엑셀 그룹 단가/판매 근사값 복제 금지.
- 같은 연도·평가 시점 이하 마지막 완전한 매입, 정확 과거 환율, 동일 단위·입고 행 수를 요구한다.
- 운임·통관 재현은 실지 청구서 인증이 아니다. 통관 스냅샷 부재 시 기본값이 포함되는 한계를 표시한다.
- 최근 FIFO와 과거 carry 환율을 같은 함수로 공급한다. E/F는 각 기간 재고와 근거로 계산.

### 1. 원인과 수정
**Q.** DB를 건드리지 말고 태국 두 품목의 34차 매입·운송·통관을 확인해 38~41에 이어 계산하고 배포.

**A.** 실제 dnSpy 입고 조회와 SQL probe에서 매입 존재를 확인했다. 최근4차수 창이 종료되는 시점에 태국이 과거 매입 목록에서 빠져 누락됐다. 기존 최근 FIFO는 현재환율이 높은 경우 가격 하한 검사로 통과했다. 태국의 기간환율을 명시하고 과거매입 조회를 추가했다.

도착원가 엔진의 통관 기본값과 손익표 H의 GW 기반 비용은 다르다. 실제 통관 청구 확정 근거가 없으므로 같은 값으로 강제 조정하거나 실비 확인 완료로 표시하지 않는다. 웹 검증 경고에 제한을 추가했다.

**결과.** lib/profitReport.js, profitReportAcquisitionCarry.mjs, profitReportAudit.js; 계약/합성 회귀/운영 다운로드 assertion 보강. 계산식과 원장은 보존.
