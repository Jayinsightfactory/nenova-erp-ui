# 네덜란드 물량표 스크롤

2026-11-13 네덜란드 원본 물량표에 품목 열·헤더 고정과 상단 스크롤바 동기화를 적용했다. 좁은 화면에서도 고정을 유지한다. 주문·분배 API 수정 없음. 운영 배포는 기록 시점 미검증.

원본 표 영역에서 가로와 세로를 함께 이동할 때 품목과 업체를 따라갈 수 있게 했다. 매칭표와 검토표는 페이지 스크롤을 사용한다.
Chrome 격리 데이터 1366px·760px에서 헤더 위치, 가로 320·세로 240 동시 이동, 품목 열 hit-test, 상단 바 양방향 동기화, 인쇄 통과. 중국 표 회귀도 통과.
