## 이어받을 때 고정할 결정

1. 수량이 있는 셀은 기존처럼 클릭해 0 이상 수량 수정 가능하다.
2. 비어 있는 셀은 고객×품목 매트릭스 범위에 한해 입력 대상으로 식별한다. 합계, 요약, 레이블, 수식은 편집하지 않는다.
3. 빈 셀에 양수를 입력하면 원래 워크시트 좌표를 보존하는 초안 행으로 저장하고, 같은 파일을 다시 열면 복원한다.
4. 빈 셀에 0 또는 빈 값은 원래 빈 상태와 같으므로 초안 행을 만들지 않는다.
5. 수량 변경마다 과거 미리보기/적용계획을 무효화한다. 새 미리보기와 기존 별도 승인 절차 없이는 ERP 쓰기를 하지 않는다.
