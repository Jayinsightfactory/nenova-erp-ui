# 로그인 아이디 유지 — 2026-10-09

Q. 로그인 시 계정 아이디를 남겨 비밀번호만 입력하게 해 달라.
A. 웹/PC가 함께 쓰는 /login에서 마지막 성공 아이디를 표시 전용 쿠키에 기억하고 재진입 시 아이디를 복원하며 빈 비밀번호 입력에 초점을 둔다. 아이디는 수정 가능하고 취소는 아이디를 유지한 채 비밀번호·오류만 지운다. 비밀번호 저장·자동 로그인 기능은 추가하지 않는다.

쿠키는 host-only, SameSite=Lax, HTTPS Secure, 1년 유지다. PC 계정 전환의 localStorage 정리와 별개이며 인증 쿠키·API·권한·ERP 원장은 바꾸지 않는다. 저장이 차단되어도 로그인은 계속할 수 있다. 성공 전 오타/실패 아이디로 기존 기억을 덮어쓰지 않는다. /m/login은 이번 범위 밖이다.

메뉴 기준선:
- 적용: 현재 로그인 화면만 변경, 1920×1080/100% 및 작은 화면 검사, 표준label/input과 비밀번호 초점, 로딩/오류/기존redirect 유지.
- 해당 없음: 매칭·분배·파일 업로드·표열 조절·ERP 원장 쓰기·연도차수 업무.
- 예외: 없음. 아이디 기억은 사용자 명시 요청이며 인증으로 사용하지 않는다.
