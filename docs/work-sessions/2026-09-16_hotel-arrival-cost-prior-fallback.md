# 2026-09-16 호텔 도착원가 이전 최신 차수 표시

## 사용자 요청

해당 차수의 도착원가가 없으면 그전 최신 차수 값을 표시한다.

## 적용 결정

- 품목별로 현재 대차수의 활성 도착원가가 있으면 현재 세부차수 값만 표시한다.
- 없으면 같은 연도에서 가장 가까운 이전 대차수 하나를 고르고 그 대차수의 세부차수를 모두 표시한다.
- 대체값은 `이전 최신 차수` 배지와 색상으로 구분한다.
- 미래 차수와 다른 연도는 사용하지 않는다.
- 웹 상세 표시 전용이며 엑셀·인쇄·ERP 원장은 변경하지 않는다.

## 검증

- `__tests__/raumPnlArrivalReference.test.js`에 현재값 우선·이전 최신 대체·미래 제외·품목 격리 fixture를 추가했다.
- 필수 ERP 계약·dnSpy 근거·쓰기 가드·빌드 후 배포한다.
