# 원본 화면 관찰 기록

원본 조회 담당자가 2026-10-20 로그인된 Chrome에서 확인한 UI 메타데이터만 기록한다. 실제 계좌번호·거래값·개인정보·세션 URL은 저장하지 않는다.

## E010205

상단에서 Search(F3), Option, 도움말을 확인했다. 하단에는 입금보고서작성, 즉시조회, 통장등록, 매핑조회, Excel, 자동알림, 수집처별확인사항이 있다. 입금보고서작성·통장등록 등 원본 쓰기 동작은 실행하지 않았다. 즉시조회·자동알림 등 부작용이 확정되지 않은 동작도 실행하지 않았다.

표의 열 이름은 선택 열, 입/출금일자, 구분, 계좌번호, 계좌명, 거래처코드, 거래처명, 금액, 입금처(출금처), 비 고, 원화잔액, 지점명/상대은행, 회계전표 순이다. 열 이름만 관찰했으며 행 값은 이 기록에 포함하지 않는다.

Search(F3)를 클릭하면 새창이 아닌 화면 내부 검색 패널이 열린다. 날짜 범위, 전체/입금/출금, 검색(F8), 금일/전일/금주(~오늘)/전주/금월(~오늘)/전월/종료일/최근7일/전월+금월, 설정, 다시 작성이 표시된다. Search(F3) 이외 검색 패널 버튼의 실행 결과는 이번 관찰에서 확정하지 않았다.

매핑조회를 클릭하면 같은 탭 안에 조회 오버레이가 열린다. 선택 열, 입금처(출금처), 계좌번호, 지점명, 매핑여부, 거래처코드, 거래처명 열과 Search(F3), Option, Excel, 닫기 버튼이 표시된다. 닫기를 클릭하면 부모 은행 화면으로 돌아온다. 선택이나 쓰기는 실행하지 않았으므로 선택 결과 전달은 미확인이다.

이 기록은 부분 관찰이다. 전체 버튼·창 개수, 숨겨진 옵션, 권한별 차이, 오류·빈 결과·다운로드 산출물은 미검증이며 네노바 동등성 완료를 의미하지 않는다.

## E040214

2026-10-20 원본 담당자가 초기 조회 화면의 Option, 도움말, 미수내역, 검색(F8), 금일, 전일, 금주(~오늘), 전주, 금월(~오늘), 전월, 종료일, 다시 작성, 인쇄, Excel 버튼을 확인했다.

검색(F8)을 조회 전용으로 실행하면 결과 표가 나타난다. 열 이름은 거래처명, 매출합계, 수금합계, 기타할인등차액, 잔액, 미회수월 순이다. 결과 화면의 Search(F3), Option, 도움말, 인쇄, Excel 버튼을 확인했다. 행 값·거래처명 값은 기록하지 않았다.

원본 검색→결과 전환만 관찰했다. 다른 버튼 기능, 인쇄·다운로드 산출물, 모든 팝업과 오류 상태, 네노바 동등성은 미검증이다. SQL 안전 투영에 거래처 식별/미회수월 등이 없다면 해당 원본 열은 구현 완료가 아니다.

## E040309

2026-10-20 원본에서 검색(F8)을 조회 전용으로 실행했다. 결과 열: 거래처코드, 거래처명, 기초채무, 재고매입, 회계매입, 지급합계, 기타할인등차액, 잔액, 미청구액. 결과 버튼: Search(F3), Option, 도움말, 인쇄, Excel. 조회 이외 버튼 동작/창/출력물과 원본값은 기록하지 않았다.

## E040207

2026-10-20 원본에서 검색(F8)을 조회 전용으로 실행했다. 결과 열: 일자-No., 거래처명, 품목명, 수량, 단가(vat포함), 공급가액, 부가세, 합계, 적요. 결과 버튼: Search(F3), Option, 도움말, 인쇄, Excel(화면). 조회 이외 버튼 동작/창/출력물과 원본값은 기록하지 않았다. 보관된 날짜 필드는 일자-No.의 문서번호 전체를 대체하지 않는다.

## 2026-10-21 거래처별채권 간편검색 프리셋 관측

2026-10-21(화) 원본 E040214(거래처별채권) 검색 패널에서 간편검색 버튼을 하나씩 눌러 기준일자 from~to 만 읽었다. 조회만 실행했으며 원본 쓰기·설정 저장·간편검색설정 변경은 하지 않았다. 행 값·거래처명은 기록하지 않는다.

| 버튼 | 관측 결과 (from~to) | 웹 id (`datePreset`) | 비고 |
|---|---|---|---|
| 금일 | 2026-10-21~2026-10-21 | `today` | |
| 전일 | 2026-10-20~2026-10-20 | `yesterday` | |
| 금주(~오늘) | 2026-10-18~2026-10-21 | `thisWeek` (`weekStartsOn:0`) | 주 시작 일요일. 2026-10-20 E040207 판매현황 관측과 일치 |
| 전주 | 2026-10-11~2026-10-17 | `previousWeek` (`weekStartsOn:0`) | |
| 금월(~오늘) | 2026-10-01~2026-10-21 | `thisMonth` | |
| 전월 | 2026-09-01~2026-09-30 | `previousMonth` | |
| 전월+금월 | 2026-09-01~2026-10-21 | `previousAndThisMonth` | 이 화면의 기본 프리셋 |
| 종료일 | 2026-09-30~2026-09-30 | 없음 (`presetIdForLabel` → null) | 직전 프리셋이 전월(09-01~09-30)인 상태에서 클릭. "현재 종료일을 시작일로도 복사"로 해석되나 순서 의존이 확인 전이라 구현하지 않음 |
| 다시 작성 | 전월+금월(09-01~10-21)로 복원 | 없음 (`resetSearch`) | 화면 기본 프리셋 복원 |

`lib/ecountPageActions.cjs` 의 `presetIdForLabel(label)` 은 위 7개 라벨만 id 로 매핑하고 종료일·다시 작성은 null 을 돌려준다. 주 시작요일 기본값은 두지 않으며 호출자가 관측 근거(이 화면은 0=일요일)를 명시한다. 회귀 테스트는 `__tests__/ecountPageActions.test.cjs` 에서 `todayISO='2026-10-21'` 로 위 9건을 그대로 재현한다.

원본 '간편검색설정' 대화상자에 정의된 프리셋 명칭은 다음 39개다(동작 미관측, 이름만 기록): 금일, 전일, 금주(~오늘), 전주, 금월(~오늘), 전월, 종료일, 전월+금월, 말일, 금주, 금주(오늘~), 차주, 금월, 금월(오늘~), 이번기수(~전월), 차월, 금년, 금년(~오늘), 금년(오늘~), 전년+금년, 최근 1년, 전년, 이번기수, 직전기수, 직전분기, 직전반기, 종료월, 1분기, 2분기, 3분기, 4분기, 상반기, 하반기, 최근7일, 최근3일+7일, 6개월(+1개월), 3개월, 최근30일, 최근30일(+1개월).

위 7개를 제외한 나머지(종료일 포함 32개)는 `KNOWN_UNVERIFIED_PRESET_LABELS` 상수로 이름만 노출하며, `presetIdForLabel` 과 `datePreset` 모두 `UNVERIFIED_PRESET` 으로 거부한다. 기수·분기·반기 계산 규칙, 금주/금월(오늘~) 의 종료일, 최근N일의 포함 범위는 관측되지 않았으므로 추정하지 않는다. 간편검색설정 대화상자에서 어떤 버튼이 노출될지는 사용자 설정값이므로 다른 화면·계정에 일반화하지 않는다.
