# 오늘의 내 업무 메모장 (Desktop 1.3.19)

디자인 기준: `docs/design/task-launch-1112/`의 GPT 시안과 320px 최종 시안. 홈은 처음 8개와 시간표, PC 메모장은 content 폭320px·기본행51px로 구성한다. 업무명12px·보조10px, 추가·편집은 별도 dialog로 열고 알림 설정은 접는다.

- 홈에서 반복 기준을 없음/매일/매주(요일 선택)/매월(시작일의 날짜) 중 선택한다. 매월 29~31일에 시작한 업무는 짧은 달의 말일에 표시한다. 기존 weekdays 저장 기록은 읽을 때 호환 변환한다.
- 홈의 `업무 메모장 열기`는 로그인한 계정 전용 보조 창을 연다. 제목 수정, 완료, 삭제(보관), 추가는 서버의 개인 업무 API와 revision CAS로 저장된다. 새로고침과 클립보드 목록 복사를 제공한다.
- `바로가기 다운로드`는 설치된 Windows 앱을 여는 `.url` 파일을 저장한다. 독립 실행 파일이 아니며, 네노바 데스크톱 앱과 로그인 상태가 필요하다.
- 창 고정 여부와 알림 시간은 계정 식별자를 SHA-256으로 해시한 로컬 설정 파일에 저장한다. 앱이 켜져 있고 로그인한 경우 설정 시간 이후 미완료 업무를 하루 한 번 일반 문구로 알린다. 앱 종료 중에는 시스템 예약 알림을 보내지 않는다.
- 계정 잠금 또는 로그아웃 시 메모장 창을 닫는다. 메모장 renderer는 직접 네트워크에 연결하지 않고, 고정된 IPC를 통해 인증된 API만 사용한다. ERP SQL 원장은 변경하지 않는다.

검증: 월말/윤년/연도 경계 unit fixture, desktop bridge unit, Electron smoke(IPC 격리/추가/복사/알림/계정 전환), 패키징, ERP 계약·manifest·dnSpy·쓰기 가드·빌드.

- 시작·종료 시간을 선택할 수 있다(KST, 미정 허용, 종료>시작). 시간표의 빈 시간을 누르면 시작 시간이 채워진다. 시간만으로 자동 실행하지 않는다.
- 업무별 데스크톱 메뉴/웹 링크를 연결한다. 메뉴는 현재 로그인 계정 bootstrap 목록과 실행 직전에 대조한다. 웹은 http(s)만 허용하고 기본 브라우저로 열기 전에 주소를 확인한다. 이동은 완료 상태를 바꾸지 않는다.
- 시간·연결은 개인업무 원자적 저장/CAS와 함께 저장한다. 선택 occurrence는 즉시, 반복의 다음날 이후에 반영하며 이전 날짜 snapshot과 구형 앱의 제목만 수정하는 요청을 보존한다.
- 사용 가이드: `/desktop-guide`, 홈과 메모장에 연결.
