# 2026-10-20 국가별 원가 출력 수식 복구

## 사용자 결정

- 기존 입고, 재고, 저장 원가 변경 금지. 다운로드만 수정.
- 원본 수식 계산값, 기존 저장값, 차이를 함께 표시(사용자 확인).
- 중국 해상 기존 원가는 수량 배분, 원본 실제입고 표는 CBM 배분이다.
  저장값을 덮거나 수량 배분을 원본 수식이라고 표시하지 않는다.

## 원본 확인

`invoiceCostExportProfiles.js`의 해시와 일치하는 10개 양식 원본을 읽었다.
공통 format-only 자산에는 항목명과 수식이 없고 exporter가 일부 값만 채운다.
US/VN/AU/NZ의 차수/중량/비용 내역, NL/EC/CO/TH의 운임·비용 계산
영역이 불완전하다. 원본 수식을 무조건 복사하면 과거 물량/단가가 혼입된다.

| 양식 | 원본 근거 | 재계산 기준 |
|---|---|---|
| NL 40-2 | G15:P16, C6:C11 | 상품금액 비율 운임/통관, 환율, 행별 관세 |
| CN SEA 41-1 해상 (95% 기준) | AH8:AK34 | 실제 단수×박스CBM÷박스당 단수, CBM 비율 운임 |
| CN AIR 27-2 CLOUD | K7:U13, AD8:AI15 | GW=CW 무게비, GW<CW 부피중량비, 통관 무게비 |
| US 40-1 | F13:L13 | CNF 박스, 수량비 통관, 단위 환산 |
| VN 24-1 | G19:M21 | CNF 송이, 수량비 통관 |
| AU 38-1 | G13:M16 | CNF 단, 수량비 통관 |
| NZ Sheet1 | G13:M19 | CNF 송이, 수량비 통관 |
| EC 40-2 | G14:O27 | 송이수 비율 운임/통관 |
| CO 12-2 | K7:U10, G15:O25 | 그룹 무게/부피중량, 그룹 내 송이 비율 |
| TH 40 | H16:P40, J7:K10 | 그룹 박스비×그룹 내 송이비 |

원본 TH 첫 행 P15는 N15×O15가 아니라 배분식이 잘못 복사돼 있다.
기존 검증된 P16 패턴을 사용한다. 중국 해상/태국 원본의 #REF!를 복사하지 않는다.
판매가·마진은 원가 입력이 아니므로 과거 판매값을 복원하지 않는다.

## 기준·부작용

| 동작 | 입고/주문/출고/재고/견적/매출 | WebInvoiceCost*/WebArrivalCost | 파일 |
|---|---|---|---|
| 다운로드 | 읽기 또는 보존, SP 호출 없음 | 읽기/보존, 재저장 없음 | 승인값 본표 + 원본수식 비교 |

- 기존 checkedRows/current approval/second live fingerprint 검증 유지.
- 연도/차수/문서/revision/operation/warehouse/lineId 키 유지.
- EXE MakeTempTable의 단수/송이/OutQuantity/UPrice/TPrice는 별도 필드.
- 재계산 입력은 승인 snapshot의 현재 입고·환율·운임·관세·통관비다.
  과거 서류비/수수료 등 개별 비용을 총액에서 역산하지 않는다.
- 원본 부대비 계산의 현행 입력 근거가 없는 부분은 명시적으로 입력 필요.
- 현재 중국 해상 snapshot은 CBM/박스당단수 필드가 없으므로 공란 입력란과
  전체 운임 미산정 상태가 필요하다. 부분행만 배분해서 합계를 축소하지 않는다.
- 비교 수식은 원본 산식의 셀 주소를 현재 입력/행 범위로 치환한다.
  저장 원가와 반올림·배분 잔액 차이를 숨기지 않는다.

## 검증 계획

10개 양식/0값/누락/교차연도/수량·환율 변경 재계산/동적 행,
잘못된 원본 참조 금지, 승인값 불변, 외부 링크 및 과거 값 혼입 금지.
필수 ERP gate/빌드/CI/배포/운영 다운로드까지 통과 전 완료 아님.
