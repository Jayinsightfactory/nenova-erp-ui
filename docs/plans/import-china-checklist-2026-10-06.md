# 중국 인보이스 Excel / 요일별 공동 체크리스트

## 근거와 범위
- 사용자 제공 `41-1 중국 해상 ci1.xlsx`: INVOICE 시트 11행 헤더, 12~112행 품목, 113행 품목 합계, 120~126행 부대비용, 127행 품목금액 반복, 128행 전체금액.
- 표본 합계: 429박스 / 5,390단 / 68,775송이 / 품목 CNY 126,325 / 비용 포함 CNY 172,150.50.
- 파일 약 33MiB. 중국 XLSX만 50MiB까지 브라우저 로컬 분석. PDF 기존 한도·명시적 AI 동의 유지.
- Total of Flower Material=단수. Stems=송이수. Unit Price=단당 CNY. 장미 길이는 품목 매칭 식별에 포함, 복합 길이를 임의로 단일 길이로 바꾸지 않는다.
- 0원 행도 유효 데이터. 부대비용과 품목금액 반복 행을 꽃 수량으로 읽지 않는다.

## 체크리스트 계약
- 요일별 반복 업무 추가·수정·삭제. 기존 기본 업무 키 및 날짜별 boolean 체크 기록 보존.
- 업무 삭제 확인, 안정적인 ID, revision 충돌 처리. 원본 113개 기본 템플릿은 변경하지 않는다.
- 체크한 계정과 시각은 서버 인증 주체에서 생성한다. 다른 항목 저장으로 이전 체크 담당자를 덮어쓰지 않는다.
- 과거 boolean 기록의 담당자는 추정하지 않고 미확인으로 표시한다.
- 공동 자료는 기존 웹 전용 파일 저장소와 이력 사용. 운영 SQL, 주문, 분배, 재고, nenova.exe 변경 없음.

## 검증
- 실제 업로드 파일 분석 및 생성 Excel 수량/단가/송이/비용 검산, 길이 구분·미매칭 수동 확인.
- 요일 업무 CRUD, 새로고침 지속, 체크 담당자, 충돌·저장 실패 검증.
- 1920×1080 CSS px / 100%, 작은 화면 오버플로 확인.
- import-team tests, ERP guards, build, 리뷰 후 배포 및 읽기 중심 운영 smoke.
