## 왜 기존 숫자만 다시 켜면 안 되는가

중국03차 기말/04차 기초의 원본 FIFO 근거에는 Prod2754 시네신스500g의 **101,906원/단**과 `erp-freight-arrival:2025:52-01:...:live:단` 출처가 있다. 높은 수치의 정확한 원인은 별도 확인이 필요하지만, 단위·당시환율 검증 없이 이것을 정상 원가로 재표시할 근거는 없다. `VERIFIED_FIFO_PURCHASE`라는 오래된 라벨만으로 인증하지 않는다.

또한 새 H 관세와 옛 E/F 평가액을 무조건 조합하면 비용이 중복되거나 재고 원가와 다른 기준을 섞는다. 기존 저장값을 참고로 보여주는 것과 검증된 평균으로 새 계산을 만드는 것은 별도 경로여야 한다. 원본 저장값·수기는 덮지 않는다.

## 권장 단일 설계

1. 현재 유효한 실제/수기값과 명시0을 유지한다. 공란 또는 근거 미충족 성분에만 별도 계산용 대체값을 만든다.
2. 같은 품목의 현재 및 과거 입고를 먼저 사용하고, 없으면 같은 국가·품종·상품형태의 과거 입고를 사용한다. 각 입고를 송이로 정규화한 뒤 `총 도착원가 합 / 유효 송이수 합`으로 가중평균한다.
3. 도착원가에는 상품·국제운임·관세·비관세비용 성분을 보존한다. E/F 전체 도착원가 평가와 H 당기비용을 혼동하지 않고, 기존 H 일부가 있는 경우 평균 전체 H를 덧붙이지 않는다.
4. 공식적 과거 환율 또는 승인된 통관주간 규칙, 승인된460원/kg·실중량 운송공식처럼 재현되는 비용은 donor로 허용한다. 오래된 CurrencyMaster/근거 없는 기본값은 그대로 재사용하지 않는다.
5. 같은 품종 근거도 없으면 승인된 국가 평균을 사용한다. 유사품목 환산도 승인됐지만 어떤 품목의 어느 환산계수를 빌렸는지 기록하고, 총원가/송이 분모를 같은 범위로 맞춘다. 국가 평균과 유사환산을 확정 실비처럼 설명하지 않는다.
6. 출력은 계산값을 제공하되 상세의 계산 기준·대체성분·참조차수·참조품목을 보존한다. 실제 납부/확정원가라고 위장하지 않는다. 가짜0·판매단가 원가 대체·이번 fallback 결과의 재귀 donor 사용은 금지한다. 후대자료를 당시실제원가로 위장하는 것은 금지하되, 과거완전근거가 없는 경우에 한해 다음의 `country_reference_period` 참고경로를 허용한다.

## 구현 중 독립 검토 항목

### 최신 기간정책: 과거 우선 / 후대 참고 분리

사용자의 국가평균·공란보완 승인에 맞춰 주담당이 “시점 이전 완전원가가 없으면 확인 가능한 같은국가 평균을 보완 참고기준으로 사용하며 당시 실매입 인증은 아니고 자료기간을 상세로 남긴다”고 안내했다. 이를 다음과 같이 구현한다.

1. 추가 독립검산에서 다른품종의 과거국가pool이 같은품종 참고원가를 밀어내는 문제가 확인되어 주담당이 우선순위를 정정했다. **exact past → exact reference → same-variety past → same-variety reference → country past → country reference** 순서다. 같은범위에서는 과거를 우선하고 수익률이 유리한값을 선택하지 않는다.
2. 해당범위 historical donor가 없을 때만 완전한 원도착원가를 수량가중하여 `same_product_reference_period`/`same_variety_reference_period`/`country_reference_period` 등 실제범위를 명시한다. sourcePeriods와 기준기간 시작·끝, target평가시점을 보존한다. 다른품종국가pool은동품목/동품종reference까지없을때만쓴다.
3. 후대 특정품목 가격을 과거 exact실매입이라고 설명하지 않는다. 참고국가평균 적용과 당시실제거래근거를 구분한다.
4. 다른국가 혼합·대체결과의재귀학습·판매단가원가사용·실제값/0/수기덮기는 계속 금지한다.
5. 회귀는 과거donor존재시후대무시,과거없는경우명시참고경로,국가자체완전원가없음,단위정규화·중복비용·자료기간누락 차단을 포함한다.
