# 국가별 도착원가 판매 기준 자동 계산

## 최신 사용자 지시
레퍼런스 판매 기준·추천식으로 판매가/이익률/총판매가/총이익을 자동 채운다. 기존 판매칸 무조건 공란 정책을 이 파일 계산에 한해 대체한다. 운영 DB 수정 금지.

## 원천과 기준 ledger
- 활성 11개 profile sourceHash와 실제 원본 파일 해시를 대조한다. 원본 판매 입력이 비어 있는 NL/AU/CO/TH/CN에는 확정 실판매값이 존재한다고 추정하지 않는다.
- 원본에 숫자 판매 입력이 있는 품목은 정확 이름·환산수량 일치에 한해 참고값으로 사용한다. 중복 이름의 상이 가격·환산단위 불일치는 적용하지 않는다.
- AU의 별도 38-1 품목별 참고판매표도 이름 정확 일치·단 기준에서 사용한다.
- 나머지는 원본 추천 수식을 현재 원가에 적용: 중국 해상 `원가/0.85*1.1`, 그 외 원본11프로필 `원가/0.77`. 현재 실제 판매가가 아닌 자동 기준가이며 엑셀에서 변경 가능하다.
- 출처 차수·원본 셀·기준 유형을 각 품목 옆에 표시한다. 직접 숫자0은 유효, 수량0은 합계에 영향0, 누락 원가는 입력 필요를 유지한다.
- 현재 수량/환산수량으로 VAT별도 판매·이익·가중 총이익률·총판매가·총이익을 계산한다. 표본행 숫자를 복사하지 않으며 전체 동적 범위와 캐시도 갱신한다.

## 부작용 표
| 동작 | Order*/Shipment*/Warehouse*/Stock*/Estimate/WebProfitReport/승인원가 | XLSX |
|---|---|---|
| 참고 판매 기준 조회·원가 다운로드 | 전부 보존. 기존 GET/메모리 계산만 사용. SQL 추가·변경 없음 | 원본 양식 계산의 판매 영역만 자동 기본값/수식/근거 적용 |
| 다운로드 후 판매가 변경 | 전부 보존 | 해당 파일의 판매·손익 재계산 |

EXE `ExcelLoadingPackingList.MakeTempTable` UPrice/TPrice와 `InsertMaster` native 입고/재고 저장 호출은 이번 변경 범위가 아니다. 관련 decompile 원문 재확인. 기존 원가/수량 스냅샷과 원본 JSON 서식 hash는 변경하지 않는다. 파일 생성 자체는 ERP 저장 증거가 아니다.

## 검증
11프로필 양성/미원가/명시0/취소/충돌가격/단위불일치/이름변형/다른연도 fixture, 전체 ERP guard·빌드·CI. Aside 실제 다운로드 후 값·수식·강조·원장 미변경 확인. 미검증은 완료라고 보고하지 않는다.

메뉴 기준: 화면 shell/키보드 해당 없음(다운로드 생성만 수정). 출처 표시·실제 다운로드 검증 적용.
