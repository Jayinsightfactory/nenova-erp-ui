# 국가별 원가 빈 셀 복원

## 사용자 기준
- 모든 활성 국가 양식의 원본과 생성 결과를 대조하여 제목·항목·기본값·수식 누락을 복원한다.
- 운영 DB 수정 금지. 첫 결과 시트는 조회/승인 시점의 고정값을 보존하며 편집용 원본 계산 시트의 수식과 역할을 명확히 구별한다.
- 실제 수동 입력이 필요한 판매가만 구분한다. 이미 확인된 환율·중량·통관합계를 다시 입력하도록 요구하지 않는다. 근거 없는 세부 청구액은 실비0이나 과거 값으로 채우지 않는다.
- 주광 우선 추정배분/원가합계/현재 입력·원본 수식·단위·재조회 경계를 보존한다.

## 원천 검증
- 실제 설치 EXE ExcelLoadingPackingList를 dnSpy CLI로 재확인: SteamQuantity/UPrice/TPrice 별도 매핑. 이번 변경은 파일 표현만 수정하고 InsertMaster/SP를 호출하지 않는다.
- 2026/43-02 Holex7814 SELECT-only:71품목/GW1226.1/CW1364. 원장 쓰기0.
- 기존 원가자료11개(국가9개, 중국 항공/해상 및 콜롬비아 구형/42-1)의 파일 해시가 각 활성 profile.sourceHash와 일치한다. 개인 원본은 outputs/source-header-audit.json에만 분석하며 커밋하지 않는다.
- 핵심 원인: 형식 전용 asset에는 값이 없으며 첫 결과 시트의 값 whitelist와 편집용 원본 계산의 복원 범위가 달랐다. 비어 있는 예전 표 테두리가 입력 미완료처럼 남았다.

## 부작용 행렬
| 동작 | Order/Shipment/Warehouse/Stock/Estimate/WebProfitReport/승인원가 | 파일 |
|---|---|---|
| 생성/다운로드/Excel 입력 | 모두 보존 | 항목·현재 값·입력 안내 및 계산 수식만 복원 |
- 업무키 OrderYear+OrderWeek+WarehouseKey+ProdKey. SQL·권한·원가계산/승인식/게이트 변경 없음.
- 메뉴/웹 레이아웃 기준 해당 없음(웹 화면 구조 미변경), 실제 웹앱 다운로드 검증 적용.
- 근거 없는 과거 품목·거래처·환율·판매가·금액·95% 예상물량은 복사하지 않는다. 과거 참고 세율은 명시 참고 표시에만 사용한다.

## 검증 계획
- 첫 결과/원본 편집의 역할, 메타/합계/표 제목, 명시0/누락/교차연도, 모든11 profile 행확장, 입력의 조건부 표시, 기본값/승인 금액 보존, 입력→판매/이익/합계 반응, 수식 오류와 셀 겹침 검사.
- 국가별 실제 원본 해시/항목 대조 및 fixture 다운로드. 네덜란드 실제입고는 SELECT-only 다운로드와 Excel 검산. 다른국가 fixture에는 시험값을 명시한다.
- 필수 ERP 가드·빌드·CI 통과 후 squash/배포, 네노바 Desktop 실제 다운로드 확인. 아직 완료 전.
