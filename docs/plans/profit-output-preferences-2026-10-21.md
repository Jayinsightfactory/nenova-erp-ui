# 보고서 출력 항목·화면 컬럼 선택 유지

## 변경 전 기준과 부작용

- 현재 master 017741ab의 `ProfitRangeOutput`: 엑셀은 1~조회 차수 전체, 인쇄는 `selected`만 조회. 기본 인쇄 선택은 현재 차수 하나다. 41차 조회 자체가 41차 전체 인쇄를 뜻하지 않는다.
- 웹 출력 설정만 변경한다. 기존 `profit-range-output-2026-10-19.md`의 dnSpy FormStockView.GetData/운영 SELECT 근거와 기존 출력 GET의 연도·차수/확정값을 재사용한다. 이번 작업은 SQL, EXE 저장/SP, 원가 계산을 수정하지 않는다. 신규 운영 DB probe는 실행하지 않으며 실제 자료 최신성 검증으로 표시하지 않는다.
- 메뉴 기준: 반응형, 네이티브 checkbox/버튼, Escape 닫기/초점 복귀, 범위 표시 적용. 출력 iframe은 명시 미리보기 내부 스크롤 예외. 업로드/ERP 변경 승인 흐름은 해당 없음.

| 기준 | 원천·소비자 | 기본값/실패 처리 |

| 출력 컬럼 | 동일 COLUMN_DEFS, 출력 선택/GET/엑셀/인쇄 | 저장값 없으면 현재 화면 선택; 화면 설정 가져오기 명시 버튼 |
| 저장 범위 | localStorage | 같은 브라우저에서 재방문/연도 변경에도 유지; 다른 기기 동기화 아님 |
| 빈 선택 | 명시 [] 유효 설정 | 복원 가능, 출력은 1개 이상 선택 전 차단 |

## 검증 계획

설정 없음/정상/빈 배열/손상/낡은 키/차단 저장소, 최초 복원 전 덮어쓰기 방지, 재마운트, 교차연도 설정 유지와 데이터 범위 분리, 선택 항목 실제 xlsx/인쇄 반영, 41차 단독 1회 조회와 전체41회 조회, 원장 쓰기 없음. ERP gate/build 후 PR/배포/브라우저 확인. 실제 프린터 출력은 사용자 장치 확인 대상.
