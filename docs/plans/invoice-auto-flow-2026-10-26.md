# 인보이스 자동 입력·단계 연결

## 사용자 승인 범위
- 최초 파일은 로컬/캐시 우선, 필요 시 AI 자동 분석. 기존 파일은 재검증 여부 선택.
- 입력 근거가 완전하면 매칭→입고→원가를 하나의 실행 의도로 연결한다.
- 미매칭·모호한 농장·날짜·수량/금액 모순·필수 비용 누락만 요청한다. 임의 비용0/확인 플래그 강제 금지.
- 운영 DB는 SELECT만. 44-01 송장25529는 이미 입고되어 운영 재등록 금지.

## 기준 ledger
| 항목 | 원천 | 정책 |
|---|---|---|
| 입고일 | 실제 dnSpy MakeTempTable G3, 변환기 inv.date | 유효 원문 날짜를 자동 제안; 충돌·불가능 날짜는 보류; 오늘 fallback 금지 |
| 농장 | 실제 dnSpy C2 / 활성 Farm | 법인 구두점·접미사 정규화의 유일 후보만 자동 연결. fuzzy 1위 강제 금지 |
| 연도/차수 | 명시 선택→파일명·인보이스 날짜 | 기존 invoiceReceiptYear 규칙 유지, 교차연도 검증 |
| 수량 | 원문 박스·단·송이 및 기존 adapter | 기존 입고 수량을 새 파일에 복사하지 않음 |
| 중복 | 연도·송장·공급자/원본·AWB | 농장 별칭 차이로 기존 송장 재등록 금지 |
| 실행 | 사용자 단일 실행 의도 | 각 단계 readback 후 다음 진행, 불명 결과는 재조회; 입고 완료 후 원가 실패 시 입고 재시도 금지 |
| 원가 | 기존 국가 공식·실제 입력 | 누락 비용을 0으로 대체하지 않음; 확정 원가 변경 범위는 기존 계약 |

- 2026-10-26 실제 dnSpy ExcelLoadingPackingList: G2차수/C2농장/G3일자; CreateWarehouse→StockCalculation.
- 운영 SELECT 비교: 2026/44-01 송장25529, WarehouseKey7845, FarmName C.I Flores Balverde S.A.S, InputDate2026-10-23,107박스/3210송이/USD2733. Farm41 Balverde. 운영 변경 없음.
