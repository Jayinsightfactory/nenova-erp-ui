# 태국 통관 실비 근거 일치 — 2026-10-22

## 요청·판정 기준 (구현 전)
- DB 쓰기 없이 34차 태국 도착원가와 매출자료 통관비 차이를 확인하고 웹만 수정·배포한다.
- SQL 실제 운송료 행과 저장 통관 구성요소/검증된 H만 비용 근거다. 코드 기본값, GW 트럭 추천, 현재 요율을 실비로 확정하지 않는다.
- SQL의 명시 0은 유효하고 NULL/행 없음은 미확인이다. 확인된 금액과 누락 항목을 구분한다.
- 원가의 매입연도/차수/품목과 과세환율을 보존한다. 과거 매입 비용을 현재 차수 비용으로 대체하지 않는다.
- 완전한 비용과 배분 수량이 없으면 단가 근거로 승격하지 않는다. 미확인 H는 0원으로 이익률을 완성하지 않는다.
- 완전한 경우에만 같은 SQL H를 AWB 실중량 비율, 기존 AWB 배분식으로 배분한다. 단/송이는 각 행의 실제 환산수량으로 환산하고 합계 비용을 보존한다.

## 읽기 전용 근거
- 실제 dnSpy CLI FormWarehouseView.GetData/FocusedRowChanged: WarehouseMaster/Detail와 Product JOIN, UPrice/TPrice 조회 확인. EXE 재고 삭제/재계산 경로는 호출하지 않는다.
- 2026/34 태국: 운송료 전표 있음. FreightCost, WebCustomsWeekly, WebForwardingWeekly, WebArrivalCostLine, WebInvoiceCostRevision의 해당 실비 근거 없음. WebCustomsRateConfig/History도 빈 상태.
- 기존 도착원가 통관 기본합계와 보고서 GW 추천 합계는 서로 다르며 둘 다 실비가 아니다.
- 해당 입고에 ProdKey NULL인 상품금액 행도 존재한다. 품목을 추정 연결하거나 다른 품목에 비용을 떠넘기지 않는다.
- 운영 상세 금액/키는 git 제외 .verify/sql-cost.json. SQL query 변경문, execute/batch/transaction을 차단한 probe 사용.

## 검증·배포 차단
- 교차연도/세부차수, 저장 0/NULL, 미저장 기본값 금지, 누락 품목·단위·비용 총액 보존 회귀.
- 1~41 SQL 읽기 전후 비교, 태국 외 불변, 원장 지문, 산술/연속성 검산. 미확인 숫자는 정답으로 주장하지 않는다.
- ERP 전체 gate/build와 PR CI 성공 전 배포 금지. code-only Cafe24 후 실제 보고서/다운로드 확인.

## 구현·사전 검증 결과
- 실제 SQL 기준 1~41차 독립 산술 15,058개 검사 일치, 비교 가능한 기말→다음 기초 차이 없음. 숫자 변경은 태국 E/F/H/I/J/K에 한정, 매출·매입·환율·운송료와 타 국가는 불변.
- 실제 통관비 근거가 부족한 태국 차수는 이익률 확정을 보류한다. 기존 전체 합계도 부분 합계를 정상 이익률처럼 표시하지 않는다. 이는 자료가 완전해졌다는 뜻이 아니다.
- 저장된 28~31차 통관비는 사용하되 이전 재고 원가가 미확인인 차수는 별도로 보류한다. 34차 원가의 기본 통관비가 38~41차 확정 근거로 이월되지 않음을 검증한다.
- 코드 리뷰에서 운송료 일부 행 NULL의 0원 합산을 발견해 모든 운송료 행 완전성 검사로 차단했다. 명시 0원은 유지하며 NULL/빈 값/비유한/음수 fixture를 추가했다.
- 태국 불완전 도착원가를 매입액+H만으로 복구하는 가격 하한 우회도 차단했다. SQL 실제 운송료까지 포함된 완전한 근거가 필요하다.
