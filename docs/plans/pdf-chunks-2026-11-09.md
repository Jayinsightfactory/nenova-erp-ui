# PDF 분할 분석 기준

- 대상: 큰 콜롬비아 묶음 PDF. 다른 국가와 입고 writer는 보존한다.
- 원본 PDF 페이지를 중복·누락 없이 최대 3쪽 구간으로 나눈다. 경계를 넘는 송장은 supplier+invoice+currency의 정확한 식별자로만 합친다. 식별자/금액이 불명확하면 중단한다.
- 구간 결과는 같은 사용자·원본 해시·프롬프트 버전의 기존 작업 저널에 보관한다. 재시도는 명시한 실패 작업만 허용하고 성공 구간은 재호출하지 않는다.
- 각 호출 전 durable claim, 호출당 기존 quota를 적용한다. 실패 구간 자동 유료 재시도 없음.
- 모든 구간의 완료, 원본 페이지 대조, 송장별 상품+부대비=인쇄 총액, manifest 송장 목록 대조 후 기존 응답 계약으로 반환한다.
- page는 원본 1-based 페이지로 복원한다. 부분/잘린 JSON을 성공으로 복구하지 않는다.

| 동작 | 웹 분석 저널 | 주문/출고/입고/재고/견적/손익 |
|---|---|---|
| 분석/조회/명시 재시도 | 사용자 격리 결과·진행 상태만 기록 | 모두 보존; SQL 호출 없음 |

화면 입력·메뉴·업무 순서 변경 없음. 진행 상세는 기존 분석 상태에만 표시. 새 사용 가이드 대상 아님.
추가 유료 원본 분석은 이번 수정 검증에서 실행하지 않는다. 실파일 E2E/배포 전 필수 gate는 별도 결과로 기록한다.
