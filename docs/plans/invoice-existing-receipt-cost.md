기준: NL/송이/명시 EUR, 같은 연도·세부차수·공급자·송장·발행연도. ProdKey+단가별 원문 송이·금액 합계와 유일한 기존 상세가 일치해야 한다. 원문146행은 보존하며82입고상세에 다대일 연결한다. 원문 행별 원가수량은 원문 송이수이며 전체입고수량을 각 행에 복제하지 않는다. 무게/운송료3행은 엄격한 품목 식별 및 금액 대조 후 계산상품에서 제외하되 전체 스냅샷에 포함한다.

미리보기와 연결 저장은 같은 helper로 대조하고 전체헤더·상세 digest를 비교한다. 저장은 문서·기존입고에 잠금을 잡고 웹 테이블만 쓰며, 실패 시 전체 롤백. 이미 연결된 문서의 일반 입고 writer는 항상 차단한다. 기존확정품목은 원가전용 연결을 막지 않지만 입고 수정허가를 뜻하지 않는다.

원가 입력에는 추정 여부/원천/산식/시각을 저장·표시·엑셀로 전달. ACTUAL은 실입고수량 기준이라는 뜻이며 비용확정 여부와 구분. 원본 과거차수 금액을 복사하지 않고 현재 송장·현재입력으로 계산한다. 다운로드 시트명은 선택한 연도·세부차수로 생성하고 원본 양식/입력/수식 결과를 별도 검증한다.
