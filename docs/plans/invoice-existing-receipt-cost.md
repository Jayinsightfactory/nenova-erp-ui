# 기존 입고 원가만 연결 — 2026-10-19

## 직접 입력 보완
자동 근거가 없는 관세율은 담당자 직접 입력으로 진행한다. 화면은 % (25), 기존 계산·저장 계약은 비율(0.25)을 유지한다. 빈칸과 명시0을 구분한다. 송이 원가의 선택적 단당 송이수는 누락으로 표시하지 않는다. 입력필요 필터는 클릭 시 행을 고정하여 입력 도중 초점을 잃지 않으며 문서 identity가 바뀌면 적용하지 않는다. 최종 승인 입력은 기존 서버 snapshot/readback/복원 경로로 저장한다. 미승인 편집값을 서버 저장본으로 표시하지 않는다. 품목은 기존 문서 검색·초안 저장을 재사용한다. ERP writer/DB 구조/계산식은 변경하지 않는다.

기준선: 기존 페이지 shell/스크롤 보존, 기본 버튼·숫자입력 키보드 조작 적용, 입력누락·저장단계 구분 적용. 새 메뉴/레이아웃 추가 해당 없음. 운영 레우코취 실제관세율 근거는 미확인으로 임의0 저장 금지.

사용자 승인: 기존 입고 보존, 환율·추정 통관비 적용 원가 저장, 다운로드 원본 양식·차수 시트 대조.

기준: NL/송이/명시 EUR, 같은 연도·세부차수·공급자·송장·발행연도. ProdKey+단가별 원문 송이·금액 합계와 유일한 기존 상세가 일치해야 한다. 원문146행은 보존하며82입고상세에 다대일 연결한다. 원문 행별 원가수량은 원문 송이수이며 전체입고수량을 각 행에 복제하지 않는다. 무게/운송료3행은 엄격한 품목 식별 및 금액 대조 후 계산상품에서 제외하되 전체 스냅샷에 포함한다.

미리보기와 연결 저장은 같은 helper로 대조하고 전체헤더·상세 digest를 비교한다. 저장은 문서·기존입고에 잠금을 잡고 웹 테이블만 쓰며, 실패 시 전체 롤백. 이미 연결된 문서의 일반 입고 writer는 항상 차단한다. 기존확정품목은 원가전용 연결을 막지 않지만 입고 수정허가를 뜻하지 않는다.

원가 입력에는 추정 여부/원천/산식/시각을 저장·표시·엑셀로 전달. ACTUAL은 실입고수량 기준이라는 뜻이며 비용확정 여부와 구분. 원본 과거차수 금액을 복사하지 않고 현재 송장·현재입력으로 계산한다. 다운로드 시트명은 선택한 연도·세부차수로 생성하고 원본 양식/입력/수식 결과를 별도 검증한다.

선행 근거: 실제 dnSpy CLI 재실행, 읽기전용SQL7662/85행/16251상품송이. Action CHECK는 CREATE/UPDATE만 있어 명시LINK값 추가 필요. ERP 스키마/SP 변경 금지. 신규 웹 제약 변경은 별도 제한된 마이그레이션으로 수행·검증한다.
