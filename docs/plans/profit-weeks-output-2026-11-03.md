# 차수별 조회 출력 연결과 인쇄 비고 가로 흐름

## 기준 ledger
- 카테고리별 기존 출력/편집 흐름은 유지. 차수별은 조회 완료된 연도·from/to만 출력하며 조회 범위 전체를 최초 선택한다. 전체선택도 이 범위 안이다.
- 입력 변경, 최신 요청 전환, 늦은 응답, 응답 연도/차수 불일치, 부분 실패를 출력 완료 범위로 승격하지 않는다. 범위별 성공 전까지 출력 차단; 실패 차수 명시.
- 차수별은 읽기 전용이며 저장/확정 버튼을 새로 노출하지 않는다. 카테고리 미저장 초안이 있으면 먼저 저장/취소하도록 안내하고 자동 저장하지 않는다.
- 기존 22열/별도 출력 선택/선택 차수만 출력/1차수1장 유지. 인쇄 userNote만 CRLF/LF 줄을 trim 후 ` · `로 잇고 빈 줄을 제외해 가로 흐름·자동 줄바꿈한다. DB비고/XLSX B28/원 metadata는 보존한다.
