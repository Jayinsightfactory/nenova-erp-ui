# 입고 단 수량 확인

기준은 `warehouse-bunch-weight-2026-11-20.md`의 동일 I열·Product 출고/견적 단위·운영 읽기 전용 대조다. 저장 대상 신규 입고의 연도·차수·농장·송장 키와 재고 트랜잭션을 유지한다.

| 동작 | Product | 입고 Master/Detail | 재고 | 주문·출고·견적·매출 |
|---|---|---|---|---|
| 다운로드·미리보기·후보 확인 | 현재 품목 조회 | 보존 | 보존 | 보존 |
| 확인 뒤 신규 입고 | 같은 품목/단위 재조회 | 기존 트랜잭션에서 추가 | 기존 순서대로 반영 | 직접 변경 없음 |

원본 명시 단을 보존한다. 수량이 빠지면 인쇄된 단당 송이와 박스당 단 기준으로 계산하고, 후보가 정수이고 모순이 없을 때만 자동 적용한다. 마스터 환산이나 충돌은 산식을 표시하고 사용자 확인을 받는다. 중량행에는 상품 단 계산을 하지 않는다. 운영 기존 수량 보정은 범위 밖이다.
