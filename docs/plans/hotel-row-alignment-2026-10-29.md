# 호텔 원본·매칭 행 높이 일치

각 원본 표의 실제 가로 경계선에서 품목 행 위치를 검출한다. 첫 품목 시작 위치와 행 높이를 원본 이미지/매칭표에 공통 적용한다. 이미지 세로 표시 크기를 최소 30px 행 기준으로 맞추고 표 머리글을 같은 시작점에 둔다. 원본 전체 내용 보존. 자동 판정이 불명확하면 기존 표시와 표별 수동 첫 줄/간격을 사용하고 수량/순서 추정 금지.

|동작|쓰기 및 보존|
|---|---|
|이미지 로드·크기 조절·hover/focus|브라우저 픽셀 분석/표시만, 모든 원장·초안 보존|
|표별 수동 줄 조정|기존 서버 초안 alignment 메타데이터만, 품목/수량/단위/원본 보존|
|저장·등록|기존 계약 그대로, 이번 검증에서 ERP 등록 안 함|

OrderYear+OrderWeek+CustKey+ProdKey 보존. Order/Shipment/Stock/Estimate/WebProfitReport와 금액·확정값 변경 없음. 기존 FormOrderAdd dnSpy/읽기 probe 근거 재사용, SQL/API 변경 없음.

메뉴 기준: 단일 shell·기본 키보드·페이지 세로 스크롤 적용. 좁은 화면 표 가로 스크롤은 예외. 신규 메뉴/ERP 쓰기 추가 해당 없음. 좌우 독립 표, 서로 다른 제목 높이, 긴 표, resize, 수량 편집/미매칭/행 삭제 회귀 확인.
