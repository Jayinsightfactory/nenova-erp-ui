# 기초재고 입력칸과 줄별 비고
사용자 명확화: 기초재고는 실제 붙여넣기 textarea 자체. 별도 표로 대체하지 않는다. 항상 보이는 입력칸과 비고를 동일 줄높이/원문 줄번호로 나란히 두며, 빈줄·구분선도 동일 위치에 유지한다. 원문 입력은 wrap off 및 자동 높이로 세로 스크롤·줄바꿈에 의한 어긋남을 방지. 비고는 최근 1건만 고정높이, 전체본은 행 높이를 바꾸지 않는 overlay. 수정중인 기초재고는 적용 전 변경입력 차단. 계산·페이지·차수 저장·ERP API 불변.
검색어: 실제 기초재고 입력칸 줄맞춤 StockInputRemarks
