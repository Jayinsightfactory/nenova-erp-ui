# 수입부 업무도구 한국어·화면 정리

## 범위와 수용 기준
- `/import/tools`의 패킹리스트/AWB, 국가별 발주서, 체크리스트/항공/휴가/재배, 변경 이력 전체.
- 한국어 기본, 기존 외국어 선택은 유지. 사용자 입력·품목명·업체명·출력 Excel 계약은 번역하지 않는다.
- 네이비 본문/파랑 주요 버튼,14px 기본 글씨,36px 이상 주요 조작, 명확한 오류·저장 상태, 표 자체 스크롤.
- 1920×1080 CSS pixel/100% 우선.900px 및 좁은 화면에서 가로 넘침·겹침·모달 이탈 확인.
- 체크리스트의 스페인어 업무키는 그대로 보존하고 표시만 번역한다. 기존 체크 상태를 잃지 않는다.

## 동작·부작용 및 기준
| 동작 | 변경 | 보존 |
|---|---|---|
| 탭·표·한국어 표시 | 화면만 | 파일 변환 수량·국가 ID·Excel 열/파일명 |
| 체크리스트 표시 | 별도 번역 사전 | 저장키·revision·동시수정/초안 보호 |
| 공동 저장·삭제 | 기존 API 동작 유지 | ERP 주문·출고·재고·견적 전체 |
| AI 선택 | 기존 명시적 선택/비용 안내 유지 | 자동 AI 호출 금지·20MiB 한도 |

서버/API/SQL 변경 없음. 운영 테스트는 읽기 및 브라우저 격리 저장만 사용한다.
구현은 분리된 파일 책임으로 병렬 진행. 지정 terra 미지원으로 gpt-6.1-sol/high 대체, 최종 검토는 고성능 모델.
