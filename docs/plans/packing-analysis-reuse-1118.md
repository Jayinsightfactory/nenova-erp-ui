## 추가 요청: 이력 대조·농장 선택 (11-18)

- 이력 GET과 원본 SHA 검증만 사용하여 원본 추출/현재 보관 분석의 품목·박스·단·송이·행별 단가·상품합계·송장총액을 구분한다. 실제 ERP 저장 readback이라고 표시하지 않는다. 누락은 미확인, 명시 0 보존, 통화/송장 합산 금지.
- 농장 검색/자동제안은 활성 Farm 및 활성 WarehouseMaster의 정확한 이름/PK 근거만 사용한다. 동일 국가·정규화 공급자명이 동일하고 사용건수 최상위가 유일한 경우만 과거 다빈도 이름을 자동제안한다. 다른 국가·동률·다른 공급자는 자동 제안하지 않는다. 수동 선택 및 확정문서 보존.
- 모든 조회/비교 동작은 Warehouse/Farm/Product/주문/출고/재고/견적/손익 보존. 신규 입고는 기존 명시 승인 writer만 사용하며 본 검증에서 운영 commit 금지.
- 콜롬비아 누락 단수는 원본 품종에 대한 기존 importPacking.stemsPerBunchCO 규칙만 사용해 결정적으로 환산한다. 인보이스 송이수·단가·금액/명시 단수(0 포함)를 바꾸지 않는다. 모르는 품종은 추정하지 않는다.
