# 수입부 파일 도구 보완 계약

## 사용자 정정과 완료 기준

- 정상적인 0수량은 오류가 아니며 다운로드 가능하다. 읽기 실패를 0으로 바꿔 원본 수량을 잃는 동작만 수정한다.
- PDF 파일당 20MiB. JSON base64 오버헤드 때문에 API 30MiB, nginx 정확 경로 32MiB. 다른 API의 전역 한도는 변경하지 않는다.
- AWB 총액과 문서 날짜는 원문 근거가 있을 때만 자동 입력한다. 오늘 날짜/가장 큰 숫자를 원문 값으로 오인시키지 않는다.
- 알려진 NL Holex 텍스트 PDF는 코드 우선. 전체 페이지와 수량/금액 검증 통과 때만 사용한다. 미지원/스캔/불완전 파싱은 명시적으로 AI 분석 선택이 가능하게 한다.
- 동일 사용자·파일 해시·국가·프롬프트/모델 버전의 정상 AI 결과는 30일/최대100건 재사용한다. 원본 PDF는 캐시에 보관하지 않는다. 실패/잘린 결과는 재사용하지 않는다.
- 카탈로그는 저장 전 국가별 변경 건수를 보여주고 병합 또는 전체교체를 명시 선택한다. 병합이 기본이며 전체교체는 별도 확인한다.
- 미확인 품목 건수는 중복 행과 품종의 의미를 일치시킨다.

## 부작용 및 기준

| 사용자 동작 | 웹 전용 데이터 | Order / Shipment / Stock / Estimate / WebProfitReport |
|---|---|---|
| 파일 업로드·변환·다운로드 | 브라우저 메모리 | 접근/변경 없음 |
| 명시 AI 분석 | 사용자별 요청 제한 및 분석결과 캐시 | 접근/변경 없음 |
| 카탈로그 병합/교체 확인 | 기존 revision/수정자 이력으로 공동 저장 | 접근/변경 없음 |

기존 import-team-tools 계약을 확장한다. 새 SQL/SP/EXE 변경, 재고잠금, 주문등록은 없다.

## 회귀 근거

- 실제 업무드라이브 중국 최신 matrix: 구조화된 숫자 시트 우선, CustKey로 동일 코드 고객 구분, 수량0/빈값/형식실패 구분.
- 실제 Colombia 39품목/2120 보존.
- 실제 AWB: 총액1379.60 및 2026-10-01, GW303/CW380/rate3.37.
- 실제 NL: 원본90행 수량7589와 금액 대조. 미확인 매칭 안전장치 보존.
- 20MiB 경계, 사용자 캐시 격리/만료/프롬프트변경, nginx exact-route 인증/upstream 보존.
- UI 1920×1080 CSS pixels / 100%, modal/overflow/sticky 및 저장실패 초안 보존.

## 작업 분담

메인은 계약·API·서버 한도·최종 통합·배포를 담당한다. 지정 terra가 제공되지 않아 구현 하위작업은 gpt-6.1-sol/high로 대체했다. 중국 발주 변환, 로컬 PDF 추출, 카탈로그 UI를 파일별로 분리한다. 하위작업은 P0_LOCAL이며 외부 쓰기 및 운영자료 변경을 하지 않는다.
