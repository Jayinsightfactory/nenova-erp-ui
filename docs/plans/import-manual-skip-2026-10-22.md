# 수동 품목 연결과 명시 건너뛰기

사용자 요청: 수동 연결은 반영하고 건너뛴 품목만 제외한 나머지를 분배한다. 진행 중 업로드 보호를 위해 운영 배포는 기존 유예 조건을 유지한다.

## 구현 전 근거와 기준

- 설치 EXE FormShipmentDistribution을 dnSpy.Console로 재추출(2026-10-22). btnSave_Click: GetShipmentMaster(CustKey), ProdKey/수량/환산/금액 저장, 변경 농장 저장, 수량 변경 시 ShipmentDate 삭제→재생성. 연도+차수 조회 확인. 기존 writer 및 환산 정책 유지.
- SELECT-only Product probe: 1717 Ruscus Green, 3085 Ruscus Green 40cm, FlowerName=루스커스, CountryFlower=콜롬비아루스커스, OutUnit=박스. 추론 함수에는 루스커스 분류가 없어 빈값. 2025/43-01/1717 출고22행·58박스·22확정, 2026/43-01 해당 출고 없음. 운영 변경 없음.
- 수동 선택은 유효한 활성 DB ProdKey만 허용하며 자동·파일 키보다 우선한다. 잘못된 수동 키는 자동 후보로 대체하지 않는다. 자동 매칭의 품종 차단은 유지한다.
- 건너뛰기는 현재 파일의 sheet|label|family에 한정. 모달 닫기와 별개. 재검증 후 서버가 제외를 반영한 계획을 생성한다.
- 제외 품목의 DB 키를 모르는 경우도 있으므로, 건너뛰기가 있으면 교체 범위를 **파일에 남아 매칭된 ProdKey**로 제한한다. 파일 밖 품목도 보존됨을 명시한다. 포함 품목의 누락 거래처 분배0 계약은 유지한다. 제외와 포함이 같은 키로 겹치면 적용을 차단하고 선택을 재검토한다.
- 서버 발행 HMAC에 적용 품목 범위를 포함. 미리보기, coverage 사전검사/트랜잭션 재검사, 사후 검증은 같은 범위. 범위 위변조·다른 연도·확정·stale는 계속 차단.

## 검증 기준

수국 제목+루스커스 2종 수동 선택, 잘못된 키, 기존 파일 키보다 수동 우선, 제외·취소·전부제외, 같은 품목 연결 충돌, 2025/2026 동일 차수, 서명 범위 변조, scope SQL 일치, 제외 기존 출고/확정/날짜 보존. 필수 ERP 검사 및 빌드, 로컬 브라우저 후 실제 배포는 업로드 보호 조건 충족 후 수행.

메뉴 기준: 적용=원문/선택/제외 안내·명시 승인·키보드 기본 버튼·오류 표시. 해당 없음=새 메뉴/shell/이력 신설. 기존 UI 범위만 수정.
