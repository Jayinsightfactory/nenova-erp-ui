# 수입부 업무도구 관리 메뉴 · 2026-10-07

## 요청과 완료 기준
- 일일 업무, 항공 일정, 휴가 관리, 재배 계획, 기존 불량 피드백을 상위 메뉴에서 바로 선택한다.
- 기존 개별 내역 추가·수정·삭제와 공동 저장/CAS/서버 수정자 이력을 유지한다.
- 휴가 직원·연간 한도, 재배 품종·목표의 고정값을 공동 설정으로 확장한다. 설정 삭제로 기존 업무 기록을 삭제하지 않는다.
- 기존 농장 불량·피드백을 동일 인증·권한·자료로 사용한다. 별도 피드백 저장소/원장/권한을 만들지 않는다.
- 1920×1080 CSS px, 확대 100%를 기준으로 900/480 너비에서 잘림도 검사한다.

## 부작용 경계
| 동작 | 저장 대상 | ERP 주문/분배/출고일/입고/재고/견적/매출 |
|---|---|---|
| 메뉴 이동 | React 화면 상태 | 보존 |
| 일정·휴가·재배 CRUD 및 설정 | 기존 웹 전용 runtime record, revision/actor history | 접근·변경 없음 |
| 불량피드백 탭 조회 | 기존 `/sales/farm-quality?popup=1` 조회 | 기존 읽기 계약 유지, 자동 쓰기 없음 |
| 불량피드백 명시 저장/수정/삭제 | 기존 farm-quality API 및 권한 그대로 | 기존 계약 그대로, 신규 SQL/DDL 없음 |

`farm-quality.json`의 코멘트 정정은 이력 추가 방식, 삭제는 기존 제한을 그대로 따른다. 일반 설정 삭제 버튼과 동일한 무제한 CRUD로 바꾸지 않는다. iframe은 첫 방문에만 생성하고 탭 이동 시 유지하여 작성 초안을 보존한다.

## 원본 대비 확인한 차이 (100% 동등하다고 주장하지 않음)
원본: `Import_Team_Checklist_Diario_2.html`.
- 항공: 원문 추가·삭제, 도착/반입 체크, 도착일 정렬 존재. 웹은 수정·공동 저장·체크 계정 이력을 추가했다. 원본의 반입대기 탭 배지/단축키를 보완한다.
- 휴가: 연도별 등록/수정/삭제, 직원 필터, 잔여량 표시 존재. 원본 자동 연도 이동 대신 선택연도와 시작연도 불일치를 차단한다. 잘못된 종료일도 차단한다.
- 재배: 농장/품종/전체 보기, 박스 배정·목표·줄기당 USD 단가 존재. 박스당 줄기 수 없이 금액을 추정하지 않는다.
- 일일 업무: 요일 반복 템플릿 CRUD, 날짜별 체크/초기화, 월별 결제, 미결업무 존재. 원본 요일만 저장과 달리 실제 날짜별 저장이다. 원본의 일괄 주간 초기화는 제공하지 않는다.
- 원본도 직원/휴가한도·품종/목표·월별 결제 목록은 하드코딩이었다. 이번 직원/품종 설정은 원본 이상의 관리 기능이다. 월별 결제 항목 설정은 이번 범위에 포함하지 않는다.
- 원본 HTML의 localStorage에 저장된 직원 PC 자료는 업로드된 HTML 자체에 포함되지 않는다. 자동 이관 완료로 설명하지 않는다. 필요 시 해당 PC의 자료 내보내기와 별도 검증 이관이 필요하다.
- 패킹/발주 변환의 이전 검증은 기존 회귀로 유지한다. 모든 임의 양식의 자동 매칭 100%를 보장하지 않는다.

## 검증
임시 저장소 테스트와 브라우저 요청 fixture로 CRUD·계정 이력을 검증한다. 운영에 가짜 일정/휴가/피드백을 생성하지 않는다. 운영 불량피드백은 읽기 스모크만 수행한다.

## 같은 작업 중 추가 요청
- 잔여 휴가 직접 수정: 기존 사용 내역은 보존하고 사용 일수 + 원하는 잔여 일수로 연간 총 한도를 조정한다. 사유와 변경 전후 값은 서버 인증 계정/시각과 함께 기록한다.
- 인수인계·특이사항: 제목, 이슈, 처리 방법, 주의사항, 체크사항, 상태(확인 필요/처리 중/처리 완료), 중요도. `checklist.handoffs` 웹 공동 저장이며 한 번에 한 항목만 변경한다.
- 인수인계 이력은 서버가 실제 저장 전후를 계산한다. 계정/시각은 클라이언트 입력으로 받지 않는다. 최근50회 화면 표시, 이전 이력은 기존 불변 파일 보관으로 보존한다. 삭제 전 내용도 이력에 남는다.
- 인수인계와 휴가 조정은 ERP 원장/재고잠금과 무관하다.
