# 중국 39차 이상 두 농장 분해 — 구현 전 기준

## 승인과 기준

중국 부모 합계·이익률·저장본은 바꾸지 않는다. 39차 이상에만 HUBFRESH 배와 Cloudland 비행기 두 행을 표시한다. 실제 출고농장 및 동일 품목 당차 입고비율을 먼저 사용한다. 미귀속·공통비·조정·저장본 차이의 잔차는 당차 중국 전체 입고의 공통 근거로 두 행에 나눈다.

| 기준 | 처리 | 실패/예외 |
|---|---|---|
| 연도·차수 | 기존 엄격 파서 + major>=39 공용 eligibility | 38차 이하 UI 숨김, API DB 조회 전 거절 |
| 품목별 직접 근거 | 기존 실제 농장/같은 품목 입고비율/매입/운임 | 미귀속분은 잔차에 포함 |
| 전체 공통 비율 | 전체 입고의 단위가 하나로 검증되면 OutQuantity 비율 | 단·송이·박스를 합산하지 않음 |
| 혼합 단위 대안 | 기존 보고서 분류상 양측 모두 CNY인 입고 TPrice 합계 비율 | 모든 행 금액이 유한·비음수, 합계 양수여야 함. 누락·다른 통화·알 수 없는 농장이 있으면 불가 |
| 환산 확대 | 검증되지 않은 단↔송이 계수를 만들지 않음 | 혼합 단위는 명시한 매입액 비율 사용 |
| 잔차 | 직접 근거 다음에 공통 비율로 배분, 열별 차액/기준 표시 | 양측 근거 없음 또는 배분 불가 시 해당 금액은 분해 불가, 원천 NULL 유지 |
| 합계 | 소수 계산과 화면 원단위 모두 부모 보존 | 두 행 이익률의 단순평균 금지, 전체 이익/전체 매출 기준 |
| UI | 두 행 + 부모 합계, 14px 한글 고딕, 고대비, 금액 고정폭 | 가이드·키보드·작은 화면 검증 |

## 구현 전 근거

기존 PR1885 이후 ERP 가드/DB 구조/기능 계약 문서의 Git 내용 변경 없음을 확인하고 같은 기준을 유지한다. 2026/44 최신 SELECT-only 기준 조회 469 SELECT, 약20.4초: 매출39,413,527, 이익−18,524,012.37186063, 이익률−0.46999123858822967. 입고104행은 단·송이 혼합이며 HUBFRESH 상품매입48,375 CNY / Cloudland188,795 CNY. 186개 확정 출고는 농장배정0. 같은 날 실제 설치 exe에 dnSpy ClassShipmentFarm/FormWarehouseView 재실행: FarmKey/ShipmentQuantity/SdetailKey 및 OrderYear/OrderWeek/TPrice 확인. SP/쓰기 메서드 호출 없음. 원천 상세/인증정보는 커밋하지 않는다.

## 검증 예정

38/39 경계, 연도 분리, 실제/동일품목 우선, 단위 혼합 금액 대안, 누락·다른 통화·알 수 없는 농장·음수·0·NULL, 양측 무근거 차단, 표시 합계 및 부모 이익률 불변, 44차 전후 SELECT와 실제 운영 UI. 실행하지 않은 검사는 미완료로 유지한다. 메뉴 기본값: 읽기전용·스크롤·키보드·가이드 적용, 저장/일괄적용 확인은 해당 없음.

## 실행 결과 — 배포 전

- 순수 정책/API 회귀 PASS. 38차 API는 DB 조회 전에 400, UI는 숨김. 39차와 다른 연도 동일 차수 양성 fixture, 누락·0·NULL·알 수 없는 농장·서로 다른 통화 fixture 포함.
- 같은 업무키 2026/44 후속 SELECT 469회, 약10.1초. 수정 전후 저장본 calc 객체 완전 동일. 원장/저장본 쓰기 0회.
- 전체 단·송이를 더하지 않고 보고서 CNY 매입액 48,375 / 188,795 비율(20.3967618164% / 79.6032381836%) 적용.
- 표시 매출: HUBFRESH 16,409,459 + Cloudland 23,004,068 = 중국 39,413,527원. 표시 이익: −395,074 + −18,128,938 = −18,524,012원. 모든 금액 열 원단위 합계 및 소수 합계 보존. 전체 이익률 −46.9991238588% 보존.
- 현재 186개 확정출고는 농장배정이 없어 품목별 당차 입고비율 적용. 기초 6품목·기말 10품목 평가 근거 미확인은 경고를 유지한다. 이 분해는 당시 농장별 재고나 원가의 확정이 아니다.
- 기존 Layout/desktop 메뉴의 주차별 매출이익 경로에서 동일 컴포넌트를 사용한다. 신규 URL/메뉴는 만들지 않고 데스크톱 1.3.64로 갱신한다.
- `npm run verify:erp-change` 전체 PASS(계약·dnSpy 근거·변경 manifest·쓰기 가드·운영 빌드). 별도 데스크톱 메뉴 3개 테스트 PASS.
- 가이드 116.45초 실제 연습 화면 재녹화, 시작/중간/끝 프레임 확인 및 MP4/VTT/목차/키보드/접기 정지/1920·390 재생 스모크 PASS. 모든 API 합성, 운영 쓰기 0.
- PR/CI 및 운영 두 행 표시 확인은 이 기록 시점 미완료. 최종 배포 상태는 PR의 인계 기록에 추가한다.
