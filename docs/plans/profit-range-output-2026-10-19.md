# 주차별 보고서 범위 출력

## 사전 근거와 기준

- 2026-10-19 실제 `dnSpy.Console.exe --no-color -t FormStockView`로 설치 EXE GetData를 확인했다. StockMaster/ProductStock와 ViewWarehouse/ViewShipment, StockHistory/CodeInfo.StockType를 선택 연도·차수로 읽는다. 이 출력 기능은 EXE 저장 메서드/SP를 호출하지 않는다.
- 운영 SELECT로 선택 연도 보고서 snapshot, 입출고, 기초/기말 snapshot, 실제 조정 이력을 대조했다. 운영 세부 수치는 공개 저장소에 싣지 않는다.
- 공통 보고서 계산과 확정 snapshot 우선순위는 loadWeeklyReportPayload(preferLive=true)를 그대로 사용한다. 확정값 재계산·저장과 ERP 수량/금액 보정은 금지한다.
- 범위는 조회 완료된 연도와 대차수다. 다운로드는 01부터 선택 차수까지 빠짐없이 숫자순. 인쇄는 그 범위에서 명시 선택한 차수만 숫자순. 누락 연도/잘못된 차수/빈 인쇄 선택은 거부한다.
- 각 차수는 별도 읽기 요청으로 조회하여 진행률과 실패 차수를 표시한다. 하나라도 실패하면 부분 파일을 성공 다운로드하지 않는다. 범위 전환/취소 시 오래된 응답을 폐기한다.
- 사용자 후속 명시: 다운로드는 차수당 표시용 한 시트만 제공하고 원본 중복 시트는 넣지 않는다. 웹에서 실제 표시되는 열 순서·품명 숨김·프리셋을 적용하며 비고/검증은 같은 시트 하단에 보존한다. 기존 단건/MOYI 원본 양식 생성기는 호환성을 유지한다. 브라우저 인쇄는 같은 표시열을 사용하며 확정값·0·미확정 값의 의미를 바꾸지 않는다.
- 조회되지 않은 연도·차수 입력 상태에서는 출력을 비활성화하여 기존 수기 저장과 출력 범위가 엇갈리지 않게 한다.

## 부작용 표

| 동작 | 주문/출고/견적/입고 | ProductStock/StockHistory | WebProfitReport/확정/계산 snapshot |
|---|---|---|---|
| 차수별 출력 자료 GET | 기존 보고서 SELECT | SELECT | SELECT, 자동 저장 없음 |
| 엑셀 조립/인쇄 선택 | 보존 | 보존 | 보존, 브라우저 메모리만 사용 |

## 메뉴 기준

페이지 세로 스크롤/반응형/키보드/범위 보존/오류 안내 적용. 명시 인쇄 미리보기 iframe은 독립 스크롤 예외. ERP 입력 전 확인/업로드 매칭은 해당 없음. 기존 수기 초안은 기존 저장 흐름을 거쳐 출력한다. 실제 프린터 출력은 사용자 장치 검증 대상이다.
