# 원장 알림 대조

기준: 사용자가 원래 신고·등록이력·현재 견적·다른번호 차감을 한곳에서 확인하고 기본접힘 요청.

|동작|주문/출고/견적/재고/손익|웹 불량/이력|
|---|---|---|
|펼치기/대조/재조회/닫기|SELECT만, 모두 보존|SELECT만, 모두 보존|

기준표: 선택 연도+대차수로 원장 적용범위 검증, DeductionKey는 양의 정수. 원차수는 변경하지 않는다. 후보는 원연도 또는 적용연도 내 같은 CustKey+ProdKey의 음수 견적 전 차수(범위 표시), 현재견적은 적용연도 대차수. 단위동의어 비교, 수량다름/다른신고 연결을 자동 완료로 단정하지 않는다. 첫 CREATE snapshot이 있는 경우에만 최초신고라 표시하고 없으면 현재 저장 신고만 표시. 원본 카톡 파일은 DB에 없으므로 저장 비고/출처와 구분. 이력 JSON은 허용한 업무필드만 투영. 실패는 빈 결과가 아닌 오류. 기본접힘, 차수/재조회 변경시 상세 폐기, Esc 닫기/초점복귀.

실제 dnSpy CLI 2026-11-18: ClassEstimate.Select/Insert/Update/Delete 확인, Delete는 EstimateKey 물리삭제이고 삭제자/시각 감사 없음. SQL SELECT probe: 2026/45 적용 DeductionKey752(원41),1080/1124(원43)의 연결11177/11179/11181 현행0건. 이력 CREATE/REGISTER_ESTIMATE에 before/after 업무 snapshot 존재. 조회 외 DML0.

기준선: 페이지스크롤/키보드/오류/범위표시 적용. 입력·저장·매칭반영 해당없음. 신규 읽기 대조 영상 제작 예정.

검증: 새 함수로 운영 2026/45 알림16건 전부 조회, 최초 CREATE·등록이력 있음. 후보95행은 비교 참고이며 중복/차감필요 확정 아님. 부분이월 Application 연결도 조회. 모든 SQL SELECT만. 단위/수량/단가/다른신고/삭제헤더 반례와 전년도 경계 검증. 1920/1280/390 실제 브라우저 합성자료·Esc 초점복귀·조회 실패 검증. 가이드 MP4/한국어 VTT/목차/키보드 재생 검증, 3단계 42초 내외(정확한 길이는 proof). 배포 상태는 WORK_MEMORY 참조.
