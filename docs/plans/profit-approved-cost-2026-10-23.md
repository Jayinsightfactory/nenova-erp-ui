사용자: 백상 460원/kg 고정, 국내운송 3톤=2.5톤+1톤(187,000+99,000), 소액차이 때문에 화면 계산을 보류하지 말 것. DB 수정 금지.

이 정책은 2026-10-22 실비만 허용하던 규칙을 보고서 전용 승인 추정 범위에서 대체한다. 수량 오류, 환율 누락, 타 연도, 실제 운송료 누락은 비용 소액 허용과 무관하게 계속 차단한다. 수기 확정 H와 확정 revision 우선순위는 유지한다.

## 근거·검증

실제 설치 EXE FormWarehouseView.GetData/상세의 WarehouseMaster/Detail 조회를 dnSpy CLI로 확인. 웹 보고서 전용 변경이며 EXE 저장 경로는 변경하지 않는다.
운영 읽기 전용 probe는 Request 변경문/EXEC/batch/transaction 차단 상태에서 1~41차를 전후 조회한다. 수량·원천 지문·독립 산술·웹/엑셀 일치, 승인 추정/미배부 표시를 확인한다.
배포 조건: ERP 계약/dnSpy/manifest/write guard/build 성공, PR CI 성공, code-only Cafe24, 인증 브라우저 다운로드 스모크. 현재 진행 중이며 완료 결과는 후속 기록.

## 로컬 검증 결과
- verify:erp-change(전체 계약+build), dnSpy, origin/master 기준 manifest/write guard 성공.
- SELECT-only 1~41차 전후 비교: 독립 산술15,058개 실패0, N/L/O/Q/R/S·수기·재고수량 변경0. 관측 원천 지문 동일(비원자 조회라는 한계 유지).
- 태국34~38 및41차 계산 가능, FIFO/이월 원가누락0. 39차 GW 없음,40차 국제운임 원천 없음은 소액 통관 추정과 다른 문제이므로 H/이익률 보류.
- 백상460 고정으로22차 콜롬비아 과거370 요율 및23차 기초평가도 최신 계산에서 변경. 기존 확정 revision/원장 수정 없음.
- 태국 관세 추정의 과세가격 대용은 본표 Q+S이다. 미매칭70USD를 Q 또는 특정 품목에 임의 편입하지 않으므로 실제 신고액과 소액 차이 가능.
- 별도 검토자가 source/0/누락/연도/샘플평균 경계를 재검토했고 회귀 통과. 실제 청구서 확정 인증 아님.
