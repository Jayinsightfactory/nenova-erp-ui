# 데스크톱 홈·메모장 독립 유지

2026-11-13 사용자 요청·첨부 화면, 대상 확인: 일반 브라우저 /dashboard는 제외하고 데스크톱 앱 홈만 개편.

배치: 왼쪽 개발요청 게시판→내 업무 달력→즐겨찾기/전체 메뉴. 오른쪽 오늘의 내 업무→주의 업무지침→수입부 피드백. 상단은 검색과 작은 앱 관리/PM 상태로 축소. 기존 메뉴·계정 권한·소식 상세/읽음·즐겨찾기와 320px 메모장 유지.

| 동작 | 개인업무 파일 | 직원요청 파일 | ERP 원장·견적·재고 |
|---|---|---|---|
| 홈 조회·달력 | 기존 owner 읽기/월별 일정 집계 | 기존 GET 목록의 제목·상태만 읽기 | 모두 보존 |
| 업무 추가·수정·완료 | 기존 CAS·멱등 저장만 | 보존 | 모두 보존 |
| 개발요청 보기/작성 | 보존 | 기존 /pm 게시판을 사용자가 열어 처리 | 모두 보존 |
| 메인 창 X / 메모장 유지 | 새 쓰기 없음 | 보존 | 모두 보존 |

종료: 메인 창 X는 메모장이 열렸으면 작업창만 닫는다. 메모장이 없으면 종전처럼 종료. 메모장에서도 홈 다시 열기와 프로그램 완전 종료 제공. 마지막 메모장까지 닫으면 정상 종료, 명시 종료/로그아웃/계정 잠금은 메모장도 닫음. 미저장 입력 경고 유지·메모장 초안 추가. 계정 세션은 계속 동작하며 저장 API의 401/계정 변경 fencing 유지. 숨겨진 빈 프로세스는 남기지 않는다.

달력: KST, 2000~2100. 기존 occurrence/version/보관/완료 규칙으로 해당 월 각 날짜의 실제 업무만 집계(과거 이월을 그날 업무로 중복 집계하지 않음). 홈 GET의 calendarMonth만 선택적으로 사용, 노트 GET은 추가 집계 안 함. 달 이동은 조회 날짜를 바꾸지 않고 날짜 선택만 업무 조회와 연결. 작성 중인 업무가 있으면 날짜 전환 차단·선택 유지. 요일/월말/윤년/교차연도/완료·보관 fixture.

게시판: main 프로세스에서 기존 /api/pm/staff-requests GET 하나만 사용, 로그인 계정·세대 확인. 사용자 이름·본문·첨부는 홈에 전달하지 않고 최근 제목·분류·상태·수정시각/ID만 전달. 오류는 개인업무와 분리. 작성은 기존 게시판의 명시적인 작성 버튼에서만 진행, 자동 요청 생성0.

모션: 버튼 140~180ms 눌림/hover, 카드와 월 전환 180~220ms, View Transitions 지원 시 월 영역만 전환, 미지원 즉시 처리. prefers-reduced-motion이면 전환·이동/자동 ticker 정지. 키보드와 초점은 모션 완료를 기다리지 않음. 상시 반짝임·큰 배경 움직임 없음.

참고(2026-11-13 확인): https://m3.material.io/styles/motion / https://developer.mozilla.org/en-US/docs/Web/API/Document/startViewTransition / https://developer.mozilla.org/en-US/docs/Web/CSS/@media/prefers-reduced-motion

검증: native Electron 종료/노트만 저장·조회/재개/마지막 노트 종료/명시 종료 취소/계정전환; 월 집계 양성·경계·기존 snapshot; 게시판 owner race·고정 GET·projection; 실제 1920/1280/800/390 레이아웃·키보드·reduced-motion·데이터 실패/빈 상태; 실제 가이드 갱신, 필수 계약/가드/webpack, PR CI·1.3.21 설치파일·Cafe24·운영 smoke.

### 추가 사용자 지시: 큰 주간 시간 블록 달력
- 2026-11-13 첨부처럼 최종 사용자 정정: 큰 월간보기가 기본이며 그 하단에 월~일 가로/시간 세로 주간 시간표를 항상 함께 표시. 보기전환 탭 없음. 계획 영역 맨 위, 08~19시 기본 높이(업무가 이른/늦은 시간에 있으면 범위 확장), 실제 종료 시간·반복 일정·시간 미정을 구분. 월간 날짜칸에 시간순 일정2건·추가건수와 완료/전체 표시.
- 겹친 일정은 나란히 분할, 색은 업무ID별 일관됨. 일정/날짜 클릭은 해당일 조회, 빈 시간 클릭은 기존 업무 입력의 날짜·시간만 채움(자동 저장 없음). 100건/일 초과는 건수와 일별조회로 안내, 제목·본문 임의 생성 없음.
- 주간 데이터는 기존 owner GET의 calendarWeek 선택 조회와 기존 mutation 응답의 읽기 projection이며 SQL/새 쓰기 없음. 실제 윤년/교차연도/보관/스냅샷·시간·projection 상한/불변 테스트.
