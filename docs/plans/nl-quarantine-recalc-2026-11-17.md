# 네덜란드 검역 손실 가산·Excel 동적 재선택

## 기준
- 사용자 2026-11-17 승인: 원본 도착원가식 우선. 실제 46-2 NL 원가자료의 40-1,40-2,41-2,43-2,43-2(2),44-2,45-1,45-2,46-1,46-2는 모두 Q10=SUM(Q6:Q9)+S6+S7.
- 검역 손실은 종류별 최저 도착원가 상품 하나의 FOB/송이 × 원본 차감 송이수 × 환율. 통관비에 가산하고 기존 상품금액비율로 배분한다. 미입고 품종의 과거 가격은 가져오지 않는다. 표에 없는 종류는 기존 승인대로 0.
- 단가·환율·운임·세율·GW 수정은 Excel 내 32단계 비순환 전개로 재선택한다. 서버의 같은 고정점 알고리즘을 사용한다. 동일 단가는 lineId 순, 32단계 미수렴은 NA로 드러내며 조용히 확정하지 않는다.
- 원본 파일의 수기 잔존값을 기준값으로 복제하지 않는다. AWB950/1056과 레퍼런스1063의 차이는 숨기지 않는다.

## 부작용

|---|---|---|---|

| 다운로드 사본 입력 변경 | 보존 | 보존 | 보존 |

SQL/API 쓰기·스키마·권한·UI 작업순서 변경 없음. 기존 승인 스냅샷은 재계산하거나 저장하지 않는다. 이전 차수의 파일은 보존한다. 코드 산식 수정만이며 새 메뉴/작업순서 영상은 해당 없음. 기존 영상 정확성은 별도 검증.

## 검증
양성: 같은 종류 복수 품목·같은 단가·관세 차이·미입고·누락 샘플·환율 변경.
반례: 변경 전 고정행 및 통관비 차감 부호. 최종 배포·실제 앱 다운로드·Excel 재계산 결과는 WORK_MEMORY에 별도 기록하며 실행 전 완료로 간주하지 않는다.
