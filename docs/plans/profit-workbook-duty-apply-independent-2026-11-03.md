# 원본 관세 적용 독립 검토 기준

2026-11-03. 최신 사용자 적용 승인에 따른 진행 계획. 조사 전용 기록을 삭제하지 않고 이번 적용 승인과 구분한다. DB 쓰기 금지, 구현·검증·배포는 아직 진행 중이다.

## 판정 기준

| 기준 | 허용 | 금지 / 차단 |
|---|---|---|
| 실제 근거 | 실제 관세액·명시 0·수기 우선 | 원본율로 실제 값을 덮기 |
| 직접 원본율 | 2026+정확 품목+세부차수의 유효 동일행 수식 | 해당 차수 원본처럼 미래 시트를 설명하기 |
| 상품 기본규칙 | 승인된 exact 이름/키와 상품형태, 계산규칙임을 기록 | 모든 중국/태국 동일율 또는 CO3.2 가정 |
| 원본 예외 | 확인된 모든 차수 직접율 우선 | 17/27만 예외로 고정하고 28/32 예외 누락 |
| 수식 | 동일행 CNF원화×율 | 21-2 K30=J31×8% 등 교차행 오참조 학습 |
| 단위·통화 | 기존 실제 환산·환율 검증 유지 | 품명 중국 재분류만으로 USD를 CNY로 변환 |
| 금액 | H 및 재고평가의 기존 성분 경계 유지 | G 운임과 H 관세를 중복 가산 |
| 결과 | 연결 수·공란 회복·수익률 확정 여부를 따로 집계 | 정책 연결만으로 정확한 수익률 완료 선언 |

원본 동일행 exact 이름 연결은 실제 신고행 수량 1:1 매칭이나 실납부 인증이 아니다. 실제 원본의 수량과 SQL 입고 수량을 대조하지 못한 항목은 그 상태를 남긴다. 태국 Oncidium/Vanda/White Necklace는 승인된 해당 원본 세부차수만 허용하고 상품 광역 기본값으로 확대하지 않는다. Sample·불명은 제외한다.

## 원본 재확인 결과

중국 (3) 및 태국 (38-1) 원본을 다시 읽어 동일행 수식과 정확 품명을 기존 SELECT 연간지문에 연결했다. 공백·대소문자 정규화 이외 fuzzy 연결은 하지 않았다. 1,238 원본 관측행/214 고유키, 1,092 고유 품목·세부차수 조합이다. 동일 품목·세부차수의 상이율 충돌은 0이었다. 이는 후보 근거 규모이며 런타임 적용 건수나 금액 복구 건수가 아니다.

- 17-01: 3075 Amaranthus 및 3086/3087/3088/3089 Preserved 모두 21.4%.
- 27-02: 3120 비짜루500g 및 3210 Preserved Blue 21.4%.
- 28-02: 3210 Preserved Blue 21.4%.
- 32-02: 3120 비짜루500g 21.4%; 다른 확인 차수는 8%.
- 21-2 MEL K30은 다음 행 J31 참조이므로 제외한다.

정확 원본·해시·셀은 [원본 보고서](../work-reports/2026-11-03_china-thailand-original-duty-cells.md), 후보는 로컬 `.verify/workbook-duty-exact-observations.json` 및 `.verify/workbook-duty-registry-candidates.json`에 있다. 후보는 런타임 정책을 자동 승인하는 파일이 아니다.
