# 호주 분류 적용·검색 / CNF 안내

## 구현 전 기준
- Product SELECT(2026-10-27):2997 ProdName=Wolly Bush Green Tip, DisplayName=울리부쉬그린;2998 Red Tip/울리부쉬레드. 두 품목 활성, 호주, 단. 기본 datalist는 DisplayName만 노출해 영문 검색 불가.
- `applyInvoiceAllocation`은 원본4합계 보존 및 문서별 확인. UI 임시 productSearch가 남으면 선택품목 대신 이전 검색어 표시. 적용 후 검색어 제거·품목명 표시, 성공/실패 안내.
- 최신 사용자: 호주 단가에 운임 포함. 기존 AU_CNF_BUNCH_V1도 freightIncluded=true, 단수 배분이며 CW/GW를 계산에 요구하지 않음. 누락 중량을0/서로 복사하지 않는다. 호주에 잘못된 CW필수 안내 제거, 새 원가폼의 추가운임만0 제안, 기존 양수/저장값 보존하여 중복운임 검증 유지.
- 검색은 ProdName/DisplayName/ProdCode/ProdKey를 함께 사용, Woolly/Wolly 철자 정규화는 후보검색만. 명시 선택 없이는 확정하지 않음. 국가/활성범위 보존.
