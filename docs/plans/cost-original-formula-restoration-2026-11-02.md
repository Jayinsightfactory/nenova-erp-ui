# 국가별 원가 엑셀 빈칸·수식 복원

## 범위와 기준
- 기존 승인값/입고 스냅샷과 비교 시트는 보존한다. 원본 양식 계산 시트를 기본으로 열어 판매·이익·합계를 계산한다.
- NL 원본: 로컬 `37-2 NL 원가자료 (2).xlsx` 37-2. E/F 상품, G 상품금액비, H:I CNF, J:L 원화·관세·통관, M 원가/송이, N 환산, O:P 원가/단위·VAT, Q:R 판매, S /0.77 추천가, T:W 이익·합계.
- 원본 표기 '15%'와 실제 /0.77은 다르므로 수식은 유지하고 표기는 '원본 /0.77 참고가'로 명시한다. 현재 판매가는 비워두되 계산 수식은 존재해야 한다. 명시 판매가0은 유효하다.
- 타 국가: US/NZ/VN/EC/CN항공/해상/CO구형/TH 원본 배치와 판매영역을 점검한다. 검증된 공용 원가 비교 모델의 현재 원가를 참조해 국가별 원본 단위/판매열을 복원한다. AU/CO42-1 기존 원본 계산은 보존한다.
- 과거 품목명·수량·환율·판매가격은 복사하지 않는다. 세부 비용 미보유는 '내역 미보유'; 승인 합계나 확인된 NL 기본값만 사용한다. 임의 실비0 생성 금지.

## 부작용·기준 ledger
| 동작 | 입고/주문/분배/재고/견적/손익/승인원가 | 파일 |
|---|---|---|
| XLSX 생성·엑셀 편집 | 모두 보존, SQL 변경 없음 | 파일 안에서만 계산 |
- 업무 식별자 OrderYear+OrderWeek+WarehouseKey. 원가 검증/지문/권한/다운로드 전 재조회 정책 유지.
- UI/키보드/페이지 기준: 해당 없음(화면 구조 변경 없음), 실제 웹앱 다운로드 확인은 적용.
- 검증: 국가별 fixture, 빈판매가/명시0/판매가 입력/추가행/교차연도, 원가합계 대조, 실제 Excel 재계산·저장·다시읽기, 전체 ERP guard/build/CI/배포.
