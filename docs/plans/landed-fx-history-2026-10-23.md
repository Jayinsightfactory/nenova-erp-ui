# 승인 도착원가 연결·호텔 환율 비교

## 사용자 확정
- 인보이스에서 생성·승인한 최신 실제 원가를 웹 참고 원가에 연결한다.
- 호텔 표 머리글에서 통화별 환율을 적용하고 품목별 차수 이동을 제공한다.
- 환율은 도착원가 표시만 비교한다. 매입액·이익·원본 확정 원가·엑셀 결산은 보존한다.

## 부작용 표
| 동작 | 원가/입고 자료 | 호텔 결산 | 주문·출고·재고·견적·WebProfitReport |
|---|---|---|---|
| 최신 원가/차수 이력 조회 | SELECT만 | SELECT만 | 보존 |
| 환율 적용/초기화/차수 이동 | 무쓰기 | 브라우저 표시만 | 보존 |

## 기준 ledger
- 명시 선택 연도 + 양수 ProdKey. 연도 간 동일 차수 혼합 금지.
- 인보이스 실제 APPROVED + 현재 문서 revision/operation + liveReceipt MATCH만 허용. EXPECTED_95/시험값 제외.
- 최신은 업로드 시각이 아닌 세부차수 숫자 순서. 농장·단위·출처별 값은 합치거나 최고가로 대체하지 않는다.
- 기존 호텔 참조 범위는 호환 함수에 유지하고 별도 전체 차수 이력을 최신 기본 화면에 사용한다.
- USD/EUR/CNY 등 원문 통화 확인 가능한 행만 해당 통화 입력값 적용. 미확인 통화는 경고.
- 인보이스 비용 구성의 원화 고정비는 유지하고 환율연동 항목만 비교. 값/단위/구성 불명은 원본을 보존하고 경고.
- 확정 손익/재고 평가는 대상 차수 당시 기준을 유지한다. 최신 참고값으로 역사적 원장 계산을 대체하지 않는다.

## 근거와 검증
- 실제 Nenova.exe FormWarehouseView dnSpy CLI 실행: WarehouseMaster.OrderYear, GetDetail의 WarehouseDetail 조회 확인(2026-10-23).
- 웹 전용 원가 표시 변경이며 native 저장/SP 호출 변경 없음.
- 회귀: 같은 차수 전년도, 미승인/수정된 입고/시험값, 원가 단위 불명, 다른 통화, 환율0/빈값, 차수 끝, 저장값 보존.
- 운영 읽기 probe·실브라우저·게이트·배포는 완료 시 후속 기록. 현재 미검증.
