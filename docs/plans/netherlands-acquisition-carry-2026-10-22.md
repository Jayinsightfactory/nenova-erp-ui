# 네덜란드 재고 이월 복구 후 원가 이월 보완

## 요청·증거

네덜란드·베트남 수량 이월 복구와 41차까지 SQL 검산 요청의 후속이다. 수량 복구는 PR #1225 배포 후 완료했으며 이 작업에서 반복하지 않는다. 복원된 네덜란드 재고를 검산하면서 최근 4차수 밖 실제 매입이 에콰도르 전용 복원 경로에서 제외되어 판매단가 자동평가로 넘어가는 것을 확인했다.

실제 설치 EXE를 dnSpy.Console의 FormWarehouseView/FormProductAdd로 다시 확인했다. 입고 UPrice/TPrice와 Product.Cost(출고단가)는 별도다. SQL SELECT로 같은 2026년 품목의 마지막 매입, EstUnit, 매입 차수 정확 과세환율, 같은 차수 FreightCost 재현 원가를 확인했다. 운영 수량·금액·원장은 비공개 `.verify/nl-cost-probe.json`에 보관한다. 판매단가를 매입원가 근거로 승격하지 않는다.

## 제한과 부작용

- 기존 에콰도르 정책을 네덜란드에만 확장한다. 베트남의 국가별 평균원가 산식은 유지한다.
- 같은 연도·품목·단위, 대상 세부차수 이하 마지막 실제 매입, 최근 4차수 밖이라는 조건을 모두 유지한다.
- 해당 매입 차수의 정확 과세환율과 완전한 도착원가가 있어야 한다. 미래 매입, 현재 통화마스터 근사, 다른 국가 환율은 허용하지 않는다.
- 과세환율 원천은 기존 보고서 우선순위를 유지한다. 이번 22차 재현의 환율 근거는 기존 `excel_historical_snapshot`이며, SQL 매입·수량과 구분해 응답 근거에 표시한다. 모든 환율이 SQL에 저장되어 있다고 주장하지 않는다.
- 동일 세부차수에 국가가 달라도 환율·도착원가 캐시는 국가별로 분리한다. EUR/USD를 섞지 않는다.
- 직접 근거/기존 FIFO/확정 이월 근거가 우선이다. 근거 부족 시 기존 경고를 남긴다.

| 동작 | 주문·출고·입고·재고·이력·견적 | 웹 수기값·확정 revision |
|---|---|---|
| 보고서 조회·원가 재현·검산 | SELECT만, 보존 | 보존 |

재고 재보정, SP/스키마 수정, 확정본 자동 덮어쓰기는 없다. 미확정 캐시는 계산 hash 변경으로 최신화 필요를 표시한다. 새 메뉴·입력·화면틀·키보드 흐름 변경은 해당 없음.

## 검증

네덜란드 최근/오래된 매입, 다른 연도, 미래 매입, 베트남 제외, 단위/행수/환율 누락, 직접 근거 우선, 국가·통화 격리 회귀를 실행한다. 1~41차 실제 SQL 조회와 독립 수식/매출·매입 원장 대조, 전체 ERP 가드, build, CI, Cafe24와 실제 다운로드 smoke를 확인한다. 원가가 재현된다는 사실은 물리적 실사 수량과 일치한다는 증명이 아니다.
