# CO46 실제 AWB 숫자·원본 판정 보완

## 기준
- 실제 46-1 수국 CI/AWB 160-17338020: 인보이스16개·46행·662박스·19960송이·상품13366.76USD. AWB GW3487/CW4152/Rate2.95/운임12248.40+부대72=12320.40USD. 실행일07-Nov-26.
- 기존 parsePrintedDate의 실행일(2자리 연도는2000대)을 공용 사용. 수정시각/업로드일을 운송장 연도로 사용하지 않는다.
- 쉼표/점 소수점과 올바른 천단위 조합을 지원한다. 잘못된/모호한 조합은 수동 확인, 단순 쉼표 제거로4152,0을41520으로 만들지 않는다. 위치 기반 합계·prepaid/collect 충돌 보호 유지.
- 파일명은 후보 필터/충돌 증거다. 연도·국가가 빠진 실제 AWB는 본문 실행일·출발 Colombia·AWB번호로 확인할 수 있다. 명시된 다른 연도/국가/차수는 거절. 미확인 차수는 같은 AWB의 명시 원가시트 연도/차수와 연결한 서버 증거가 있어야 한다. PDF 형식·해시·검증 결과 scope·저장 전 재조회는 유지한다.
- 인보이스 업로드→매칭→신규 입고 writer→공동AWB 원가 다운로드를 실제 웹 페이지/격리 SQL로 검증한다. 캐시가 없으면 무료 텍스트 추출/검토 전사로 구분하며 유료 AI는 호출하지 않는다. 기존 입고 복사본 계산만으로 전체 E2E 성공이라 하지 않는다.
