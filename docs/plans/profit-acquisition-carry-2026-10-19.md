# 오래된 에콰도르 재고의 매입원가 이월

## 요청과 근거

41차 기초재고의 판매단가 대체 원인을 조사하고 실제 매입 근거와 비교, 이전 차수 회귀와 배포까지 수행한다. 운영 금액·품목별 원장은 공개 저장소에 저장하지 않는다.

실제 설치 EXE를 `dnSpy.Console.exe --no-color -t FormWarehouseView` 및 `-t FormProductAdd`로 재확인했다. 입고 상세는 WarehouseKey의 WarehouseDetail.UPrice/TPrice, 판매단가는 Product.Cost(라벨 출고단가)다. 운영 SELECT와 실제 모듈 실행에서 40차 마지막 ProductStock의 일부 품목은 마지막 매입이 최근 4차수 밖이라 FIFO 후보에서 빠지고 판매단가로 넘어감을 확인했다. 전체 국가 재고가 판매단가라는 뜻은 아니다.

## 기준 원장

| 기준 | 원천·소비자 |
|---|---|
| 대상 | 에콰도르, 같은 OrderYear+ProdKey, 대상 세부차수 이하 마지막 실제 매입 |
| 기존 우선순위 | 직접 근거·기존 FIFO·정확 도착원가·catalog·확정 이월 근거 보존 |
| 추가 이월 | 위 근거가 없는 품목만 마지막 실제 매입 세부차수의 도착원가 재현. 미래·타 연도 매입 제외 |
| 환율 | 그 매입 대차수의 정확 과세환율. CurrencyMaster 근사·현재 차수 환율 불허 |
| 단위 | 같은 EstUnit 또는 입증된 품목 환산. 누락을 1배로 추정하지 않음 |
| 원가 | 입고 TPrice와 운임·통관 재현. 배분 계산값이며 원본 인보이스 전수 확인과 구분 |
| 근거 부족 | 기존 경고·입력 필요 유지. 단가 0 정상 처리 금지 |
| 기초/기말 | 각각 자기 연도·세부차수 cutoff. 기말 자료를 기초에 적용 금지 |
| 저장본 | 확정 revision 보존. 계산 소스 hash로 미확정 캐시만 재계산 필요 표시 |

## 검증

최근4차수 밖 매입, 새 매입, 동일 품목 다른 연도, 미래 매입, 단위 불일치, 환율 누락/근사, 원가 누락, 직접 근거 우선, 기초/기말 cutoff 분리 합성 fixture. 운영 1~41차 SELECT 비교 및 41차 기초 품목별 원인 분리. verify:erp-change/관련 회귀/build/CI 통과 전 배포 금지.
