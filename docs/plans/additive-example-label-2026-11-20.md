# 출고분배 다운로드 숫자의 예시 표시

사용자가 다운로드 라디오의 고정 숫자를 실제 수량으로 오해하지 않도록 ‘그냥 예시로 표시해줘’라고 요청했다.

- 합산본: `합산본 (예시: 기존 10 + 추가 3 = 최종 13)`
- 추가분: `추가분 별도 (예시: 이번 파일 3만)`

라디오 value(FINAL/ADDITIONAL), 이벤트, 계산, API, 원장, Excel 다운로드 및 인쇄 설정은 변경하지 않았다. 기존 Desktop 메뉴·URL에서 그대로 제공되며 새 화면/기능/조작이 아니므로 버전·설치본을 추가하지 않는다.

기존 React UI 검사 안에 두 문구 확인을 추가했고7개 모두 통과했다. manifest236·변경 API0 쓰기 가드·dnSpy 근거 검사 통과. 기존 숫자/다운로드/원장 회귀와 사용자 원본 native Excel 검증은 변경 범위 밖이라 반복하지 않는다.

가이드 검사에 copy-only 자동 면제가 없어 관련 기존 영상2편만 현재 실제 합성 UI로 다시 촬영한다. 기존 촬영 source hash를 임의로 덮어쓰거나 사용자 재촬영 면제 승인을 추론하지 않는다. 변경하지 않은 현장물량표의 합성 인쇄 확인 이미지는 기존 검증본을 그대로 사용한다.
