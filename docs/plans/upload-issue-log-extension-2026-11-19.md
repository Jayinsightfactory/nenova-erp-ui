# 기존 업로드 문제 로그 확장 설계 — 구현 전

사용자11/19 명시 요청. 기존 /import/tools의 인보이스 업로드 문제 로그를 확장하며 새 메뉴/중복 로그 화면을 만들지 않는다. 47-02 오류 수정이 우선이다. 이 설계는 과거 입고 보정·Farm/Customer 변경·유료재분석을 승인하지 않는다.

## 실패 수명주기

- 초안 DocumentId가 생기기 전 admission(파일형식/크기/권한/접수), analyze(제공자 응답), validation(구간/페이지/상품총액/manifest), matching, save(ERP 트랜잭션), readback을 각각 기록한다. 통신요청/응답/검증/commit 성공은 서로 다른 상태다.
- correlationId를 최초 파일 작업에서 생성하고 jobId/attemptId/선택연도·차수/명시 국가/원본 해시 또는 비공개 참조로 연결한다. DocumentId는 nullable. 서버에서 확인한 단계·시각과 브라우저가 보고한 단계·시각을 출처별로 구분한다.
- 상태: 접수/진행/실패/검토필요/재검증통과/저장확인/미확인. 클라이언트 오프라인 또는 전송실패는 브라우저 로컬의 `미전송` 상태이며 서버 영구저장 완료로 표시하지 않는다. 사용자가 누르는 `로그 전송`만 허용하고 자동 재전송·분석 재시도하지 않는다. 서버 응답 유실도 성공/실패를 추정하지 않는다.
- 서버의 실제 실패는 초안 존재 여부와 무관하게 남긴다. 폴링 반복은 correlationId+attemptId+stage+서버eventId의 idempotency로 한 사건으로 묶고 마지막 확인시각/반복횟수를 표시한다. 같은 파일의 사용자가 명시한 새 시도는 별개 attempt로 보존한다.

## 기존 패널 표시/동작

- 파일명, 원본 공급자명과 확인된 DB농장명(다르면 별도), 국가/연도·차수와 근거 출처, 최초/최근시각(KST), 단계, 오류코드, 쉬운 원인, 다음 조치, 상태, job/correlation 식별자. 미확인은 빈값을 추정하지 말고 미확인 표시.
- 예: validation / PDF_CHUNK_VALIDATION / 송장18065 상품합계3483 vs 인쇄총액1741.50 → ‘집계행을 상품과 중복 추출했는지 확인 필요’. 원본 대조 전에는 확정 원인처럼 표시하지 않는다.
- `저장 응답으로 무료 재검증`은 같은 권한·소유 범위·원본해시·parser버전·job/구간 완결성을 확인한 경우만 활성화. 제공자호출0을 서버에서 강제하며 saved response가 없으면 버튼 비활성+누락사유, 유료분석으로 자동 fallback하지 않는다. 무료 replay 성공은 ERP 저장 성공이 아니다.
- `파일 다시 선택·검토`는 기존 파일선택 단계로 이동만 한다. 자동업로드/자동유료호출/입고등록 없음. save/readback 사건은 기존 OperationId 조회를 먼저 하며 새 적용을 자동 시작하지 않는다.
- 날짜범위(오늘/7일/직접), 국가, 연도+차수, 파일·공급자검색, 단계, 상태, 오류코드, 전송상태 필터. 타연도 같은차수 혼입 금지. 현재50건 제한의 페이지네이션 및 필터된 전체건수를 서버에서 제공하며 페이지별 합계를 전체라 하지 않는다.

## 보안과 보존

관리자·허용된 수입팀에만 조회/재검증, 소유자/팀 범위를 서버에서 검사한다. 클라이언트 전달 actor/권한 신뢰 금지. 로그에 원본PDF·상품전체·주소·계좌·토큰·provider원응답·인증정보를 넣지 않는다. 오류문구는 whitelist코드+정제 메시지로 저장하고 원본 참조는 권한 검사 후에만 읽는다. 브라우저 미전송 저장은 최소 메타데이터만 보관하고 만료/명시삭제 정책을 둔다. 기존 SystemActionLog 이력은 재해석/덮어쓰기하지 않는다.

## 수용 조건 및 실제 스크린샷

운영 읽기전용: 기존 메뉴/로그버튼 위치 → 필터조건 → 실제 사건의 단계·코드·조치·상태 확인(개인정보 제외). 격리 fixture: 초안없는 실패/오프라인미전송/명시전송/폴링중복1건/타계정거부/다른연도필터/원응답없는재검증비활성/무료재검증제공자0/저장후readback을 각각 before·action·result 스크린샷과 실행 테스트로 남긴다. 1920x1080/100% 및390px, Tab/Enter/Space/Escape, 개인정보가림·오류줄바꿈·가로잘림을 확인한다. 미배포 설계 그림을 실제 기능 캡처로 제시하지 않는다.

실제 구현 때 계약manifest/공통정책/격리테스트/영상 갱신/Desktop 기존 메뉴 검색·즐겨찾기·버전 기준 검토/전체ERP게이트/CI/배포/운영readonly스모크가 필요하다. 이 문서만으로 구현 완료로 표시하지 않는다.
