# 주광 요일표 스크롤·잔량 가독성

## 요청 / 완료 기준

- 표 위·아래에 가로 스크롤바를 두고 어느 쪽을 조작해도 같은 열을 표시한다.
- 차수 바로 보기, 검색, 화면 크기 변경 후에도 스크롤 범위와 위치가 일치한다.
- 잔량을 주 숫자로 표시하고 상태, 분배 합계, 최초 대비 변경, 견적 대조를 읽을 수 있는 간격으로 구분한다.
- 주 숫자 14px 이상, 보조 정보 12px 이상. 1920×1080 CSS pixel / 100%와 작은 화면에서 겹침·가로 페이지 이탈을 검사한다.
- 품목 고정열, 행 강조, 변경/초안/선출고 색, 비고·견적 대조 버튼과 안전 상태를 유지한다.
- 스크롤마다 React 표 전체를 재계산하지 않는다. DOM scrollLeft 동기화 및 크기 관찰은 정리한다.

## ERP 부작용 경계

| 동작 | 주문/분배/출고일/농장 | 최초 기준·비고·감사 | 재고/견적/금액/확정/손익 |
|---|---|---|---|
| 스크롤·열 표시·글꼴/간격 | 보존 | 보존 | 보존 |
| 기존 변경 비고·견적 대조 버튼 | 기존 핸들러 유지 | 기존 정책 유지 | 기존 정책 유지 |

계산 helper, SQL, API payload, 인쇄 양식은 수정하지 않는다. 불명 값을 0으로 치환하지 않고
미확정 예상과 저장 기준을 구분한다. dnSpy 및 운영 조회 근거는 기존 FormEstimateView /
weekday-erp-apply-2026-10-01의 검증을 재사용하며 이번 작업은 화면만 변경한다.

## 검증

로컬 API 격리 브라우저 fixture로 상·하단/표 스크롤 동기화, 크기 변경, 검색, 긴 숫자,
미확정/초안/알스트로/견적 불일치, 행 강조를 검증한다. ERP 계약·manifest·쓰기 guard·
dnSpy 증거·빌드를 통과한 뒤 병합/배포한다. 운영 수량 시험 변경은 하지 않는다.
