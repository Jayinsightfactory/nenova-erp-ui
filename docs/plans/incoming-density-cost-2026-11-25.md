# 입고 원장 밀도·최신 원가 표시 회귀

| 동작 | 기준 | 영향 |
|---|---|---|
| 원장·상세 표시 | 원본 연도·차수·원장키로 조회, 실제 표기값/검색칸 최소 폭 사용 | 읽기 전용, 수량 합계와 업무 키 유지 |
| 최신 원가 | 상품 품목만 조회, HTTP 상태와 JSON을 확인, 오류는 상세 상단에 한 번 표시 | 기존 최신 원가 API·검증된 원가 값 유지 |
| 수량 수정 | 기존 입고 상세 키, 확정·연결·원가·재고 가드 및 금액 근거 그대로 | 상품에만 기존 검토/저장 진입 제공, 운송료·중량 처리 기존 경로 안내 |

설치 EXE FormWarehouseAdd의 CheckFixSave, UnitQuantity, TPrice와 재고 계산 호출을 재대조했다. 운영 2026/48-01 #8205의 상세 50907/50908은 Gross/Chargeable Weight(3100/3101), 50905/50906은 운송료(2182)였다. 모두 상품 최신 원가의 대상이 아니다. 해당 3개 품목 HTTP 조회는 200 JSON, 40개 요청(2,089자)도 200 JSON으로 사용자 시점의 HTML 응답은 재현되지 않았다. HTML을 통해 원가 오류 문구가 행마다 확장되지 않도록 한다. 50905 숫자 변경의 기존 미리보기 가능과 50906의 금액 기준 모호함을 각각 확인했다. 운영 저장하지 않았다.

전역 배포 가드는 별개 master #1635의 PM 일지 소스 해시 문제로 막혔다. 현재 로컬 모의 Chrome에서 PM 필수 6장과 4장의 새 자율 작업 구역을 재촬영·재생해 영상과 증빙만 갱신했다. PM 제품 코드는 이 변경에 포함하지 않는다.
