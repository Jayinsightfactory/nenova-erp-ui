# 중국 운송수단별 참고 내역 — 구현 전 기준

## 승인 범위

중국 부모 행과 전체 합계는 그대로 보존한다. HUBFRESH(배), Cloudland(비행기), 미배정 하위 내역만 읽기 전용으로 추가한다. 실제 ShipmentFarm 배정 우선, 배정 없는 출고와 재고는 같은 품목의 **당차** 입고 수량 비율을 사용한다. 과거 이월 농장을 추적하지 않는 근사임을 표시한다. 입고 없는 품목에 임의 비율을 만들지 않는다. 44차 태국·수국 입력은 범위 밖이다.

## 기준표

| 항목 | 권위/처리 | 미확인 처리 |
|---|---|---|
| 부모 금액 | 이미 조회한 중국 row.calc, 수정 없음 | NULL 유지 |
| 순수매출 N | 기존 보고서와 같은 연도/차수/확정/금액 필터 | 저장본과 현재 원천 차액은 미배정 |
| 농장 배정 | ShipmentFarm.SdetailKey→ShipmentDetail, FarmKey→Farm | 잘못된 수량/초과 배정은 미배정, 강제 정규화 금지 |
| 배정 없는 출고 | 동일 ProdKey 당차 양수 입고 OutQuantity 비율 | 입고 없음/비정상 입고는 미배정 |
| 상품 매입 Q | 실제 입고 WarehouseKey 농장별 TPrice | 알 수 없는 농장 미배정 |
| 포워딩 S | 기존 포워딩 분류 원천의 WarehouseKey 농장 | 0원·누락 별도 경고, 공통값 미배정 |
| 재고 E/F | 기존 평가기의 품목별 선택 원가×수량, 당차 품목별 입고비율 | 원가 없음·저장본과 차액 미배정 |
| 차감 L/O, 통관·창고 H | 직접 운송수단 연결 근거 없음 | 미배정, 판매/매입 비중으로 임의 배분 금지 |
| 파생금액 | 같은 엑셀식의 하위 참고 계산 | 부모 값과 차이는 미배정, 비율은 합산하지 않음 |

하위 이익률은 공통비 미배정의 참고값이지 농장별 확정 손익이 아니다. 음수 미배정은 원천/저장 시점 차이일 수 있고 숨기지 않는다. 기존 XLSX·인쇄·확정 스냅샷은 변경하지 않는다.

## 부작용 표

| 동작 | 조회 | 쓰기 |
|---|---|---|
| 내역 펼침 | 명시 OrderYear+MajorWeek의 입고/확정출고/농장배정/선택 재고·원가 | 없음 |
| 차수 변경/접기/재조회 | 이전 응답 폐기, 현재 범위만 표시 | 없음 |

Order/Shipment/ShipmentDate/ShipmentFarm/Warehouse/ProductStock/StockHistory/Estimate/WebProfitReport 및 모든 확정·계산 snapshot 보존. SQL SP, DDL, 운영 원장 보정, 과거 보고서 갱신 금지.

## 구현 전 실제 증거

2026-11-19 설치 Nenova.exe에 실제 dnSpy.Console `-t Nenova.ClassShipmentFarm`, `-t FormWarehouseView` 실행. ClassShipmentFarm의 FarmKey/ShipmentQuantity/SdetailKey와 입고 OrderYear/OrderWeek/TPrice 읽기 확인. 출력에 나타난 쓰기·재계산 메서드는 실행하지 않음.

같은 날 SELECT-only 2026/44 재조회: 중국 HUBFRESH 2,185단, Cloudland 2,615단+600송이, 보고서 필터 확정 상세186행, 농장 배정0행. 단·송이를 합산한 비율은 금지하며 동일 ProdKey 안에서만 비율을 만든다. 운영 상세/업체 개인정보는 커밋하지 않는다.

## 검증 계획 (구현 전 작성)

순수 정책: 실제/부분/초과 농장배정, 혼합농장, 무입고, 알 수 없는 농장, 음수·0·NULL, 저장본 차액, 합계 보존, 연도 분리. API GET-only·잘못된 범위 DB0, UI 늦은 응답 폐기, 44차 읽기 스모크, 46 운임0 경고. ERP 계약·manifest·dnSpy·쓰기 가드·build·데스크톱 메뉴·영상·PR CI·배포 후 스모크. 미실행 검사를 완료로 기록하지 않는다.

## 구현 단계 확인 결과

- 정책/API 회귀 통과: 실제·부분·초과 배정, 동일 품목 비율, 단위 혼재, 무입고, NULL/0/음수 잔차, 원본 불변, 원단위 표시 합계 보존, 사용자별 비동기 조회 격리. 2027년 1차 기초는 2026년 달력의 최종 53차를 선택하며 달력 누락 때 52차를 임의 생성하지 않는 fixture 통과.
- 실제 44/46 SELECT-only probe 각각 468/474개 SELECT, 약 11.3/16.8초. 44차 확정 상세186개, 46차192개는 모두 실제 농장배정이 없어 당차 입고비율 참고 안분. 실제 업체 상세/SQL 원문 결과는 비공개 로컬 검증 산출물로만 보관.
- 44차 HUBFRESH 운임 37,075.5 CNY, Cloudland 26,817 CNY. 기초43-03 원가 미확인6품목, 기말44-04 미확인10품목: 알려진 평가액만 안분하고 부모 차액은 미배정.
- 46차 HUBFRESH 입고8082 운임 전표는 명시0, Cloudland 합계28,736 CNY. 기말46-03 중국18품목 원가 미확인으로 부모 기말재고액 전체가 미배정. 명시0과 전표 누락 경고를 구분하며 환율 NULL인 저장본의 원화 매입·운임·손익 NULL도 보존.
- 1920×1080, 브라우저100% 합성 UI에서 조회 범위/표/경고를 확인하고 5단계 번호·한국어 자막·확대/복귀 가이드를 재녹화. 영상 시작/중간/끝 프레임 및 가이드 해시 검사 통과. 합성 API만 사용, 운영 쓰기0.
- 전체 ERP gate·빌드·PR CI·배포 후 검증은 실행 결과가 확인되는 순서대로 인계에 기록한다. 운영 원장과 기존 보고서 저장본 변경은 금지한다.
