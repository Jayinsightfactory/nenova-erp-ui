# CLOUD CBM 원가 기준 — 2026-11-18

사용자 정정: 첨부 46-2 중국 원가자료의 `46-2 CLOUD cbm `을 CLOUD에 적용한다. HUBFRESH에 새 식을 적용하지 않는다.

## 입력·계산 기준

- 원본 SHA256 `25c1690b748e7ba4c8bf60c538790d40153bf4d34663a18bb4410a9d36231732`.
- 21종 카테고리: 원본 K/L/M/Q의 박스당 단수·규격·세율. 운임은 `규격곱/6000/박스당단수 × 실제단수` 비율로 배분한다. AWB CW를 이 분모로 임의 대체하지 않는다.
- 통관비는 `GW×460 + 33000 + 활성 품종수×10000 + 국내운송비 + 기타40000 + 소독200000`. 세부 원가는 통관비/전체 단수(`N33=$T$11`). 사용되지 않는 GW 배분 보조표 Y로 대체하지 않는다.
- 국내운송비 99000원은 이 원본의 추정값으로만 표시하며 보편적인 중량요율로 선언하지 않는다. 확정 운송비는 수정할 수 있다. 빈 값과 명시0은 다르게 처리한다.
- 호접 허가증 원본 E12=300 CNY를 호접 단수로 나누어 CNF에 포함. 수정·0원 가능.
- `(FOB + 운임/단 + 허가증/단)×1.03×환율` 후 품종 세율, 통관비/단을 더한다. 수량은 단수이며 송이/박스를 임의 대입하지 않는다.
- 추천 판매가는 원가/0.77을 VAT포함 비교값으로 표시, 실제 판매가가 아니라고 명시한다. 매입·출고·견적·손익에 저장하지 않는다.
- 미매칭만 기본 표시하되 전체 보기에서 기존 카테고리도 변경·해제 가능. 변경 시 계산 승인/미리보기 무효화. 저장된 명시 변경·해제를 자동값으로 덮지 않는다.
- 신규 CLOUD에서 구 항공식 사용은 서버에서 거부한다. 검증된 과거 승인 스냅샷 출력 내부에서만 역사 공식 재현을 허용하며 승인 API는 해당 옵션을 요청에서 받지 않는다.

## 실측 및 미검증

- 원본 43품목, 2280단: 원가 43행 모두 차이 1e-6 미만, 합계 20094336.64221원.
- 원본의 판매가 공란/0은 실제 매출이 없다는 뜻이다. 생성본 추천가를 원본의 실제 매출과 같다고 주장하지 않는다.
- 원본 원가표 대조는 인보이스 E2E가 아니다. 실제 CLOUD CI/AWB 업로드·입고 저장·브라우저 다운로드, native Excel 입력변경 재계산, 최종 가이드 영상은 별도 검증 필요.
