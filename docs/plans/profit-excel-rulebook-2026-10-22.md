# 주차 손익: 26~31차 원본 우선 계산 근거 정리

## 사용자 범위와 합격 기준
- 26~31차 원본을 우선 근거로 공통 계산식/국가·품종 예외를 분리한다. 1~25차는 보조 대조이며 이전 숫자나 단가 자체를 미래에 복사하지 않는다.
- SQL 원천에 같은 공식을 적용한다. DB·확정 revision·재고 수량·원가 증거를 수정하지 않는다.
- 후속 사용자 확정: 엑셀의 품목 묶음은 편의상 작성한 것. 전산 표시는 SQL 품목 구분·각 품목 매입단가·수량을 따르며, 울리부쉬 그린팁/레드팁도 별도 근거로 계산한다.
- 기본식/합계식/6품종 평균원가/일회성 이익조정을 구분한다. 입력된 재고액만 있는 셀에서 새로운 원가 공식을 발명하지 않는다.
- 판매단가, 근사 환율, 대상 외 카테고리 평균을 검증된 취득원가로 인증하지 않는다. 근거 부족은 계산 보류로 전달한다.
- 같은 SQL 원천의 변경 전후 1~41차 차이를 대조하고, 테스트/빌드/CI 통과 후 코드만 배포한다. 전수 숫자 일치와 산술 일치를 별도로 보고한다.

## 확인된 경계
- 일반 I=E+G+H-F, J=C-I(+AJ), K=J/C. 이스라엘/뉴질랜드/일본은 I=E+G+H, J=C-I+F(+AJ), K=J/(C+F). 합계 K=J/(C+F).
- 28~31차 콜롬비아 5품종, 28/29/31차 베트남 F에서 (G+H)/구매수량*재고수량이 직접 확인된다. 26/27차 및 30차 베트남 F의 숫자 입력을 수식 증명으로 확대하지 않는다.
- 호주 F는 27~29차 재고잔량 R54와 일치하지만 30/31차는 R54+Q54에 근접한다. 통관비 반영 변화이므로 단일 고정 단가/전국 평균으로 일반화하지 않는다.
- 비평균 국가의 F 숫자 입력은 판매단가나 FIFO 기간이 맞다는 증거가 아니다. 기존 검증된 품목 취득원가만 보존하고 추정 대체 경로를 구분한다.
- 30/31차 베트남 J의 반대방향 조정은 개별 AJ 원천이며 공통식에 상수를 추가하지 않는다.
