# 인보이스 품목 검토

표는 Linear와 Stripe의 촘촘한 원장처럼 품목명과 숫자를 한 행에서 비교한다. 확정품목 변경 제한은 표 위에 한 번 표시하고 실제 문제와 수정 동작은 행에 남긴다.

| 동작 | 기준 | 원장 영향 |
| --- | --- | --- |
| 송장·품목 정렬 | 명시 저장된 품목 연결이 앞선다. 화면 표시만 정렬하고 원본 행 번호와 경로는 보존한다. | 모두 보존 |
| 기본 후보 | 같은 국가에서 선택 가능한 후보의 이름 점수 90 이상 단독 1위. 별칭으로 확인한 현재 품목을 우선한다. 동일 점수·반대 국가·중복 또는 사용 중단 품목 차단. | 모두 보존 |
| 공용 매칭 저장 | 기존 국가·원문·ProdKey·revision 검증 및 명시 클릭. | 팀 공용 매칭만 업데이트 |
| 입고 저장 | 기존 승인 및 품목 교체 차단, 연도·세부차수·입고번호 및 원장 트랜잭션 유지. | 기존 입고 계약 |

2026-11-19 설치 EXE의 `ExcelLoadingPackingList.MakeTempTable/InsertMaster`를 dnSpy로 조회했다. `uspCreateWarehouse` 및 `uspStockCalculation` 순서를 확인했다. 같은 송장 2026/47-02의 운영 조회 결과는 품목 8, 전년도 같은 송장 0, 주문 15이며 출고·확정출고·출고일·농장분배·견적·확정매출은 모두 0건이다.
