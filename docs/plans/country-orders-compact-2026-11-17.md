## 판정 기준
- 기준 수량과 업무키는 기존 country-orders 계약 그대로. 축약은 표시만, 원품명은 상세와 원본 양식에 보존한다.
- 숫자·규격·색상은 삭제하지 않고 알려진 공통 접두어만 제거한다. 그룹은 국가와 품종이다.
- 공통 첫 시트에 모든 업체·품목·단위별 원수량을 표시하고 기존 국가 양식은 추가 시트로 보존한다.
- 중국은 기존 Melody 기본값을 유지하고 수신명을 수정할 수 있다. 파일 나누기는 기본 꺼짐이며 켠 경우 두 번째 기본 수신명은 CLOUD다. 품목 선택은 ProdKey 기준으로 전체 업체 수량에 적용하고, 미선택은 두 번째 농장으로 보낸다. 서로 같은 농장명·비어 있는 이름·현재 범위에 없는 품목 지정은 차단한다.
- 이전 연도·차수 데이터 혼합은 기존 행렬 어댑터가 차단한다. 입력 변경 시 예전 결과와 ETA 창은 무효화한다.
- 수량 0은 빈칸 표시하되 숫자·수식은 보존한다. 품목을 제외하여 오류를 회피하지 않는다.

## 기준선 확인
- 적용: 연도·세부차수 업무키, 기존 저장 수량 권위, 페이지 세로 스크롤·표 가로 스크롤, 의미 있는 버튼·체크박스·키보드, 늦은 응답/오래된 다운로드 차단, 한국어 진단, 실제 화면 가이드.
- 해당 없음: 새 메뉴·레이아웃, ERP 원장 보정, SSMS 마이그레이션, 입고·견적 확정. 기존 명시적 품목 기준 저장 경로는 보존한다.
- 2026-11-17 사용자 추가 확인: 중국 기존 기본값 Melody 유지, 농장명 수정 허용. 농장별 분리는 기본 꺼짐. 기존 다른 국가 파일명과 기존 양식도 유지한다.
- 실자료 대조: 2026/47-02 콜롬비아61품목29업체4파일, 네덜란드17품목6업체1파일, 중국34품목11업체2농장파일의 고객별·단위별 수량이 직렬화/재개봉 후 일치. 중국 혼합 단위는 농장당 한 파일, 단·송이 합계는 별도 표기. 나머지 국가는 해당 차수 실자료 없음(합성 fixture 검증).
