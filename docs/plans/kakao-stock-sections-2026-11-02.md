# 차수·품종 구역별 품목 식별
사용자 제공 51품목/11구역 원문에서 품목명만으로 중복 판정한 오류 수정. key는 제목의 명시 연도/차수/품종+품목. 연도 없는 제목은 페이지의 연도, 원문 변경은 작성연도/명시연도와 구역을 대조. 같은 구역 안의 중복은 오류, 다른 구역 동일품목은 독립. header의 공백 유무와 원문 줄·구분선·단위/60cm 등 규격은 보존. direct dropdown/이력/리뷰에는 구역표시. 이전 unscoped 이벤트는 유일한 후보만 호환; 애매하면 보존하며 오류. 이미 scoped된 이벤트의 구역 자동이동 금지. 기존 UserFavorite JSON 및 ERP SQL/원장 변경없음. 초기 중복 오류로 적용조차 되지 않은 사용자 원문은 그대로 다시 붙여넣고 적용/저장 가능.
검색어: 차수별 동일품목 구역 중복 parseStockSection 유카리체리 로다스 진핑크
