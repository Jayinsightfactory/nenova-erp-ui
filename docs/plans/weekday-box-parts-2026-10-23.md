# 2026-10-23 주광 박스 + 낱개 입력

- 대상: 주광 요일 수량 입력. 방향키/Tab 입력은 기존 OutUnit(대상 품목은 박스), 클릭 또는 F2는 박스+낱개 대화상자. 알스트로 기존 경로 보존.
- 실제 dnSpy FormShipmentDistribution CellValueChanged: 단/BunchOf1Box, 송이/SteamOf1Box로 decimal 환산. N2는 표시 형식이며 ClassShipmentDetail INSERT/UPDATE에 수량 ROUND 없음. 운영 컬럼은 float. 기존 공용 헬퍼의 2자리 저장 주석을 native 근거로 사용하지 않는다.
- SELECT probe: 카네이션359/363/365/389/518=15단/300송이, 수국866=30송이,873=50송이,3472=16송이. 품목 마스터만 사용하고 30/15 하드코딩 금지.
- 박스 품목의 낱개 정수 환산은 소수9자리로 전달하고 1e-6 이하 부동소수 허용 내에서 낱개 정수를 검증한다. 표시만 N2, 수량 자체를 표시 소수로 절사하지 않는다. 해당 품목의 환산 가능 입력만 3자리 client 제한 예외.
- 부작용: UI 입력은 초안만, 기존 ALLOCATION 저장/확정/재고 부족/감사/롤백 경로 유지. 임의 StockHistory 재고조정 없음. 수량 변경에 수반하는 기존 주문/출고/금액만 계약대로 반영. Estimate/WebProfitReport 직접 쓰기 없음.
- 필수: 복수날짜 1송이+1송이 합계2, 1박스+3단=1.2, 포장50/16, 환산미확인, 전년도 동일차수 보존, 실SQL 저장/출력, 키보드 복귀, 빌드/배포.
- 메뉴 기준 적용: 기존 shell/페이지 세로 스크롤/가로바 유지/키보드/F2/ESC 초점복귀/기존 저장검토. 새 메뉴 없음.
