# 수입방 원문 선별·합산 기준

- 사용자 정정: 모든 카톡/기존 추출표 표시가 아니라 발주에 해당하는 원문만 선별하고 품목·수량을 직접 분석한다. 최근 서울 오늘+어제, 최신순, 1분 갱신 유지.
- 원천: nenovakakao 수입방 주문검토의 원문(R), 원문 시각(C), 원문 작성자(D), 요청번호(A). 기존 매칭 업체/품목은 원문 키가 일치할 때만 보조하며 수량의 빈칸/기존 오추출은 원문보다 우선하지 않는다.
- 포함: 발주/추가 의도와 품목·수량, 또는 구조화된 품목 수량 목록. 국가/품목군/차수 제목과 업체/CL 문맥은 같은 원문 안에서만 이어받는다. 날짜·길이(cm)·중량(g)·금액은 주문 수량으로 읽지 않는다. st/스템/스팀/송이 표기는 송이로 정규화하고 단/박스는 변환하지 않는다.
- 분리: 취소/대체/수량정정/차수이동/조건부 문의/누락된 단위 및 불명확한 발주 지시 → 검토 목록, 자동합산 제외. 일반 문의·불량·사진·일정·인사 제외. 불명확한 답글을 이전 메시지에 임의 연결하지 않는다.
- 중복: 동일 원문시각+작성자+공백정규화원문으로만 중복 제거. 삭제표시가 붙은 동일 원문은 삭제 검토 대상으로 합산 제외. 서로 다른 시각/작성자의 같은 주문은 별도 유지. 기존 재분석/archived 상태만으로 원문 신규발주를 버리지 않는다.
- 합계 키: 원문 연도+차수+국가+품목군+품종+단위. 차수/단위 미상은 확인 전 자동포함하지 않는다. 업체 없는 주문은 합계 포함, 비고에는 실제 확인된 업체/CL별 수량만 기록. 업체명/CL의 명확한 기존 매칭만 재사용.
- 조회/수정/제외/복사: Sheet GET + 브라우저 편집/clipboard만. MSSQL SELECT/쓰기, ERP 등록, 외부 카톡 발송 없음. Order/Shipment/ShipmentDate/ShipmentFarm/StockHistory/Estimate/WebProfitReport 전부 보존. EXE 관련 변경SQL 없음, 신규 dnSpy/DB probe 해당없음(기존 CountryOrders 근거 유지).
- 합산/원문/품목군 필터가 공통 분석 결과를 사용한다. 수정은 브라우저에만 유지하고 재조회 중 같은 원문 행의 제외·수정은 보존한다. 카톡 수량을 ERP 주문으로 자동등록하지 않는다.
- 검증: 수국 화이트30+주광10=40, 카네이션 문라이트, 루스커스3, st/스템23품목, CL별 문맥, 무업체, 단위·차수·연도 분리, 문의400/불량3/길이60cm 제외, 취소/삭제/중복/차수이동/부분누락 검토. 실제 Chrome 원문기반 mock 경유 필터/합계/복사/검토/갱신/키보드/모바일 및 최신 가이드 확인.
- 메뉴 기본값: 적용=기존 화면·키보드·페이지스크롤·반응형·최신가이드·원문대조. 해당없음=새메뉴/ERP등록/전산저장/DB스키마. 알려진 한계=사진 속 문자와 문맥 불명 답글은 임의수량 생성 없이 검토.
