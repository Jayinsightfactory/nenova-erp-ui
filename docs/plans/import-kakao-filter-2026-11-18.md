# 수입방 원문 선별·합산 기준

- 사용자 정정: 모든 카톡/기존 추출표 표시가 아니라 발주에 해당하는 원문만 선별하고 품목·수량을 직접 분석한다. 발주가 있는 최신2개 날짜, 최신순, 1분 갱신(11/18 사용자 명시 정정).
- 원천: nenovakakao 수입방 주문검토의 원문(R), 원문 시각(C), 원문 작성자(D), 요청번호(A). 기존 매칭 업체/품목은 원문 키가 일치할 때만 보조하며 수량의 빈칸/기존 오추출은 원문보다 우선하지 않는다.
- 포함: 발주/추가 의도와 품목·수량, 또는 구조화된 품목 수량 목록. 국가/품목군/차수 제목과 업체/CL 문맥은 같은 원문 안에서만 이어받는다. 날짜·길이(cm)·중량(g)·금액은 주문 수량으로 읽지 않는다. st/스템/스팀/송이 표기는 송이로 정규화하고 단/박스는 변환하지 않는다.
- 분리: 취소/대체/수량정정/차수이동/조건부 문의/누락된 단위 및 불명확한 발주 지시 → 검토 목록, 자동합산 제외. 일반 문의·불량·사진·일정·인사 제외. 불명확한 답글을 이전 메시지에 임의 연결하지 않는다.
- 중복: 동일 원문시각+작성자+공백정규화원문으로만 중복 제거. 삭제표시가 붙은 동일 원문은 삭제 검토 대상으로 합산 제외. 서로 다른 시각/작성자의 같은 주문은 별도 유지. 기존 재분석/archived 상태만으로 원문 신규발주를 버리지 않는다.
- 합계 키: 원문 연도+차수+국가+품목군+품종+단위. 차수/단위 미상은 확인 전 자동포함하지 않는다. 업체 없는 주문은 합계 포함, 비고에는 실제 확인된 업체/CL별 수량만 기록. 업체명/CL의 명확한 기존 매칭만 재사용.

- 합산/원문/품목군 필터가 공통 분석 결과를 사용한다. 수정은 브라우저에만 유지하고 재조회 중 같은 원문 행의 제외·수정은 보존한다. 카톡 수량을 ERP 주문으로 자동등록하지 않는다.

## 2026-11-18 사용자 기준 정정
- 기본 2일은 오늘+어제가 아니라 실제 발주가 있는 최근 서로 다른 2일이다. 전체 수집원문을 먼저 분류한 뒤 최신 발주일 2개를 선택한다. 해당 발주 이후 오늘까지의 취소/변경 검토는 유지한다. 취소로 검토 전환된 원발주일도 보존하여 임의로 더 오래된 발주를 끌어오지 않는다.
- 화면에 선택 발주일 두 개와 취소/변경 확인 기준일을 명시한다. 미래 원문 제외, 원문 연도/차수 보존. 명시 day GET은 기존 동작 유지.
- 기존대로 더글라스200박스만 받겠다는 문장은 기존주문 유지 정보로 표시하며 신규 추가합계에 넣지 않는다. 앞선 발주 연결 근거 없는 취소는 자동 차감하지 않는다.
- 부작용/ERP 보존표는 위와 동일: Sheet GET, 브라우저 표시/계산만. SQL·EXE 변경0, 신규 dnSpy/probe 해당없음.

## 2026-11-18 부분 합산
명시적인 추가 발주에 해석이 끝난 행과 단위가 빠진 별도 행이 섞여 있으면 완료 행만 자동 합산한다. 누락 단위를 추정하지 않으며 원문 한 건과 모든 품목을 같이 표시한다. 취소·조건부·해석 불가 수량 행은 기존 검토 방식을 유지한다. 수집 시트 조회 이외 ERP 원장 효과 없음.

## 2026-11-18 수입방 원문 자료 대조
별도 보관 원문과 주문검토 시트의 정규화 시각·본문을 대조했다. 시트 합산은 자체 수량과 일치하나, 원문 최근 2일에 명시된 추가 발주 중 28건이 시트에 없었다. 주문검토 시트는 신규 체크포인트 및 현재 업무범위를 통과한 분석 큐의 상태만 반영하므로 전체 원문의 대체 자료가 아니다. 합산기는 기존 인증의 고정 수입방 원문 조회를 사용하고 시트는 거래처 별칭에만 사용한다. 고정 출처·방·시각·외부 메시지 식별자·페이지 총계를 검증한다. 최근 7일 우선, 발주일이 두 개보다 적으면 31일 이내를 추가 조회한다. 조회 실패는 502로 표시하고 오래된 시트로 대체하지 않는다. 원문 아카이브는 nenovakakao 공통 수집 이후의 자료로, 카카오톡 PC 원본 자체 전량 도착 여부는 미검증이다. 사진 OCR 및 MSSQL 쓰기 없음.

## 2026-11-18 미리보기·가독성·ETA
세부차수 버튼에서 새 창(Desktop에서는 승인된 업무 탭)을 동기적으로 열어 같은 상태의 매칭 표, 업체 수량 조정, 다운로드를 제공한다. 팝업을 열 수 없으면 전체 화면 대화상자로 전환한다. 닫았다 다시 열어도 같은 선택의 수량 편집값은 유지하고 차수·국가 변경 시 기존 초기화를 적용한다. ETA A1 제목은 ISO 날짜와 영문 요일을 유지하며 수량·수식, 원본 스냅샷은 변경하지 않는다. 카톡 원문은 제목/시각/품목을 간단히 표시하고 매칭 원문은 열어 준다. 버튼은 접어도 선택이 표시되며 단위와 수량을 한 줄로 유지한다. 새로운 SQL/API 입력이나 Desktop 권한 경로 추가 없음.
