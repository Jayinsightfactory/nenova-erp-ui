# 주광 입력 피드백·페이지 고정 헤더

- 적용: 1920×1080/100%, 페이지 세로 스크롤·기존 품목 왼쪽 고정·표 가로바 유지. 작은 화면, 열기/닫기, 키보드와 포커스 복귀 검증.
- 입력 오류는 초점을 빼앗거나 큰 창을 자동 표시하지 않는다. 작은 상태·수동 내역 버튼으로 안내하며 원인 전문은 사용자가 연다.
- 가로 overflow 안의 CSS sticky는 페이지 스크롤을 따라가지 못하므로, 동일 React 헤더를 페이지 스크롤 경계에서 별도 고정 표시한다. 원본 표와 가로 위치·열 너비를 동기화하고 헤더의 선택·인쇄 동작은 같은 핸들러를 사용한다.
- 표 안에 세로 스크롤 또는 고정 viewport 높이를 만들지 않는다. 표 끝에서 고정 헤더를 숨기며 창 크기·상세 접기·가로 이동 때 위치를 재검증한다.
- 표 하단이 고정 헤더 높이 이내로 진입하면 고정을 해제한다. 마지막 행과 이후 내용을 고정 헤더로 덮지 않기 위한 의도된 경계다.
- 수동 상세는 최대 폭 420px·본문 14px이며 작은 화면에서는 좌우 16px 여백을 유지한다. 최대 높이와 내부 상세 스크롤은 보존하고, 열린 상세 및 셀 부모의 stacking context는 헤더보다 높게 둔다.
- 부작용 없음: 입력값·초안·업무키·저장·분배·확정·재고·견적 인쇄 데이터 정책은 보존. 수정 대상은 matrix 표현만.
- 메뉴 기준: 화면·키보드·명확한 상태 적용. 새 shell/메뉴 등록·ERP 원장 변경 해당 없음. 수동 상세 팝오버는 명시 모달/상세 예외.
