# 붙여넣기 4열 작업 화면·영업방 최신화

## 범위와 기준

2026-09-11 사용자 스케치 기준. 1920×1080 CSS pixel, 확대100%.
1열 물량표/영업방, 2열 주문/기초재고 입력, 3열 분석/제외/검토,
4열 작업결과/최근이력. 작은 화면에서는 2열/1열로 흐른다.
큰 표는 영역 안에서 스크롤하고 입력/처리 버튼을 가리지 않는다.

## 조건 원장

- ERP scope: 현재 week와 resolveOrderWeekQuery의 명시 year. 이전 응답은 새 차수/업체에 표시하지 않는다.
- 이력: 기존 /api/orders/history GET, 최근12행. 빈 결과와 조회 실패를 구분한다. 같은 범위 실패에는 마지막 정상 목록을 보존한다.
- 영업방: 인증된 기존 /api/kakao/sales-feed GET만 사용. source/room/기간/afterKey 계약 변경 없음.
- 수집 업로드와 웹 갱신은 별도 단계. 서버에 도착했다는 사실을 매크로가 현재 실행 중이라는 증거로 과장하지 않는다.
- 자동 갱신은 GET만 수행하며 LLM분석/체크리스트 저장/ERP등록을 호출하지 않는다.
- 사용자 메시지 선택, 입력 초안, 과거 검토 결과는 자동 수신으로 덮어쓰지 않는다.
- 숨겨진 탭/오프라인/작업중에는 갱신을 멈추며 실패 시 목록 보존 및 지연 상태를 표시한다.
- 빈칸/미조회/실패를 성공 또는0으로 표시하지 않는다.

- PostgreSQL 영업방/nenovakakao5214건, 마지막 원문 시각2026-09-11 09:28 KST.

- 매크로 clone의 core/moyi_worker.py는 sales 작업을 priority10/interval5초로 등록한다.
  core/agent_runtime.py는 작업 종료 후5초에 다음 실행 예정이며 다른 우선 작업/카톡 UI 처리로 지연될 수 있다.
