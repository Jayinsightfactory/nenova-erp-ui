# 영업방 즉시 표시 보완

사용자 요청: 불러오기 버튼 없이 첫 칸에서 카톡 원문을 바로 보고, 원문 옆에서 작업 버튼을 조작한다.

## 기준 및 부작용

- 첫 진입: 선택 ERP 연도/차수가 준비되고 화면이 보이며 온라인이고 저장 중이 아니면 오늘 KST 대화를 GET으로 자동 조회.
- 영업방 기본 펼침. 빈 목록은 조회 전/조회 중/실패/조회 완료0건을 구분한다.
- 조회 후15초 확인. 사용자가 날짜를 편집했을 때는 과거 원문을 새 기간으로 오인시키지 않는다.
- 대화는 최신순 표시. 원문 옆 ‘입력칸으로’는 기존 onLoadText 확인 흐름만 호출한다. 자동 분석/등록 없음.
- 선택 입력 및 검토·비교 접근 버튼을 원문 가까이 고정. 설명·수동 확인 목록은 접어서 원문에 공간을 우선 배정.
- 신규 수신은 작성/선택/검토 보존. 기존 GET 스코프와600건 상한·지연 경고 유지.
- 선택·검토 중이 아니면 새 원문을 자동 표시한다. 선택·검토 중이면 새 대화 버튼에 대기시키며 기존 내용은 덮지 않는다.
- 검토 영역을 접더라도 작성 중인 확인 메모와 이미 조회한 비교 결과를 버리지 않는다.
- 첫 진입/자동 갱신/행 입력/검토 열기 모두 Order/Shipment/Stock/Estimate/WebProfitReport 보존.
- 비교 실행과 수동 상태 저장은 기존 명시적 버튼에서만 실행. 누락 비교는 자문용이며 ERP작업을 막지 않는다.

## 검증

첫 자동 조회, 실패와빈목록, 토글 false, 저장/숨김/오프라인, 날짜편집, 연도/차수전환 늦은응답,
기존선택 보존, 클릭전 분석/등록0건. 1920×1080 원문과버튼 캡처, 작은화면 가로넘침 검사.

## 구현·검사 기록

- 구현 terra/high(P0_LOCAL), 독립 검토 sol/high(P0_LOCAL), 메인 통합·외부반영.
- 수신함 기본 펼침, 오늘KST 자동GET, 다음15초부터 갱신. 최신순표시/선택전송은시간순.
- 원문별 입력칸으로/비교선택, 접이식 검토·비교. 명시 클릭 없이LLM/POST없음.
- 전체 ERP 계약, 연결17파일, manifest55, dnSpy evidence, 쓰기 가드 통과.
- 초깃값미완성/잘못된달/교차연도/숨김/오프라인/저장중/false토글/늦은응답 fixture 통과.
- 독립검토 지적: 전체영업방접기 시 검토state소실은 hidden 유지로 보완.
  파일업로드와자동수신경합은 최신state함수형merge로 보완하고 양쪽완료순서 회귀 추가.
- ERP API/SQL/원장 수정 없음.
