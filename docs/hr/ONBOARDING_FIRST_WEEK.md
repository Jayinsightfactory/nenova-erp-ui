# 새 직원 첫 주에 볼 것 — 업무 순서대로

기준일 2026-11-12 · 담당 에이전트 `.claude/agents/nenova-hr.md` · 판단 기준 `docs/canon/CANON.md`

이미 있는 업무 매뉴얼과 가이드 영상을 **업무가 흘러가는 순서**(주문 등록 → 발주 → 입고 → 분배 → 출고 → 견적)로 묶은 목록이다.
새로 만든 화면·영상은 없다. 가이드 영상이 없는 업무는 **가이드 없음**이라고 적었다.

읽는 법:

- **화면 주소**는 `https://nenovaweb.com` 뒤에 붙는 주소다. 괄호 안은 왼쪽 메뉴에 보이는 이름이다.
- **가이드 영상**은 그 화면 안의 "사용 가이드"에서 재생된다. 표에는 영상 파일 경로(`public/guides/…`)와 목차 수를 적었다. 영상은 연습 자료로 찍은 것이라 실제 거래처·금액이 아니다.
- **업무 매뉴얼**은 `data/work-manuals/` 안의 파일 이름이다(뒤의 `.draft.json`은 생략). 전부 **AI 초안**이다 — 관찰 기록에서 뽑은 절차이고 담당자가 확인한 것이 아니다. 틀린 곳이 있을 수 있다.
- 매뉴얼 초안은 `/work/manuals`(부서별 업무 매뉴얼)의 "직원별 절차 초안"에서 보는데, **직원에게는 본인 것만 보인다**(사장님은 전체). 새 직원은 아래 초안을 화면에서 직접 볼 수 없으므로, 사장님이나 사수가 열어서 같이 본다.

## 측정

**재는 것:** 새 직원이 가이드만 보고 첫 주문 등록을 끝낸 시간.

- 시작: 이 문서의 "1. 주문 등록"을 열어 영상을 틀기 시작한 때
- 끝: 연습용으로 정해 준 주문 1건이 주문관리(`/orders`)에 보일 때
- 같이 적을 것: 중간에 사람에게 물어본 횟수, 막힌 화면 이름
- 적는 방법: 사수나 본인이 손으로 적는다(아래 표). 화면 기록이나 작업 기록에서 자동으로 뽑지 않는다.
- 연습 주문을 어느 거래처·차수로 넣고 끝난 뒤 어떻게 지울지는 사수가 정한다. 실제 주문과 섞이지 않게 한다(이 문서는 방법을 정하지 않았다 — 미정).

| 날짜 | 부서 | 걸린 시간 | 물어본 횟수 | 막힌 화면 |
|---|---|---|---|---|
| | | | | |

**기준값 없음.** 지금까지 한 번도 재지 않았다. 첫 측정이 기준값이 된다. 목표 시간은 정하지 않는다(정하면 가설이다).

이 표는 **가이드가 충분한지**를 보는 것이다. 새 직원을 평가하는 데 쓰지 않는다. 시간이 오래 걸렸으면 가이드에서 빠진 곳을 찾아 이 문서의 "가이드 없음"을 줄인다.

## 가장 큰 약점

- 주문 등록 화면 여섯 개 중 영상이 있는 것은 하나뿐이고, 매뉴얼 초안은 전산 프로그램 기준이다. **새 직원이 "가이드만 보고" 웹에서 첫 주문을 등록할 수 있는지는 확인하지 못했다(미검증).**
- 매뉴얼 초안은 담당자 확인을 거치지 않았고, 새 직원 계정으로는 화면에서 볼 수 없다.
- 네노바에는 새 직원이 자주 들어오지 않아 이 문서를 실제로 써 볼 기회가 적다.
