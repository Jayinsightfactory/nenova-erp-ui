# 인수인계 문서 틀

기준일 2026-11-12 · 담당 에이전트 `.claude/agents/nenova-hr.md` · 판단 기준 `docs/canon/CANON.md`

담당 업무 하나를 다른 사람이 **문서만 보고 대신 처리**할 수 있게 묶는 틀이다. 이 파일은 틀이고 내용은 채우지 않았다.

쓰는 법:

1. 이 파일을 복사해 업무별 문서를 만든다. 업무 하나에 문서 하나.
2. 넘겨주는 담당자가 말하거나 확인한 것만 적는다. 확인하지 않은 줄에는 "미확인"이라고 적는다. 추측으로 채우지 않는다.
3. 이미 있는 화면·가이드 영상·매뉴얼은 다시 쓰지 말고 **경로만 가리킨다**(목록: `docs/hr/ONBOARDING_FIRST_WEEK.md`). 없으면 "가이드 없음"이라고 적는다.
4. 금액·단가·계좌·비밀번호·거래처 연락처는 적지 않는다. **어디에서 보는지**(화면 주소, 물어볼 사람)만 적는다.
5. 수입부 업무의 인수인계 내용은 별도 작업("수입부 업무 인수인계 매뉴얼 재구축")이 만들고 있다. 그 문서가 있으면 이 틀로 다시 쓰지 않고 그 문서를 쓴다.

## 10. 측정

**재는 것:** 문서만 받고 대신 처리한 업무 수.

- 세는 것: 받는 사람이 넘겨준 사람에게 **묻지 않고** 끝낸 건
- 따로 세는 것: 물어보고 끝낸 건, 못 끝낸 건 — 이 둘은 문서에서 빠진 곳을 알려 준다
- 적는 방법: 받는 사람이 손으로 적는다. 작업 기록에서 자동으로 뽑지 않는다.

| 날짜 | 건 | 묻지 않고 끝냄 / 물어보고 끝냄 / 못 끝냄 | 문서에서 빠져 있던 것 |
|---|---|---|---|
| | | | |

**기준값 없음.** 지금까지 한 번도 재지 않았다. 첫 인수인계에서 나온 수가 기준값이 된다.

이 표는 **문서가 충분한지**를 보는 것이다. 받는 사람이나 넘겨준 사람을 평가하는 데 쓰지 않는다. "물어보고 끝냄"과 "못 끝냄"이 나오면 3~7절에 빠진 줄을 채운다.

## 틀의 가장 큰 약점

넘겨주는 사람이 바쁠 때 쓰는 문서라, 정작 5절(주의점)과 4절(거래처별 방식)처럼 머릿속에만 있는 내용이 비어 있기 쉽다. 틀만으로는 이것을 막지 못한다. 실제 인수인계에 써 본 적이 없다(미검증).
