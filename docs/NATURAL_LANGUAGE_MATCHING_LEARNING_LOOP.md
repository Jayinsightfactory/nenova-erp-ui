# 자연어 품목 매칭 학습 루프

검색 원문은 최소화·해시화하고, 권한이 분리된 원본 참조키만 선택적으로 남긴다. 이벤트는 후보 노출, 사용자 선택, 자동 제안 확인, 수정, 제외, 저장, 확정, 확정 후 재수정/취소를 구분한다. 자동 선택은 정답으로 재학습하지 않고 `ConfirmedByUser=1`인 선택만 긍정 표본이다. 수정 전 후보는 음성 신호다.

alias는 전역과 거래처별로 분리한다. 제안 상태에서 최소 5회 확인, 서로 다른 확인자 2명, precision 95% 이상, 국가·품종 충돌 0건을 만족해야 승격한다. 표본이 부족하거나 drift가 감지되면 승격하지 않는다. 관리자 승인, 모델/규칙 버전, 적용 시각, rollback 버전을 남긴다.

오프라인 골든셋은 개인정보를 제거한 query 구조와 정답 ProdKey/국가/품종/단위만 보존한다. 배포 전 현재 버전과 후보 버전의 top-1/top-3, 미매칭, 잘못된 자동매칭을 비교하고 어느 주요 그룹도 악화시키지 않아야 한다. Product/Order/Shipment/Estimate/수량은 학습기가 수정할 수 없다.
